Configuration reference

openprogram config list              # value, group, apply mode
openprogram config get ui.web_port
openprogram config set ui.web_port 8101

One registry, openprogram/state/settings.py, drives the setup wizard, TUI and Web settings. Every setting, generated from it: Settings keys. Everyday use: Configuration and data directory.
