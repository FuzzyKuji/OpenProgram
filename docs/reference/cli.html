CLI command reference

Full flags: openprogram <command> -h, openprogram logs tail -h, or one generated page per command.

Global

CommandDoes
openprogramOpens the chat. A bare run first asks terminal UI or web UI, and launches a worker if none is running.
--print PROMPTOne-shot prompt; prints the reply and exits. Works in the current directory and runs until the model answers; a failure prints to stderr and exits non-zero. Run in its own process, it makes no model request beside the turn and leaves memory to the next worker: the conversation keeps the title cut from the prompt
--print, stoppedCtrl-C or SIGTERM stops the run, waits up to 30 seconds for it to stop (2 seconds once a second signal comes), writes the usage and transcript files and exits 128 plus the first signal's number (130 for Ctrl-C, 143 for SIGTERM, 129 for SIGHUP), whatever signal follows; a turn still busy then has its commands stopped
-p, --print --p is --print. With no prompt or - the prompt comes from stdin; a prompt plus piped stdin adds the input as a <stdin> block. An empty prompt exits 2
--output-format FORMATWhat --print writes on stdout: text (the reply), json (one record of how the run ended) or stream-json (one event per line, init first, result last); --include-partial-messages adds text and reasoning deltas to the stream
--permission-mode MODEPermission mode for this --print turn only: ask, acceptEdits, plan, auto, bypass. A call that would ask is refused, since nobody can answer; it shows on stderr and the run still exits 0
--continue, --session-id ID, --at REF--continue (-c) runs on this folder's latest conversation; --session-id starts a new one with that id and fails if it exists; --at with --resume or --continue picks a branch or a message to run after
--standalone, --no-project-binding, --no-webRun in this process instead of the App's Worker; keep a new conversation in the profile and write nothing in the folder; run the turn without web tools or the provider's own search
--json-schema PATHRequires JSON Schema output for --print; - reads stdin
--model PROVIDER/MODELModel for a --print run in a new conversation; the provider needs a key from providers login <provider> --api-key-stdin
--effort LEVELReasoning effort for one --print run: off (or none), minimal, low, medium, high, xhigh, max. Not saved; without it the Agent's effort applies
--usage-file PATHAfter --print, writes tokens, cost, model, rounds and how the run ended to PATH as JSON
--transcript-file PATHAfter --print, writes the turn to PATH as JSON lines: each model request with its tokens, the reply text, every tool call with its arguments and its result, in order, with times
--resume SESSION_IDResumes a session; ids from openprogram sessions list or the Web UI sidebar. With --print, an unknown id exits 1
--profile PROFILEState directory ~/.openprogram-<name>/; same as OPENPROGRAM_PROFILE
--no-alt-screenInline TUI, keeps terminal scrollback
--screen-readerInline assistive-technology mode, no mouse tracking
--versionPrints the version

Chat and running

CommandDoes
tui (alias chat)Launches the Ink terminal UI directly on Windows, macOS or Linux; terminals without raw input fall back to Rich. Takes --print, --json-schema, --model, --effort, --usage-file, --transcript-file, --resume, --no-alt-screen, --screen-reader.
webStarts the service and opens http://localhost:18100. --web-port (this run; default stored preference, then 18100), --no-browser. web auth-url prints an authenticated link.
acpAgent Client Protocol server. --agent, --permission.

mcp

VerbDoes
token createCreates and prints a token for the local stdio server
serveAuthenticated MCP over local stdio; needs an exact OPENPROGRAM_MCP_TOKEN
list, showServers and status; one server's tools and schemas
addStdio command server; writes mcp_servers.json and starts it
rmStops and deletes the config
restart, enable, disabledisable stops it and keeps the config
editRemoved; reports to use add/rm or the MCP settings page
testStarts a config temporarily to check its tool list; writes nothing
 
openprogram mcp token create
export OPENPROGRAM_MCP_TOKEN="<paste the token printed above>"
openprogram mcp serve

token create prints the raw token once and does not set the variable. If one exists, reuse the saved token.

Execution

CommandDoes
executionpause, continue, step, steer, cancel, fork, retry, wait-answer, wait-decline
jobslist, get: job resource views
transcriptRebuilds a --print run's transcript from its stored state, as --transcript-file writes it, for a run killed before it wrote one. --state DIR, --session ID, --output PATH
scheduler-worker (cron-worker)Foreground loop for one-time, recurring and monitor tasks. A failed daemon tick logs a warning and traceback to stderr, then evaluation continues at the next minute without replaying a failed initial @reboot tick. --once runs one tick and propagates failures; --list shows match state.
