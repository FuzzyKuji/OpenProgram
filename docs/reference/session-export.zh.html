会话导出

入口操作
CLIopenprogram sessions export <session-id>--format md|html，默认 md--output PATH，默认 ./<session-id>.<format>
Web UI在侧栏右键对话，或点它的 ⋯，再选导出和格式
HTTPGET /api/sessions/{session_id}/export?format=md|html，需要 owner 认证，以 Content-Disposition: attachment 返回

会话 id：openprogram sessions list 或 Web 侧栏。

文件里有什么

部分规则
范围只有当前分支，从分支头向前走，与 Web 对话视图相同
每一轮角色、本地时间、文本，文本不截断
工具调用，在所属轮次之下名称、成功或失败、参数、结果
参数截断到 1,000 字符，标记 … [+N chars truncated]
工具结果截断到 4,000 字符，标记相同
HTML单个文件：内联样式，无脚本和外部请求，通过 prefers-color-scheme 跟随亮暗

脱敏

标题、会话 id、角色标签、工具名、轮次文本、参数和结果都先经过 remove_secret_values（openprogram/models/providers/recording/recording.py），再截断。存储的对话不变。

匹配替换为
密钥命名的字段：api_key、authorization、token、password 等[secret removed]
自由文本中的 bearer token、sk- 密钥、URL 查询参数或 userinfo 里的凭据[secret removed]
嵌套过深无法安全脱敏的参数[arguments omitted: nesting too deep]

只覆盖已知的凭据形状。发到公开场合前先读一遍。
