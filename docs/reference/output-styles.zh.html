输出风格

追加到系统提示词的一段文本。它改变语气、长度和结构，不改变工具、能力或模型。同一时间只有一种风格生效，作用于所有经过提示词组装器的调用：对话轮次、agentic function 函数体、后台 agent。

切换

位置方法
TUI/style 列出并标记当前风格；/style concise 切换；/style default 清除
Shellopenprogram config get agent.output_style
openprogram config set agent.output_style concise
Web设置，Agent 分组

全局设置，保存在 ~/.openprogram/config.json 的 agent.output_style。从下一轮生效。

内置风格

名称效果
default什么都不追加
concise用问题允许的最少字数；结果在前，无开场和结尾总结
explanatory先答案，再讲理由、权衡，以及改动如何融入周围代码
direct直接下结论；去掉不影响决策的保留说明；直接纠正错误前提
detailed覆盖边界情况、失败模式和假设；较长回答用标题或列表

自定义

一个 Markdown 文件。文件名是风格名，正文是追加的文本。

mkdir -p ~/.openprogram/output-styles
cat > ~/.openprogram/output-styles/lab-notes.md <<'END'
## Output style: lab notes

Report work as a lab notebook entry. State what was tried, what was observed,
and what it implies. Record negative results as plainly as positive ones.
END

openprogram config set agent.output_style lab-notes
优先级来源路径
1，最低内置上表
2用户~/.openprogram/output-styles/<name>.md
3，优先项目<cwd>/output-styles/<name>.md

YAML frontmatter 会被去掉，所以 description: 不会到达模型。正文为空的文件被忽略。

文本落在哪里
  • 注册的上下文组件（output_style，L0 层），经 openprogram/runtime/context/components.py 的组装器进入，而不是贴在用户消息上。
  • 位于身份和工具使用指引之后、agent 内联系统提示词之前，所以冲突时 agent 的指令优先。
  • default 为空，空组件被丢弃：提示词与没有该组件时逐字节相同。
