Agent 与 Context

入口作用
agent() / agent_async()执行模型工具循环
Agent保存可复用配置，为普通子类方法建立作用域
Context提供命名内容和历史选择
 
from openprogram import Agent, agent, agent_async

answer = agent("Summarize this text", tools=[])

class Researcher(Agent):
    instructions = "Return a short, factual answer."
    tools = []

    def prepare(self, question):
        """Remove surrounding whitespace."""
        return question.strip()

    def research(self, question):
        """Answer the prepared question."""
        return self(self.prepare(question))

researcher = Researcher(model="configured-model")
answer = researcher.research("A question")
# In async code: answer = await researcher.arun("A question")
# Or: answer = await agent_async("A question", tools=[])

所有入口复用现有 Runtime 和 Session DAG。普通调用不用手动构造 Context。

Context

from openprogram import Agent, Context

context = Context(
    {"notes": "Use the project terminology."},
    providers={"current_topic": lambda current: "Agent context"},
)
researcher = Agent(context=context, tools=[])

显式会话生命周期

要让多次独立调用接续同一会话，传入现有的 SessionNodeWriter。

from openprogram import Agent, Context
from openprogram.state.store import SessionStore, SessionNodeWriter

store = SessionStore(root_path="/var/lib/myapp/sessions")
store.create_session("research", agent_id="main")
writer = SessionNodeWriter(store, "research")
researcher = Agent(context=Context(store=writer), tools=[])
try:
    first = researcher("List the project requirements.")
    second = researcher("Review the requirements from the previous call.")
finally:
    store.close()
  • head_id 选择现有分支末端；None 接续当前 head。
  • store 由调用方持有并关闭，执行作用域不会关闭它。
  • 这提供了 NOOA 风格重复实例调用所需的事件生命周期。Agent 仍只保存配置，默认调用仍相互独立。

方法配置

from openprogram import Agent
from openprogram.runtime.agent import llm

class ExampleAgent(Agent):
    method_options = {
        'f': {'tool': True},
    }

    def f(self, x: str) -> str:
        """One-line summary of what f does."""
        return llm([{"type": "text", "text": f"...{x}..."}])

_example_agent = ExampleAgent()
f = _example_agent.f

签名和 docstring 提供名称、类型、默认值和摘要，其余由 method_options 提供，无需装饰器。Agent 负责方法执行和注册，Context 解析请求内容和可见历史。

方法使用的 Runtime

方法运行在其 Agent 的 Runtime 上，Agent 没有时用调用方的：ExampleAgent(runtime=rt).f("x") 让 f、其中的模型请求和它调用的 Agent 方法都用 rt。在程序入口配置 Runtime，不要通过方法参数传递。一个工作流用两个模型时，给第二个角色单独的 Agent 实例。

旧函数：Runtime 注入

名为 runtime、exec_runtime 或 review_runtime 的参数在调用方未传时自动填充：取自当前调用链；入口调用则用 create_runtime() 创建，函数返回时关闭。多个这样的参数得到同一个 runtime。它们不出现在工具 schema 和 WebUI 表单里。新方法不声明它们。

内省与安全
  • fn.spec：生成的工具 spec {"name", "description", "parameters"}。fn.execute(**kwargs) 以 LLM 提供的参数调用。
  • 自身重入超过 5 层抛出 RecursionError；注入的情境提示也会引导模型避免自调用。
  • add_pre_invocation_hook / remove_pre_invocation_hook：钩子在每次调用开始时运行，可抛 CancelledError 中止，WebUI 停止按钮即如此。
写入 DAG
时机写入
进入函数code 节点（output=None，status="running"）；docstring 存入 metadata.doc，渲染时放在 function_name(args) 之前
函数体内每次 llm()一个 llm 节点
退出回填同一 code 节点的 output 和 status

expose="hidden" 不写任何节点。没有安装 DAG 存储时，记录为空操作。

持久步骤与代码选择

from openprogram import Agent
from openprogram.runtime.agent.durable_steps import step

class ExampleAgent(Agent):
    method_options = {
        'report': {'tool': True, 'resumable': True},
    }

    def report(self, topic: str):
        research = step("research", collect_research, topic)
        return step("write", write_report, research)

_example_agent = ExampleAgent()
report = _example_agent.report

执行在显式步骤处恢复，而不是任意 Python 栈帧。collect_research 和 write_report 是普通的源码定义函数。

构造规则
step(name, fn, *args, **kwargs)输入和结果须兼容 JSON。已完成的步骤返回保存的结果，不再调用动作。重复名称按出现次序区分；保持顺序和已完成输入稳定。
workflow(name, fn, *args, **kwargs)嵌套编排
parallel({"branch": (fn, args, kwargs)})具名工作流并发运行，各有独立的持久进度；所有分支结束才释放所有权
execution.code_change_policy重启后
keep_original（默认）运行保留的源码。采用 B 后，之后重启仍保留 B，即使已安装的是 C。
use_latest已完成结果保留，当前函数运行其余兼容步骤

任务的“继续”控件可以覆盖此策略。

结果情形
暂停已记录步骤被删除或重排、已完成输入改变、固定依赖不可用或已改变
保留当前版本在采用任何剩余步骤之前未通过兼容性检查的候选
仍要检查权限和工具参数契约的变化
步骤运行前拒绝保留的辅助函数内的 import、动态 import API、生成代码、作为不透明依赖的第三方和用户包对象（仅支持固定的标准库）
不支持步骤外的调用和外部修改、异步编排、生成器、活动句柄、非 JSON 结果
需要对账外部动作开始后、结果提交前进程崩溃；恢复时不能假定动作失败
绝不自动重试显式暂停、取消、未答复的审批、不确定的外部结果
编写要点
  • 持久状态经 JSON 步骤输入和结果传递。步骤之间不要共享可变全局变量、闭包或默认值。
  • 在模块作用域导入步骤依赖。源码定义的 Python 辅助函数会被递归保留。
  • 如果 B 需要不同的本地状态形状，在其剩余步骤之前用对已保存 JSON 的纯编排完成转换。
  • 手动调用恢复同一执行和函数记录。聊天调用把最终结果返回给原来待处理的工具调用。
  • 重启导致的中断遵循 execution.auto_resume_window_seconds（默认 -1 不限；0 关闭自动重启）。
  • 函数运行对话框会区分声明此契约的函数和中断后需要重新运行的普通函数。
