Runtime

Wraps an LLM provider, computes context from the session DAG, calls the model and writes the reply back. Source.

from openprogram import Agent, Runtime

def my_llm(content, model="host-model", response_format=None):
    texts = [block["text"] for block in content if block["type"] == "text"]
    return call_my_api("\n".join(texts), model=model)

runtime = Runtime(call=my_llm, model="host-model")

class Observer(Agent):
    tools = []

    def observe(self, task: str):
        """Identify the requested screen element."""
        return self([
            {"type": "text", "text": f"Find: {task}"},
            {"type": "image", "path": "screenshot.png"},
        ])

observer = Observer(runtime=runtime)
try:
    answer = observer.observe("login button")
finally:
    runtime.close()

Ordinary methods inherit the Runtime; no decorator or manual Context. See Agent and Context.

Content blocks

{"type": "text",  "text": "Find the login button."}
{"type": "image", "path": "screenshot.png"}
{"type": "image", "data": "<base64>", "mime_type": "image/png"}
{"type": "video", "path": "clip.mp4"}
{"type": "audio", "path": "recording.wav"}

Media takes path (read and encoded, type guessed from the extension) or data + mime_type. A text block may carry "role": "system". Text and image blocks accept cache_control. Unknown block types are skipped.

Structured output
  • Verified provider and model combinations use their native mapping. Otherwise fallback="auto" may use the verified hidden strict-tool path; prompt fallback needs explicit fallback="prompt". Unsupported or lossy combinations fail closed.
  • The final value is parsed and validated locally against the original schema.
  • max_validation_retries is 0, 1 or 2 (default 2); validation repair and truncated generation share it. Also forwarded to _call().

The boundaries of retrying
AllowanceRule
Failure recoveryShared by structured-output repairs and repetitive tool-enabled responses. A repetitive response is discarded and regenerated in the same Agent context, keeping completed tool results and receipts. No aggregate token or duration limit.
TransportOPENPROGRAM_PROVIDER_STREAM_RETRIES minus one, separate, so a dropped connection spends no repair. A request that recovers returns them: bounded per request, not per Agent loop.
Network waitEndpoint unreachable, retries spent, no output committed: waits up to OPENPROGRAM_NETWORK_WAIT_MAX_S (default 30 minutes), checking every 5 to 30 s, then continues. A recovery limit of 0, a single-attempt request, cancellation or the deadline ends it.
  • Explicit caller limits, cancellation, permission failures and exhausted recovery remain authoritative.
  • Repeating a response is not permission to repeat an external write; an uncertain write needs inspection first.
  • Function logic errors still need a code fix.
