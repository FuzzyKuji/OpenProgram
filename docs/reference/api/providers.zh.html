函数

函数行为
create_runtime(provider=None, model=None, **kwargs)返回可用的 Runtime。None 或 "auto" 运行 detect_provider()。**kwargs 转给构造函数。每个 runtime 都有权威的 provider_id。
detect_provider() -> (name, default_model)顺序见下。找不到时抛 RuntimeError 并给出配置指引。
check_providers() -> dict五个专用 provider 的 {name: {"available": bool, "method": "CLI"|"API", "model": default}}；"default": True 标记检测会选中的那个
 
from openprogram.models.providers.catalog.registry import detect_provider, check_providers

检测顺序

  1. 环境变量：AGENTIC_PROVIDER / AGENTIC_MODEL
  2. ~/.openprogram/config.json → last_used_model
  3. 调用环境：在 Codex CLI 内则使用它
  4. CLI 程序：codex → openai-codex，gemini → gemini-cli
  5. 已存 API key：anthropic → openai → google

自定义 Provider

from openprogram.runtime.agent.runtime import Runtime

class MyRuntime(Runtime):
    def __init__(self, api_key, model="my-model"):
        super().__init__(model=model)
        self.api_key = api_key

    def _call(self, content, model="default", response_format=None):
        texts = [b["text"] for b in content if b["type"] == "text"]
        return my_api_call("\n".join(texts), model=model)

_call() 接收 content: list[dict]，返回 str。Runtime(call=fn) 无需子类也能达到同样效果。
