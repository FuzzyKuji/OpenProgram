Runtime

封装 LLM provider，从会话 DAG 计算上下文，调用模型并写回回复。源码。

from openprogram import Agent, Runtime

def my_llm(content, model="host-model", response_format=None):
    texts = [block["text"] for block in content if block["type"] == "text"]
    return call_my_api("\n".join(texts), model=model)

runtime = Runtime(call=my_llm, model="host-model")

class Observer(Agent):
    tools = []

    def observe(self, task: str):
        """Identify the requested screen element."""
        return self([
            {"type": "text", "text": f"Find: {task}"},
            {"type": "image", "path": "screenshot.png"},
        ])

observer = Observer(runtime=runtime)
try:
    answer = observer.observe("login button")
finally:
    runtime.close()

普通方法继承 Runtime，无需装饰器或手动 Context。见 Agent 与 Context。

构造函数

Runtime(call=None, model="default", max_retries=None, api_key=None, skills=None)
参数含义
callfn(content: list[dict], model: str, response_format: dict) -> str，经 CallableModel 包入标准 provider 路径，DAG 记录和历史渲染相同。既无 call 也无 provider:model_id 模型时，子类化并覆盖 _call()。
model默认 "default"。"provider:model_id" 经 openprogram.models.providers 解析，未知值抛 ValueError。其他字符串只在有 call= 或子类时有效。
max_retries尝试次数，含第一次，至少 1。None 读 OPENPROGRAM_MAX_RETRIES，默认 6。
api_keyNone 从凭据库解析
skillsNone/False 关闭；True 探测默认用户和仓库目录；list[str] 显式指定。每次 exec() 向系统提示追加 <available_skills>。
属性含义
model默认模型名
max_retries解析后的重试额度
system可赋值的系统提示；method_options[...]["system"] 在单次调用中设置
thinking_level"off"（默认）、"low"、"medium"、"high"、"xhigh"；传给 provider
session_id这个 Runtime 自己的 "op-<hex>"。不作提示缓存 key 发出：模型、系统提示和工具都相同的调用共用一个由它们算出的 id，跨 Runtime 也一样。给它赋值即自己指定 key
on_streamfn(event_dict)，接收 text、thinking、tool_use、tool_result 事件
last_usage上次调用的 {input_tokens, output_tokens, total_tokens, cache_read, cache_create, ...}

exec()

Runtime.exec(content, context=None, response_format=None, model=None,
             tools=None, toolset=None, tools_source=None, tools_allow=None,
             tools_deny=None, tool_choice=None, parallel_tool_calls=None,
             max_iterations=None, stop_after_tool_round=False, choices=None,
             timeout_s=None, on_retry=None, web_search=None, stream_fn=None,
             effort=None, execution_kind="agent") -> Any
调用场景行为
在 Agent 方法或受管函数内render_context 按 expose 和 render_range 选历史节点，render_dag_messages 渲染，_call() 发送，回复写入开始时打开的 llm 节点。每次 exec() 都是新 llm 节点。
未安装 DAG 存储content 作为一条用户消息单轮调用，不记录
参数含义
contentlist[dict] 或字符串（一个文本块）
context遗留参数，被忽略
response_formatJSON Schema 或 JsonSchemaOutput，见结构化输出
model覆盖默认模型
tools已注册的 Agent 方法、{"spec":..., "execute":...} 字典或带 .spec/.execute 的对象；循环直到返回纯文本。None 不是“无工具”：它拿到全部已注册工具。要无工具用 toolset="none" 或 tools=[]。
toolset预设；"full" 是隐式默认，"none" 不用工具
tools_source按渠道来源过滤
tools_allow, tools_deny名称允许和拒绝列表
tool_choice未设即 "auto"。"required"、"none" 或 {"type":"function","name":"X"}；按 provider 映射。
parallel_tool_calls未设时用 provider 默认；True/False 允许或禁止一轮多个调用
max_iterations未设即 20。一次迭代是一次模型调用加其工具。实际值 max(1, n)。聊天回合不设上限。
stop_after_tool_round一轮工具后停止，供先消费回执的调用方工作流使用。不能与 response_format 同用。
choices约束回合结束方式，见下一步决策
timeout_s整个调用的墙钟预算，含重试等待；抛 LLMError（reason=TIMEOUT，retryable=False）。None 回退到 OPENPROGRAM_EXEC_TIMEOUT_S（未设或 0：不限）。
on_retry每次退避等待前收到 RetryInfo；最终失败不触发；回调异常被吞掉
web_searchprovider 原生网络搜索（如支持）
stream_fn单次流函数覆盖，供分发器和测试使用
effort仅本次调用的推理强度，不改 thinking_level
execution_kindDAG 标签；单请求原语为 llm，否则 agent

内容块

{"type": "text",  "text": "Find the login button."}
{"type": "image", "path": "screenshot.png"}
{"type": "image", "data": "<base64>", "mime_type": "image/png"}
{"type": "video", "path": "clip.mp4"}
{"type": "audio", "path": "recording.wav"}

媒体接受 path（自动读取编码，按扩展名猜类型）或 data + mime_type。文本块可带 "role": "system"。文本和图片块接受 cache_control。未知类型被跳过。

结构化输出错误提供 .code 和有界的 .issues。provider 候选文本不属于诊断内容。

结构化输出
  • 已验证的 provider 和模型组合使用原生映射。否则 fallback="auto" 可走已验证的隐藏严格工具路径；提示回退需要显式 fallback="prompt"。不支持或有损的组合直接失败。
  • 最终值在本地按原 schema 解析和校验。
  • max_validation_retries 为 0、1 或 2（默认 2），校验修复和截断生成共用。同时转给 _call()。

其他方法

方法效果
await async_exec(content, ...)参数相同（无 choices），返回和错误契约相同。调用 _async_call()；call= 函数可同步或异步；重试用 asyncio.sleep，可取消。
_call(content, model="default", response_format=None)一次调用，无重试。配置了 provider 模型或 call= 时经 AgentSession，否则 NotImplementedError。子类化时覆盖它。 历史由 provider 路径从 DAG 渲染。返回原始文本或校验后的 JSON 值。
await _async_call(...)异步 _call()；异步 provider 覆盖它
close()结束会话；之后 exec() 抛 RuntimeError。with Runtime(...) as rt: 退出时关闭。子类在此清理。

重试

情况处理
瞬态异常记录尝试，退避 1.5 秒 × 2^attempt ±25% 抖动，重试至 max_retries。Retry-After 作为下限。基数：OPENPROGRAM_RETRY_BACKOFF_BASE。
永久错误：图片数据错误、认证过期、key 无效或 retryable=False立即 LLMError，retryable=False
provider 已耗尽传输重试（transport_exhausted）LLMError，不再重试
TypeError, NotImplementedError立即抛出
全部失败带尝试报告的结构化 LLMError
 
LLMError: exec() failed after 3 attempt(s):
Attempt 1: ConnectionError: timeout
Attempt 2: RateLimitError: 429 Too Many Requests
Attempt 3: ConnectionError: timeout
rt = Runtime(call=my_llm)                # OPENPROGRAM_MAX_RETRIES, else 6
rt = Runtime(call=my_llm, max_retries=1) # raise on the first failure
重试的边界
额度规则
失败恢复结构化输出修复和重复的工具响应共用。重复响应被丢弃，在同一 Agent 上下文中重新生成，保留已完成的工具结果和回执。没有总 token 或时长上限。
传输OPENPROGRAM_PROVIDER_STREAM_RETRIES 减一，独立计算，断连不消耗修复额度。恢复的请求归还额度：按请求限制，而不是按 Agent 循环。
等待网络端点不可达、重试用尽且没有已提交输出：最多等待 OPENPROGRAM_NETWORK_WAIT_MAX_S（默认 30 分钟），每 5 至 30 秒检查，然后继续。恢复上限为 0、单次尝试请求、取消或截止时间会结束等待。
  • 调用方的显式限制、取消、权限失败和恢复耗尽仍是最终结果。
  • 重复响应不等于允许重复外部写入；结果不确定的写入须先检查。
  • 函数逻辑错误仍需修改代码。
