文档治理列出每条规则和运行位置。

规则

方面检查判断不了的
事实取自代码和命令输出，写不出真内容的区块就不要。
文字标题说事物本身；报错写出了什么、怎么办。一个概念一个词，全站一致。
形状只有真步骤才编号。不用眉题、彩色侧条、嵌套卡片、全大写标签。
代码等宽字体只给代码和参数，并加 translate="no"。
颜色全走变量；强调色只给链接、当前状态、焦点；红色只表示拒绝。每格都有文字。
图静止，有 aria-label；窄时换排法，不缩小。
动效没有入场和滚动动画；悬停只变色；手机宽度没有页面横向滚动。

每页同时发布 topic.html.md，由构建生成给 Agent 读：每张图一次，折叠内容展开。
