Docs governance lists every rule and where it runs.

Rules

AreaWhat the check cannot judge
FactsTaken from code and command output. No real content, no block.
WordsHeadings name the thing. Errors say what happened and what to do. One word per concept across the site.
ShapeNumbers only for real steps. No eyebrows, coloured side bars, nested cards or all-caps labels.
CodeMonospace only for code and arguments, with translate="no".
ColourThrough tokens. Accent for links, current state and focus; red only for refusal. Every cell has words.
FiguresStill, with an aria-label; they change layout rather than shrink.
MotionNo entrance or scroll animation. Hover changes colour only. No sideways page scroll at phone width.

Each page also publishes topic.html.md, generated for Agents: figures once, folds open.
