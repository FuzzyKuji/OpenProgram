Harness 标准

harness 是自带仓库的自包含 agentic 程序。凡在 ~/.openprogram/programs/ 中通过 <pkg>/agentics/__init__.py 暴露函数的都是。不改宿主文件；OpenProgram 不捆绑任何 harness，宿主也不点名任何 harness。

<Harness-Repo>/          openprogram programs install 放进 programs/ 的目录
└── <pkg>/               可导入的包；文件夹名 == 导入名
    ├── __init__.py      标记为包
    └── agentics/
        └── __init__.py  入口，暴露 PROGRAM_ENTRIES

不符合的文件夹被静默忽略。可从目录、Git URL 或 GitHub owner/repo 安装：安装程序。加载器：openprogram/programs/_host/registry.py。来源记录：openprogram/programs/_host/sources.py。

入口

"""Entry point for the Foo harness."""
try:
    from .foo_agent import foo_agent, foo_helper
    PROGRAM_ENTRIES = [foo_agent, foo_helper]
except Exception:          # missing optional dep, unsupported platform
    PROGRAM_ENTRIES = []

导入时触发 Agent 方法装饰器，注册到共享工具注册表；这个列表也是声明的公开接口。加载失败的原因：OPENPROGRAM_DEBUG_REGISTRY=1。

符合性

规则说明
包内层 <pkg>/ 文件夹名等于导入名；harness 根目录进入 sys.path。仓库文件夹带连字符没问题。
PROGRAM_ENTRIES必须定义，可以是 []
try/except必需：导入失败得到 []，绝不抛错。这样依赖装好前也能克隆。
导入成本导入时不下载模型、不联网、不抓 GUI
运行时来自宿主：方法运行在调用它的 Runtime 上，用 llm() / agent()，不声明 runtime 参数。第二个模型是在运行起点配置的另一个 Agent 实例。宿主内路径不得自建 provider 或读 ANTHROPIC_API_KEY。独立 CLI 可以调用 create_runtime(...)。
配置零配置可用；不要求文件、向导或首次运行提示
状态openprogram.state.paths 的 get_state_dir() / "harnesses" / "<pkg>"。绝不用已废弃的 ~/.agentic 或其他写死的家目录路径。
openprogram不作 Git 依赖：pip install <harness> 会重新拉取甚至降级宿主。只写成前提说明。
自身依赖写在 pyproject.toml 或 requirements.txt；由 harness 的安装步骤安装，宿主绝不自动安装。重型或原生依赖放进 extra。
平台不支持就是 PROGRAM_ENTRIES = []，经 except 或 platform.system() 判断，绝不在导入时抛 NotImplementedError。运行时探测后端（shutil.which、importlib.util.find_spec）；各系统的设置写进 README。
配置约定

标准的是机制，不是参数。

类别位置
每次调用不同带默认值的函数参数
机器级带 harness 前缀的环境变量，写进 README，例如 WAH_VAULT
 
from openprogram import Agent

class HarnessAgent(Agent):
    method_options = {"foo_agent": {"tool": True, "name": "foo_agent"}}

    def foo_agent(self, task: str, max_steps: int = 15) -> dict:
        ...

内嵌的包

harness 可以内嵌 third_party/ 这类同级包。宿主只把带 agentics/ 子包的那个包当入口，其余随 sys.path 带上。

发现

时机行为
启动导入每个匹配的文件夹
运行中Web worker 每 2 秒轮询 Programs 目录和已记录来源，执行同样的发现；POST /api/programs/refresh 走同一路径。新工具广播 programs:changed，界面无需重启即可列出。
移除或替换需要重启 worker：重新扫描只增加 harness 工具
