浏览器应用

内置浏览器是应用 openprogram/programs/applications/browser/。核心从不 import 它：应用的 setup(ctx) 提供服务 browser，核心里每个调用方都用 _services.lookup("browser") 查找它，查找返回 None 时就在没有浏览器的情况下运行。

模块作用
__init__.pysetup：提供服务，注册 L2 上下文段 pages。应用不注册任何工具
service.pyBrowserService，即服务的成员（见下）
pages.pyBrowserResourceStore、按对话的 Page 投影、资源控制、人的页面输入
tabs.pycomputer_use_agent(target="browser") 的标签页驱动
extension.py经 Playwright Extension 操作用户的 Chrome 或 Edge
page_actions.py、file_inputs.py上面两者共用的参数解析和页面脚本；一次上传发送的已批准本地文件
app_endpoint.py、privacy.pyApp 的 CDP 端点；密码值脱敏
prompt.py一次调用的 prompt 里关于已打开 Page 的段落

Agent 只用一个工具操作浏览器：computer_use_agent(target="browser")。App 的标签页走标签页驱动，用户的 Chrome 或 Edge 走扩展。动作见浏览器标签页动作。

服务的成员是 pages、tabs、chrome、extension、user_browser_names、open_tab(url)、authorized_page(arguments, window_id) 和 browser_of()。

调用方无服务时
调用提示词没有 Pages 部分；已打开的 Page 不会给该轮加上屏幕工具
进程路由不列出浏览器资源；浏览器控制返回 404
网页标签桥跳过 Page 记账
computer_use_agent(target="browser")报告该目标不可用；桌面目标照常工作
程序的网页标签命令以 browser_not_enabled 拒绝
权限策略看不到用户浏览器

程序的网页标签

项目
打开framework 接口的 tabs.openWebTab 调用 open_tab(url)：标签页在后台为当前对话打开，和浏览器目标的 open 一样。
操作对网页标签的原生展示命令用 arguments.tab 指明标签页，即 tabs 给出的标签页 id（省略时是对话上次用的标签页）。authorized_page 按 App 当前的窗口和绑定核对它，再把 App 自己的标签页 id 发给 App。
权限两者都需要 computer_use_agent 所需的权限：不能用屏幕工具的轮次，也不能这样接触网页标签。
