Other products

Claude Code's plugin manager has installed, discover and error tasks but no OpenProgram Skills or MCP runtime readiness. opencode's MCP and plugin surfaces have no cross-type model. Hermes groups skills without the three-type availability summary. Hence the shared task vocabulary, with OpenProgram's live MCP state and Skill hierarchy kept.
