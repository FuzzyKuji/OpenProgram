MCP 客户端集成

OpenProgram 作为 MCP 客户端：mcp_servers.json 中服务的每个工具都成为普通的 AgentTool，名为 {server}__{tool}。把 OpenProgram 自己的工具暴露出去是相反方向：MCP 服务端。

调用路径

  • 在 worker 的事件循环上等待完成。会话过期的调用重连后重试一次。
  • 只有模型发起这些调用。programs run 和 /programs 页面用于本地函数。

配置

<state_dir>/mcp_servers.json，经 paths.get_state_dir 跟随 profile。文件缺失或解析失败时记录一条警告，worker 以零个服务启动。

{
  "servers": {
    "drawio": {
      "type": "local",
      "command": ["npx", "-y", "@drawio/mcp"],
      "env": {},
      "enabled": true,
      "timeout_seconds": 60
    }
  }
}
字段含义
typelocal（stdio 子进程）、http（Streamable HTTP）、sse（旧版 SSE）。远程类型带 url、headers、auth（none、bearer、oauth）
command子进程命令和参数
env对继承环境的覆盖和追加
enabledfalse 停用但不删除
timeout_seconds启动等待和单次调用的读取超时

凭据

env 和 headers 的每个值都算密钥，因为任何一项都可能是，bearer token 和 OAuth client secret 同样。

PATCH /api/mcp/servers/{name}效果
名字或整个字段缺失保留
名字带值替换
名字带空字符串删除

auth.token 和 auth.client_secret 同样规则。改 auth.kind 会丢弃另一种的密钥。Web UI 打开时密钥输入框为空，只列出已存名字。

序列化与存储
项规则
to_storage_dict()完整值，只用于写 mcp_servers.json
to_response_dict()每个值变成 {"has_value": bool, "masked": str}；认证密钥变成 has_token / has_client_secret 和掩码。/api/mcp/servers、/api/mcp/servers/{name}、/api/mcp/catalog、/api/mcp/catalog/diff 都返回它。

启动与就绪

情形可观察结果
App lifespan 和 /healthzMCP 传输、npm 下载或 OAuth 未完成时也就绪；标准执行恢复仍是就绪门槛
状态和工具注册表启动中和失败的客户端显示真实的就绪、错误、认证字段，密钥已掩码，不提前出现工具
连接成功带命名空间的工具和 prompt 变为可用
启动中关闭启动被取消并排空；客户端、supervisor、回调资源和注册都释放；不会迟到注册
所有者删除或停用排队中的服务保持缺失或停用；没有新进程或工具；管理操作的替换优先于启动快照
自有 OAuth 回调被取消释放 socket、线程和等待者，不伪造 code；正常的 code 和 state 校验不变
背后的规则
  • 服务器 lifespan 把 load_mcp_servers() 作为受管后台任务运行；服务按顺序连接，使用各自配置的超时。
  • 每个客户端在等待连接前就发布到注册表：ready=false，没有工具。掩码管理 API 保持可用。
  • 排队的服务轮到时读取当前持久化的配置。
  • 不在首次用工具时才连接。不等待所有连接，因为认证可能超过健康检查期限。也不另起 worker、改所有者超时、压制认证错误或把未完成的客户端标为就绪。

机制

工具名

adapter.namespace_tool_name(server, tool) 把 [A-Za-z0-9_-] 之外的字符换成 _，截断到 OpenAI 上限 64，保留工具后缀。用双下划线是因为 OpenAI 的名称规则拒绝 opencode 的冒号。重名时后注册的生效。

内容转换

MCP 类型转成
TextContentproviders.types.TextContent
ImageContentproviders.types.ImageContent

isError=True 写入 details["is_error"]；模型看到结果文本，与本地工具一致。

持久连接与 supervisor 任务

MCP 是长连接双向协议，SDK 用嵌套的上下文管理器暴露。一个 supervisor asyncio.Task 保持它们打开。

async def _supervisor(self):
    async with stdio_client(params) as (r, w):
        async with ClientSession(r, w) as session:
            await session.initialize()
            result = await session.list_tools()
            self._session = session
            self.tools = list(result.tools)
            self._ready.set()
            await self._shutdown.wait()
  • start() 创建任务并等待 _ready；call_tool() 复用 _session；stop() 设置 _shutdown，子进程随之关闭。
  • 启动失败同样设置 _ready 并记录 error；管理器跳过注册，记一行日志。
OAuth
  • 经 PersistentOAuthProvider 委托给 SDK 的 OAuthClientProvider。
  • 跨重启持久化：带绝对 expires_at 的 token；动态客户端注册，复用回环端口，重新认证时提供已注册的 redirect_uri；发现的服务元数据，冷启动刷新能到达真实 token 端点。
  • 过期 token 后台续期。浏览器授权只在首次认证或刷新被拒时运行，表现为 error_kind="needs_reauth"。
  • 只有在有人从 App 或 CLI 连接该服务器时才打开浏览器授权。工作进程自行连接服务器时（启动时或自己重连，oauth_flow.unattended），链接留在 /api/mcp/auth/pending，不会有浏览器挡到用户正在做的事前面。
测试隔离

config.py 用 from openprogram.state import paths as _paths，每次实时调用 _paths.get_state_dir()。from … import get_state_dir 会绑定 tests/integration/store/test_attach_lazy_session.py 打补丁的 lambda，因为该测试经 _start_mcp_servers 触发首次导入，补丁会泄漏。新增 paths 补丁时仍要走模块引用。
