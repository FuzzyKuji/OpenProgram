LSP tools

ToolReturns
lsp_diagnostics(file)Compiler-grade errors and warnings the moment an edit ends, without running tests
lsp_references(file, line, column)Every real call site; grep misses dynamic calls and matches same-named strings
lsp_definition(file, line, column)The true location across files and packages
  • Python (pyright) and TypeScript (typescript-language-server), the two languages of this repository.
  • One server per language per workspace, started on first use, cached, shut down at process exit.
  • A missing binary gives an "unavailable: install X" result. The tools stay registered so the model learns what is possible.
  • Server processes use the sandbox-wrapping entry of every other child, so sandbox.mode applies.

ACP server

DirectionMethods
From the editorinitialize, session/new, session/load, session/prompt, session/cancel
To the editorsession/update, session/request_permission
  • Sits on dispatcher.process_user_turn, the non-HTTP entry of the webui thread, sub-agents and the task runner, so tool gating, authority and persistence are shared.
  • Turns carry local_owner_authority(): an editor on this machine is the owner speaking interactively, which makes approval.request available.
  • Approvals subscribe to question.asked and answer with the canonical execution wait command, leaving the gate, its rules and "always allow" persistence untouched.
