LSP 工具

工具返回
lsp_diagnostics(file)编辑一结束就有编译器级的错误和警告，不用跑测试
lsp_references(file, line, column)每个真实调用点；grep 会漏掉动态调用、误中同名字符串
lsp_definition(file, line, column)跨文件、跨包的真实位置
  • Python（pyright）和 TypeScript（typescript-language-server），本仓库的两种语言。
  • 每语言每工作区一个服务，首次使用时启动并缓存，进程退出时关闭。
  • 缺二进制时返回“unavailable: install X”。工具保持注册，让模型知道有这个能力。
  • 服务进程走和其他子进程相同的沙箱包装入口，sandbox.mode 同样生效。

ACP 服务

方向方法
来自编辑器initialize、session/new、session/load、session/prompt、session/cancel
发给编辑器session/update、session/request_permission
  • 建在 dispatcher.process_user_turn 上，这是 webui 线程、子 agent 和任务运行器共用的非 HTTP 入口，工具门控、权限和持久化都共用。
  • 轮次带 local_owner_authority()：本机编辑器就是所有者在交互，因此 approval.request 可用。
  • 审批订阅 question.asked，用标准的执行等待命令作答，审批门、规则和“始终允许”的持久化都不变。
