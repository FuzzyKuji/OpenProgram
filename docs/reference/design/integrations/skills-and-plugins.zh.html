技能和插件

类型是什么
技能含 SKILL.md 的目录，可选 references/、templates/。描述列入系统提示词，skill 工具加载正文
插件一份清单，贡献技能、命令、智能体、钩子、MCP 服务端和 provider 目录。不带代码，启用时不在 worker 里运行任何东西

在 Abilities 页面和 openprogram skills、openprogram plugins 管理。挂载：插件运行时。

技能

---
name: my-skill
description: One-line trigger description
category: devops              # hermes-style grouping
optional: false               # replaces hermes optional-skills directory
allowed-tools: [Read, Edit]   # claude-code: restrict usable tools
triggers:                     # OpenProgram extension
  keywords: ["deploy", "ci"]
  file_patterns: ["*.yml"]
  slash: "/deploy"
version: 1.0.0
author: ...
---
优先级，从低到高位置
远程缓存~/.openprogram/cache/skills/<name>/，从远程索引拉取
插件已启用插件贡献
用户~/.openprogram/skills/<name>/
项目<project>/skills/<name>/

冲突时后者覆盖前者。名字是相对来源根目录的路径（anthropic-skills/docx），重名即同一技能的两个来源。

清单形式来自
.claude-plugin/plugin.json、.codex-plugin/plugin.json、根目录 plugin.jsonClaude Code、Codex
pyproject.toml 的 [tool.openprogram.plugin]OpenProgram
package.json 的 openprogram、opencode 或 hermes 字段npm 包
plugin.yaml、plugin.ymlHermes
来源位置
npm~/.openprogram/plugins/node_modules/<name>/
本地路径、git 克隆~/.openprogram/plugins/<name>/；本地路径为链接
项目固定<project>/.openprogram/plugins.json：启用、版本、来源
入口类型注入到
skills技能注册表，和文件系统技能合并
commandsavailableFunctions，标记 source=plugin:<name>
mcpServersopenprogram/extensions/mcp/ 注册表
providersprovider 注册表；和内置适配器相同的 provider.json 契约
agents子智能体注册表
hooks事件总线，作为 shell 命令
信任加载
verified、community挂载内容。钩子和 MCP 服务端作为独立进程运行
untrusted 和未列入的插件不启用；界面要求确认信任。存于 ~/.openprogram/plugin-trust.json

清单指向代码时被拒绝；添加工具或 UI 的代码是应用。worker 里没有插件代码，所以没有进程内或 RPC 模式。

技能 API
方法路径说明
GET/api/skills合并列表，含来源、启用、分类、optional
GET/api/skills/_complete、_search、_resolve给输入框和 skill 工具的补全、搜索、解析
GET/api/skills/{name}全文、frontmatter、资源树
GET/api/skills/{name}/file单个资源文件
POST、PUT/api/skills、/api/skills/{name}在项目或用户下创建；编辑
DELETE/api/skills/{name}只限项目、用户或远程缓存
POST/api/skills/{name}/toggle启用或禁用
POST/api/skills/{name}/invoke-trace最近一次调用的注入记录
GET、POST/api/skills/discovery/sources列出或添加远程索引
POST/api/skills/discovery/pull把一个技能拉入缓存
GET/api/skills/discovery/suggested、browse、diff推荐索引、浏览、和来源比较
POST/api/skills/discovery/install从索引安装
WSskills:changed来自 watcher 和修改类路由
插件 API
方法路径说明
GET/api/plugins已安装列表、状态、错误
GET/api/plugins/inspect面向作者的实时自描述
GET/api/plugins/updates可用更新
GET/api/plugins/commands、builtin贡献的斜杠命令；内置条目
GET/api/plugins/{name}详情、清单、入口状态
POST/api/plugins/install{source: npm|git|path, spec, ref}；拒绝代码
POST/api/plugins/{name}/uninstall、toggle卸载、启用或禁用
POST/api/plugins/{name}/reload同 claude-code /reload-plugins
POST/api/plugins/{name}/validate试运行：清单、入口、依赖、兼容性
GET、POST/api/plugins/{name}/options读写选项
POST/api/plugins/{name}/trust设置信任级别
GET、POST/api/plugins/marketplaces列出或添加，兼容 claude-code schema
DELETE/api/plugins/marketplaces/{id}移除
GET/api/plugins/marketplace/{id}/index浏览，支持搜索、分类、分页
WSplugins:changed、plugins:update_available变更后；更新轮询后
前端
路由显示
导航在 Abilities 下，和 Programs、MCP 服务端相邻；/skills、/plugins、/mcp、/programs 时高亮
/skills按分类列表，optional 折叠；详情含调用轨迹；创建；远程索引
/pluginsInstalled、Marketplace、Errors 三个标签页

技能详情把 SKILL.md 当不受信 Markdown 渲染：原始 HTML 和类 HTML 公式显示为文本，技能链接不获得资源解析或文件系统访问。
