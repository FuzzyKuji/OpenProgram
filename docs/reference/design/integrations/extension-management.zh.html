其他产品

Claude Code 的插件管理有已安装、发现和错误任务，但没有 OpenProgram 的技能或 MCP 运行就绪状态。opencode 的 MCP 和插件界面没有跨类型模型。Hermes 给技能分组，但没有三类可用性摘要。因此采用共同任务词汇，并保留 OpenProgram 的 MCP 实时状态和技能层级。
