Web Use

能力职责入口
Web Use内置浏览器的 Page、标签页、弹窗、分屏、跨窗口发现，以及 DOM、ARIA、视口操作web_use，供 Program 和 MCP 客户端调用
Computer Use应用程序、内置和无头浏览器、虚拟机computer_use_agent，模型的屏幕工具。其 browser 目标使用独立的标签页驱动

后端

创建 WebSession 时固定；每个会话一个 Page。

后端类型提供方
playwright_mcp（默认）DOM、ARIA、元素引用固定版本的 Microsoft Playwright MCP
chrome_devtools_mcpCDP、快照、诊断固定版本的 Chrome DevTools MCP，经 MCP 适配器
open_claude_chromeOpen Claude in Chrome 的工具契约和视觉操作OpenProgram 的 Electron 和 CDP 适配器，无需扩展

Page 绑定、权限、验证和后端选择由 OpenProgram 负责，三个后端共用。直接调用 Electron webContents.debugger 和 CDP，不复制 Claude 源码。命令、令牌、失败：web_use 运行时。

观察结果中的引用

类型规则
MCP 和控制器引用命名空间分开，即使都是 e 加数字
file_ 引用不透明，限当前会话和当前观察。在 elements 中暴露原生文件输入及标签、禁用状态、已选文件名。只支持 upload 和 file_selected 验证
上传映射到已观察的确切原生句柄，绝不按标签、序号或 MCP 引用解析。不要先点 Choose File。在同一受保护控制器的所有者线程上运行；权限、大小限制、新鲜度、取消和不确定选择保护仍然有效

选中文件不代表服务器已接收。

失败

事件效果
桌面确认超时当前命令失败；绑定和 WebSession 保留。清除缓存的观察权限，act 或 verify 前必须成功 observe
断开、过期、归属或目标修订变化撤销访问
任何情况不自动重放修改

聊天渲染

存在进行中的助手回复或其运行时卡片时，Web Use 树更新不重新加载对话，因此消息身份、流式输出、滚动和消息操作都不受影响。没有持久卡片的独立运行可以做一次初始水合。

Claude Code 的视觉点击路径，用于对照
  1. computer(screenshot, tabId) 到达 claude-in-chrome MCP 工具，再到 Native Messaging host 和 Chrome 扩展 service worker。
  2. worker 对标签页调用 Page.captureScreenshot，PNG 和视口元数据原路返回。
  3. computer(left_click, [x,y], tabId) 走同一路径。
  4. worker 校验标签页、权限和坐标映射，必要时暂停请求用户授权。
  5. UPDATE_PHANTOM_CURSOR 移动页面内光标，只是视觉提示。
  6. Input.dispatchMouseEvent 经 CDP 发送移动、按下、释放，不移动系统鼠标。

来自本地检查的 Claude Code 2.1.227 和 Chrome 扩展 1.0.85 安装包；不是稳定接口。按页面引用点击不需要先截图。Claude Code 浏览器文档、Playwright MCP。
