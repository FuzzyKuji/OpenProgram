Plugin runtime

A plugin is a manifest naming skills, commands, agents, hooks, MCP servers and provider directories. The host mounts them through one ProgramContext; no plugin code is imported and there is no plugin-only registry. Manifest forms, sources, trust: Skills and plugins. Model: Program Model.

ctx.dispose() runs disposers in reverse, collects errors instead of stopping, and empties ctx.contributions, the per-kind record the Plugins page and plugin tool show. Defined in programs/_host/context.py.

Code is refused

extensions/plugins/manifest.py records keys naming code in code: python, module, setup, main, tools, client, web, sidebar, a module:name hooks value, an __init__.py beside a Hermes plugin.yaml. code_refusal names them and says to add an application.json and run openprogram programs install <dir>.
