Usage

from openprogram import agent
answer = agent("Analyze this paper", model="configured-model")

Uses the current execution session, or opens one independent execution.

from openprogram import Agent
bot = Agent(model="configured-model")
first = bot("Investigate this topic")
second = bot(first)

Reuses configuration, not history: execution scope decides continuity, and independent top-level calls share none.

class Researcher(Agent):
    model = "configured-model"
    def research(self, question):
        text = self.prepare(question)
        return self(text)
    def prepare(self, text):
        return text.strip()
result = Researcher().research("A topic")

No per-method decorators. research is an entry, prepare an unrecorded helper.

Context is a runtime construction object; complete intermediate values are neither copied nor persisted. Session persistence and Trace export stay separate.

Tool visibility, approvalSeparate from DAG visibility. Inner configuration cannot expand outer authority

Default construction needs model interactions and call relationships, not ordinary arguments or locals. Explicit content is bounded; self is represented by identity or type; method names are qualified by module and class. Call recording does not approve arbitrary Python effects; the sandbox still governs them.

Concurrency and failure

  • Current Context, call identity and effective configuration bind per task and restore on exit. Inheritance copies no history or mutable branch configuration. Nested reentry is allowed.
  • Shared Agent configuration does not imply shared history. Mutable instance content and shared sessions need defined synchronization.
  • Errors, timeouts and cancellation restore the parent and keep completed interactions. Recovery uses safe points and explicit steps, never arbitrary Python stacks. Standalone calls reuse permission context and non-interactive approval rules.
  • Without an outer execution, the entry owns an environment and releases it on exit.
  • Resumable functions keep one durable node ID across call and continuation; provider tool-call identity stays in node metadata.

No function decorator

  • The removed public decorator has no adapter or replacement. Agent.method_options keeps input metadata, Runtime injection, registration and schemas, availability, permissions, visibility, retry, execution controls and explicit-step recovery.
  • Managed sources declare PROGRAM_ENTRIES and __agent_options__. Methods carry _is_agent_method. Stored node schemas and history stay readable.
  • First-party workflows, generated programs, scanners and dispatchers use ordinary Agent classes.
  • Harness packages migrate in their own repositories and keep their agentics paths; the runtime bundles none. Six locally published workflows migrated in isolation, which is no upstream release.
Behavior-test host and cancellation display
  • The host initializes the standard SessionStore before the OS sandbox. The runner binds its SessionNodeWriter through Context and Agent calls reuse it. Candidate tests cannot spawn processes, write the source snapshot, read host secrets or use the network.
  • Cancellation closes the canonical execution; unresolved external effects stay inspectable.
  • The assistant projection retries through the durable DAG outbox when its node or storage is unavailable. A display failure does not reject an applied cancellation.
  • Cancelling a paused continuation error replaces its error display with cancelled, clears error metadata and keeps content.
  • Resource-release observer failures stay visible to the control caller. Normal Job completion keeps its result-bearing projection owner; cancellation notifications do not publish other terminal Job rows before it supplies result and error fields.
