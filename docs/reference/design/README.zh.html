维护规则

  • 每页只属于一个侧栏分类。在 scripts/docs_site/nav.py 登记页面和阅读顺序；未分类页面显示在“待分类”下。分类调整不改变 URL。
  • 每个主题一份当前设计。图、对比和记录说明与它的关系，不复制正文。
  • 默认英文，中文同步。见文档约定。
  • 文档声明、源码存在、测试通过、已发布和已安装 App 验收是不同状态。分类不代表完成度。
