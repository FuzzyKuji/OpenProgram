阅读结构与视觉规范

新页面是同一基底上的 HTML 文档：中性色加一个蓝色强调色，亮暗两套。原型页通过 --bg、--bg-code、--tx、--tx-soft、--acc、--bd 工作，它们是基底令牌的别名。文章内不写固定的仅亮色配色。

  • 页面从问题、读者、范围和实现边界出发；公开入口和数据流先于细节；页尾写剩余工作。
  • 稳定的标题 id 提供页内导航。
  • 图有可访问的标题和描述。详细证据放进原生折叠。键盘焦点、减少动态和手机阅读都属于验收。
  • 宽表保留在可键盘操作的横向滚动区域，列宽可读。独立 HTML 另有图表滚动区域，未定义背景时有不透明兜底画布。这些辅助不证明页面所述的实现成立。

方案比较

阅读导航

部分行为

指示线一条连续虚线从首行到选中行，圆角末端对齐标签中心；组内导航时改变高度。悬停和焦点预览单独的中性指示线。焦点是文字下划线加淡行背景。筛选、换行、语言和缩放都重算几何。
进度跟踪当前滚动容器中的活动标题。展开后是真实锚点，选择后关闭并跳转；Esc 和点击外部关闭。SPA 导航重建引用。全屏用内容滚动容器。独立 iframe 时隐藏。减少动态时不做滚动动画。
代码块语言头和始终可用、位于横向溢出之外的复制按钮。只复制代码文本并报告成败。作者自带的复制控件保留。
根概览明确的中英文标签，不由文件名推导。
依赖不增加外部运行时请求。

设计文档的信息结构

三级：领域、模块、页面。七个领域：架构、Agent 与工作流、上下文与记忆、界面、模型与外部连接、安全与工程、支撑材料。落地页使用同样的七个。架构直接列出入口页。

  • 每页属于一个模块。加载或导航到某页时展开其祖先。
  • 筛选匹配页面和分类名，保持匹配祖先展开；清空后各级恢复原状。原生 details 和 summary 提供键盘操作。
  • 新页面出现在“待分类”领域。
  • 两种语言共用层级、顺序和输出映射。
  • 原型、实现记录和研究在“支撑材料”下分开，不表示产品已实现。

文档完整性

仓库 README 和结构相同的中文版介绍项目、经核实的入口命令、示例和引用。文档首页引向九个 Tab，不重复它。参考概览链接任务指南和生成的细节。

参考生成从同一 argparse 树、设置 schema 和供应商清单输出中英文配对；名称、参数、键、默认值和协议值保持精确。

  • 源字符串目录（reference_zh.json）提供中文；缺翻译时生成失败。
  • 两种语言遍历每一层命令、选项相同，只在内容变化时写入。删除的命令页两种语言都删。
  • 只读 schema 默认值，不读用户配置；不含凭据。
  • 生成器在发现页面前完成；失败则中止构建。

验收：所有参考配对、递归选项一致、缺翻译失败、幂等、清理过期页、首页语言链接、短名称、链接、语言检查，以及默认本地实例上可见的语言切换。

标题层级

  • 没有页内目录的页面隐藏空列，把空间给文章；全屏控件留在右边缘；SPA 导航随之更新。
  • 嵌套列表覆盖 h2 到 h6。每个标题归属最近的、更浅的前置标题；跳级不产生空组。顺序、标签和锚点不变。
  • 每组有自己缩进的虚线引导。选中标题和祖先路径有各组自己的指示线，线条不跨越无关层级。中性子引导在选中子项前显示结构。
  • 有子项的标题使用侧栏的 details/summary 箭头，只切换该子树；链接仍可导航。叶子没有箭头，保留弯曲引导端点。分组默认展开，滚动尊重用户折叠；折叠的活动后代标记其父路径，跟踪最近的可见祖先。悬停和选中不加行框。
  • 端点使用实际换行后的行。预览限于同级组内。只有一个 aria-current 位置。缩放和 SPA 变化重算几何并释放旧观察器。

验收：多个父组、跳级、深层标题、换行、活动祖先、悬停、缩放、SPA 导航。
