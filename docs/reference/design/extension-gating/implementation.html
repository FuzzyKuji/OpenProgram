resolve_tools

A per-turn override beats profile.tools.

WantedResult
Noneagent_tools(source=…, only_available=True)
[], mode: noneNo tools
mode: automatic, or a dict with no enabled, toolset, preset, allowedFull toolset minus disabled
mode: selected or presetThose names minus disabled; adds tool_search when any is deferred
enabled listExactly those names; beats allowed
toolsetThat set, filtered by both pattern lists
Other dictDEFAULT_TOOLS filtered by both pattern lists
List of namesExactly those, resident unless tool_search is present

Profile MCP gates apply on every path, including per-turn lists. web_search is overlaid separately by its own boolean. required is checked after filtering, before provider execution.

Compatibility

skills, tools and mcp must be objects. AgentSpec.from_dict passes them through dict(), so legacy lists such as skills: ["pdf", "drawio"] raise ValueError on load and are not migrated. A tools dict holding only empty lists counts as automatic.

Testing

No dedicated unit tests: match_any is fnmatchcase plus iteration. openprogram doctor checks that skills load and MCP configs read, not gating. Add tests if semantics diverge from fnmatchcase, such as ** support.
