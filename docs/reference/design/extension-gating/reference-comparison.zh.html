Claude Code

每种类型有自己的列表字段，写精确名称：易读，覆盖面大时啰嗦。

Agent 字段含义
tools白名单
disallowedTools黑名单
skills预加载
mcpServers引用或内联定义，Agent 能自带 MCP 配置
hooks按 Agent、限于会话。OpenProgram 在 openprogram/extensions/plugins/hooks.py 的插件钩子没有按 Agent 的作用域
permissionMode该 Agent 的权限模式

opencode

每个 Agent 一个 permission 规则集：{pattern, action: allow | deny} 规则用 glob 匹配 tools:bash、mcp:slack/* 这类键。首个匹配生效。

  • 新类型只需一个命名空间前缀，不改 schema。
  • 一条规则可抵多条（{pattern: "mcp:*", action: "deny"}）。
  • 代价：用户要学习模式语法。

hermes

专注平台适配器（Discord、Slack、ntfy 等）。每个适配器的 plugin.yaml 规定它在网络上能做什么，属于渠道级，没有对应的 Agent 配置门控。本层没有采用其内容。

设计理由

Claude Code 的骨架加 opencode 的通配符。按类型的字段名即含义，allowed、categories、required 可机械地加到既有结构上。fnmatch 用一个辅助函数消除纯列表的啰嗦，精确名称照常可用。单一规则集只是纯重构（未构建）。未来框架出现实质不同的模型时再重新考虑。
