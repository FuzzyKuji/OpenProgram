Web UI

One workspace UI: a React and Next.js app (apps/web/), built ahead of time and served by the Python worker on the API's port, so the same pages run in a browser tab, the desktop app and against a remote server. apps/desktop/ is an Electron shell for macOS and Windows; Linux and servers use a browser.

PartToday
Sidebar and pagesProjects and chats; Agents, Abilities (Programs, skills, plugins, MCP), Applications, History, Scheduler. Settings in the user menu. List pages share one secondary rail.
Center tabsChats, files, terminals, web pages. Tabs split into panes; tabs and groups move between windows.
TranscriptReply with tool calls folded into rows, file-change summary, sub-agent rows, waiting requests. Follows new output until you scroll away.
ComposerAttachments, model and effort pickers, per-folder git pills, Options menu. Local paths survive into model context.
Visual systemColours, sizes and shapes from tokens and themes; icons, dots and hover tips each follow one rule set.
