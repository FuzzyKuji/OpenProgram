思考深度选择器

布局和时序参照观察到的 Claude desktop 2.31226.0，独立实现。Claude 的 Ultracode 工作流模式没有对应物：OpenProgram 保留提供商的深度 id。选项和“推荐”来自所选模型；Radix 负责指针和键盘选择；状态走输入框设置。Fast 和帮助相互独立。

动效

元素行为
轨道中性填充、离散刻度，裁剪填充内反向平移的全宽动画场
手柄白色；拖动时放大 12%；弹性的子级反馈；120ms 吸附
选择拖动时预览，松手提交。指针取消时清除拖动反馈。
标签四层过渡：垂直移动，200ms 内从模糊变清晰

最高档动画场

在多个选项中的最高档运行（xhigh、max 或 high）。只有一个或没有选项时不动。

单元
4px 网格上的 3px 圆角方块，淡紫色
图案
WebGL2 八脉冲场从右侧传播，五级亮度，单元亮度漂移，按主题的预乘颜色
时序
700ms 进入；离开时 850ms 淡出，画布保持轨道全宽
分辨率
跟随设备像素比，上限 4,147,200 像素

生命周期

情况规则
动画一个动画回调，在关闭、卸载、文档隐藏或减少动态时取消。
失败减少动态时关闭动画场。Canvas 失败时滑块仍可用。
无障碍主题色来自 CSS token。具名值、键盘焦点和推荐刻度保持无障碍。
验收

在真实 ThinkingEffortPill 上：指针和键盘选择的深度 id 不变；xhigh 有动画；离开后淡出为空；重新打开和换模型正常；Fast 保持独立；减少动态时画面稳定；深色、浅色和窄布局清晰。
