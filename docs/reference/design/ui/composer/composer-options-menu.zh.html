输入框选项菜单

ControlsCluster 里的 + 菜单。和其他菜单一样，是基于 apps/web/components/ui/menu/menu-styles.ts token 的 Radix DropdownMenu。没有模块 CSS。

菜单行

行类型选择后
添加文件或照片动作关闭
录制 Workflow动作；仅 macOS 桌面 App关闭
网页搜索开关，在分隔线后保持打开
沙箱开关。不可用时禁用，原生 title 说明原因保持打开
无人值守开关，在分隔线后保持打开

每行都是 PlusMenuRow（controls/menu-pieces.tsx）：itemCls(false) 加 MENU_ITEM_STATES。16px Solar 图标列、标签、可选元数据、勾选列。选中行显示 14px check-circle，只弹入一次；其他行用 CHECK_SLOT_PAD 占位。

面板
MENU_PANEL：rounded-lg、p-1
行
itemCls：最小 28px、rounded-md、基础字号，悬停是唯一着色
分隔线
MENU_SEPARATOR，通栏
位置
挂在 body 的 Radix portal，z-[200]，side="top" align="start" sideOffset={9}；Radix 处理锚定、翻转和碰撞

没有工具开关

没有 Tools 开关，也没有 Access 预设。聊天能调用哪些工具由 Agent 配置决定（Agents → 能力 → Programs：全部、某范围或预设、无）。输入框只叠加网页搜索。见工具开关管理。

方案对比
方案结果
共用 token 的 Radix采用：打开状态、portal、翻转、roving focus、typeahead、Escape、点外部关闭；全站一套菜单语法
Base UI Menu 加 CSS 模块移除：第二个库，样式副本会漂移
手动固定定位否决：没有 portal 顺序、翻转和完整键盘行为
原生 Popover API未采用：没有 roving focus 和定位约定
验收
  • 面板、行、分隔线和勾选来自 menu-styles.ts；composer.module.css 没有 .plusMenu* 规则。
  • 没有 Tools 行、Access 预设子菜单或 Tools chip。
  • 没有 menuPosition 或手算的固定坐标。
