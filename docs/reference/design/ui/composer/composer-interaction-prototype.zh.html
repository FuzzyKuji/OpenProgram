输入框交互布局

职责与送达见输入框与用户决策输出。不引入新主题或依赖；沿用中性配色、12px 间距和 28px 决策控件。

界面

界面显示操作
工具审批“需要你的输入”、1/1、“允许这条命令吗？”、OperationCode 中的操作拒绝和允许一次同在底部一行，直接提交。没有选择、讨论或发送步骤。
问题面板进度徽标、当前问题、全宽选项行（标题、可选说明、数字）、输入框可见的“其他”左侧上一步；右侧跳过和下一步或提交
函数表单只有任务输入，四周 12px 内边距沿用标题栏：运行、关闭

问题面板

与输入框同宽；字体、字号和颜色沿用应用。

操作结果
下一步校验当前答案，显示下一题，不发送
上一步保留所有选择
提交通过带确认的执行命令发送一份有序答案
跳过拒绝整个请求。后端要求每题都有有效答案，所以没有部分或空答案。
折叠、关闭缩成标题栏。重新打开保留答案，不发命令。
数字键选择选项，仅在可编辑文本之外
Ctrl/Cmd+Enter前进或提交。IME 输入和多行讨论保持编辑语义。
问题到达不移动焦点
矮屏幕内容滚动，标题栏和操作保持可见

可选的 question_title 和 option_descriptions 提供行布局。只渲染显式字符串条目；继承的对象属性不算元数据，也不限制选项标签。纯答案和完整提示留给其他客户端。多个待处理请求是各自带 key 的面板。

讨论

方面规则
入口普通问题：讨论这个问题。审批只有允许一次和拒绝。
输入区卡片内联；标题表明是讨论；最小 96px；共用 Textarea。原问题只读，没有重复的答案控件。隐藏进度。
打开、取消不发送；等待保持未决
发送把问题、工具详情和反馈绑定到确切的规范等待，作为同一轮的拒绝原因
拒绝拒绝操作，不产生讨论轮次
提交中阻止其他审批控件。结果未知时保留命令和反馈用于重试。切换会话不会改变目标。
身份session 与 wait 共同标识请求；反馈、命令 id 和送达状态在组件重挂后保留

与 Claude Agent SDK、OpenCode 一样，反馈绑定原调用。OpenProgram 不合成第一人称拒绝话术，也不把问题当工具权限。

字体与对齐

文字
应用无衬线字体、基础字号、行高 1.5，桌面断点不缩小。提示和字段标题 600；值、提示和占位符 400。
代码
命令和 JSON 用共享 OperationCode：等宽字体，语言标签与首行同规格，次级背景，内嵌 1px 主题边框，复制图标对齐首行。没有单独工具栏。
复制
剪贴板确认后才显示成功；失败会播报
边缘
标题、正文、编辑器边框同一左边缘，距容器 12px。没有负外边距。
操作区
滚动内容的不收缩兄弟节点，高度过渡和溢出时都固定在底部
命令详情
原生折叠，间距 12px；工作目录只出现在 JSON 参数里。沙箱提权说明保持可见。

函数表单

项目规则
输入Programs 使用、收藏和重新打开的表单都只有任务输入。限制、超时、后端和会话句柄是内部项，有可用默认值，没有折叠或提示。
专用表单浏览器 Workflow：任务和可选 URL。文本润色按文本选风格。页码范围、输出位置和修订目标仍是输入。
待处理的使用请求待处理的使用请求在聊天初始化后才消费，初始化不会清掉表单。
高度高度测量释放 textarea 的 flex 增长，并计入原生行高和边框，最后一个字段保留内边距。
Goal 详情Goal 详情保留进度和任务控件，没有 Agent 或预算编辑。新 Goal 用一次无工具模型请求选择思考深度，失败回退默认；恢复的 Goal 保留已存角色。

键盘归属

功能规则
历史回溯保留确切草稿；在最新一条之后按 Down 恢复。编辑回溯文本开始新一轮。状态按输入框所有者隔离，其他分栏不会重置。选择、修饰键方向、IME、文件和斜杠菜单优先。
文件提及结果绑定 token 位置和查询。查询变化即失效；Escape、替换或卸载后迟到的响应不能恢复。Escape 关闭直到 token 变化。
提及查询中Enter 和 Tab 保留草稿，不选择也不发送。Escape 可用。IME 和 Shift+Enter 保持编辑。没有超时或重试。
提及为空或失败Enter 发送；Tab 移动焦点
发送意图被拒所有者预留保留未发送正文，即使只有附件或设置不同，聚焦和绑定输入框都一样。已接受的帧保留载荷；成功只清除匹配文本。预留 token 在 finally 中释放。
长期审批
项目规则
过期人工工具审批默认不过期。持久等待保留确切操作和文件指纹；safe-point 交接结束本次尝试并释放执行槽。显式期限仍用于其他等待。
恢复恢复时加载检查点，复用保存的系统提示和浏览器工具选择。校验模型、工具实现、权限和位置；Page 访问在每次调用时检查。不兼容的续接报告未恢复执行。
清除错误恢复到达运行或完成后，清除之前的续接错误元数据。重放修复已完成消息，不重新执行。
取消取消和终态事件移除待处理决策，重连后也一样。已过期的保持过期。Job 恢复只处理 Job 准入。再次暂停的操作不会凭旧答案重试。
文件审批文件编辑、写入和补丁审批绑定路径和内容，派发前和变更前都检查。目标变化或缺失时不写入；Agent 得到未执行结果，必须重读。不透明的 shell 命令不能声称有此保证。
拒绝或过期终态的拒绝或过期等待通过持久 DAG outbox 把结果投影到它的 assistant 节点，不执行也不开新轮；重放不重复。
终态释放执行到达终态时释放活动会话的输入框，除非有更新的执行；回复的终态行以转录更新到达，不重新加载。续接打开新审批时发布到共享 WebSocket 事件流。
同类Claude Agent SDK 的无限期 canUseTool 等待、OpenCode permission/next.ts、Codex tools/approvals.rs。

验收
  • 讨论：空输入区带上下文；取消保留请求；发送后拒绝并在本轮返回反馈，无额外消息；单独拒绝不产生消息；提交中不能批准；重试仍是一条命令。
  • 问题，在真实 Composer 和 QuestionMode 上：上一步、下一步、提交顺序，数字键，自定义和多选，重挂，窄屏和矮屏，折叠，会话隔离，不确定重试，回执。
  • 提及，在真实 hook 和菜单上：查询变化后 Enter 不选旧结果；Escape 在迟到响应后仍有效；失败和空结果回退；查询中和 IME 不提交；卸载抑制迟到工作。
