Responsive composer controls

Each row responds to its own measured width, with no fixed breakpoint: chat and DAG pages have different controls at the same width. Menus, values, keyboard, tooltips and accessible names never change.

Environment row

LevelShows
0Everything
1Names capped near 12 characters with an ellipsis; Local chip icon-only
2Branch names hidden: branch icon and diff badge
3 (data-compact)Every label hidden (status, surface, project, directory, DAG Fit, zoom percentage, Legend); diff badge becomes a half-green, half-red dot

use-compact-environment-row.ts lays the row out per level with transitions off (data-measuring), then animates to the first data-squeeze level that fits clientWidth. It measures the last chip's right edge with auto margins zeroed: that margin makes scrollWidth always fill the row. Roomier levels need 12px of slack. Split panes use the same logic.

Rules

  • One row, never wrapping; no control hidden. Composer height and splitRatio do not change.
  • Labels do not flex-shrink. A capped name ends in an ellipsis. One transition rule, no display:none.
  • Icon triggers keep size, order and operation; chat and execution use distinct icons; effort-icon colour shows the level.
  • Native ResizeObserver and MutationObserver; model, permission and effort state untouched.

Acceptance
  1. Overflow squeezes through data-squeeze to data-compact, with no fixed-width cases or label flex-shrink:1.
  2. All labels share one animation rule.
  3. Past the split-pane threshold, all right-hand settings and left permission and more controls stay visible without overlap.
  4. Permission, chat model, execution model and effort icons each open their menu.
  5. Widening returns all labels; reselecting split, switching chat and DAG, and refreshing preserve this.
  6. Bottom controls have a non-transparent surface at rest, border 0, no shadow, and a stronger background on hover or open.
  7. Reopened Context statistics come from the cache; background completion updates cache and ring.
  8. Cache isolated by session and branch; stale requests cancelled; failed refreshes keep the cache; 32-entry eviction.
