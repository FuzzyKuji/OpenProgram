Git 文件夹胶囊

Git 检出内的工作文件夹，在环境行的胶囊里有一个 git 半边：哪个分支、改了什么，以及聊天需要的几个 Git 操作。

哪些文件夹

文件夹git 半边
主项目文件夹真实项目才有。默认主目录项目没有：那个仓库是 OpenProgram 的存储。
每个附加工作文件夹有
不在 Git 检出内无
同一检出内的两个文件夹只有一个 git 半边：项目优先，然后按列表顺序（git-chip-registry.ts）。不同 worktree 根不同，各有各的。

胶囊

分段内容
文件夹（左）图标、名称；工作文件夹在悬停或键盘聚焦时显示 ✕。打开项目菜单。
Git（右）Solar git-branch、分支名最后一段（claude/foo 显示 foo；分离 HEAD 时显示短提交 id）、未提交的 +N −N
分隔全高发丝线，不占宽度，两侧悬停填充相接；悬停或打开时淡出
diff 徽标绿红两半，与文件改动卡片一致。未跟踪文本文件算新增。只有二进制改动：中性“N 个文件”，3 级圆点为灰色，绝不显示“+0 −0”。干净：只显示分支。
提示仓库、完整分支、计数

components/chat/top-bar/chips/folder-pill.ts。收缩级别见输入框响应式控件。

拉取请求

状态行
已有打开的 PR“查看拉取请求 #N”，在系统浏览器打开
没有“创建拉取请求”：git push -u origin HEAD，对默认分支 gh pr create --fill，然后打开
禁用附原因：没有 gh、没有 origin、分离 HEAD、在默认分支。后端还拒绝没有领先提交的分支。
有未提交改动“提交并让 Agent 开 PR……”把指令放进输入框，不发送

错误

情况卡片
任何错误在菜单底部，菜单保持打开：标题直白，git 输出在“显示 git 输出”文字按钮后
切换会覆盖改动列出文件并提供在 worktree 中打开或带上改动
带上改动依次 stash（含未跟踪）、切换、pop
pop 冲突切换保留，改动留在最新 stash，卡片会说明
不提供强制切换或丢弃

刷新时机

不轮询。胶囊在挂载和文件夹变化、菜单打开（唯一列分支和查 PR 的读取）、轮次结束、窗口获得焦点、项目变化，以及同一检出发生变更（op:git-changed）时读取。

后端

逻辑在 openprogram/state/worktree/folder_git.py；ws_actions/folder_git.py 把它移出事件循环。每个回复都带 path。

Action回复做什么
git_folder_statusgit_folder_statusstatus --porcelain=v2 --branch、diff --numstat HEAD、worktree list、默认分支、origin、gh；带 include_branches、include_pr 时列分支、gh pr view
git_switch_branchgit_switch_branch_resultgit switch [-c] <branch>；带 carry 时前后 stash。拒绝帧：code（overwrite 加 files，或 stash_conflict）、detail

GIT_OPTIONAL_LOCKS=0 让状态读取不与用户的 git 争用。GIT_TERMINAL_PROMPT=0 让需要凭据的推送失败而不是挂起。
