Slash commands and context compaction

Slash commands

When input starts with / and has no space, the menu expands upward; a space closes it over 380ms. Enter runs a registered first word, otherwise sends chat. A menu that is closing does not intercept Enter. Skills, plugins and user commands come from /api/commands; built-ins win dispatch.

CommandSelection or Enter
/compact [keep_recent_tokens]Compacts at once
/rewindWeb: opens a picker of earlier messages and takes no arguments. The default TUI has no such command. Rich fallback only: lists points; /rewind N previews one; /rewind N confirm <plan_hash> <idempotency_key>, as printed by the preview, rewinds
/branch [name]Runs at once
/contextOpens the ring panel
/clear, /newNew conversation
/task, /skill, /mergeFill the prefix and wait for required arguments
/helpSets input to /, showing the menu again; no separate page
/sandboxToggles the system sandbox
/memoryOpens the memory page
/doctorRuns health checks and shows the report locally, never to the model

Optional arguments (only […]) run at once. Without a session, session commands keep the input and warn "Start a conversation first".

Known small issues
  • A registry item also named compact shows twice in the menu; dispatch still picks the built-in.
  • Jump to latest may overlap the menu position.

What compaction sends

One rolling summary. Further compaction combines the old summary and more turns into a new one.

[System prompt] [Current summary] [Recent uncompacted turns] [New user message]

Triggers

TriggerConditionPath
Manual /compactFrom the composer, optionally keeping the latest N tokensaction: compact, handle_compact
Automatic, before a turnBudget at or above context.auto_compact_percent (default 80). Compact.loop_runner.py
Overflow recoveryModel returns 413 or prompt_too_long; at most once per turnreactive.py

All three use compaction_started, compaction_finished and compaction_failed, each with a system message.

Steps

  1. Read rendered history from SessionDB: the summary and remaining turns. Text already covered is not reread.
  2. Threshold. Fewer than four messages: stop; the manual path explains. Already summary plus tail with no valid cut: nothing to compact, no model call.
  3. Summarize with a separate model call. Default tail: 10% of the window, clamped to 8k–40k tokens, at least four non-empty messages. /compact 2000 overrides.
  4. Persist a summary_* node (role=llm, name=context/summary); covers_ids marks the range. Session metadata records it. Old turns stay and HEAD does not move.
  5. Graph. The DAG shows a capsule. The old summary is superseded and stops rendering.
