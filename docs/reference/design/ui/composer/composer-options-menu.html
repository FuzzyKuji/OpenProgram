Composer options menu

The + menu in ControlsCluster. Radix DropdownMenu on the tokens in apps/web/components/ui/menu/menu-styles.ts, like every other menu. No module CSS.

Every row is PlusMenuRow (controls/menu-pieces.tsx): itemCls(false) plus MENU_ITEM_STATES. A 16px Solar icon column, label, optional metadata, check column. Checked rows show a 14px check-circle that pops in once; others reserve the column with CHECK_SLOT_PAD.

Panel
MENU_PANEL: rounded-lg, p-1
Row
itemCls: 28px minimum, rounded-md, base text, hover is the only tint
Separator
MENU_SEPARATOR, full-bleed
Position
Radix portal on body, z-[200], side="top" align="start" sideOffset={9}; radix handles anchoring, flip and collisions

No tool switch

No Tools switch and no Access preset. Which tools a chat can call is the Agent's configuration (Agents → Capabilities → Programs: all, a scope or preset, or none). The composer only overlays Web Search. See tool toggle management.

  • Panel, rows, separators and checks come from menu-styles.ts; composer.module.css has no .plusMenu* rules.
