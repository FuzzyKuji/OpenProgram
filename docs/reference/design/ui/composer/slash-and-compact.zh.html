斜杠命令与上下文压缩

斜杠命令

输入以 / 开头且没有空格时，菜单向上展开；出现空格后 380ms 收起。Enter 执行已注册的首词，否则发送聊天。正在关闭的菜单不拦截 Enter。技能、插件和用户命令来自 /api/commands；内置命令派发优先。

命令选择或 Enter
/compact [keep_recent_tokens]立即压缩
/rewindWeb：打开选择器选一条较早的消息，不带参数。默认 TUI 没有这个命令。仅 Rich 回退界面：列出回退点；/rewind N 预览；/rewind N confirm <plan_hash> <idempotency_key>（预览时打印）回退
/branch [name]立即执行
/context打开圆环面板
/clear、/new新对话
/task、/skill、/merge填入前缀，等待必填参数
/help把输入设为 /，重新显示菜单；没有单独页面
/sandbox开关系统沙箱
/memory打开记忆页
/doctor运行健康检查，在本地显示报告，不发给模型

可选参数（只有 […]）立即执行。没有会话时，会话命令保留输入并提示“先开始一段对话再执行此命令”。

已知小问题
  • 注册表里也叫 compact 的项目会在菜单里重复；派发仍选内置。
  • “跳到最新”可能与菜单位置重叠。

压缩后发送什么

只有一份滚动摘要。再次压缩把旧摘要和更多轮次合成新摘要。

[System prompt] [Current summary] [Recent uncompacted turns] [New user message]

触发

触发条件路径
手动 /compact从输入框执行，可选保留最近 N tokenaction: compact、handle_compact
自动，轮次开始前预算达到 context.auto_compact_percent（默认 80）。压缩。loop_runner.py
溢出恢复模型返回 413 或 prompt_too_long；每轮最多一次reactive.py

三者都用 compaction_started、compaction_finished、compaction_failed，各有一条系统消息。

步骤

  1. 读取 SessionDB 渲染后的历史：摘要和剩余轮次。已被覆盖的原文不重读。
  2. 阈值。少于四条消息：停止，手动路径会说明。已经是摘要加尾部且没有有效切点：无可压缩，不调用模型。
  3. 摘要，单独一次模型调用。默认尾部：窗口的 10%，限制在 8k–40k token，至少四条非空消息。/compact 2000 可覆盖。
  4. 持久化 summary_* 节点（role=llm、name=context/summary）；covers_ids 标记范围。会话元数据记录它。旧轮次保留，HEAD 不动。
  5. 图。DAG 显示胶囊。旧摘要被取代，不再参与渲染。

圆环

右下角：占用除以窗口大小，基于压缩后的视图。低于 50% 绿色，50–80% 黄色，80% 及以上红色。测量、运行状态、无可压缩和“立即压缩”见占用与压缩。
