Effort picker

Layout and timing follow the observed Claude desktop 2.31226.0, written independently. Claude's Ultracode workflow mode has no counterpart: OpenProgram keeps provider effort ids. Options and Recommended come from the selected model; Radix owns pointer and keyboard selection; state flows through composer settings. Fast and help are independent.

Motion

ElementBehaviour
TrackNeutral fill, discrete ticks, clipped fill with an inverse-translated full-width field
HandleWhite; 12% larger while dragging; elastic sub-step feedback; snaps in 120ms
SelectionPreviews while dragging, commits on release. Pointer cancel clears drag feedback.
LabelsFour-layer transition: vertical move, resolving from blur in 200ms

Highest-option field

Runs on the highest of several options (xhigh, max or high). One or zero options never animate.

Cells
Rounded 3px squares on a 4px grid; lavender
Pattern
WebGL2 eight-pulse field propagating from the right, five intensity steps, per-cell brightness drift, premultiplied per-theme colour
Timing
Enters over 700ms; fades over 850ms on leaving, canvas staying full track width
Resolution
Device pixel ratio, capped at 4,147,200 pixels

Lifecycle

CaseRule
AnimationOne animation callback, cancelled on close, unmount, hidden document or reduced motion.
FailureReduced motion disables the field. Canvas failure leaves a usable slider.
AccessibilityTheme colours come from CSS tokens. Named values, keyboard focus and the recommended tick stay accessible.
Acceptance

On the real ThinkingEffortPill: pointer and keyboard select unchanged effort ids; xhigh animates; leaving fades to empty; reopen and model changes work; Fast stays independent; reduced motion gives a stable frame; dark, light and narrow layouts stay legible.

Implementation status

Implemented. Pixel-identical match with the reference is not claimed.
