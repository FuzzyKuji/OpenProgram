References and rejected options

Adopted: xAI's request and actual-tier separation, through OpenProgram's OpenAI-compatible xAI adapter. Rejected: a global Grok name-prefix override, reduced reasoning as a substitute for Fast, a fixed speed multiplier.

Acceptance
  • Capability: xAI API and Grok 4.6 subscription are separate from unknown subscription models; switching routes updates the reason; catalogue failure preserves known support.
  • Composer: keyboard and pointer select speed, reload preserves it, a different model starts at Standard, narrow layouts work.
  • Dispatch: priority only for the selected supported route; queued settings stable; reasoning unchanged.
  • Response: synthetic priority, default, absent, error and cancelled responses keep accurate status, with no duplicate request or invented price.

Implementation status

Gauge, capability, request preference, saved response tier and actual xAI cost are implemented. Live paid calls are not part of automated verification.
