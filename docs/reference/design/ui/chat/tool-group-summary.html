RuleBehaviour
Thinking"Thought" or "Thinking…" only when the group has nothing else
NamesA bucket names its target only with exactly one distinct target. Repeated calls on one file count once. Files show the basename, search patterns are quoted and cut to 24 characters, fetches show the host, commands are never named.
NumbersEnglish: "a"/"an" for one, digits above. Chinese: always digits with a measure word.
FailuresMuted red "· N failed" after the label. A failed call counts in its bucket and adds nothing to the badge.
RunningThe bucket of the call in progress moves to the end, in the present tense with "…"; the shimmer stays. When the call finishes it returns to past tense at its first position.
WidthOne 28px line. The label has min-width:0 and a CSS ellipsis; failure note, badge and chevron are flex:none. No character budget.
HoverNo tip: transcript content, and expanding shows every call
Stringstext(en, zh). Each bucket has a past and a present form, each with a one-target and a count variant.

Change badge

Shows when at least one file-writing call succeeded and every successful one has known counts. Sums them, shows zeros (+16 −0), reuses the .turn-files-diff pill.

ToolCounts
apply_patch+ and - lines of the patch body. Exact.
editLine diff of old_string against new_string, times the replacement count. Above 2,000 lines a side: plain line counts.
writecreate in turnFiles: +lines(content) −0. modify with every write to the path in this group: the turnFiles numbers. Otherwise unknown, and the badge waits for the turn to settle.

Before turnFiles exists, a write is "Created" only if the turn has not read or edited that path. modify makes it "Edited".
