附件处理

加入方式输入框模型收到之后重新打开
粘贴截图图片，随聊天保存图片内容，加上路径同一张截图
拖入图片图片，已存聊天副本立即收到图片内容发送时的版本，原文件改动或消失也不受影响
文本、代码、数据原文件引用路径，按任务读取。不上传、不复制、不把文本放入请求原文件当前内容；文件不存在时明确报告
PDF、Word、Excel原文件引用路径。助手选择按页读取、段落提取或表格分析。加入时不解析；缺工具或扫描件不可读时说明原因默认无副本
文件夹project/ · 文件夹第一层清单（最多 200 项、8 KB），再按需打开文件清单文本，不是文件夹副本
限制或例外规则
图片大小原图最多保留 32 MiB。发给模型的版本最多 5 MiB，超出时等比缩放。这是应用限制，不是自动发现的模型限制
模型不支持图片输入这一轮停止，并提示 “The selected model does not support image input. Choose a model that supports images.”
浏览器选择、没有本机路径的文件由后端保存：单文件 32 MB，单轮 64 MB

文件在聊天中的显示以及 Agent 如何回传文件：聊天附件。不涉及远程连接功能。

所有附件共用的规则

规则说明
失败发送确认前，文字和附件都保留。上传、读取和发送失败都说明原因。断线后先查上次结果，避免重复发送
版本引用会随编辑、移动和删除变化。保存的副本固定版本。清单和摘录都不是文件副本
附件文本是提供的材料，不是新的用户指令
分开处理聊天持久化、图片传递和文件读取分开处理。把所有图片压到执行输入上限并不够，复制所有本地文件也不是解法

输入框附件条

部分规则
名称单行截断；格式和大小始终可见
第二行已确认的格式，未知时写“文件”。文件夹写“文件夹”，不编造大小
缩略图图片等比显示，不大幅圆角裁切。其他文件用带格式文字的图标，不只靠颜色区分
项目主体打开预览或详情：完整名称、位置、大小、副本状态。移除始终可见，是单独的可键盘操作
项目很多时统一换行，最多两行（112 px），之后滚动，文本区始终可用
读取中或失败显示在该项上，高度不变。说明为什么不能发送；只需重新添加或移除失败项，其他项不动

排队消息

运行中输入的消息集中在输入框上方的一张浮起卡片里，位于滚动对话之外。每条消息保留自己的身份、顺序、附件和设置。

方面规则
行一行：标签（“下一轮”，或未发送的原因）、文字、悬停操作（加入本轮、重试、编辑、移除）。点击文字展开完整消息和附件
卡片高度有上限。标题可折叠；全部清除移除未在编辑的行。拖动或 Alt+↑/↓ 调整发送顺序
捕获内容文字、展开后的粘贴内容、附件字节或原始路径、发送设置。附件可以排队而不启动新的执行
编辑文字、选择文件、拖入文件、预览、移除单个附件。该行保持到保存（保留位置和原设置）或取消（保留原内容），期间不发送
加入本轮附件一起带上：保存到会话并以路径写入文字，图片保留到下一个安全点给模型。编辑或移除投递未确认的行时，先把消息从本轮收回；本轮已收到的保留
发送走普通聊天发送和附件封装，按顺序，使用编辑后的确切内容。失败或被拒时保留整条消息，被接受后才释放
保留范围刷新、关闭窗口、重启 App 后都在。行存 localStorage，字节存 IndexedDB；窗口在一把独占锁下接管无主的行。发送前先移除该行：崩溃可能丢这一次发送，但绝不重复
排队附件的预览和限制
  • 未发送的预览使用捕获的本地内容，包括会话工作目录之外的本机路径：图片和文本直接渲染，有大小上限的 PDF 用本地 Blob URL。
  • 本机文档发送时仍是路径引用；预览字节不扩大后端文件访问范围。
  • 已持久化的附件沿用只读的 DocumentWindow。预览缺失或不支持时说明限制，附件保留。
  • 对话中的用户消息保留各自的控件和气泡，纵向间距收紧。历史编辑仍是分叉后重新发送。
  • 队列不删除历史、不改变模型行为、不合并指令、不修改审批决定。
  • 布局参照用户对 Codex 的描述：保留消息靠近输入框、占位小。不假设 Codex 未公开的存储或编辑行为。
未采用的方案
场景方案取舍
粘贴截图保存后由工具按需读取推迟读取，但多一步工具调用；没有工具就无法分析
拖入图片引用原文件，按需复制省存储，但原文件移动或删除后可能打不开，之后读到的是编辑后的内容

其他实现
项目观察结果
Codex 公开终端，不是桌面 UI选择文件时插入路径；可解码的图片成为图片输入；剪贴板图片写成临时 PNG。桌面端的长期副本策略未确认。有多种图片处理模式，按能力和配置选择；工具的默认尺寸不等于所有模型的限制。文件选择 · 剪贴板 · 图片指南 · 图片准备 · 图片输入
OpenCode V2受支持的文本附件包含其文本；目录包含非递归清单；PNG、JPEG、GIF、WebP 成为图片媒体。SVG 按文本；PDF、音视频和其他二进制不直接进入模型请求。服务器可访问的文件可被引用。可配置的缩放不保证满足每个模型的限制。附件指南
OpenClaw频道媒体下载到运行时。支持视觉的模型可收到图片；其他配置生成描述。文档可提取文本，扫描件有配置的页面图回退。交给工具需要可访问的保存路径。频道接收限制不是通用模型限制，也不等同于本地拖放。媒体 · 理解

临时存储、上传到运行时和聊天长期保留是不同的承诺；来源未说明的保留期限不做推断。
