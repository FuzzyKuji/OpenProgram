聊天引用与消息编辑

引用选中文字

方面规则
显示松开指针或键盘选择完成后，在选区上方显示加入当前聊天
隐藏拖动过程中、再次按下指针、选区取消时
结果向该会话的草稿追加 Markdown 引用块并聚焦其输入框。原有草稿和附件保留；发送由用户决定
唯一入口消息操作行没有引用按钮
归属每个窗格明确对应自己的会话，引用回到来源窗格。独立的侧边对话窗口不在范围内
工具条外观与图标
  • 一个紧凑操作，外边距 3 px，圆角 8 px，细边框和阴影，不透明、跟随主题的弹层背景。
  • 悬停和按下混合实色主题色，不用半透明覆盖层。键盘焦点有可见轮廓。
  • QuoteIcon 在共享 animated-icons 组件中。上游图标目录没有 Quote，所以用官方 Lucide 字形，配共享的 start/stop 接口和 CopyIcon 的弹簧与位移。
  • 整个按钮在悬停和键盘聚焦时驱动动画，两者都结束后复位。禁用控件和减少动态偏好下图标静止。

编辑已发送的消息

方面规则
编辑器内联，与底部输入框相同的文本框、文件提及选择器、附件处理和预览条
附件已有附件可移除；图片和文档可选择、粘贴或拖入。URL 仍是可编辑文本
取消只放弃这次编辑
保存并重新发送通过 POST /api/chat/edit 创建同级分支
失败保留编辑内容，显示可重试的提示
存储与权限
  • 上传字节走有上限的附件持久化和图片分发路径。保留的图片副本经授权的原始文件 API 读取；保留的旧式附件块不损失内容。
  • 不自动提交，不增加权限模式。

实现状态

已实现。浏览器测试覆盖引用时草稿保留、分屏归属、内联附件编辑、失败保留，以及图标在普通和减少动态下的表现；REST 测试覆盖编辑附件的校验和分发。
