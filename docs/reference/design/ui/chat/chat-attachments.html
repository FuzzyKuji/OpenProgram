Chat attachments

One text marker carries every file in a message:

[attachment: notes.txt (txt, 18 KB, 4210 lines) @json "/abs/path/notes.txt"]

Written only by format_marker in openprogram/state/attachments.py; a fifth source calls it too. Read on the web only by parseAttachments. An optional @previewjson names a saved preview. The older @ /abs/path spelling stays readable. How content enters model context: Attachment handling.

Channel text is prefixed with [display name (id)] and markers follow. _one_line removes brackets from the name so a prefix cannot be forged. Unnamed pasted images get an extension from their media type.

HTML sandbox and archives
  • GET /api/file-page serves only .html and .htm, with sandbox allow-scripts and no allow-same-origin. A srcdoc frame would inherit the app's script-src 'self' and a script-drawn page would be blank.
  • The page has an opaque origin: no access to the app or its storage, its Origin: null requests are refused, it cannot navigate or open windows. Relative files are missing from the strip because the strict cookie is not sent; the page opened in a browser tab has them.
  • FileViewer sends a zip or tar to ArchivePreview: full tree on the left, the selected member on the right through the same FileViewer. Nothing is extracted to disk.

Target design

Any file, from any source, opens through the same viewer in every interface. User and agent files differ only in their source field.

CapabilitySolvesTodayWhy deferred

Excluded: global content-addressed blob storage. Each session workdir is committed every turn and stays replayable, so large binaries staying in git history is the accepted cost.

Instruction-line and implicit designs all keep paths inside allowed roots, resolving symlinks first.

Other techniques

  • Output as a page: openclaw serves canvas documents embedded with [embed ref=…]; Codex materialises ::codex-inline-vis{ in a sandboxed viewer (2 MB, strict CSP); pi-mono's /share publishes a session as a private gist.
  • Signed tokens: openclaw's mediaTicket, v1.<payload>.<signature>, five-minute TTL.
  • Chips as editing units: claude-code sends an image only while its [Image #N] stays in the text.
  • Hermes rewrites host cache paths to container paths. Codex has view_image.
