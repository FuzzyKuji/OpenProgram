会话记录跟随

App 和浏览器共用一套由 React 持有的策略：发送就是跳到最新，模型输出不是。

什么叫最新

主会话并排会话
留白max(25vh, overlay + 24)--peer-composer-h = overlay + 24
浮层--main-composer-height输入框根节点的 offsetHeight；不用 --peer-composer-h
容差留白 − 浮层 + 824 + 8

latestScrollTop = max(0, scrollHeight - clientHeight)。isChatAtBottom：剩余滚动量 ≤ 容差。

谁写滚动位置

负责方职责
useChatAreaStick唯一的跟随写入方：主会话和并排会话的定位、发送、跳到最新、贴底状态、每个视口待完成的最新页加载
chat-scroll.ts几何计算、take-latest 标记、保存的位置、跳转动画。resolveChatScrollTop 决定切换 key 时的位置
history-viewport.ts历史窗口替换时恢复锚点；唯一的另一个滚动写入方，不是跟随策略
useHistoryWindow、history-autoload.ts有界分页和预取；不写滚动
loadSessionHistoryWindow发布消息行和窗口元数据；不定位到最新
WebSocket 处理函数不滚动，也不写标记

什么会移动视口

入口贴底动作
发送：输入框提交、欢迎页首条、真正调用 sendChatMessage 的队列出队、被接受的排队或转向、斜杠或内置命令提交在最新窗口上立即为真。在旧窗口上保持假，跳转按钮保留，最新页加载后为真瞬时定位，锁定。定位时才隐藏跳转按钮，等待时不隐藏
跳到最新（主会话：挂在 #chatView 上；并排会话：头部按钮，无挂载、无实时条）确认最新已在屏幕上后为真等最新页，再原生平滑滚动，不预先定位；减少动态时瞬时。完成判定
滚轮、指针、滚动键isChatAtBottom 且在最新窗口。向上脱离，回到容差内重新贴底无。取消待完成的工作
增长：流式、工具、KaTeX、行回收、留白或输入框尺寸变化不变。滚动事件只有在顶部上移时才算离开最新仅在贴底、最新窗口、无跳转进行中，且距真实指针、滚轮或滚动键输入超过 600 ms 时贴到最新
切换会话（chatKey 变化）见恢复不算发送。待处理标记只转给这份草稿采用的会话
非发送或跳转引起的历史窗口加载设有 after 时为假，否则按几何判断按区域恢复锚点；较旧和较新的页不当作最新来贴
远端 local_command、压缩、状态、跟进、chat_response不变只通过贴底时的增长

把行放进队列不算发送。附件加载中或失败时，在创建队列项、清空草稿和发布标记之前就被拒绝；已有标记及其代数不变。

发送锁定

时机发生什么
提交提交路径追加本地轮次，然后调用 noteTakeLatest({sessionId, scrollerKey, turnSeed})。key 来自捕获的会话和 background，不读实时的 activeChatKey；send-queue.ts 不感知它
通知 hookchatKey 等于 scrollerKey 的 hook 看到比已应用代数更新的标记。即使没有行变化，发布也会通知它
设有 after 或 loading保持脱离，保留跳转按钮，不动旧页，在布局 effect 之外等待已确认的最新窗口
到达最新后无视 600 ms 窗口和当前几何，直接贴底，再 snapToLatest

跟随操作的生命周期

标记标识一次发送，不是永久的滚动许可。每个异步完成、尺寸定位、欢迎页重试和动画回调都先检查会话、滚动区 key、代数和交互 epoch。

事件结果
更新的发送替换该滚动区的旧操作
发送等待中点跳转替换它
跳转中发送停止原生动画，再瞬时定位
滚轮、触摸或指针滚动、滚动键让待完成工作和重试失效；由几何决定贴底。延迟增长绝不重新贴底。程序触发的滚动事件不算取消
key 变化或真正卸载让离开方的操作失效；已完成或已取消的标记不重放
Strict Mode 清理取消该 effect 的资源；setup 恢复仍有效的操作，不重复发送，不丢重试，不留孤儿请求
请求进行中，after 尚未设置after || loading 进入等待。被取消或失败的请求不留重试，也不能隐藏跳转按钮；旧的完成不能清掉新手势
会话显示前的欢迎页首条待处理交接保留到它的视图，重试一次，并在临时会话绑定为真实会话时保持身份：只限这份草稿采用的会话，不是任意 local_* key
删除会话、丢弃草稿清除该会话的标记
标记的存储
  • 按 (sessionId, scrollerKey) 存，同一会话的主会话和并排会话互相独立。
  • 读取不删除。完成和取消单独记录，每个视图有已应用代数；开始加载最新页不算完成。
  • 没有视口的空闲已完成标记上限 32 个；等待中的保留。释放视口后在本轮结束时清理，同一 tick 内重新挂载可以留住。
  • turnSeed 是被接受的乐观轮次，不是 ack 后的最后一行。
  • 没人请求的最新页（续期、重试）会给每个没有跟随锁的视口写一个标记。

跳转完成

  • 跳转进行中，尺寸变化只记录新目标，不贴底。
  • 动画结束或 700 ms 看门狗到时，重算当前目标并做一次瞬时修正，误差 2 px 内；这里不用重新贴底的容差。
  • 之后操作仍有效才隐藏按钮。减少动态时做同样检查。
  • 取消会停止浏览器动画和回调；被取消的操作不修正。

回到一个会话

情况打开位置
新的 App 或网页文档最新；忽略其他运行实例的保存状态
首次打开或没有保存位置最新，并跟随延迟布局和文件卡片增长
离开不足一小时，当时在跟随最新，并跟随延迟布局
离开不足一小时，当时在看历史保存的偏移和历史锚点
离开满一小时最新
应用失焦一小时后回来最新。没有定时器移动正在看的会话
缺少新鲜度信息的旧记录最新
首次打开已加载的旧窗口保持脱离、不定位，直到发布已确认的最新响应

按视口保存在 sessionStorage 的 chatScrollByKey：偏移、贴底意图、时间戳、运行实例标识。离开、隐藏或卸载时记录离开时间。带 data-self-update-verification 时跳过。阈值是 CHAT_READING_POSITION_TTL_MS。

细节
  • 恢复到最新时清除历史锚点，并使用可取消的最新窗口加载。用户手势取消待跟随；保存的像素偏移不是最新锚点。
  • 空会话也保留最新意图：在 ResizeObserver 回调前提交的行保持跟随状态。高度增长不算阅读手势。
  • 加载器不用旧像素覆盖最新定位，重载也不安排第二次像素恢复：缓存的偏移可能超过较短的最新页。
  • 位置未变时，重载保留跟随状态。欢迎页发送在激活期间保留，直到视图就绪。
旧版文件改动摘要
  • 只在接近视口时加载，然后存在会话消息存储中。卡片重新挂载时立即显示结果，包括确认为空的结果。
  • 错误可重试。已中止或过期的响应不会更新别的会话。
  • 历史预检保持新鲜，撤销授权仍在服务端；摘要只是描述，不是撤销许可。

历史窗口

  • 较旧、较新和定位窗口替换：每个已注册区域在更新前捕获自己的锚点、顶部和高度，flushSync 后仅在仍为同一会话和 chatKey 注册时恢复。行高缓存用该区域自己的 key。
  • 失去注册的区域不恢复。未注册的 #chatArea 回退只在捕获时没有任何注册、且节点仍是活的主滚动区时适用；仅仍在文档中不够。
  • 持有跟随锁的视口跳过恢复。
  • 主会话和并排会话共用行：未发起请求的窗格保持自己的锚点。锚点被淘汰时，保持到留存一端的距离。结果为负（过期快照续成最新页）时显示新窗口的末端，而不是顶部。

失败与边界

情况行为
最新页加载失败或已过期脱离，跳转按钮可见，不动旧页；失败时结算标记
存储写入失败吞掉
虚拟化回收保留已测量的占位，使 scrollHeight 准确；回收后贴底。不用虚拟列表库
宽度变化已测高度保留为估计值，整个列表不重渲染。变化期间区域带 data-width-settling，屏外行用 content-visibility: auto。静止 120 ms 后第一条可见行保持位置，贴底时除外
KaTeX在被观察的列上 typesetMath，位于贴底路径内；不扫描整个文档

不跟随：DAG 条展开、压缩折叠 easeScrollBy / pinWhile、返回父节点 scrollIntoView、消息导轨定位、分支切换 _postCheckoutScrollTo。CLI 的 ScrollBox 是另一套。后端协议不变，占用、队列准入和 ack 配对不受影响。
