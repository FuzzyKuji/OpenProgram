Indicator dots

Every status and activity dot is .indicator-dot (apps/web/app/styles/chat/execution/indicator-dot.css). The outer box always has the width of a ● at 14px font, so dots line up with header glyphs and across rows with no per-site nudges. ::before paints the disc and carries the animation, so the layout slot never moves.
