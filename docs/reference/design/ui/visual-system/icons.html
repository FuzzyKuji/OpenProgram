The composer's fill rule

Applies inside the composer and its popups: chips, control row, menus, effort capsule, context-usage card, Goal dialog. Question and approval cards sit under the reply and keep their sizes.

Box
16 × 16px
Measure
The painted ink, not the view box
Scale
s = 16 / max(inkWidth, inkHeight)
Place
Ink centre on box centre
Hover
18 × 18px on the control's hover (HOVER_POP_FILL, 1.125)

A wide glyph is 16px wide (WeChat 16 × 13.1px), a tall one 16px high.

DrawingHow
SolarSolarIcon fit="fill" crops the view box to a square round the ink. Bounds in solar-icons/ink-bounds.ts, generated by rasterising bodies.ts (the 50% layer counts): npm run generate:solar-ink-bounds --workspace apps/web.
Brand logosBrandMark fit="fill", through ModelMark and ChannelLogo fit="fill", from brand-mark/ink-bounds.generated.ts
Agent charactersfit="mark", botMarkFit in components/avatar/bot/catalog.ts; body as ink. Uploaded picture, letter tile or DiceBear already fill the box and only pop.
Anything elseFillIcon (components/ui/fill-icon.tsx) crops an svg to geometry plus half stroke, fits an image or canvas whole. App icons and favicons are runtime rasters with no measured ink. The context ring only takes the hover.
Exceptions
  • Send plane: grows to 18px like the other composer glyphs, and does not glide.
  • Stop: 8 × 8px square in a 16px box.
  • Trailing chevrons, menu checks: static lucide at 16px.
  • Chip's sliding ×, capability marks, effort gauge and ?, drop overlay's paperclip: their own sizes.
  • Outside the composer a Solar glyph draws its whole view box (ink 20/24) and pops 1.12 (HOVER_POP).

Brand marks

Provider logos (public/images/providers) and channel logos (public/images/channels) are drawn only by BrandMark (apps/web/components/brand-mark). One-colour logos are masks in text or brand colour; coloured logos are the picture. Outside the composer: fit="contain", no hover motion.

Execution timeline

Each row starts with a 24px tinted tile (20px nested) holding a 13px glyph (11px nested), static (motionPreset="none") with no tooltip. presentTool() in components/chat/messages/execution/tool-presentation.ts picks the glyph; StepRow in execution-strip.tsx falls back by row kind.
