间距和圆角

Tailwind 的间距单位在所有界面上都是 4px（p-2 = 8px），因为默认的 0.25rem 在 14px 根字号上会落到半像素。手写 CSS 尽量用整数倍的 px。

档位大小用于
2xs2px细条、进度轨、光标、提示箭头
xs4px标签、kbd、复选框、行内代码、徽记
sm6px行内的芯片和小控件
md8px所有 Button、输入框、选择框、手写按钮
lg10px列表行、菜单、弹层、Select 弹出、卡片
xl12px中间卡片、分栏面板、页面面板、对话框
2xl16px用户气泡、大型浮层
full9999px胶囊、头像、圆点

CSS（var(--radius-lg)）和 Tailwind（rounded-lg）用同样的名字。--ui-button-radius 是 md，--ui-list-radius 是 lg。允许按盒子比例（50%、方圆的 26%）和基于档位的同心 calc()。来自没有档位的表面的圆角用 shape: 注释说明。

哪一层写什么

写法负责不做
components/ui 里的 shadcn 部件所有控件：按钮、输入框、选择器、菜单、弹窗、开关、复选框—
JSX 里的 Tailwind 类布局和间距（flex、grid、gap、padding、尺寸）、简单状态复杂选择器
组件旁边的 *.module.cssTailwind 表达不了的：伪元素（项目引导线）、data-* 和父级选择器、关键帧、分层层叠手搓控件、写死数值
仍留在模块里的布局规则

约 280 条单类、纯布局规则保留。Tailwind 工具类在 @layer utilities，模块规则不分层，所以移走的规则会输给元素上每条不分层规则。

以下情况留在模块：类名在样式表中更早出现、元素自己合并类名（DialogContent 保留 sm:max-w-*）、另一个模块类设置了相同属性、样式对象被重新导出或整体传递。组件被编辑时才移动；守卫确保数量只减不增。

守卫

apps/web/scripts/ui/check-design-tokens.mjs 由 npm run check 运行，扫描所有样式表和 .ts、.tsx 文件。apps/web/tests/ui/ui-kit-is-nova.test.mjs 拒绝字面量控件高度。

类别拒绝
字体不在 --fs-* 档位的字号、任意 text-[…]、自带 text-xs 到 text-2xl、手写字体、font 简写、强制 tabular-nums（字体和数字样式由设置决定）
字重400、500、600、700 以外的值
圆角px、任意 rounded-[…]、裸 rounded、rounded-3xl 及以上、--radius、非档位的 --radius-*
墨色--text-tertiary、--text-dim、text-[var(--text-*)]、components/ui 之外的 shadcn 墨色名
图标28 以下且不是档位的 size
颜色app/styles/themes/、app/styles/design/ 和 app/styles/ 的自定义属性行之外的 #hex、rgb()、hsl()
模块布局超过 apps/web/scripts/ui/module-layout-baseline.json 允许的纯布局规则；新模块不能有。node apps/web/scripts/ui/check-design-tokens.mjs --write-layout-baseline 下调数字
具名例外
  • 接受像素的 API：xterm、Mermaid、canvas、Electron 视图。
  • Agent 卡片上 Framer Motion 的数字圆角。
  • 输入框：圆角、字重和图标保持原样。
  • 写有 glyph:、shape: 或 mask: 的行。
  • COLOUR_DATA：用户选择的调色板和图表系列、美术图（Launchpad 和记忆图标、代码雨、搜索引擎图形）、接受颜色字符串的 API（canvas、WebGL、xterm、Mermaid、pdf.js、web manifest）、用 hsl() 计算的努力度热度色。
