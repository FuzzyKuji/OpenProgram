状态圆点

所有状态和活动圆点都是 .indicator-dot（apps/web/app/styles/chat/execution/indicator-dot.css）。外框宽度始终等于 14px 字号下 ● 的宽度，圆点与标题字形、各行之间都能对齐，无需逐处微调。::before 画圆盘并承载动画，布局占位不动。

修饰类效果
无（md）12.8px 外框内 10px 圆盘（inset 1.4px）
.sm10px 外框内 6px 圆盘（inset 2px）
无颜色修饰currentColor，默认 --accent-blue；父元素可用 color 指定色相
.--ok .--warn .--err .--neutral--dot-color 分别取 --accent-green、--accent-yellow、--accent-red、--accent-blue
.pulse-opacity透明度 1 到 0.4，1.5s，循环
.pulse-scale缩放 0.85 到 1.15，1.4s，循环

使用方：cards/attach-card.tsx、输入框环境行、右侧栏运行面板、lib/runtime-bridge/ui.ts 和 DAG 渲染器（dag/render/agents.ts、dag/graph/nodes.css）。
