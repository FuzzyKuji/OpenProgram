共享文件类型图标

FileTypeIcon（apps/web/components/files/file-type-icon.tsx）绘制 Pierre Trees（@pierre/trees，Apache 2.0，保留 NOTICE）的完整彩色图标集，上游 SVG 路径和文件名映射不改。图标是可见文件名旁的装饰，对辅助功能 API 隐藏。

方面规则
界面侧栏和中央文件页（共用 FileTree，Pierre 的 React 渲染器）、文件标签、分栏选择器、审查列表、输入框文件建议
尺寸文件行 16px，标签 14px；行高、缩进和文件夹控件不变
匹配统一路径分隔符和大小写后取 basename。精确文件名优先于扩展名；带点的父目录不计。
特殊名称AGENTS.md 用 Markdown，CLAUDE.md 用 Claude，Git 元数据用 Git
未知文件中性文档图标
constructor 这类名称与继承对象属性同名的文件名和扩展名，进入解析器前就取默认图标
颜色浅色和深色主题下都能辨认
文件夹、控件Lucide，不变

文件名或路径 → basename → FileTypeIcon → SVG。不读文件内容，不联网，不加状态、持久化、权限或修改 API。不影响附件上传状态、文件缓存、草稿、审查状态，以及文件夹展开、辅助线、搜索和打开；以现有标签和焦点行为为准。

对比过的来源
来源结论
已安装的 Codex默认文件、Markdown 和 Python 的文件树资源与 Pierre 的 SVG 一致。OpenProgram 用公开上游图标集，不从 Codex 分发包提取任何资源。
React SymbolsMIT 的 React SVG 库，支持文件和扩展名解析；未采用
Material Icon Theme带 manifest 的文件与文件夹 SVG；需要资源集成，不能直接用 React 渲染
只用 Lucide通用轮廓分不出语言类型

验收

  • Python、TypeScript、shell、JSON、Markdown 和 Git 示例解析为各自不同的 SVG。
  • CLAUDE.md、AGENTS.md、大写扩展名、Windows 路径和未知类型渲染正确。
  • 上述界面都用共享渲染器；展开文件夹和打开文件的行为不变。
