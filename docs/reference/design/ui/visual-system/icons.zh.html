图标系统

每个家族有自己的地盘，同一屏不会无意间混用填充和线条图标。没有人手写图标 SVG。

家族范围来源、许可
Solar Bold Duotone输入框区域（胶囊、控件行、加号菜单、模型和权限徽章、思考力度、发送）、提问与审批面板、时间线行方块、操作菜单、DAG 视图控件和视角条apps/web/components/solar-icons，CC BY 4.0
pqoqubbw 动态线条应用外框：左侧导轨、中间标签、侧栏、设置导航、函数卡片。不打算迁移。apps/web/components/animated-icons，MIT
lucide-react其余不需要动效的地方：设置内容、对话框、时间线折叠箭头lucide-react，ISC

Solar 图形由 apps/web/scripts/icons/fetch-solar.mjs 从 Iconify 收录到 bodies.ts：扩展 ICONS，重跑，提交，构建无需联网。填充字形加一层 50% 浅色，因为线条图标在 14 到 16px 下显得普通。用户头像来自 DiceBear；Agent 头像是角色（Agent 头像）。

图形做法
SolarSolarIcon fit="fill" 把 view box 裁成围绕墨迹的正方形。边界在 solar-icons/ink-bounds.ts，光栅化 bodies.ts 生成（50% 层也算墨迹）：npm run generate:solar-ink-bounds --workspace apps/web。
品牌标志BrandMark fit="fill"，经 ModelMark 和 ChannelLogo fit="fill"，数据来自 brand-mark/ink-bounds.generated.ts
Agent 角色fit="mark"，components/avatar/bot/catalog.ts 的 botMarkFit；身体作墨迹。上传图、字母方块或 DiceBear 本来就填满方框，只放大。
其他FillIcon（components/ui/fill-icon.tsx）按几何加半个描边裁剪 svg，图片或 canvas 整体放入。应用图标和 favicon 是运行时位图，没有测得的墨迹。上下文圆环只响应悬停。
例外
  • 发送纸飞机：和输入框其他图标一样增大到 18px，不滑行。
  • 停止：16px 方框内 8 × 8px 方块。
  • 行尾箭头、菜单勾选：静态 lucide，16px。
  • 胶囊滑出的 ×、能力标记、力度仪表和 ?、拖放浮层的回形针：保持各自尺寸。
  • 输入框之外，Solar 图标绘制整个 view box（墨迹占 20/24），放大 1.12（HOVER_POP）。

品牌标志

供应商标志（public/images/providers）和渠道标志（public/images/channels）只由 BrandMark（apps/web/components/brand-mark）绘制。单色标志是文字色或品牌色的遮罩；彩色标志就是图片本身。输入框之外：fit="contain"，悬停不动。
