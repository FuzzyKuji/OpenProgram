设置里的外观

设置打开时在通用页。所有与外观有关的设置都在外观页（appearance-section.tsx）：配色和主题、文字、对话视图和宽度、标签拖动效果、浏览器书签栏、自定义 CSS。主题包、强调色和覆盖层合同见主题系统。

控件行为
模式自动跟随系统；它是模式，不是主题
Vivid 标签栏颜色Vivid 的表面、文字层级和默认强调色都是 oklch(from var(--tabrow-seed) …) 色调，与 Chrome 的配色主题相同
强调色颜色输入、来自各主题包默认 --accent-orange 的预设、恢复主题默认
覆盖层启用自定义 CSS；插入模板写入针对 html 和当前 data-theme 的起始片段；清除则清空

桌面窗口外观

Electron 窗口的第一个像素就与解析后的 Web 主题一致：BrowserWindow 用该主题的 --bg-primary 创建。

方面行为
解析Schema 3 键加旧 agentic_theme。来源优先级见排查。auto 跟随 nativeTheme.shouldUseDarkColors。
颜色表apps/desktop/main/windows/theme-chrome.js 复制主题 CSS 的取值。custom id 解析为 beige 一对。
错误页和列表页使用同一组外观令牌
切换主题渲染进程调用 theme.setChrome，更新每个 BrowserWindow 的背景，下次显示或刷新不闪旧色
窗口状态不受影响，见窗口状态
