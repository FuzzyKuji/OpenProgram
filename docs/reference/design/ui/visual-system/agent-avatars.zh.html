Agent 头像

每个 Agent 的名字旁都有一张图。没设置过的显示由 id 派生的角色，所以任何界面都不会退回通用图标，已存储的 Agent 也无需迁移。Agent 使用与个人头像相同的 Avatar 和 AvatarConfig（apps/web/components/avatar/）；角色只是 dicebear、upload、letter 之外的又一种 kind。

角色

组成取值
形状22 种：chat、controller、mug、lightbulb、sprout、watering-can、barbell、book、brain、bull、bunny、camera、cat、cloud、ghost、magnifier、paint-brush、palette、rocket、shield、star、witch-hat
颜色8 种具名颜色：blue、orange、green、violet、pink、teal、yellow、red
眼睛白色
状态idle、thinking、happy

目录：components/avatar/bot/catalog.ts。颜色按名称保存，用固定十六进制值绘制；角色图是唯一不跟主题的地方。卡片、圆环和文字仍用主题 token。

存储

  • {} 表示没有自己的头像，是默认值。更新时整体替换。
  • API 严格校验，不合格返回 400（openprogram/runtime/agent_registry/manager.py 的 validate_avatar）。加载时宽松：不再合格的已存头像读作 {}。
  • Agent 选择器限制上传 256 KB，因为每次列表都带这张图。
  • 试用对话的配置快照不含头像。

渲染

模式绘制内容何时
静止一张静态 SVGAvatar 的默认
活动一个会眨眼、晃动、东张西望的 canvaslive；AgentAvatar 的默认

渲染器：open-bot-avatar，由 bot/runtime.ts 首次使用时加载。BotAvatar 挂载到指定大小的宿主元素。活动角色共用一个动画循环，离开屏幕或页面隐藏时暂停，减少动态时显示静态图。

轮廓本身就是图：不裁圆，没有底板。上传和生成的 Agent 图保留圆角方框。app/styles/design/icons.css 让角色在把 svg 当图标定尺寸的控件里保持身体框大小。

预热：不在一帧里准备形状

渲染器首次绘制时从轮廓推算形状体积，每个形状 25 到 90 ms，在页面生命周期内保留。十七个 Agent 同时出现要在一帧里花半秒以上，静态图也需要同样的准备。

bot/warm.ts 每个任务准备一个形状：等待中的放到下一个任务，其余在渲染器加载后的空闲时间。准备好之前以及服务端标记里，角色是渲染器将要使用的框里的扁平图形；渲染器在同一次提交里替换它。

四处张望

内置的空闲游移在图标尺寸下只移动眼睛约一像素，同形状步调一致。bot/wander.ts 让每个角色有自己的 lookAt 目标：

方面数值
停留0.9 到 2.6 秒
范围x 最多 0.95，y 最多 0.6；至少偏向一侧约三分之一
看正前方四次里一次
成本每个角色一个定时器，每次张望触发一次；随机起始和停顿
情绪思考或开心时保持姿势

followPointer 保持关闭：跟随光标显得在盯着用户，还会每帧调用 getBoundingClientRect。

视觉大小

各图形在 100 单位的框里留白不同：云 82 x 52，幽灵 54 x 76。BotAvatar 有指定大小的槽位和其中的身体框，渲染器按实际显示大小绘入身体框。

适配用于规则16px 的云
botFit其他所有地方几何平均边长为槽位 0.8，任一边不超过 0.94，居中（来自 BOT_EXTENTS，有测试校验）约 15 x 9.5px
botMarkFit，fit="mark"输入框 Agent 芯片、Agent 菜单行（填充规则）长边等于 16 x 16px 槽位，居中16 x 10.1px

上传、字母和 DiceBear 头像本来就填满槽位，fit="mark" 只给它们 18px 的悬停。

悬停

槽位随控件弹起，与图标完全相同：components/ui/hover-pop.ts 保存可点击宿主选择器、1.12 倍比例和弹簧，SolarIcon 和 BotAvatar 共用。控件之外按自身悬停。输入框 Agent 芯片和 Agent 菜单行里长到正好 18 x 18px（HOVER_POP_FILL）。减少动态时关闭。

AgentAvatar 默认活动；选择器的形状卡是样例，不代表 Agent。只有 id 的界面用 AgentAvatarById，读共享的 useAgents 列表，加载前显示 id 的角色；Agents 页写入同一缓存。

Agents 的页面图标（导航入口、中间标签）和子 Agent 工具调用的 ghost 表示一类事物，仍是图标。

彩色芯片里的扁平图形

bot/glyph.ts，React 里是 BotGlyph：身体路径用当前颜色，眼睛镂空。轮廓顺时针，眼睛下身体的环绕数为 1，所以每只眼是逆时针胶囊，nonzero 填充把它挖掉；有测试检查每个形状。视图框按 botFit 贴合身体。

它不动，像 Solar 图标一样克隆进图的 SVG，颜色取分支色（图渲染）。主 Agent 的图形是对话 Agent 的角色（useConversationAgentShape；用上传或生成图的 Agent 用其 id 的角色）；子 Agent 的由名字决定。

选择器

Agent 编辑器的通用区使用个人资料的 AvatarPicker，来源为角色、生成和上传。角色显示形状卡（预览当前颜色）和色板。它编辑草稿，随其他配置一起保存或丢弃。
