按钮

apps/web/components/ui/button.tsx 是官方 registry 的 shadcn radix-nova Button。本地改动：import、React 18 的 forwardRef、固定 px 尺寸和统一外观：所有尺寸 rounded-md（8px）、无边框、输入框阴影对（shadow-raised、shadow-raised-hover）抬起。只靠颜色区分角色。档位表见设计令牌。

变体外观、悬停用途
defaultbg-primary；primary/90每个区域一个主操作：Run、Save、Test、Apply、Send、New
elevated--bg-input；阴影加深。按下、选中或开启：1.5px primary 环。其余操作、筛选和选择；输入框触发器、环境胶囊
destructivebg-destructive/10；/20Delete、Remove、Stop、Clear history
ghost透明无阴影；bg-muted（深色 /50）悬停才显现的图标工具：关闭、更多、重命名
link主色文字；下划线行内

按下时都下沉 1px，键盘焦点 3px ring/50，禁用 50% 透明度。侧栏行不是 Button：用 .ui-list-item 或 nav-classes.ts。不提供 outline 和 secondary。Toggle、ToggleGroup 有与 elevated 相同的外观。

  • 不能做成 <Button> 的元素（自带 ✕ 的 span、渲染成 span 的 Radix 触发器）用 cn(buttonVariants({ variant, size }))；cn() 合并才能解决 border-transparent 与变体边框的冲突。
  • 标题行（搜索、胶囊、图标按钮）里 1 到 2px 的高度差是 bug。

选择器和菜单

固定列表选择都用 radix-nova Select（components/ui/select.tsx）。没有原生 <select>，没有手写 listbox。SimpleSelect 是一行写法（value、onValueChange、options、label、placeholder、size；分组用 {label, options}）。

部分规则
触发器Nova 字段：rounded-lg、border-input、bg-transparent、dark:bg-input/30、h-8 或 h-7。默认 w-full max-w-48；调用处只加宽度或错误边框。
弹层菜单框架内实色 bg-popover，item-aligned，z-[130] 高于对话框。淡色标题写明选什么（label，否则 aria-label），每组一个。选中行一个普通勾。
空值Radix 保留 ""：取该值的选项在 SimpleSelect 内用哨兵值；否则 "" 显示占位
其他菜单DropdownMenu、弹层选择器、侧栏底部、标签和函数上下文菜单都用 components/ui/menu/menu-styles.ts 的 MENU_PANEL、itemCls、GROUP_LABEL、MENU_SEPARATOR。CSS 模块只留定位。

小按钮或右键打开的操作菜单用 MenuRow（components/ui/menu/menu-parts.tsx）构建行，页面和桌面浮层相同（DesktopContextMenuItem 带 glyph 和 keys）。apps/web/scripts/ui/check-menu-rows.mjs 约束所有菜单文件。从左到右：

文字占满行
按键价签（MenuKey）：10px 尖端，是 Solar tag-horizontal 的圆头镜像朝左，接 shadcn Kbd 底板，高 18px，接尖端处方角，右侧 5px 圆角，内边距 1px 6px，文字至少 8px 宽。填充 --menu-key-bg，弹层上 12% 墨色。文字来自 formatMenuKeys：⌘T、⇧⌘C，或 Ctrl+T、Ctrl+Shift+C。只显示真能用的按键；不为填价签加全局快捷键。
勾选MenuCheck；同组无勾的行保留这一列（CHECK_SLOT_PAD）

输入框和边框

设置、对话框、插件和 MCP 编辑器共用一层 1px 边（border: 1px solid var(--border)，填充 --bg-input）。悬停保留边框；聚焦不加 2px 光晕。

对话框

所有模态都是 radix-nova Dialog 或 AlertDialog（components/ui/）。没有手写遮罩，没有浏览器 confirm()。

History 项目标签页

Settings 和 Info 用同样的块。Chats、Memory、Settings、Info 共用一种布局：头部和标签栏固定，面板通栏各自滚动（Settings 和 Info 留 24px 边）。Chats 按时间分组，每组一张带标题的 Card。Today、Last 7 days 和最新一组默认展开，更早的折叠；每组的选择记在当前浏览器。

展开的组列 8 条，然后是“Show all N”（10 条以内全列）。工具栏按钮全部展开或折叠；搜索时全部展开。apps/web/scripts/projects/check-project-tabs.mjs（在 npm run check 中）守护这些规则。
