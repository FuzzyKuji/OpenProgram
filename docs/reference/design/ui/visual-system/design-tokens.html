Design tokens

A component names a tier and never writes a value. Tiers live in apps/web/app/styles/design/; npm run check fails on anything written by hand. A value that fits no tier is a design change: add the tier or the table row first.

Spacing and radius

Tailwind's spacing unit is 4px on every surface (p-2 = 8px), because the default 0.25rem lands on half pixels on the 14px root. Hand-written CSS uses whole px multiples where it can.

TierSizeUsed by
2xs2pxHairline bars, progress tracks, carets, a tip's arrow
xs4pxTags, kbd, checkboxes, inline code, badges
sm6pxChips and small controls inside a row
md8pxEvery Button size, inputs, selects, hand-written buttons
lg10pxList rows, menus, popovers, Select popups, cards
xl12pxThe centre card, split panes, page panels, dialogs
2xl16pxUser bubbles, large floating surfaces
full9999pxPills, avatars, dots

Same names in CSS (var(--radius-lg)) and Tailwind (rounded-lg). --ui-button-radius is md, --ui-list-radius lg. A share of the box (50%, a squircle's 26%) and a concentric calc() over a tier are allowed. A radius from a surface with no tier says so with a shape: comment.

Step tones in styles/tool-tones.css (--tool-tone-*, --timeline-*) are the same kind of token.

  • Every shadcn role is a full colour: read var(--ring). Wrapping in hsl() resolves invalid. Translucent: color-mix(in srgb, var(--muted) 34%, transparent).
  • var(--role, literal) names an always-defined role (theme roles, --accent, --destructive, --muted-foreground) with no dead literal. A role no theme defines (--danger, --warning, --success, --red, --orange, --status-error, --border-color) is replaced by the token holding its literal.

Layout rules still in modules

About 280 one-class, layout-only rules remain. A Tailwind utility sits in @layer utilities and a module rule is unlayered, so a moved rule loses to every unlayered rule on the element.

A rule stays when its class appears earlier in the stylesheet, the element merges its own classes (a DialogContent keeps sm:max-w-*), another module class sets one of the same properties, or the styles object is re-exported or passed whole. They move when their component is edited; the guard makes sure the number only goes down.

The guard

apps/web/scripts/ui/check-design-tokens.mjs, run by npm run check, scans every stylesheet and .ts or .tsx file. apps/web/tests/ui/ui-kit-is-nova.test.mjs refuses a literal control height.

Named exceptions
  • APIs that take pixels: xterm, Mermaid, canvas, Electron views.
  • Framer Motion's numeric radius on the Agent cards.
  • The input box: its radii, weights and icons stay as drawn.
  • A line that says glyph:, shape: or mask:.
  • COLOUR_DATA: user-picked palettes and chart series, artwork (Launchpad and memory icons, code rain, search-provider glyphs), APIs taking a colour string (canvas, WebGL, xterm, Mermaid, pdf.js, the web manifest), the effort heat scale computed as hsl().
