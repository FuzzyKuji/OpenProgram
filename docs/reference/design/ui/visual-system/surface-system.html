Buttons

apps/web/components/ui/button.tsx is the shadcn radix-nova Button from the official registry. Local changes: imports, a forwardRef for React 18, px-pinned sizes and one look: rounded-md (8px) at every size, no border, raised by the composer shadow pair (shadow-raised, shadow-raised-hover). Colour alone marks the role. Tier tables: Design tokens.

VariantFace, hoverUse
defaultbg-primary; primary/90One main action per area: Run, Save, Test, Apply, Send, New
elevated--bg-input; deeper shadow. Pressed, checked or on: 1.5px primary ring.Every other action, filter or choice; composer triggers, environment chips
destructivebg-destructive/10; /20Delete, Remove, Stop, Clear history
ghostTransparent, no shadow; bg-muted (/50 dark)Icon tools hidden until hover: close, more, rename
linkPrimary text; underlineInline

All press 1px while active, show a 3px ring/50 on keyboard focus, and go to 50% when disabled. Sidebar rows are not Buttons: use .ui-list-item or nav-classes.ts. outline and secondary are not offered. Toggle and ToggleGroup offer the same face as elevated.

  • What cannot be a <Button> (a span hosting its own ✕, a Radix trigger span) uses cn(buttonVariants({ variant, size })); the cn() merge resolves border-transparent against the variant's border.
  • A 1 to 2px height mismatch inside a header row (search, pills, icon buttons) is a bug.

Selects and menus

Every fixed-list choice is the radix-nova Select (components/ui/select.tsx). No native <select>, no hand-rolled listbox. SimpleSelect is the one-line form (value, onValueChange, options, label, placeholder, size; groups as {label, options}).

Inputs and borders

One single-layer 1px edge (border: 1px solid var(--border), fill --bg-input) in Settings, dialogs, plugins and MCP editors. Hover keeps the border; no 2px halo on focus.

Settings and Info use the same blocks. Chats, Memory, Settings and Info share one layout: fixed head and tab bar, each panel scrolls edge to edge (Settings and Info with a 24px edge). Chats groups by recency, one titled Card per group.

Today, Last 7 days and the newest group start open, older ones folded; the choice per group is remembered in this browser. An open group lists 8, then "Show all N" (10 or fewer: all). A toolbar button expands or folds all; a search opens all. apps/web/scripts/projects/check-project-tabs.mjs (in npm run check) guards this.
