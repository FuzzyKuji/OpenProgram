Web 样式组织

全局 CSS 与组件树一一对应：改一个组件的样式，只打开一个以它命名的文件。

apps/web/app/
  globals.css       entry: tailwindcss → design → themes → styles
  styles/
    index.css       imports the global layer in cascade order
    design/         design tokens and Tailwind's names for them
    themes/         colour values, one file per theme (+ fallback.css)
    base/           document, focus, list row, shell layout, scrollbar,
                    sidebar, desktop chrome, motion, canvas drag
    chat/           pane/ messages/ cards/ execution/ composer/ welcome/
    dag/            graph/ panels/
    right-dock/     right-sidebar panels

index.css 层叠顺序：base、chat、right-dock、dag。令牌和档位见设计令牌。

规则

规则说明
一个组件一个文件文件开头注释写明组件和源码路径。新组件建新文件。
位置跟随组件树绘制代码在 lib/runtime-bridge/dag/render/nodes.ts 的样式放 dag/graph/nodes.css；聊天气泡放 chat/messages/bubbles.css
全局的留在全局令牌在 design/，主题值在 themes/，外壳在 base/。chat/pane/layout.css（.main、#chatView）是唯一有意跨组件的文件。
Module CSS 不动已用 *.module.css 的组件（输入框）继续用；这棵树只管全局层
样式测试通过 postcss 读取组件各自的文件，如 apps/web/tests/tabs/canvas-css-geometry.test.mjs 读 center-tabs 模块

不用原生滚动条

base/scrollbar.css 以零优先级隐藏原生滚动条，因为 macOS Chromium 在指针进入可滚动区域时会闪出一条。lib/runtime-bridge/dom/scrollbar.ts 在区域第一次滚动时装上细的浮动滑块。

方面行为
显示只在区域滚动或滑块被按住时；900ms 后淡出。纵向，横向溢出时也有横向。
不显示悬停、尺寸变化、内容变化。淡出的滑块不接收指针事件。
布局不占宽度
层级在最上层，包括对话框。data-scrollbar-layer="content" 让它留在区域的行之上、边缘控件之下（Agent 列表、Agent 网格）。
Shadow root自己隐藏滚动条并调用 attachOverlayScrollbar

字体与字号

方面规则
字号design/type.css 九档，--fs-2xs（11px）到 --fs-display（30px）；分配见字号。apps/web/scripts/ui/check-design-tokens.mjs（在 npm run check 中）拒绝其他字号。
字体Inter 和 JetBrains Mono 的拉丁字符文件走 next/font（app/fonts.ts）：预加载，display: block，不会先用后备字体再重排。其他文字用 @fontsource。
语言导出的 HTML 是英文。其他语言时头部脚本标记 <html data-locale-pending> 隐藏正文；useTranslation 在 layout effect 中于绘制前切换并去掉标记。脚本没运行时 1.5s 后显示。
