宽度行为

components/layout/use-resizable-rail.ts 是唯一实现：保存展开宽度、限制范围、处理指针捕获、生成展开和折叠样式、控制过渡。每个侧栏传入自己的范围和增长方向。

方面规则
手柄.rail-resize-handle，分隔线两侧约 8px 可点击，不影响布局宽度。外壳允许它溢出，内部内容仍裁切。
拖动只有主键触发；手柄上禁用触摸平移和文字选择。悬停时出现和分屏分隔线相同的短条，位于两张卡片之间 8px 缝隙的正中；拖动时变实，宽度停在默认值上时变成主题色。
回到默认两侧相同：双击拖动条，或焦点在拖动条上时按 Enter，用 280ms 缓出回到 288px；宽度像拖动一样逐帧变化，侧栏里面的内容跟着边缘一起动。处于默认宽度时不保存。
吸附拖到吸附点 8px 内会停在上面，拖动条变蓝。左侧栏只有 288px 一个吸附点。右侧栏是 288、544、800px，正好放下一、二、三列完整的运行记录时间图。
结束拖动松开、指针取消或窗口失焦。窗口级结束事件作为被捕获手柄事件的补充；移动事件发现按键已松开也会结束。每次都恢复折叠动画。

开合

每个部件在两种状态下都存在：开合时不在侧栏内挂载、卸载或改变 display，方向相反或中途再次切换也一样。外壳宽度在点击那一帧开始变化，.collapsed 在同一次渲染里切换。规则见 app/styles/base/layout.css 的 “Opening and closing”。

类别部件如何移动
一个位置左侧栏的新建对话按钮和链接图标贴着不动的左边缘布局。每行的盒子跟着卡片移动的边缘，内缩 8px。
两个位置两个开关、右侧面板的视图行、左下角头像开关在展开时距移动边缘 8px，折叠时在卡片内居中。右侧面板的行始终一列，跟着移动的左边缘。头像左内边距从 16px 滑到 5px，右内边距从 16px 到 27px，名称宽度不变。
仅展开时字标、文字标签、能力刷新按钮、收藏、对话列表、滚动分隔线、页脚名称和箭头、右侧面板的视图（文件、活动、资源、详情、上下文）两种状态都按展开宽度布局并被卡片裁切，不会重新换行。只靠透明度淡入淡出，时长和曲线与宽度相同（页脚名称用自己的 160ms 曲线）。从关闭结束到打开结束期间为 inert。文字标签和页脚名称在折叠侧栏保留的行里仍可访问。
为什么不改继承属性

移动时不改任何继承属性（pointer-events、visibility、color、自定义属性）。这类变化会让浏览器重算整个子树的样式，在点击那一帧就是整个对话列表：pointer-events 1,764 个元素，visibility 1,946 个，opacity 1 个（实测）。

use-resizable-rail.ts 在结束时（宽度的 transitionend 或定时器）自己给最外层的仅展开部件写 inert，让重算发生在移动之后。侧栏静止折叠时才挂载的部件随之变为 inert。

关闭结束状态和首帧
  • 开关的两个图形（隐藏、显示）始终挂载并交叉淡入淡出。
  • data-rail-closed 表示关闭已结束。只有看不见的东西依赖它：窄布局回到分栏画布旁的文档流、左侧列表重置滚动、暂停隐藏列表里的运行标记。
  • 左侧栏滚动时关闭，链接随宽度滑到顶部（一个 transform 的 Web Animation），结束时在同一帧重置滚动。
  • 右侧面板的视图只在打开时工作：折叠期间暂停活动、资源的进程、页面截图和终端读取。
  • 已保存为关闭的左侧栏在首帧按 html[data-sidebar-closed] 画成折叠，没有过渡，仅展开部件靠 interactivity: inert 不可达，直到侧栏挂载后把它们设为 inert。
