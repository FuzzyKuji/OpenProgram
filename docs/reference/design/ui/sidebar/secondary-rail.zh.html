二级侧栏

主侧栏和页面内容之间的列表列。全部是 SecondaryRail，页面不自己写侧栏行样式。

部件

部件基于说明
RailSplitCSS grid侧栏列宽 --sidebar-width - 1px，与主侧栏对齐；收起时为 --rail-collapsed-w。
SecondaryRailnav 或 aside8px 内边距，行间 1px，右侧细线，自身不设背景。
RailSearchui/search-input全站唯一的搜索框。收起时隐藏。可选的 action 放在旁边。
RailGroupLabelmenu-styles.ts 的 GROUP_LABEL与菜单相同的分组标题。可选的 action 放在右端。
RailActionui/button ghost icon-xs放进搜索框或分组标题 action 位的图标操作（记忆的刷新），带 HoverTip。
RailItem.ui-list-item主侧栏的行：30px，内边距 6px 8px，间距 12px，文字 --nav-color。传 description 变成两行（最少 48px，最多两行）。depth 每层缩进 16px。传 href 渲染 Link，否则是 button。
RailBadgeui/badge outline名称后的小标签（“默认”“已隐藏”）。
RailCount文字尾部的浅色计数。
RailSeparatorui/separator放在“添加…”行上方。

从上到下：搜索、分组标题、行、分隔线、低调的“添加……”行。页面顶栏（ManagePageHeader，64px）横跨侧栏和内容。

行状态

状态样式
悬停、键盘焦点--bg-hover
选中--bg-hover 加 --text-bright；所有侧栏同一种选中色
“添加……”行quiet：弱化文字

配方：表面体系。

文件夹图标

主侧栏的 Solar folder 和 folder-open（双色，--folder-color，亮暗各一个值），用于项目列、记忆主题树、Programs 树和文件面板树（它的 Pierre 图标集和根路径）。

项图标
展开的树文件夹、选中的项目打开的文件夹
页面Solar file-text
缺失的文件夹Solar danger-triangle
分区行（记忆的主题、时间线等）主侧栏的线性导航图标

折叠

带 railKey 的侧栏可折叠成图标列。RailToggle 在页面顶栏标题之前（ManagePageHeader 的 railToggle），与行图标同一竖轴。

方面规则
折叠时隐藏搜索、分组标题、文字、行尾内容、嵌套行
顶层行32px 正方形；名称移到 HoverTip
保存位置localStorage["&lt;railKey&gt;NavOpen"]：settingsNavOpen、projectsNavOpen、agentsNavOpen
没有保存过窗口小于 760px 时默认折叠
窗口缩到 760px 以下折叠但不保存；放宽不会自动展开

页面

页面侧栏可收起
历史项目（PROJECTS_RAIL）是，按钮在历史页顶栏
Agents带搜索的 Agent 列表，两行行；随完整编辑区出现（页面先显示卡片）是
设置分类（Link 行）是
能力 → Programs目录树（depth）否；能力页顶栏属于四个标签共用
历史 → 项目 → 记忆分区、主题树（文件夹、与文件夹不同时显示类型标签、日期）、时间线（年 › 月 › 日）否；它在项目页内部
独立的会话列表带计数的时间筛选否

没有列表列的页面（定时任务、应用、能力页的插件、技能和 MCP）用页面顶栏的标签和 ManageSubnav。

按钮

角色变体
页面的主操作（新建、添加、安装、打开）default
次要操作（更新、重试、记忆设置）outline
行内图标操作（暂停、删除），经 ManageIconButtonghost、icon-xs，带 HoverTip
移除类操作（卸载）destructive

只用 Nova 的 ui/button 变体，不做页面级覆盖。纯图标按钮用 aria-label 命名并显示 HoverTip，不用原生 title。页面菜单是用 menu-styles.ts 样式的 ui/dropdown-menu。

守卫

apps/web/scripts/ui/check-secondary-rail.mjs 由 npm run check 运行。侧栏页面不再用 SecondaryRail、样式表重新定义侧栏行、或可折叠侧栏与顶栏开关的 key 不一致时失败。
