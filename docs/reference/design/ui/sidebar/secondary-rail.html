Secondary rail

The list column between the main sidebar and a page's content. Every one is SecondaryRail; no page styles its own rail rows.

Collapse

A rail with a railKey collapses to an icon column. RailToggle sits in the page header before the title (ManagePageHeader railToggle), on the row icons' vertical axis.

Buttons

RoleVariant
The page's main action (New, Add, Install, Open)default
Secondary actions (Update, Retry, Memory settings)outline
Row icon actions (pause, delete) via ManageIconButtonghost, icon-xs, with a HoverTip
Removing something (Uninstall)destructive

Nova ui/button variants only, no per-page overrides. Icon-only buttons name themselves with aria-label and show a HoverTip, never a native title. Page menus are ui/dropdown-menu styled with menu-styles.ts.

Guard

apps/web/scripts/ui/check-secondary-rail.mjs, run by npm run check, fails when a rail page stops using SecondaryRail, its stylesheet defines rail rows again, or a collapsible rail and its header toggle use different keys.
