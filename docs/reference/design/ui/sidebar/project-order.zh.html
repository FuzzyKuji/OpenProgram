侧栏项目与会话

登记表拥有项目成员关系。projectGroups 联接应用所选排序和置顶；会话归属绝不改变。

列表与排序

项规则
置顶项目列表上方单独的顶层列表，标题样式和缩进相同，折叠状态独立。每个项目只出现一次。为空时省略。
项目标题即使为空也保留，用于过滤。自定义分区是平级列表，为空时仍可管理。
项目排序最近活动（最新会话）、最早活动、字母顺序，拖动后为手动。与会话排序相互独立。
会话排序明确的升序或降序
可见性只显示有可见、未归档会话的项目，置顶项目也一样。归档最后一个会话时隐藏项目，恢复一个会话后重新显示。登记、选择、管理、归档内容和保存的顺序都不受影响。
保存的顺序

最近视图偏好中的项目 ID 数组，按浏览器保存，通过 storage 事件在窗口间同步。忽略未知 ID，新项目按回退排序，其他项目移动时隐藏项目保持位置。无效数组回退到默认顺序。存储失败时当前窗口保持可见顺序，并提示保存失败。

拖动

开始
指针捕获和 6px 移动阈值，无额外依赖
动效
分组纵向跟随指针，相邻分组用收藏程序的弹簧移动（stiffness 600、damping 40）。没有插入线或名称预览。减少动态时去掉弹簧。
放下
保存顺序并切到手动排序；分区和置顶位置随目标变化。会话随项目移动。
取消
按 Escape 或放到列表外不做改变
键盘
Alt+ArrowUp 和 Alt+ArrowDown 保持焦点并播报结果

项目菜单

右键和选项按钮打开同一菜单。

项效果
置顶、取消置顶只在这里；行上没有置顶按钮
编辑名称、纯文本图标或 emoji、描述、源文件夹。与项目设置共用一个编辑器。
分区本地视图偏好。删除分区后其项目回到默认分区。
在文件管理器中显示平台文件管理器操作
新建 worktree从源 HEAD 建新的用户命名分支，位于源检出之外的绝对路径；由 Git 校验两者。重复请求会登记已有的同一 worktree。源检出和未提交文件不变。
归档全部对话先持久化每个对话再广播；失败时报告已完成的 ID
移除只设置登记表的隐藏标记。归属、文件和内容保留，历史仍可通过日期或平铺分组访问。项目页或重新打开文件夹可恢复。默认主目录项目不能移除。
另有项目设置、新建项目会话

元数据

  • 更新校验支持的字段、长度和已存在的绝对目录，然后在锁内原子替换登记表，并通知所有窗口。
  • 编辑绝不改变主文件夹或成员关系；迁移是项目设置中的操作。文件夹移动见项目位置。
  • 对话没有明确的文件夹配置时，源文件夹作为默认值；有意留空的列表保持为空。
  • 过滤使用登记表 ID，改名不影响过滤。
  • 保存失败时保留表单并显示错误。
行控件和反馈
元素规则
新建对话、选项同一个类（sidebarProjectActionClass）：24px 正方形、无内边距、15px 图标，悬停比行深一档；两者间距 2px，结束于行内 4px，与对话行的选项对齐。用像素固定，不受 14px 根字号影响。
文件夹图标随分组开合，是唯一的展开提示。自定义图标保持不变。
项目行只在指针悬停或菜单打开时显示中性背景。点击、键盘激活、草稿和会话变化都不保留选中态。
会话行菜单打开时保持悬停背景和选项按钮，指针移入菜单时也是。选中的行保持常规背景。无发光或阴影。
选项触发器菜单或编辑器打开时保持可见
置顶菜单项悬停和键盘聚焦时播放动画，离开或失焦后回到静止；减少动态时为静态
右键菜单
  • 桌面端项目和会话菜单使用 Electron Menu.popup。坐标是触发点的 CSS 像素，按渲染层缩放换算；键盘触发时使用聚焦的控件。
  • Web 回退使用同一触发点并处理视口碰撞，原生菜单失败时也由它接手。
  • 桥接层只接受来自所属外壳框架的有界纯菜单描述，只返回选中的动作 ID。
  • 取消、渲染层导航、卸载和窗口销毁都会结束请求并清除临时反馈。
项目设置编辑器
  • 使用应用的 Input 和 Textarea、主题变量和系统字体。聚焦字段有细的强调色边框和柔和发光；对话框有克制的强调色边缘。
  • 图标选项有持续的选中状态，头部预览所选图标。
  • 标签 13px，字段使用共用的 10px 圆角，内容左对齐，窄屏时主体可滚动。文件夹路径换行且不挤开移除控件。
  • 对话框和遮罩位于窄屏侧栏之上，编辑器及其文件夹选择器保持可见。
  • 减少动态时关闭新增的过渡。
验收
  • 向上或向下拖动只在放下时改变顺序，重载后保留。
  • 折叠、新建会话按钮、成员关系和过滤不受影响。
  • 真实菜单入口、计算出的聚焦和选中样式、亮暗主题、减少动态、取消和不变的保存载荷。
