ConvItem resolves the state; StatusMarker draws it. Selection is aria-current="true". CSS suppresses running and finishing pseudo-elements on unselected rows. Backend status, task execution, navigation and conversation persistence are not involved.

Installation and acceptance

Source TSX and CSS go through the normal release asset pipeline; installed minified JavaScript and generated asset names are never patched by hand. The workspace root package manifest holds the workspace definitions and is separate from the desktop manifest.

  • Web tests and checks, production build, Desktop checks, repository contracts and documentation links pass.
  • Every installed frontend JavaScript chunk parses.
  • The App renders the affected conversation and another one without a client exception.
  • Worker health and the installed source revision match the validated checkout. A source check alone does not establish installed-App health.
