文件树与文件管理

侧边栏与中央 Files 页面共用一棵基于 @pierre/trees 1.0.0-beta.6 的树。Pierre 负责行、层级、选中、焦点、虚拟滚动、固定祖先行和键盘导航；OpenProgram 负责文件系统状态。行高 30 像素，密度 1。

  1. 路径面包屑，右端为复制按钮
  2. 工具搜索、新建文件、新建文件夹、刷新、排序、信息
  3. 搜索输入框，按需展开
  4. 列标题名称、大小、修改时间、类型
  5. 文件行名称：剩余宽度，中间缩略大小 100 px，修改时间 200 px，类型 140 px小于 720 px：只有名称和大小

列

方面行为
宽度ResizeObserver 测量视口，设置名称列宽度和可见列，卸载时断开。文件行不超出面板，也不横向滚动（与 Codex 的文件树一致），因此 Pierre 的选中、焦点框和命名框无需覆盖即可完整显示。
表头纵向滚动时保持可见，与文件行共享列边界。
单元格Pierre 没有可排序列。通过 renderRowDecoration 输出三个文本片段，用 unsafeCSS 设置样式，放不下的片段被裁掉。不引入表格框架，不做逐文件元数据请求。
修改时间目录与搜索响应中的秒级 mtime，按当前语言和本地时区显示。缺少时间及搜索结果的合成祖先目录留空。
类型文件夹；大写扩展名加“文件”；无扩展名时为“文件”。
排序目录列标题切换按项目保存的服务端排序，保留文件夹优先、隐藏和忽略项设置。搜索保持相关性排序，列标题不起作用。
深层目录缩进限制在名称列内部，为图标和文件名留出空间，各列保持对齐。
重命名内联重命名保持 Pierre 的列内容隐藏行为。
不包括列拖动排序、手动调宽、额外元数据字段、文件系统监听。

外观

元素规则
文件夹箭头通过 icons.remap 换成主侧边栏的 Solar 文件夹 sprite；展开状态决定开合。文件夹不旋转。
文件行距面板两侧 6 像素，内部留 6 像素。无额外上下内边距。Pierre 的缩进参考线始终显示；不用固定缩进和自定义连线。
滚动条应用的悬浮滑块不占宽度，文件行延伸到面板右边缘。
选中选中行无边框。未选中行保留键盘焦点指示。
工具栏与路径行共用 8 像素左右外留白。工具栏与列表之间无分隔线。沿用现有按钮和圆角菜单。

路径行

方面行为
组件shadcn Breadcrumb，radix-nova 样式，面板的 14 像素字号，单行。Nova 的箭头分隔符位于列表 6 像素间距之中。
颜色祖先弱化，悬停时为前景色；当前项为前景色。
放不下时放不下的祖先收进 Nova 的省略号，点击后以菜单列出。有余量时多显示一个祖先的部分名称。不显示重复名称的悬浮提示。
点击在已加载条目中定位并展开祖先，不重新读取列表或重算大小。仅目标缺失时查询。
复制按钮复制绝对路径，成功后显示 1.5 秒勾选。
右键菜单所点位置的相对路径、绝对路径或名称。

列表与搜索

方面行为
列表project_file_tree：按目录懒加载、分页，由服务端排序。可按名称、类型、修改时间、大小排序，并可文件夹优先。框架比较器保持后端顺序，不回到字母排序。
分页接近目录已加载条目末尾时自动读取下一页，没有分页按钮。
搜索使用后端权限范围与分页。结果用 Pierre 层级显示；高亮模式保留目录。
匹配模糊匹配由后端判定，以匹配标记及原生当前项选中表示。字面查询使用框架文本高亮。
定位由控制器展开与滚动，不依赖手写行 DOM。

文件与文件夹大小

情况显示
文件字节数。
可见文件夹有界后台统计，共用队列同时运行两个任务。状态：缓存、扫描中、完整、部分、取消、错误。搜索忽略的目录（如 .cache、node_modules）仍有元数据和大小。
列表中只显示数值，不附加 ≈ 或 ≥。
统计中已有数值继续更新，并以灰色缓慢明暗变化；统计停止后恢复正常。不新增文字或图标。
暂无数值留空，不显示横线。
详细信息估算、下界、时间和完整性；可继续统计。

持久样本

方面行为
复用已结束的样本在视图重新挂载和 worker 重启后保留，显示时不递归读取。最多 256 条，存于默认 profile 状态。大小排序保持近期完整样本规则。
新扫描只有刷新和重新计算。
失效Files 修改成功后，从内存和磁盘清除受影响的祖先与子目录样本，并取消相关活动扫描，包含根目录重叠的项目。
键验证后的绝对路径。设备和 inode 也须一致，因此项目重绑定或目录替换不会读到另一目录的结果。
不完整扫描保持不完整，保留跳过条目的记录。活动扫描 token 不保存。
过期样本深层编辑可能使样本过期；详细信息显示时间和完整性。不增加文件监听、递归新鲜度检查、内容读取或额外 profile。
存储现有原子 JSON 写入函数：私有临时文件加原子替换。缓存损坏或不可用时回到扫描。
为什么不用别的存储
方案结果
Python sqlite3支持持久事务和并发连接，但一个 worker 拥有的有界缓存用不上。不增加表结构或依赖。
Pierre 树、React 队列继续负责虚拟化和两个可见目录任务。二者都不提供服务端持久样本。

新建、重命名与菜单

操作行为
新建条目直接在树中命名：所在文件夹出现占位行，名称编辑框为空，默认名称作为浅色提示。
提交Enter 或离开编辑框时按输入的名称创建。Escape 或未输入就离开时移除占位行。现有表单验证后再提交。
右键菜单详情、系统定位、新建文件、新建文件夹、复制路径、剪切、复制、粘贴、移动到、重命名、确认后删除。
多行剪切、复制、移动和删除作用于全部选中项，菜单显示数量；重命名只适用于单行。
选择Cmd/Ctrl 点击切换单行，Shift 点击选择范围。在别处打开标签页或定位文件时，选择替换为该行。
按键操作
Cmd/Ctrl+C、Cmd/Ctrl+X复制、剪切
Cmd/Ctrl+V粘贴到选中的文件夹或选中文件所在文件夹
Cmd+Backspace、Delete确认后删除
F2重命名
Cmd/Ctrl+Shift+M移动到

移动

方面行为
拖放Pierre 的拖放，拖到文件夹或根目录；悬停 600 毫秒自动展开文件夹。
执行树立即显示移动结果；实际移动走与剪切粘贴相同的服务端重命名，保留草稿保护和已打开标签页的路径跟随。被拒绝时重新读取列表。
撤销每次移动显示带“撤销”的提示，撤销会把条目移回原处。
跳过移到原父目录，或移进被移动的文件夹自身。

移动到

shadcn Command 对话框，把输入当作路径。沿用同一服务端重命名与带撤销的提示；选中的文件夹在树中展开。

输入列出
未输入项目根目录、本项目最近移动到的五个文件夹、顶层文件夹。
folder/name最后一个斜杠之前的部分所指文件夹的子文件夹，来自 project_file_tree，再按其后的部分筛选，以它开头的排在前面。文件夹排在前面，读到第一个文件即停止。每层一次列表读取，因此任何大小的项目都能用。Tab 进入高亮的文件夹。
name还会用 project_file_search（type: "dir"）列出项目其他位置的结果；超过搜索快照上限时没有这部分。
路径不存在可新建该文件夹（含缺失的父目录）并移入。

当前所在文件夹与被移动的文件夹不可选。

从桌面拖入

方面行为
目标指针下的文件夹、指针下文件所在的文件夹或项目根目录。树显示描边，提示标签写明目标。
传输浏览器读取拖入的文件，逐个以项目相对路径流式发送到 POST /api/files/upload。不传本地路径，不打开项目以外的内容。
文件夹按其中的文件上传，并创建缺少的父目录。
同名项从不覆盖：上传拒绝，提示中统计未改动的数量。
上限单个文件 1 GiB。
输入框拖放停留在文件树内，不进入附件拖放。

刷新与错误

情况行为
窗口重新获得焦点重新列出已展开的目录，最多每三秒一次，不重新统计大小。
任何刷新保留选中路径、展开目录和已加载分页；等待时保留旧行。
父目录收起保持关闭，即使子目录曾展开；重新展开时恢复。
目录或分页失败停止自动重试。显示路径和显式重试，不显示虚假条目。
项目文件夹不可用原因和修复操作取代列表：确认记录位置上的文件夹，或定位文件夹。见项目位置。
保持的合同工作区范围、取消、过期响应隔离、草稿保护、服务端幂等变更、元数据和大小缓存权限。框架不接触文件内容，也不判定权限。
