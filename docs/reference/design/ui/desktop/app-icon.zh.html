应用图标规格

一个标记用于 macOS App、Windows 安装包、WebUI 标签页、PWA 和文档站。macOS 发布扁平的 icon.icns；AppIcon.icon 以 Icon Composer 图层保存同一图形。

元素位置 (dx, dy)半径颜色

以底板边长为单位，从中心量起。单元轮廓：r(θ) = R · (1 + Σ aₖ cos(kθ + φₖ))，旋转 −15°，R = 0.364。谐波 (k, a, φ)：(9, 0.12, 1.3)、(7, 0.05, 0.2)、(12, 0.035, 2.4)、(2, 0.02, 1.8)。第 9 次谐波形成约九个大小不一的圆润射线；没有尖点。最远到 0.446。

素材规则

保留
三个扁平圆盘；平滑的波浪轮廓；靛蓝底板渐变；分隔前方圆盘的阴影
避免
球面光照、玻璃半透明、单元外环、尖点、标记内的文字或位图
Icon Composer 图层
透明 1024 × 1024，每层一个元素，SVG 里没有圆角矩形、边框、滤镜或阴影。阴影来自组设置。
扁平渲染
ICNS、favicon 和 PWA 来自扁平 SVG 源，绝不用打包 App 的截图

检查

npm run icon:check
apps/desktop/scripts/check-icon.sh：四个图层、批准颜色的三个扁平圆盘、单元填充、渐变底板、组顺序，Specular、半透明和玻璃关闭。拒绝图层里的圆角矩形、边框、滤镜、阴影、文字和位图。
_complete_icon_probe
openprogram/operations/self_update/control/supervisor.py：用 sips 渲染每个图层，要求 1024 × 1024 透明画布

遵循 Apple 的 App icons HIG、Icon Composer 和 Electron Builder 图标文档。
