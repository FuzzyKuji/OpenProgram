在窗口之间移动标签页

桌面标签页可以移到另一个 OpenProgram 窗口，或松手处新建的窗口。移动结束时标签页只存在于一个窗口；任何失败都让源窗口保持原样。

目标先插入，源后移除，任何时刻都有一个活的标签页。

步骤行为
令牌不透明、一次性；15 秒内未完成即过期
准备拖拽离开标签栏时同步申请
检视只有指针下方的窗口；源窗口和第二个窗口都不行
拒绝duplicate（目标聚焦自己那份）或 group-full：通知源，什么都不变。目标无法校验的负载不接受，其令牌到期失效。
提交报告成功前，用原子替换把 committed 写入应用数据目录的 tab-transfers.json。持久性不确定：以 100 ms 到 5 s 的退避重写同一决议。写不进去：回滚。
新窗口在所有窗口外松手时，在松手处创建隐藏的拖出窗口。它认领令牌，像普通目标一样接受，标签就位后才淡入。并发拖出共用一次窗口启动。
源窗口变空日志完成后关闭
悬停指针下方的窗口收到进入和离开事件，只在此时显示落点

移动的内容

来源类型内容
tab一个未分组的标签页
segment复合分组的一个成员；其余留下
group整个复合分组，含成员、可见成员和焦点成员
方面取值
标签类型会话、文件、网页、新标签页、应用、内置页面
位置分组 id、成员序号和顺序、可见成员、焦点成员、画布布局
同时携带未保存的文件草稿；每个对话的输入框草稿和设置、待定项目、渠道选择、是否活动；每个标签页的页面历史
上限负载 20 MiB；文件草稿每次 3 份、每份 2 MiB、合计 6 MiB；字符串和嵌套值有界。格式不对的负载拿不到令牌。

网页保留状态

网页标签页是 Electron WebContentsView。协调器在窗口之间移动同一个对象，从不调用 loadURL，所以重定向、登录、表单值、滚动位置、页面内存和 DevTools 目标都保留。目标报告新边界前保持隐藏。

重新挂载前：清除 agent 操作提示和控制叠层，记录每个视图的边界和可见性，确认源窗口仍拥有每个视图。进行中的转移锁定其视图，第二个转移或 agent 命令不能占用。

日志与恢复

  1. 修改标签 store 之前，每个渲染进程在以窗口为键的本地存储（openprogram.tabTransferJournal:<windowId>）写日志：前后布局、会话状态、文件草稿、原生视图簿记。
  2. 主进程记录哪些角色打开了日志；持久化的决议把它们列为必需角色。
  3. 重载后，渲染进程查询待处理决议，应用 committed 或 rolled-back，完成自己的角色。
  4. 窗口已不在：另一个活着的窗口接管孤立角色。
  5. 必需角色全部完成：删除决议。

回滚

触发结果
过期，或目标、源失败回滚
Escape，或拖拽结束时没有目标回滚
参与窗口被销毁或正在关闭回滚
提交决议写不进去回滚
已提交永不回滚
阶段回滚内容
还没有日志丢弃令牌，通知源
日志已打开写入 rolled-back；目标撤销插入（限时 2 秒）；每个视图按原边界和可见性回到源；为这次移动创建的拖出窗口关闭，状态丢弃
源窗口已不在关闭转移中的视图，绝不留成无主

普通关闭规则不适用：移除源那份不产生关闭记录，不删除草稿，目标确认前也不打开兜底新标签页。

移动后的路由

菜单命令和 agent 网页标签命令只发给获得焦点的窗口。原生视图消息只接受来自拥有该视图的窗口的渲染进程。
