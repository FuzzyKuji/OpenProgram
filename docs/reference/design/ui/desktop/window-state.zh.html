桌面窗口状态

主窗口把上次的普通尺寸和最大化、全屏分开保存。普通窗口绝不贴齐菜单栏、Dock 或屏幕边缘打开，否则没有边可抓。

失败防护
Zoom 或拖满工作区后退出先创建较小的普通窗口，再恢复最大化
旧的贴边 {{x,y,width,height}} 文件迁移为最大化加内缩默认
保存的显示器已拔掉主屏工作区居中默认
文件损坏或尺寸过小最小尺寸加居中默认
标签行吞掉上沿5px no-drag 条
关闭撕下的窗口撕下的窗口不保存

代码：apps/desktop/main/windows/window-state.js、apps/desktop/main.js、apps/web/app/styles/base/desktop-chrome.css、apps/web/components/app-shell.tsx。有几个窗口、谁创建：窗口生命周期。

持久化结构

桌面 userData 目录（app.getPath("userData")，桌面名 openprogram-desktop）下的 window-state.json。

{
  "version": 2,
  "x": 160, "y": 90, "width": 1280, "height": 800,
  "isMaximized": false,
  "isFullScreen": false,
  "displayId": 1,
  "displayWorkArea": { "x": 0, "y": 38, "width": 1512, "height": 851 }
}
字段作用
x,y,width,height上次普通尺寸；绝不是铺满工作区的矩形
isMaximized上次 Zoom 或最大化
isFullScreen上次 macOS 原生全屏
displayIdElectron 显示器 id，屏幕仍连接时优先用
displayWorkArea重连后 id 变了也能对上
限制取值
最小800×500；不设最大
首次启动1440×900，在主屏工作区居中
内缩默认1440×900 会铺满工作区时，四边各内缩 24px
铺满与工作区相差不超过 8 CSS 像素；保存和恢复都检查
版本 1旧的 {{x,y,width,height}} 对象；加载时迁移

恢复

步骤动作
1. 读取并迁移JSON 损坏、缺宽高、NaN 或尺寸过小：居中默认
2. 找显示器displayId，再工作区（2px 容差），再与某块工作区重叠的尺寸。都没有：主屏工作区、居中默认，丢掉最大化和全屏
3. 检查是否铺满工作区保存的矩形铺满已连接的工作区：按最大化处理，普通尺寸改为内缩默认。BrowserWindow 从不按工作区大小构造
4. 钳制把普通矩形钳到工作区内
5. 隐藏创建按普通尺寸，并设 minWidth、minHeight。要最大化时先 setBounds 到工作区，再 maximize() 或 setFullScreen(true)，仍保持隐藏
6. 显示ready-to-show 时显示，macOS 不会从小框做放大动画

因此绿灯 Zoom 回到记住的普通尺寸。

没用 Zoom、拖满工作区

按最大化保存。保留的普通尺寸取第一个未铺满的：getNormalBounds()、内存里上次可用的矩形、内缩默认。

保存时机

事件写入
resize、move防抖 300ms
maximize、unmaximize、enter-full-screen、leave-full-screen、close立即写入
最大化、全屏或铺满时只更新标记和显示器身份，普通矩形不动

撕下的窗口

尺寸 min(1100, 普通宽) × min(720, 普通高)，不带父窗口 x/y，不继承最大化或全屏。由 centerHiddenWindowOnCursor 放到落点。

标题栏命中

区域行为
40px 标签行-webkit-app-region: drag，空白处可拖窗口
上、左、右边缘5px no-drag 条（.desktop-resize-edge），含四角，供原生缩放
macOS 红绿灯trafficLightPosition 居中于标签行：缩放为 1 时 {{x:13,y:12}}
标签页距顶 6px；边条不盖住标签、红绿灯、+ 和主菜单
贴边的普通窗口为什么拖不动

Electron 窗口仍可缩放，但在 1512 宽的显示器上 {x:0,y:38,width:1512,height:851} 没有边可抓，Zoom 也没有可回退的尺寸。通到边缘的拖动区域还会占掉上沿和四角的缩放命中。再设 resizable: true 或删文件都不解决问题；存储模型必须把普通尺寸和最大化分开。
