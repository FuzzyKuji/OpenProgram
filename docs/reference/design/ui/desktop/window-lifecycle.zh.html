桌面窗口生命周期

一个进程，一个主窗口。拖出的窗口是额外且短命的。

createWindow 是异步的。第一个 BrowserWindow 出现前，getAllWindows() 为空，不加保护的事件会各创建一个 id 为 main 的窗口，留下两个相同的窗口。

事件动作
就绪，没有存活主窗口创建一个
三者之一，创建进行中加入它
已有存活主窗口恢复、显示、聚焦
主窗口已销毁创建一个
第二个系统进程退出；第一个进程处理点击
拖出的窗口不是主窗口：自己的 id，不保存位置大小

代码

windows.get("main")
存活的主窗口
createMainWindowGate({ windows, createWindow })
返回 ensureMainWindow，创建或复用它的唯一入口
registerSingleMainWindow({ app, BrowserWindow, ensureMainWindow, recoverErroredWindows, onReady })
获取单实例锁并绑定事件。onReady（IPC、菜单、主题）只运行一次，在第一次 ensureMainWindow() 之前。
createWindow({ detached: true })
拖出路径

apps/desktop/main/windows/window-lifecycle.js、apps/desktop/main.js。测试：apps/desktop/tests/check-window-lifecycle.js。

不是窗口

  • LaunchAgent ai.openprogram.worker 让 worker 保持在 18100 端口。worker 慢时可能闪现错误页再重载，仍是一个窗口。
  • 启动 worker、ui.open_browser 和打包 .app 都不创建主 BrowserWindow。桌面壳作 UI 时，不要用系统浏览器打开 127.0.0.1:18100。
