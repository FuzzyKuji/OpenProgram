Session resources

The right-dock panel of complete software and environment objects a session uses. Code executions, commands and output belong to Activity; files to file views. Preview behaviour is in Resources and operation preview; web behaviour in built-in browser.

Panel

Entry
A Session resources row in the vertical right-sidebar navigation beside Files and Activity, with their row, icon and label classes. The dock toggle collapses to the icon rail.
Groups
The eight in Desktop. Webpage, Application and Terminal always show, folded and uncounted until loaded; other empty groups are omitted, as are closed or exited resources.
One row per Page
A Page used on several branches is listed once: the viewed branch's row if it used it, otherwise the newest. Unknown connection state stays in its type.
Filter
Only resources whose recorded owner matches the selected session, children under their type with actual owner shown. Drafts and unassigned views show none. Missing branch names create no group.
Switching session
Clears details and the selected view, and aborts previous requests.
Persistence
Type collapse per session; selected dock view across reloads. Collapsing the dock or choosing another view stops polling.
Selecting
A web row previews read-only, without activating or recreating the Page. A non-web row shows details, hiding the web preview without closing its Page. A Terminal row attaches a view to its existing PTY and never creates a shell.

Resource interface

OperationTerminalApplication
list, describeNative host inventory and generationInstalled, enabled manifest and declared operations
openCreate a private shell explicitlyOpen the installed instance
observeIndependent output cursor, input revisionInstance state, operation status
actInput or interrupt with observed revisionDeclared Agent-visible operations only

closeRequest termination, wait for exitOnly when declared

Unsupported actions return a capability error; nothing is invented. Web pages are not a provider here: computer_use_agent(target="browser") lists, opens, operates and closes them. terminal_use remains a public entry. A resource identifier is not an access grant. Hiding a view, releasing Agent access and terminating an environment are separate.

Backend operations and installed applications

Parity
Every product operation has an authenticated backend entry: HTTP from the registered schema, WebSocket commands through a request/response adapter on the same handlers. The Agent invokes operations by name without touching the interface.
Authority
Requires owner authority and tool approval, refuses an active sandbox or nonlocal backend, never returns owner credentials. Authentication, native receipt and connection-registration endpoints are not callable.
Window commands
Renderer preferences, navigation and native window functions address one connected window, with replies correlated to it. Disconnects and uncertain mutations do not retry. Window presentation needs a connected view; business and application operations do not.
Applications
An enabled installed application provides application.<id> with no restart or registry edit. open binds its durable instance, observe reads state and runs, act submits a declared operation, release removes only the association.
Lifecycle
Cancellation and answers target the exact instance and run. Disabled, removed or updated applications revoke stale descriptors. A scaffold command creates a runnable package.

Split canvases

ItemRule
Shared scopeFiles, Activity, Resources, the snapshot request and drop targets share one conversation scope; the sidebar owns the single window-level projection.
SelectionClicking a conversation selects it. Focusing a webpage or file pane keeps the last selected visible conversation. Hidden or unrelated conversations are never fallbacks.
Drop on ResourcesDropping a webpage on Resources attaches it to that panel's conversation. A split with several webpages needs the page's pane handle.
Drag feedbackTab and pane drags use the canvas docking's blue region with a release-to-add label; hovering the Resources row highlights it and its panel.
ReleaseRelease waits for native transfer cancellation and the confirmed association, then opens Resources with a success notice. Failure shows a retry message and keeps the page. Association does not change provenance.

Acceptance
  • Right-sidebar placement, per-session isolation, type grouping, session switching, collapse, pointer and keyboard use, native-browser coexistence.
  • Row-click preview, Open page of the same Page, preview hidden while that tab is active, no Pin control, no code, process or file entries beyond Background terminal.
  • Cross-session authorization; normal, exceptional and stale-owner release; reload.
  • Private-page discovery and exact-ID rejection, public opening, busy-Page rejection, acquisition after release, access changes during native operations.
  • Capability rejection before effects; user and Agent on one Terminal cwd and output; release without termination; changed-generation rejection; no write replay; actual exit before restart.
  • Backend discovery and invocation with no rendered frontend; invalid, unauthorized and unsafe calls rejected before effects; install, disable, update and remove discovery.
  • Chat and web splits, two chats plus a webpage, hidden conversations, drag hover, cancel and release, correct session IDs.
  • Reveal, navigate, close and reopen for Agent and manually associated Pages; split and bulk closure; standalone and explicit destruction.
