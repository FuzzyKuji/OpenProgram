方面规则
条目标题资源的实际名称。页面标题变化只更新条目，不改分组。
条目副标题状态（操作中、运行中、连接失败），需要时加所属 Agent、来源、分支和连接。没有会话标题这一层。
外部是来源，不是类型：外部虚拟机仍在虚拟机下，外部网页仍在网页下
范围只显示与当前会话关联的资源。跨分支的同类资源在同一组。
数量该类型的有效资源数。切换 Agent 或改名不改变分组顺序。
已关闭或已退出离开活动列表；历史可在详情中显示
状态不确定留在原类型下并显示错误，不当作已关闭
刷新失败已知类型和条目保留并显示失败。不改名，不自动选别的资源，不重试结果未知的关闭。

操作

操作视图资源

行按钮：在会话中预览重新打开小窗不变
行按钮：在标签中打开切换到已有标签不变
行按钮：关闭网页条目和小窗消失已关闭
小窗：打开页面同一资源的完整视图；网页用顶部标签。没有完整视图时隐藏。不创建副本
小窗：关闭小窗（X）小窗隐藏，条目保留页面仍在，环境继续运行
小窗：查看请求Agent 等待确认时显示不变
更多：自动显示 Agent 正在操作的网页开：显示本会话正在操作的页面。关：保持当前页面。不改变 Agent 目标和任务
终止环境文字菜单中写明对象的显式操作；仅在支持时出现沿用现有确认和权限规则

更多菜单

方面行为
网页上的项目自动显示 Agent 正在操作的网页（复选框、可换行标题、可见说明）；显示操作（复选框）；操作历史（子菜单）。虚拟机、终端和应用只显示实际支持的功能。
载体应用自己的菜单。桌面端在原生页面上方的 HTML 浮层绘制，主进程 IPC 和控制浮层共用同一个原生菜单服务。Web 用相同的内容和样式。
切换时菜单保持打开，勾选立即更新；自动切换页面也不关闭菜单
关闭方式Escape、点击外部、再次点更多、关闭小窗
跟随但没有被操作的页面保持当前页面

当前事件结果

小窗可见关闭小窗只隐藏视图，保留选择和模式。之后的 Agent 活动不会重新打开。
跟随开启，小窗可见Agent 切换页面小窗更新，只限本会话允许的页面
正在查看虚拟机、终端或应用Agent 切换页面页面跟随不替换它
重新打开网页重新打开应用会话保存的显示策略；明确选择的页面保持不变
任意切换资源替换唯一小窗的视图
任意切换会话隐藏旧小窗；恢复新会话自己的选择和可见性
无预览能力打开打开现有详情，不显示假预览或已连接状态。未知、连接中、失败都是明确状态。
  • 资源身份、会话归属和访问权限不随分组或视图切换改变。
  • 分组折叠、面板隐藏、小窗隐藏各自独立持久化。折叠只隐藏行；隐藏面板不影响小窗。分组折叠按会话和类型保存。

实现

部分代码必须成立
类型分组session-resources.ts：groupSessionResources、资源类型、预览偏好。session-resources-panel.tsx：标题、行按钮、折叠。网页和虚拟机分属不同组；改名不改分组；同类跨分支在一起
小窗和菜单web-tab-pip.tsxX 隐藏；行上的预览按钮重新打开；行按钮不变；跟随语义一致
各资源的视图现有终端和应用视图、provider 能力显示和隐藏语义相同；不新增虚拟机控制后端；不支持预览时回退到详情
状态资源存储、会话选择、已保存偏好会话隔离，隐藏后不重开，刷新后恢复，最小宽度下关闭小窗不被遮挡
桌面菜单原生菜单服务授权窗口弹出、选择返回、取消清理
