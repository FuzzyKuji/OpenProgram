Resource panel and preview

Groups come from the resource type. Names belong to entries. Hiding a preview never touches the resource.

A group, header included, appears only when it has resources; with none at all the panel shows one line saying so.

  • Resource identity, session ownership and access rights do not change with grouping or view switches.
