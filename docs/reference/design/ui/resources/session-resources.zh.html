会话资源

右侧停靠区的面板，列出会话使用的完整软件和环境对象。代码执行、命令和输出属于活动，文件属于文件视图。预览行为见资源与操作预览，网页行为见内置浏览器。

面板

入口
右侧栏纵向导航中，文件和活动旁的“会话资源”行，使用相同的行、图标和标签类。停靠切换按钮收起到图标轨。
分组
八组见桌面版。网页、应用和终端始终显示，加载前折叠且不计数；其他空组省略，已关闭或已退出的资源也省略。
一个页面一行
多个分支使用的页面只列一次：当前查看分支用过则显示其行，否则显示最新的行。连接状态未知时留在原类型。
过滤
只显示记录的所有者与所选会话匹配的资源，子 Agent 的资源按类型列出并标明实际所有者。草稿和未分配视图不显示资源。缺少分支名不产生分组。
切换会话
清除详情和选中视图，中止之前的请求。
持久化
类型折叠按会话保存；选中的停靠视图跨重载保留。收起停靠区或选择其他视图时停止轮询。
选择
网页行只读预览，不激活也不重建页面。非网页行显示详情，隐藏网页预览但不关闭页面。终端行把视图附加到现有 PTY，绝不新建 shell。

来源与归属

资源权威来源生命周期
网页CenterTab 记录和记录的会话来源；Agent 打开的标签页通过桌面命令携带可信的运行时会话 ID直到网页关闭。Agent 页面留在资源中，用户打开和置顶的页面留在标签条。
GUI 桌面、虚拟机可信使用登记表和配置的应用或虚拟机端点集成附着期间
其他集成相同可信上下文下的 resource_use(kind, title, target)上报的实际使用期
后台终端bash 调用留在运行的命令（设置了 background），ProcessStore 唯一的投影；见命令会话直到退出；只读行，带停止

集成必须指明实际的容器、虚拟机、应用或远程环境。单条命令的 Docker 调用和 SSH 子进程不登记，登记表不扫描主机，也不从 shell 文本推断对象。

授权和显示限制
项目规则
授权服务器返回资源前检查会话和执行授权。来自已授权后代范围的行仍按实际所有者过滤。
浏览器行浏览器行归渲染层所有；后端请求只覆盖所选会话。
登记表载荷登记表载荷只含有界的显示字段；URL 去掉凭据、查询参数和片段。
原生边界原生浏览器边界随剩余中央区域调整。
复用复用右侧停靠区、中央标签存储、已授权的资源路由和原生边界上报。没有第二个浏览器管理器或通用破坏性操作协议。

预览与页面访问

规则行为
预览范围按会话 ID 保存，与聊天标签无关。在标签内导航只显示所选会话的预览。
私有页面未作为顶部标签打开的保留 Agent 页面属于其会话。清单、轮次上下文、截图、解析、激活和关闭都按可信执行归属强制执行。
打开页面成为普通标签：其他会话可发现，并在独占页面租约允许时获取。来源和预览归属不变。
待返回结果交付前仍须匹配当前访问范围

关闭标签

操作页面效果
关闭标签或分屏窗格关联会话的隐藏；原生视图、导航和关联保留，可从资源重新打开
关闭标签或分屏窗格独立的移除；销毁原生视图
关闭网页、已授权的 Agent 关闭任何打开的页面，无论有无标签销毁
关闭会话其保留页面保持打开
步骤结果
关闭网页立即隐藏该行并关闭其标签
POST /api/session/{id}/resources/{resource_id}/close关闭页面记录并撤销绑定，不依赖渲染层的销毁回执
请求失败该行恢复
套接字断开期间确认的原生关闭在下次窗口注册后上报
动画结束判定归属；隐藏的页面离开分屏组，不能作为活动回退

资源接口

操作终端应用
list、describe原生主机清单和代数已安装启用的清单和声明的操作
open明确创建私有 shell打开已安装实例
observe独立的输出游标和输入修订号实例状态和操作状态
act按观察到的修订号输入或中断仅声明为 Agent 可见的操作
release释放 Agent 绑定，保留进程解除关联
close请求终止，等待退出仅在声明时

不支持的动作返回能力错误，不做虚构。网页不是这里的 provider：列出、打开、操作和关闭网页都用 computer_use_agent(target="browser")。terminal_use 仍是公开入口。资源标识符不是访问授权。隐藏视图、释放 Agent 访问和终止环境是不同的操作。

后端操作与已安装应用

一致性
每个产品操作都有经过认证的后端入口：HTTP 来自注册的 schema，WebSocket 命令通过同一处理器上的请求/响应适配器。Agent 按名称调用操作，无需接触界面。
权限
需要所有者权限和工具审批，拒绝活动沙箱或非本地后端，绝不返回所有者凭据。认证、原生回执和连接注册端点不可调用。
窗口命令
渲染偏好、导航和原生窗口功能指向一个已连接窗口，回复与其关联。断连和不确定的变更不重试。窗口呈现需要已连接视图，业务和应用操作不需要。
应用
启用的已安装应用提供 application.<id>，无需重启或编辑登记表。open 绑定其持久实例，observe 读取状态和运行，act 提交声明的操作，release 只解除关联。
生命周期
取消和回答针对确切的实例和运行。禁用、移除或更新的应用撤销过期描述符。脚手架命令创建可运行的包。

分屏画布

项目规则
共用范围文件、活动、资源、快照请求和放置目标共用一个会话范围；侧栏持有唯一的窗口级投影。
选择点击会话即选中。聚焦网页或文件窗格时保留最后选中的可见会话。隐藏或无关的会话绝不作为回退。
拖到资源把网页拖到资源上，会附加到该面板的会话。含多个网页的分屏需拖对应页面的窗格手柄。
拖动反馈标签和窗格拖动使用画布停靠的蓝色区域和“松开以添加”标签；悬停资源行时高亮它和面板。
松开松开后等待原生传输取消和关联确认，然后打开资源并提示成功。失败时显示重试信息并保留页面。关联不改变来源。
