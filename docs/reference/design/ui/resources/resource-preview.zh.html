资源与操作预览

资源按类型列出会话用到的全部目标。一个聊天预览跟随当前查看分支最近操作的目标。Agent 打开的页面留在后台，不增加顶部标签。

相关：会话资源、资源面板与预览交互、浏览器控制面、Agent 控制覆盖层。

资源上的操作

操作预览页面与标签
点击行在聊天中显示目标，自动或固定预览不变。当前标签不变
在会话中预览（图标）与点击行相同；恢复已隐藏的预览。中央是网页时，激活所属会话，不改变查看分支。同一页面，不加顶部标签
打开页面隐藏预览及其预留空间。回到会话后恢复，除非用户隐藏过。同一页面成为普通顶部标签；重复打开沿用
放大、拖动、缩放同一目标，只换呈现不复制、不重载，不把原生应用提到前台
关闭预览（隐藏）保持隐藏，之后的事件不会重新打开。没有“显示预览”控件。页面、后台工作和资源行都保留；停止捕获
关闭网页显示不可用状态关闭真实页面；先列出受影响的引用

资源没有置顶控件和搜索框。明确置顶或用户打开的顶部页面仍是普通视图，迁移不会关闭它们。

跟随

范围
每个 App 窗口最多一个预览。偏好属于当前查看的会话和分支，选择资源不会改变分支。
触发
只有该分支中主机接纳的操作事件，包括 observe。打开资源、状态轮询或收到截图都不会切换。
自动预览
“更多”里的复选框自动显示 Agent 正在操作的网页开启它，并回到最新接纳的操作。点选的目标保留到下一个被操作的页面替换它。
固定预览
取消勾选后当前页面保留。Agent 继续工作，不能替换它。重载后不保留。
子 Agent
父分支按主机派发顺序跟随自己和子执行，并标明活动 Agent。子窗口只跟随自己的分支。
切换分支
恢复该分支的偏好；新偏好跟随其最新目标、目标的不可用状态或空状态。其他分支可继续运行，但不能替换预览。
目标已关闭
清除“操作中”，显示不可用或最后一帧，直到出现更新的接纳操作或新选择。绝不退回旧资源。
其他分支的资源
查看既不检出该分支，也不授予写权限。
原生窗口和终端
  • 函数结果给出 target（window_id、pid、app_name）时，预览移到该应用。
  • Worker 按会话只在内存中保留最新窗口和截图，广播 native.window，由 /api/session/{id}/native-window/frame 提供画面。
  • agentic 子进程中的 GUI 步骤把窗口转交 Worker，Worker 归属到拥有该子进程的会话。
  • 预览显示 Agent 最后看到的内容，不是实时画面。
  • 终端开始运行或收到输入时移动预览，预览只读镜像其屏幕。
  • 置顶只保留页面。

目标类型

目标后台与预览人的入口限制
浏览器页面确切的 Page/CDP 目标，保留文档、登录和导航状态；预览不激活它实时标签：可读、可滚动、可交互页面关闭、失去归属和过期帧都会停止写入。重新打开 URL 是新资源。
原生应用窗口确切的进程和窗口；可用时支持捕获和已验证的后台输入。显示后台控制、仅预览或需要前台。原应用，即使不支持后台自动化不承诺能后台控制所有应用。最小化、锁屏、缺权限和身份不明各有说明。提到前台需明确选择。
主机桌面一块显示器及其坐标；没有独立于用户的输入环境真实键盘和鼠标全局输入会影响用户工作。绝不标为后台控制。布局变化使坐标失效。
虚拟机显示无需前台主机控制台的客机显示和输入；虚拟机、客机会话和显示服务必须运行OpenProgram 客机控制台或已授权的 VNC/RDP 控制台缺会话、客机锁定或显示断开都有明确状态。重连绝不重放不确定的输入。Docker 是可选项。
外部浏览器、只读流需要已验证的标签绑定；URL 相同不代表同一标签在原浏览器打开、仅查看、需要重连或已关闭截图绝不是输入面。重建目标是单独的操作。
页面的弹窗
方面规则
Agent 页面的弹窗在后台加载，登记到打开者的会话、分支和执行（webtab_popup）
告知 Agent列在打开它的那次动作的结果里；Agent 按标签页 id 操作它
跟随只有操作指向弹窗时才切换
用户页面的弹窗在前台打开，不被接管
桌面端在 Chromium 创建的 WebContents 上构建弹窗页面，因此 window.opener 继续可用

实时页面与人的使用

规则行为
互斥呈现页面显示为实时标签或聊天预览，二者不并存：一个原生 WebContentsView 无法占据两个矩形。不在页面旁或页面上放截图，不变暗，不加阻挡层。
预览图只读：绝不转发点击、按键或滚动。不为放大而裁剪或缩放。
人的使用在真实页面里点击、输入、滚动和导航直接作用于页面，不暂停 Agent。只有任务的暂停和停止会。
旧观察人改动过的页面（包括悬停引起的变化）使 Agent 之前的观察失效；它在操作前重新观察。
不作承诺零重叠：已派发的操作可能无法撤回，迟到结果会被记录并重新观察。不撤销人的改动。
内部状态工具栏和预览文字
active、yielding、stop_unconfirmed会话运行时为“活动中”，否则“可直接操作”
paused、idle、closed可直接操作
waiting需要你确认，并提供“查看请求”
unknown无法确认状态；断连时为“连接已断开”

停止请求 5 秒未确认即变为 stop_unconfirmed，新的 Agent 派发保持关闭。这个超时不能证明已停止。

预览外框
  • 一行且绝不换行，覆盖 240px 最小宽度、300×198.75 默认尺寸（300×168.75 图像加标题行）和 720px 放大宽度：省略的标题、状态、打开页面、更多、关闭预览。
  • 显示操作和操作历史在“更多”里。
  • 失败文字通过状态指示、标题提示和 aria-live 获取。
  • 可从四边和四角缩放。
  • 窄屏产品布局用资源抽屉选择目标，聊天和预览仍可访问。
捕获与几何
  • 从未显示过的页面以 1920×1080 CSS 像素视口和常规缩放创建。预览边界和布局缩放跟随预览尺寸。回到后台的页面保留最后的原生边界。
  • 桌面预览就是原生页面，拖动时也实时渲染。普通浏览器预览用单独的沙箱 iframe，受浏览器嵌入限制。
  • 只有可见预览订阅画面。每帧带资源 ID、连接代数、序号和捕获时间；旧绑定的帧被拒绝。
  • 延迟或失败的捕获标为“最后一帧”并显示时长；没有图像时显示“无画面”。
  • 拖动在按下时缓存容器边界，按动画帧用 transform 移动，不读布局也不写状态。抬起、取消或失去捕获时写入一次夹取后的位置。卸载、失去实时或切换资源时放弃拖动。
  • 拖动期间暂停捕获。暂停前开始的捕获被丢弃，同一时间只有一个捕获在进行。
  • 快速的目标变化合并约 200ms，只渲染最新帧。

操作提示

提示规则
位置只在 OpenProgram 自己的表面：托管网页框架和工具栏、客机控制台、预览层。绝不装饰外部应用、主机桌面和外部 VNC/RDP 客户端。
边缘在可见表面上：细微的 1px 外发光，活动中为蓝色，其他状态无发光。不变暗，不改布局和点击区域，不闪烁。
标记圆环表示点击，路径表示拖动，箭头表示滚动；输入只标字段不露秘密；快捷键用文字。绝不移动用户光标。减少动态时用短暂静态标记。
显示操作默认开启，只显示最近一次操作。隐藏标记，不影响边缘、执行和历史。
操作历史点击、输入、滚动、拖动、导航和验证，按顺序，来自可信的主机回执：已尝试、已派发、已确认、失败、未知。
坐标绑定资源 ID、代数、帧和视口映射，考虑内容边界、DPR、缩放、滚动和 iframe 偏移。几何过期时移除实时标记，历史保留旧帧标签。没有精确点时用元素边界或文字。
图层主机所有，pointer-events:none；不向外部页面注入任何内容。让出时清除标记，迟到回执只进历史。

归属与并发

描述符
资源 ID、类型、脱敏目标、实际所有者、生命周期、连接代数、预览能力。句柄和租约留在主机，无法恢复。
关联
来源调用、分支、子 Agent、共享方式，以稳定的分支身份或可验证的分叉谱系为键。分叉不复制外部页面状态。
身份
URL 相同的不同页面保持不同；同一实际页面的行合并。标题和秘密查询值绝不用于确定归属，秘密查询参数不保存。
子 Agent
列在来源父分支下，并标明实际所有者。之后的工作不能改写来源，共享分组不授予访问权。
分支写入
祖先资源显示“引用自”。浏览器写入默认用独立页面，但不声称站点或登录隔离。原生窗口和虚拟机需要明确转交或换目标。
写租约
按输入范围排除冲突。第二个写入者收到 busy，不排队不抢占。子 Agent 的租约随其结束，父级不继承。
事件
携带会话、分支、资源、代数和单调序号。分支变化、重连或撤销后丢弃过期事件。
旧记录
无法证明分支归属的放在“未分配”，不做猜测迁移。

生命周期与关闭

事件效果
任务完成释放 Python、输入租约和临时观察。页面和虚拟机保持空闲；声明为临时的资源按其策略处理。
断开窗口绝不退出应用，无论由用户还是 Agent 打开。退出应用是单独操作。
断开虚拟机只释放传输；客机和显示继续运行。停止虚拟机是单独操作，隐藏预览绝不触发。
移除引用只解除空闲关联
关闭使用中的目标显示受影响的执行，请求停止，等待租约释放。确认前保持“停止中”。已关闭记录收进不可用分组，不计入默认数量。
断连、撤销最后一帧标为过期，关闭远程输入。身份不明时停止写入并清除“操作中”。重连只读，且只连可验证的同一实例。
App 重启恢复分组和预览偏好，绝不恢复远程输入连接或写租约。页面崩溃和虚拟机重启需验证身份。
原生聚焦或结果检查失败输入失败：撤销写入，保留证据，不在后台重试
旧适配器执行中，操作状态未验证；不显示操作圆点
内存压力提供明确释放；绝不悄悄丢弃表单或停止虚拟机

“操作中”从适配器验证后派发开始，到回执、确认取消或失败结束。空闲目标保持连接但不高频捕获，也不扫描主机应用。

列表和行的外观
  • 文件、活动、资源仍是右侧栏顶部的纵向导航。每个资源不加边框卡片。
  • 分组标题复用左侧栏 SectionHeader：14px 次要文字，标题后 16px 箭头，数量在尾部；Enter 或 Space 只折叠该组。
  • 行高约 44–48px：标题，其后按需显示类型、状态和子 Agent 名称。长标题截断；详情显示完整标题、脱敏来源和身份。
  • 操作中和选中相互区分，除颜色外还有文字。
  • 网页行有三个 Lucide 图标按钮：在会话中预览、在标签中打开、关闭网页（24px 点击区、14px 图标，同 PiP 工具栏）。
后续回看与学习
  • 现有回执包含任务、分支、资源、前后观察、目标、参数、顺序、结果和人的修正。可见提示使用同一来源。
  • 经用户同意，后续任务可读取选定的脱敏片段，分析定位错误或提出可复用规则。
  • “录制我的下一次演示”是单独的选择，有明确的开始、停止、范围、预览和删除。绝不保留秘密字段、密码、安全输入和带凭据的 URL。
  • 图像只有通过权限和脱敏检查才保存，否则只留无内容的元数据。
  • 任务内回看、保存步骤和模型训练是不同阶段。不自动训练或上传；提出的规则在独立测试目标上验证。

会话中的工具活动

computer_use_agent 调用按目标和步骤显示在时间线上：应用和动作、页面动作和 URL、虚拟机动作、在应用中运行的代码，或交给新 Agent 的任务及其说明首行。早期 GUI 工具（gui_agent、computer_use、browser_use、vm_use）的调用在详情面板中打开，原始参数和输出上方有 GUI 活动卡片。

部分内容
结果运行中、动作已应用、成功、失败、需要接管、已取消、已中断、已暂停或结果不可用，卡片和时间线共用。取代传输层状态徽标。没有明确状态时为“结果不可用”。
接管突出记录的阻碍和用户操作；重复它们的摘要不显示。任务文本只在原始参数中。
步骤能力、目标、状态，按记录顺序；失败和停止的步骤附两行原因。来自结果历史，运行中来自可见的能力子节点，不计嵌套规划调用。直接的能力调用没有步骤列表。
归属详情携带会话 id，绝不替换另一会话中相同调用路径的详情。输出获取失败只显示错误，不把调用标为失败。
截图不提供：捕获路径是临时目录，不在可读附件根内。

验收用例
  • 一个分支打开五个页面：不多出顶部标签，全部列出，操作选中预览。对从未打开的页面“在会话中预览”不加标签，并进入固定预览。
  • 两个分支及其子 Agent 并发：保留来源，不重新绑定。
  • 查看 A 时 Agent 操作 B：A 保留，B 显示操作中，开启自动显示后回到 B，标签焦点不动。
  • 关闭预览、缩放和折叠分组都不重载页面、不停虚拟机、不授予控制、不销毁目标。
  • 关闭活动目标、撤销、迟到帧、重启和断连都有明确状态；未确认的停止不算已暂停。
  • 打开标签后填满内容区；不变暗的内容保持可交互，单纯聚焦不暂停。
  • 标记绝不拦截输入，也不按过期几何绘制。
  • 同进程窗口、并发用户输入和两台虚拟机分别验证冲突范围。捕获成功不代表支持后台输入。
