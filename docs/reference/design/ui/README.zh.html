Web UI

只有一套工作区界面：React 和 Next.js 应用（apps/web/），预先构建，由 Python worker 在 API 同一端口提供，所以同样的页面运行在浏览器标签页、桌面 App 和远程服务器上。apps/desktop/ 是 macOS 和 Windows 的 Electron 外壳；Linux 和服务器用浏览器。

部分现状
侧栏和页面项目和聊天；Agents、Abilities（Programs、skills、plugins、MCP）、Applications、History、Scheduler。设置在用户菜单。列表页共用一个二级侧栏。
中央标签页聊天、文件、终端、网页。标签页可分屏；标签页和分组可在窗口间移动。
转录回复，工具调用折叠成行，文件修改摘要，子代理行，等待中的请求。跟随新输出，直到你滚开。
输入框附件、模型和强度选择、按文件夹的 git 胶囊、选项菜单。本地路径保留到模型上下文。
视觉系统颜色、尺寸和形状来自 token 和主题；图标、圆点和悬浮提示各有一套规则。

改相关模块前先过一遍跨模块 UI 不变量。
