头像设置

AvatarPicker 设置显示在侧栏底部的用户头像。类型是唯一入口；生成的变体只属于当前风格。

类型控件保存为
生成从 AVATAR_STYLES 选风格，再选该风格的变体。重新生成只改种子。换风格时尽量保留种子，否则使用显示名称。kind: "dicebear"、当前风格、种子
字母字符和颜色，在选择器内编辑资料的 initial 和 color
上传一个图片文件kind: "upload"

布局

设置行左侧是不拉伸的标签，右侧是按内容取宽的控件；头像排在预览和显示名称之后。变体使用固定 48px 轨道（repeat(auto-fill, 48px)），在右侧控件组内换行，绝不拉伸。

未采用的方案
方案原因
一行列出全部风格加字母和上传类型和风格混在一层，字母字符还要到卡片外编辑
变体覆盖全部风格选变体会改变已选风格
变体网格用 1fr图块被拉伸以填满卡片

不变：AvatarConfig 的 kind（dicebear、letter、upload）、存储字段、Avatar 渲染、Agent 和用户资料存储、DiceBear 依赖。实现在 apps/web/components/avatar/avatar-picker.tsx 和 variants.ts；由 apps/web/tests/settings/avatar-randomization.test.mjs 和 theme-appearance.test.mjs 测试。
