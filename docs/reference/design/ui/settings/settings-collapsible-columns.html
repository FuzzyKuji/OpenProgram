Categories

General, Appearance, LLM Providers, Memory, Web Search, Browser, Voice, Environments, Channels, Import, Token Usage, System. Links, icons, active state and keyboard order follow this one array.

Toggle
Native button with aria-expanded, aria-controls and an explicit name, its icon on the axis of the category icons
Narrow window
Below 760px the rail starts collapsed with no saved choice, and shrinking collapses it without saving. Widening never expands it: the stored choice stands.
Rows
Same y positions, 32px height and 1px gap as the main sidebar's rows
Titles
Settings and the content title use --fs-title (18px), line height 1.2 so descenders are not clipped

Acceptance
  • No separate global Settings topbar.
  • Category rows line up with the main sidebar's first rows; the first icon keeps its y when collapsed.
  • Category order, URLs, icons, active state and keyboard order agree.
  • Provider list has no named header or collapse button; search spans the column; group labels and Add Custom Provider stay visible.
  • Route loading keeps the full Providers title structure; Memory has no duplicate title.
  • Narrow details have no overlap or overflow; account name, key, status and actions stay usable.
  • No separate Validate button. Add API key expands and cancels.
  • Icon actions carry aria-label.
