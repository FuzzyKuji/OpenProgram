分类

通用、外观、LLM Provider、记忆、网络搜索、浏览器、语音、运行环境、频道、导入对话、Token 用量、系统。链接、图标、选中状态和键盘顺序都来自这一个数组。

切换按钮
原生按钮，带 aria-expanded、aria-controls 和明确名称，图标与下方分类图标同轴
窄窗口
低于 760px 且没有保存选择时默认收起，缩窄时收起但不保存。变宽绝不展开：以保存的选择为准。
行
y 位置、32px 行高和 1px 间距与主侧栏的行相同
标题
“设置”和内容标题使用 --fs-title（18px），行高 1.2，避免下伸部被裁切

参考与不做的事
来源用途
WAI-ARIA APG Disclosure按钮语义和 Enter 或 Space。不涉及列宽和标题。
MDN aria-expanded状态与可见列一致；不用 aria-pressed。
不做拖动调整列宽、断点覆盖用户选择、改动记忆、Provider 或模型数据、改动主侧栏
验收
  • 没有单独的全局设置顶栏。
  • 分类行与主侧栏前几行对齐；收起时第一个图标的 y 不变。
  • 分类顺序、URL、图标、选中状态和键盘顺序一致。
  • Provider 列表没有命名页头和收起按钮；搜索占满列宽；分组标签和添加自定义 Provider 保持可见。
  • 路由加载保留 Provider 的完整标题结构；记忆没有重复标题。
  • 窄详情无重叠和溢出；账号名、密钥、状态和操作都可用。
  • 没有单独的验证按钮。添加 API 密钥可展开和取消。
  • 图标操作带 aria-label。
