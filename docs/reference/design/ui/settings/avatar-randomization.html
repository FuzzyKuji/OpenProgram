Avatar settings

AvatarPicker sets the user avatar shown at the bottom of the sidebar. Type is the only entry point; generated variants belong to the current style alone.

Layout

A settings row has a non-stretching label on the left and content-sized controls on the right; Avatar follows Preview and Display name. Variants use fixed 48px tracks (repeat(auto-fill, 48px)) that wrap inside the right-hand group and never stretch.
