搜索

控件行为
工具栏搜索按钮打开或关闭面板；关闭时清空查询
过滤（默认）保留匹配项及其祖先；搜索时折叠的文件夹展开；无匹配时显示空提示
高亮保留所有行，标出匹配字符
模糊（默认开）字符按序匹配；关闭时为连续子串
匹配对象行名或目录标签，不分大小写
计数当前和总数，如 2 / 5
上一个、下一个、ArrowUp、ArrowDown移动当前匹配，循环
清除清空查询，面板保持打开
Escape关闭面板

目录树

分支行用点击、Enter 或空格切换，文件夹图标随之变化。刷新会重新扫描 Programs。

增量加载

客户端行为
导航间保留已加载目录、选中项、展开的文件夹、调用图
重新校验可见文件夹和选中的图，后台每五秒一次，聚焦或手动刷新时也校验
未变化的响应只有版本确认
失败保留可用内容，允许重试
服务端行为
依赖构建响应时记录文件和目录元数据；重新校验时检查它们以及注册表和目录身份
已解析模块按文件身份、大小、纳秒级修改和变更时间失效
新增或删除的条目使父目录失效
限制现有的包含检查和源码限制仍然生效
存储有界进程内存；不加文件系统监听，不加持久用户数据缓存
验收

预热导航立即渲染；未变化的源码不读取也不解析；编辑、新增、删除更新受影响的视图；刷新保留选中和展开。
