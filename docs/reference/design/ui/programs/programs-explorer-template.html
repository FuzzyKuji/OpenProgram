Search

ControlBehaviour
Toolbar search buttonOpens or closes the panel; closing clears the query
Filter (default)Keeps matches and their ancestors; collapsed folders open while searching; no match shows an empty hint
HighlightKeeps every row and marks matching characters
Fuzzy (default on)Characters in order; off means a contiguous substring
Match targetRow name or catalog label, case-insensitive
CountCurrent and total, as 2 / 5
Previous, next, ArrowUp, ArrowDownMove the current match and wrap around
ClearEmpties the query, keeps the panel open
EscapeCloses the panel

Tree

A branch row toggles with a click, Enter or Space, and its folder icon follows. Refresh rescans Programs.

Incremental loading

ClientBehaviour
Kept across navigationLoaded directories, selection, expanded folders, call graphs
RevalidatedVisible folders and the selected graph, in the background every five seconds and on focus or manual refresh
Unchanged responseA revision acknowledgement only
FailureUsable content stays; retry is offered
ServerBehaviour
DependenciesFile and directory metadata recorded while a response is built; revalidation checks them and registry and catalog identity
Parsed modulesInvalidated by file identity, size, and nanosecond modification and change times
New or removed entriesInvalidate the parent directory
LimitsExisting containment checks and source limits remain authoritative
StorageBounded process memory; no filesystem watcher, no persistent user-data cache
Acceptance

Warm navigation renders immediately; unchanged sources are neither read nor parsed; edits, additions and deletions update affected views; refresh preserves selection and expansion.
