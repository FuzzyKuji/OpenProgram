The built-in browser does not install extensions

Removed in 0.7.0. No browser-engine replacement and no Chrome or Edge remote-control dependency.

Why

Electron implements only some extension APIs, and keeping up with the rest is outside the goal of reliable browsing and Agent web operation.

ReasonDetail
Missing APIsMany store extensions depend on Manifest V3 service workers, chrome.action, account sync or browser-specific behaviour
Partial failureDownloading and loading can succeed while login, background tasks, popups or page injection fail
Preflight limitsLabels cannot cover runtime APIs, background lifecycles, toolbar interaction or vendor browser detection
UpkeepStore protocols, CRX verification, permission explanations, API compatibility, updates and diagnostics

Architecture

persist:webtabs sessions handle only page state, cookies, downloads and DevTools or Agent control, and load no third-party code before startup. There is no manager, registry, CRX install IPC or Extensions page.

A future cleanup entry for browser-extensions/ data must list its targets and be user-initiated.
