Agent 在这些网页上

主题规则
会话网页按会话分组，在会话资源面板中默认折叠（会话资源）。记录保留会话归属和置顶状态；手动打开的网页和明确分屏留在顶层。
暂停点击、滚动、按键、导航和关闭网页都不会暂停 Agent，无论来自用户还是自动化，包括对 OpenProgram 自身的自动化。只有对话的执行控制能暂停或取消。浏览器资源没有单独的写入禁令；分发守卫、所属检查和当前帧校验保留。
目标丢失丢弃会话，工具返回带最后 URL 的恢复信息。恢复时观察在该 URL 新打开的网页，绝不重放变更操作或挑选无关标签。缺少认证或未保存的状态如实报告。
关闭截图保留 ToolReturn 图片和结构化错误。运行中的服务不会向已关闭的默认执行器提交任务；恢复尊重取消和未决的外部效果。
浏览器步骤执行和调用方上下文
  • 工作流负责观察、操作、验证循环。每个规划请求设置 stop_after_tool_round：共享 Agent 循环执行一轮经校验和授权的工具调用，保留回执后返回，不再请求模型。默认 Agent 调用仍持续到最终输出。
  • 与安全上限 max_iterations 无关。耗尽上限不可重试，已完成的操作不会重放。结构化最终输出契约不能与这种提前返回同用。
  • 每次向 Playwright 所属线程提交 BrowserPageController 任务（含清理和最终验证）都携带当前 ContextVars，按次复制。Page 隔离、绑定校验、权限和操作租约仍是最终依据。
  • 旧式浏览器任务使用明确绑定的当前 Page，不因 URL 提示而重新加载。明确绑定已过期时失败，不打开替代 Page。没有明确 Page 时，URL 和打开行为不变。
文件选择和规划失败
  • 规划器用已批准的本地路径和新鲜的 file-input ref 上传，受沙箱读取、审批、Page 所属、取消和步数限制。MCP 规划器用同一个控制器。
  • 文件输入暴露类型和所选文件名，绝不暴露字节或本地路径。选择文件不等于服务器接受：file_selected 检查确切的当前输入，最终证据重新核对。
  • 验证用 value，不用输入文字。无效调用返回可操作的错误；同一帧连续失败三次后停止并保留具体错误。规划器可以带阻塞原因停止，这不算成功。操作计数算 Page 变更，不算模型请求。

网页标签的身份

部分行为
User-Agentwebtab-user-agent.js 只去掉 App 自己的标记，保留 Electron/x 和完整 Chrome 版本：自称纯 Chrome 而 navigator.userAgentData 没有 Google Chrome 会被视为伪造，卡在 Cloudflare 质询
通行 Cookiecf_clearance、__cf_bm、cf_chl_* 只对获得它们的 User-Agent 有效。与 webtab-user-agent.json 不同时，App 在任何标签加载前移除它们，其他 Cookie 保留。
Client HintsElectron 不发 Sec-CH-UA。webtab-client-hints.js 从回环页读一次 getHighEntropyValues()，然后向安全源发送 Sec-CH-UA、-Mobile、-Platform，以及源在 Accept-CH 中点名的高熵提示
权限webtab-permissions.js 放行 Chrome 静默允许的（全屏、指针锁定、写剪贴板、外部协议），对摄像头、麦克风、定位、通知等在标签所在窗口弹原生对话框，其余拒绝。回答按源存在 webtab-permissions.json；清除网页标签 Cookie 时一并忘记。未决权限读作 denied，因为 Electron 的检查处理器只有是或否。
无人查看的网页请求权限不在聚焦窗口里显示的网页发出的请求只拒绝这一次，不保存，用户打开该网页时再询问。
引擎apps/desktop/package.json 固定的 Electron 跟随 Chrome 稳定版（Electron 45 是 Chromium 156）；安装版按稳定版和开发版实例获取
不修补window.chrome 为空，没有 Widevine。需要完整 Chrome 的网页是另一套设计：Agent 在用户自己的 Chrome 里工作。
