浏览器操作与任务控制

对固定版本 Playwright 的结果生成器增加空标签页列表检查：异步读取快照期间脱离或关闭标签页，不能导致读取不存在的页面摘要。结果暂时没有受控页面时，只重试读取快照，最多三次；不重放导航、表单输入或提交。其他网址不视为恢复成功。返回需要观察的状态，由 Agent 判断，剩余批量步骤停止。

扩展操作遇到引用失效或连接关闭时，先尝试读取相同网址的新快照，再交还 Agent 判断。恢复后的观察会停止剩余批量步骤；此前完成的步骤保留，不重放输入或提交。引用不存在表示未发送；连接关闭时动作结果未知，须检查页面。快照读取失败或返回了其他页面时仍报告错误。

在用户的 Chrome 或 Edge 中打开网址时，新建正常的工作标签页。新建工作标签页是产品的选择；扩展连接页本身也可以导航，并非天然无法使用。

对象规则
工具栏地址、导航、刷新、操作标记、操作历史、预览。页面没有暂停或继续；这些属于输入框旁的对话控件。
输入用户和 Agent 都可操作页面，包括 OpenProgram 自身。指针、滚轮、键盘、编辑和导航不改变任务状态，也不产生写入禁止。旧的页面输入通知被忽略。
关闭页面立即生效，不等任务暂停
绑定丢失重新获取原窗口和标签页。已有页面按当前状态观察；只有页面不存在才在上次 URL 重开。返回新观察；绝不重放点击或提交，也不选别的页面。连接断开不等于页面关闭。
任务暂停停止后续生成和工具分发。所有权、访问和帧校验照旧。继续时观察当前状态，没有第二层页面权限。
报告历史、标记和生命周期只描述活动，不控制活动。认证丢失和未保存数据如实报告。

输入与捕获映射
  • 渲染器边界先转成原生 DIP 再缩放。原生输入用 Chromium 的模拟视图映射。
  • 观察和截图保持 CSS 坐标。确切的原生 Page 经所有权校验的绑定回复报告 input_scale；坐标点击和指针移动在 CDP 前乘以它。滚轮增量和 window.scrollBy 保持 CSS 单位。
  • MCP 引用命名空间留在上游：缩放下的引用点击在那里执行现有点击脚本；悬停用临时精确元素标记、感知帧的 Playwright 边界和原生指针移动。
  • 操作标记共用视口和缩放。所有权校验和延迟转移恢复保留。
  • Agent 截图用固定 CSS 分辨率的 CDP 捕获，带临时设备参数和 DPR 补偿。并发捕获共享结果。清理时移除覆盖并恢复原生几何，最后的调试器分离同样如此。缩放、导航、所有权变化或退出预览使进行中的结果失效。
  • 捕获保留自有原生视图和导航代数。任何帧的开始或提交（含同文档和同 URL 刷新）使待定捕获失效；导航失败绝不恢复更早的代数。只移动位置保留原生捕获；动态 DOM 更新不算代数。
移动成本与手势
  • 只移动位置时更新边界，不碰模拟和缩放。几何相同不发请求。只有原生尺寸变化才改缩放；导航和调试器分离恢复模拟。渲染器报告共用一个取整几何，含 UI 缩放。
  • 根滚动条轨道由可撤销的 author-origin 样式隐藏；滚轮、键盘和嵌套滚动正常。离开预览时移除，包括插入与导航或退出重叠时。
  • 按住拖动或缩放时，同一渲染器里一张解码位图移动和缩放；原生边界和模拟不变，页面动画看起来冻结。松手后隐藏页面接收一次最终边界，捕获等待绘制完成，恢复实时交互。
  • 呈现捕获用 capturePage，不用 CDP 或循环。失效或超时的捕获不能隐藏或恢复已替换的预览。

分发取消

浏览器动作在等待标签页和等待页面稳定时检查任务是否已取消；一串动作在每一个之前再检查一次。已取消的待定动作不发送。已分发的动作不撤销也不重复。

验收

  • 隐藏保留页面；资源列表可重开；更多菜单项不发执行控制请求。
  • 缩放到 480 像素上下，innerWidth 保持 1920。两种尺寸下原生点击、Agent 点击、标记、滚动和新截图一致；UI 缩放、导航、标签页恢复和转移清理正常。
  • 六十次移动和重复相同边界零次模拟重置；每次缩放变化一次重置；强制恢复和样式生命周期正常；拖动和滚动连续。
