0.7.0 移除。不更换浏览器引擎，也不依赖 Chrome 或 Edge 远程控制。

原因

Electron 只实现部分扩展 API，补齐其余部分超出可靠浏览和 Agent 网页操作的目标。

原因说明
缺失 API许多商店扩展依赖 Manifest V3 service worker、chrome.action、账号同步或浏览器专有行为
部分失败下载和加载可以成功，而登录、后台任务、弹窗或页面注入失败
预检局限标签覆盖不了运行时 API、后台生命周期、工具栏交互或厂商的浏览器检测
维护成本商店协议、CRX 校验、权限说明、API 兼容、更新和诊断

架构

persist:webtabs 会话只处理页面状态、Cookie、下载和 DevTools 或 Agent 控制，启动前不加载第三方代码。没有管理器、注册表、CRX 安装 IPC 或扩展页。

将来针对 browser-extensions/ 数据的清理入口必须列出目标并由用户发起。
