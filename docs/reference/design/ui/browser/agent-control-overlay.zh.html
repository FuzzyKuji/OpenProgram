Agent 控制覆盖层

目标绘制代码
macOS 原生窗口（computer_use 窗口操作）内侧辉光、强调色标题栏灯、光标。每个对话一个透明、可穿透点击、不可聚焦的窗口，边距 32pt。window_watch.py 报告；agent-control.js 放置；menu-overlay/agent-control 渲染
App 内网页：标签页或悬浮预览内侧辉光、光标。每个页面一个这样的窗口，边距 24pt，只在视图显示时显示。辉光贴合圆角：预览 10pt，标签页圆底角。action-cues.js 放置；bridge-events.ts 的 subscribeAgentPageGlow 报告
聊天预览（PiP）、Web 版预览图上 pointer-events: none 层里的光标browser-control-bar.tsx 的 ActionCueTravel

所有表面都绘制 AgentCursor。

网页何时发光

方面规则
发光条件控制状态表明 Agent 正在操作、正在停止或未确认已停止，且其对话的运行仍在进行
运行结束后无论状态如何页面都算空闲，因为后端在对账前会保持页面活跃（browser-control.ts 的 presentedControlState）
不绘制暂停状态、页面周围的边框
页头和工具栏只在需要你确认或状态未知时说话

窗口位置

方面值
持有从首次读取或操作到最后一步后 20 秒，或 agent 转向别的窗口
轮询每 0.12 秒读 window server 的屏幕列表；有变化才报告
报告屏幕点坐标的框、相对窗口的按钮框（经辅助功能读一次）、边距内位于前方的窗口
排除标题为 OpenProgram agent overlay 的窗口
结束最后一次带 active: false 的报告
传输native.control 和 native.action 帧，仅在显示操作开启时

外观与动效

元素规格
辉光形状沿圆角边（10pt）的 18pt 强调色描边，模糊 11pt，不透明度 55%，裁剪到窗口内。边上无线，窗口外不画。
辉光呼吸每 2.6 秒在该强度的 60% 到 100% 之间
遮挡前方窗口从辉光和灯上挖掉
指示灯关闭、最小化、缩放按钮上的三个强调色圆，大半点。白层每 1.4 秒升到 40% 再落下，相隔 0.2 秒。没有按钮就没有灯。点击到达下方按钮。
光标图形Solar cursor bold duotone，26px，强调色，尾部半强度，垫 Solar cursor-bold 的白边露出 2px，加淡接触阴影
热点盒子以操作点为中心；箭头尖在其右下 2px，所以点击圆点显示在旁边。控件：操作前框的中心。坐标：截图点映射到屏幕。
停留桌面应用上停在上一步处并随窗口移动；第一步从窗口中央开始。持有的页面上步骤间停留；未持有的步骤 2.8 秒后淡出。
移动缓弧，弯曲距离的 16%、最多 56pt，ease-in-out，按距离 240–680 ms
按下点击、按压、选择、拖动或打开：箭头朝尖端缩到 82%，0.26 秒弹回；8px 强调色圆点带 2px 白环，1 秒内淡出。输入和滚动没有按下和圆点。
减少动态光标跳转；按下、圆点、呼吸和脉动关闭

强调色

--agent-accent 即 --theme-accent（themes/fallback.css），用于辉光、灯、光标和点击圆点；白边、圆点环和灯的脉动是白色。覆盖层与 App 同源、共享主题设置，主题变化立即生效。

安全

规则细节
无输入忽略鼠标，不聚焦不激活。不移动系统指针。
控制时可见整个窗口会话都在，0.36 秒淡出。窗口最小化或在别的空间时隐藏，回来再显示。
每对话一份各对话显示自己的
仅显示失败被丢弃，操作继续
没有停止控件可点击区域会截获本该给应用的点击。停止在对话的停止控件和 Running 面板。网页悬浮控件只在等待确认时提供查看请求。
