Shared with the agent

terminal_use actions: list, open, observe, input, interrupt, resize, share, release, close. Each runs on a single-use ticket issued by openprogram/host/resources/terminal.py and redeemed by the desktop host.

  • Needs approval; unsafe in plan mode; cannot bypass a task sandbox. No Desktop: an explicit unavailable result.
  • Input is raw keystrokes, not a command API. "Delivered" means reached the shell. Output is untrusted data.
  • Human typing does not pause the agent, but a changed input revision forces a new observe. Uncertain input is never retried.
  • release leaves the terminal open; close terminates the shell.

Shell directory and foreground command

Advisory, for macOS zsh and compatible bash 3.2 login shells. Exit zero proves no effect or task success; background jobs may continue. Reports never change ownership, leases, approval, input revisions or cancellation.

shell_integration?: {
  status: "starting" | "ready" | "unavailable" | "ended",
  mode: "zsh-hooks" | "bash-debug" | null,
  reason: string | null, event_sequence: number,
  cwd: { value: string, event_sequence: number } | null,
  cycle: { id: number, phase: "running" | "finished" | "unknown",
           exit_code: number | null } | null
}
Metadata semantics
  • Optional on existing reads and events; older hosts omit it. start_cwd is immutable. Top-level exit_code is the PTY process, nested the matched cycle.
  • Initial prompt: ready and cwd, cycle=null. Process exit: unfinished cycle becomes unknown, integration ends. Last values are history, not guarantees. Input still returns phase=delivered or unconfirmed with command_complete=null.
  • The Web type accepts the metadata with no renderer, prompt parser, command API or store.
Startup and compatibility
ShellIntegration
zshNative -l. Private .zshenv, .zprofile, .zshrc, .zlogin forwarders restore ZDOTDIR before sourcing each user file, then append preexec/precmd hooks. RCS stays authoritative. Existing hooks remain; readonly arrays decline. Global scripts and plugins are not claimed equivalent.
bashNative -l, one-time PROMPT_COMMAND only if none was set. Bootstrap captures DEBUG before sourcing and installs a minimal DEBUG/prompt pair. Custom DEBUG, readonly PROMPT_COMMAND, extdebug, functrace, replaced prompts and bash-preexec get none. Root-parent PID checks stop nested adoption; callbacks reject subshell reports.
OthersUsable, reports unavailable. No user config, shell option or history policy is rewritten. No Windows integration.
Protocol and lifetime 
ESC ] 777 ; OpenProgram ; 1 ; nonce ; rootPid ; eventSequence ; kind ; cycleId ; exitStatus ; cwdHex BEL
  • Kinds: ready, cwd, start, end. 128-bit nonce per launch. The parser checks the PTY PID, increasing event sequence and cycle, matching completion.
  • cwd: UTF-8 absolute, hex by printf/od/tr, 16 KiB limit, no NUL or malformed UTF-8. Frames 36 KB.
  • Incremental across chunks; incomplete candidates released after one second. Only accepted frames are removed before delivery and replay; other output is unchanged and cursors count the same filtered stream.
  • A later complete prefix before the candidate's BEL keeps the earlier bytes as output and restarts at the new prefix, so malformed output cannot swallow a genuine completion.
  • The shell can read or forge its nonce, so metadata grants no authority. No command text or environment dump. Three seconds without ready: unavailable; a later valid handshake recovers. Root exit makes a running cycle unknown, never finished.
  • Scripts are extracted through Electron fs to a per-launch 0700 directory with 0600 files; spawn failure or root exit removes them, reattach or lease release does not. Old-generation data cannot update replacements. Asset failure keeps the raw terminal.
