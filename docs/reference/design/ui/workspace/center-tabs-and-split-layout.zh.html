中心 Tab、分屏与网页 Tab 呈现

只讲 apps/web 渲染层的呈现与绑定。跨窗口转移和主进程 View 几何见各自记录。

模型

概念含义
Tab聊天、文件或文件夹、终端、网页或应用页。各有自己的前进后退历史。
组多个 Tab 并排，在条上算一项，由画布布局。MAX_CENTER_TAB_GROUP_MEMBERS 不设上限。由 groupTab 创建；预览展开成分屏走 setSplitWebTab。
叶子center-tabs store 里的 kind:"web" 条目。id 为 w:<url>；由 nextPopupWebTabId 分叉出的是 w:<url>:popup:…。悬浮不会移除它。
配对唯一的一等会话-页面关系（pairedOwnerByTabId）。一个会话可配多个页面，关闭任一方即解除。Agent 在会话里打开、用户拖进会话的分屏或用户收起时建立。独立页面没有配对，也没有收起操作。
绑定useWebTabPip 单例里至多一个活动的 (tabId, ownerTabId)，另有按会话的 previews。不持久化。换绑不清旧配对。
宿主页面此刻在哪渲染：窗格、聊天预览或无。由 pipCoversCenter 推导，组件不另存可见状态。

一个叶子同一时刻只有一个原生 WebContentsView。预览就是真实页面，不是遮罩或截图；页面 Tab 和预览不同时出现。

预览行为

情形行为
回到会话applyFollowPreview 显示该会话自己的预览。没有时，仍在画布上的窗格的预览保留，或换旁边窗格的预览；否则隐藏。
点 ✕ 后回来不会自动打开，由 chip 恢复。chip 显示 surfaceRefForChat 报告的页面，只有它是本聊天的预览页时才提供关闭或显示。分屏里只是标签。预览折叠进显示同一页面的 chip（data-web-surface-chip），优先本窗格；没有则原地淡出，从“在对话中预览”重开。
打开已绑定页面绑定和跟随偏好保留。.webFrame 测量原生边界并占满内容区，不留空位。
收起目标原 owner 还在就用它，否则组内的会话，否则配对表。都没有则不出按钮和菜单。之后：退出分屏或组、setActive(owner)、show，不重载。
可交互悬浮页
  • 复用 Electron WebContentsView 接收点击、滚动和输入，不建第二个 Page，不转发坐标。每帧更新宿主变换和原生边界，松手才保存几何。
  • 普通浏览器：HTTP(S) 用沙箱 iframe，是独立文档，登录和 frame-ancestor 限制遵循浏览器策略。受限 URL 显示不可用并保留“打开页面”。
  • 没有可见视图能力的旧桥接保留带标注的图片回退（usePipSnapshots）。当前 Desktop 桥接不截图。
  • 隐藏、切换或卸载的预览释放边界和观察器，不关闭 Page。菜单和对话框遮挡原生内容。

与产品语义的已知差异

差异细节
分叉不看已隐藏的预览pipOpenMustFork 只看活动绑定；B 的 show 清掉 A 的恢复 chip。
分叉只认规范叶子条件是 webTabId(url) === boundTabId。每次分叉可能留下孤儿叶子，靠 op=close 或用户关闭。
关闭不记打开者只查组成员：Agent 打开后被拖进组的页面关不掉，可访问的用户独立页面能关。
分屏路径不调 pipOpenMustFork只检查 agent 所有权，并改写组内网页窗格的 URL。
show 不解组别组里的叶子绑定成预览时仍是组成员。
区域定义不一致surfaceRefForChat 把未分组页面标为 right，browserPageInventory 标为 center。
绑定不持久化刷新丢失绑定、后台记录和位置，叶子回到普通 Tab，Resources 预览重新应用。

Tab 内导航

操作结果
打开会话在当前会话 Tab 或新标签页原地打开；从其他页面类型则选中已有会话 Tab 或新建。重开当前会话不加历史。
前进 / 后退只走当前 Tab 的历史，位于条最左；后退后另选会丢弃前进项。目标会话已在别的 Tab 打开时选中那个 Tab，来源历史不变。
默认入口页被替换的新标签页留在历史最前，后退回到它，不新增 Tab。
应用页每个路由（设置、Agents、Abilities、Applications、History、Scheduler）都是所选 Tab 的一次访问，标签随之变化。未知路由显示路径。
一页一 Tab访问别的 Tab 已显示的页面时聚焦那个 Tab 并移到该路由（recordRouteNavigation）。Programs、Skills、MCP、Plugins 算 Abilities；Chats、Projects、Memory 算 History；各设置分区算 Settings。
从分屏内页面在分屏后新建顶层 Tab。恢复时带页面路由的成员离开分屏。
草稿与标题历史保留草稿 id，输入按会话 id 存。后台 ACK 和标题更新修改匹配记录，不激活、不追加。
刷新与删除历史随 version-2 Tab 持久化，旧 Tab 变单条。确认删除的会话从所有历史移除，未加载记录不算删除。

同一窗口内一个会话一个 Tab：见会话 Tab 身份。

历史如何存储
  • pageHistory 是唯一存储：页面身份、会话元数据、内容路由和文件视图，无嵌套历史，不含输入和消息。旧会话历史在首次导航时转换。
  • Tab id 是实例，sessionId 是当前会话。冲突时加唯一后缀；目标已属另一 Tab 时当前槽位得到唯一身份。
  • 路由同步只响应 pathname；markSessionReady 处理会话 ACK；导航响应当前 Tab 的 sessionId 和草稿变化。
  • 原生浏览器 URL 历史留在浏览器控件，网页保留自己的控件。会话历史是应用状态，与浏览器 History 分开。
  • 窗口转移在异步 ACK 前后检查已准备的会话历史；导航变化取消过期转移，回滚不覆盖更新的导航。
  • 恢复详情路由先加载导出的宿主路由，再替换 URL，然后记录访问。重复激活共享一次导航；迟到的宿主提交恢复最新目标且不计访问。切 Tab 时详情路由不重载文档。
  • Provider 选择来自路由参数。迟到的列表响应只能在未指定页面选回退；切换详情不重载目录。
  • center-tabs-store.ts 组合 store/（状态、提交工具、动作）和 navigation/（纯函数、选择器）。没有动作模块持有第二份历史。

Tab 条

情形规则
新 Tab 位置从某 Tab 打开（链接、弹窗、会话、文件或页面预览）：在其右侧，按打开顺序（insertNextTo）。加号、新聊天、Agent 后台页：放最后。
控件后退、前进、新建：宽 28px，间距 8px。空 Tab 列表不占位。新建左侧无分隔线。
关闭最后一个 Tab允许。窗口和条保留，内容空白，跨路由和刷新保持，不自动建草稿。会话所有的隐藏页留在 Resources，不作回退。关闭在规整分屏组后选可见邻居。
按下与松开按下用拖动的背景和模糊，不换页面。未拖动松开走普通点击；拖动、Esc、取消或失焦吞掉点击。焦点环保留。
拖动外观Tab 和窗格标签的拖动预览共用背景、backdrop-filter 和阴影变量。设置 → 通用：透明度 0–100%、模糊 0–40px、阴影 0–100%，实时预览，可恢复默认。默认 20%、16px、饱和度 1.2、原阴影透明度的 25%。文字和图标保持不透明。
新窗口提示留在条内、原生页面边界之上：渲染层内容无法盖在 Electron 子视图上。
把网页拖到 Resources单个网页 Tab 松手时把这个 Page 附到当前可见会话。目标：Resources 导航行，展开时还有其正文，绝不合并成一个矩形。一道与目标外框等大的边框，不模糊内容。组、草稿和其他类型不能作来源或目标。
网页附加与拖动设置细节
  • 服务端校验 owner 授权、会话，以及注册桌面连接上的窗口/Tab/原生目标身份，再复用 BrowserResourceStore，不做 URL 副本。
  • 失败报错，不导航、不解绑、不伪造绑定。连接变化拒绝过期结果。取消不发送。成功时打开 Resources，保留会话、页面身份、顶层 Tab 和关联，不打断其他执行的操作。
  • 偏好存本地存储并规整；预绘制主题脚本在 hydrate 前应用；storage 事件同步同源窗口。换主题保留。无效字段用默认，数值夹紧，零表示关闭。普通按钮和 Resources 轮廓不受影响。条内拖动排序，条外沿用窗口转移。

会话文件预览

聊天在左、文档在右，复用 Tab 组和 DocumentWindow。

情形规则
输出行已完成的实时回复把本地 Markdown 链接和 send_file 附件显示为紧凑行。
自动打开首个支持的输出，开在其聚焦的会话旁。历史、失败或取消的回复、后台会话都不打开。手动分屏或有改动的预览保留。同一授权文件复用 Tab。
归属项目内文件：项目文档 owner。其他绝对路径：经会话校验的只读附件 owner。内容不执行、不作原始 HTML 嵌入，也不靠模型写的路径授权。
刷新可见文档检查已授权的元数据，变化时显示“文件已更改”和刷新。刷新始终可用，绕过缓存读磁盘，成功才更新，绝不丢本地编辑、待发布内容或富文本改动。隐藏窗格停止轮询；失败保留旧显示并可重试。
一文档一编辑器同一项目文档的文件 Tab 共用一个持久编辑器，随草稿移入当前布局。没有 Tab 引用时才关闭。同时可见的重复项提供“在此显示”。
