集成终端与 Claude Code 启动

仅桌面端。Web UI 不提供宿主命令执行。

选型

部件作用
node-pty真实 PTY，只在 Electron main（Windows 为 ConPTY）
xterm.js + FitAddon终端序列、原始输入、按窗格算 cols/rows；不自造协议
Claude Code CLI本机安装的 claude，PATH 经登录 shell 解析
spawn + pipe（不用）TERM=dumb，无终端设备：交互程序失去光标、重绘、颜色、快捷键和 resize

行为

主题行为
Terminal Tab项目目录下的登录 shell（macOS 为 zsh 或 bash，Windows 为 PowerShell）。切 Tab 只卸载视图；关闭 Tab、销毁渲染层或停止才释放 PTY。
Claude Code Tab在同一目录直接运行 claude。
项目未解析短暂等待后在主目录启动，不留空白页。迟到的响应不重启。
不可用桥接、PTY 模块或 CLI 缺失：Tab 显示明确错误。Web 模式没有交互控件。
主题背景、前景、光标、选区和 ANSI 16 色来自语义 token。主题或 Custom CSS 变化只更新 xterm，PTY 和缓冲不变。
工具栏预设、进程状态、实际 cwd；复制、粘贴、清屏、重启、停止。紧凑无边框。
按键有选区时 Cmd+C 或 Ctrl+Shift+C 复制。Cmd+V 或 Ctrl+Shift+V 粘贴到 PTY。Ctrl+C 中断。Cmd+K 只清当前视口。

与 Agent 共用

terminal_use 动作：list、open、observe、input、interrupt、resize、share、release、close。每次用 openprogram/host/resources/terminal.py 签发、桌面宿主兑换的一次性票据。

  • 需要批准；计划模式不可用；不能绕过任务沙箱。没有 Desktop 时明确返回不可用。
  • 输入是原始按键，不是命令 API。“已送达”只表示到了 shell。输出是不可信数据。
  • 人工输入不暂停 Agent，但输入版本变化必须重新 observe。不确定的输入绝不重试。
  • release 保留终端；close 结束 shell。

信任边界

边界规则
可执行文件渲染层只能选预设 shell 或 claude，不能传任意 argv。
cwdrealpath 后必须是目录。PTY 绑定渲染层 sender 和终端 id。
限制Agent 输入 16 KiB，人工 64 KiB；工具的 cols 20–500、rows 5–200。被替换的进程不能写入新进程。
权限本地 App 用户的权限。没有远程沙箱。

Shell 目录与前台命令

仅作参考，适用于 macOS zsh 和兼容的 bash 3.2 登录 shell。退出码 0 不代表有外部效果或任务成功；后台作业可能继续。报告不改变归属、租约、批准、输入版本或取消。

shell_integration?: {
  status: "starting" | "ready" | "unavailable" | "ended",
  mode: "zsh-hooks" | "bash-debug" | null,
  reason: string | null, event_sequence: number,
  cwd: { value: string, event_sequence: number } | null,
  cycle: { id: number, phase: "running" | "finished" | "unknown",
           exit_code: number | null } | null
}
元数据语义
  • 可选地附在现有读取和事件上，旧宿主可省略。start_cwd 不可变。顶层 exit_code 属 PTY 进程，嵌套的属匹配的命令周期。
  • 首个提示符：ready 和 cwd，cycle=null。进程退出：未完成周期变 unknown，集成结束。最后的值只是历史。输入仍返回 phase=delivered 或未确认且 command_complete=null。
  • Web 类型接受元数据，不加渲染、提示符解析、命令 API 或 store。
启动与兼容
Shell集成
zsh原生 -l。私有的 .zshenv、.zprofile、.zshrc、.zlogin 转发在 source 用户文件前恢复 ZDOTDIR，最后追加 preexec/precmd。RCS 优先。已有钩子保留，只读数组放弃安装。不声称与全局脚本和插件等价。
bash原生 -l，仅在未设置时用一次性 PROMPT_COMMAND。启动脚本在 source 前捕获 DEBUG，再装最小的 DEBUG/prompt。自定义 DEBUG、只读 PROMPT_COMMAND、extdebug、functrace、替换过的 prompt 和 bash-preexec 不集成。根父进程 PID 检查阻止嵌套接管，回调拒绝子 shell 上报。
其他可用，报告 unavailable。不改写用户配置、shell 选项或历史策略。无 Windows 集成。
协议与生命周期 
ESC ] 777 ; OpenProgram ; 1 ; nonce ; rootPid ; eventSequence ; kind ; cycleId ; exitStatus ; cwdHex BEL
  • 类型：ready、cwd、start、end。每次启动 128 位随机 nonce。解析器检查 PTY PID、递增的事件序号和周期、匹配的完成。
  • cwd：UTF-8 绝对路径，用 printf/od/tr 转十六进制，上限 16 KiB，无 NUL 或非法 UTF-8。帧上限 36 KB。
  • 跨块增量解析，不完整候选 1 秒后释放。只有被接受的帧在投递和回放前移除，其余输出不变，游标按同一过滤流计数。
  • 候选的 BEL 之前出现完整新前缀时，前面字节作为普通输出保留，从新前缀重新解析，畸形输出吞不掉真正的完成。
  • shell 能读取或伪造 nonce，所以元数据不授予权限。不含命令文本或环境。3 秒未 ready 则 unavailable，之后有效握手可恢复。根进程退出让运行中周期变 unknown，绝不是 finished。
  • 脚本经 Electron fs 解到每次启动的 0700 目录、0600 文件；启动失败或根进程退出时删除，重新附着或释放租约不删。旧代数据不能更新替换进程。资源失败时保留原始终端。

范围
