Conversation tab identity

Within one window, each conversation ID has one current session tab. Titles do not determine identity; two same-title conversations stay distinct. Other content types and separate windows are independent.

CaseBehaviour
Opening a displayed conversationSelects its tab before replacing a session or launcher
Back and ForwardSelect the open tab when the destination is already open, leaving source history unchanged; otherwise restore normally
NormalizationKeeps the active duplicate, or the first when none is active, with its history and group; other duplicate slots are removed without the close/ACK lifecycle
Historical visitsDo not reserve a conversation
Transfer into a windowRejects session ID conflicts before insertion, preserving both slots

DAG and draft state survive all of these.
