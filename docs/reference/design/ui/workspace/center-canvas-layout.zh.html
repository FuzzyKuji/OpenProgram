中间画布布局

每个布局占一个顶层标签。任何标签内容都能进格子：会话、网页、终端、文件预览、程序视图。格数的实际限制是格子的最小尺寸。浮动窗口归画中画；格子不跨窗口共享。

布局树

type LayoutNode =
  | { kind: "pane";  id: string; content: string | null }   // null = empty pane
  | { kind: "split"; id: string; dir: "row" | "col";
      children: LayoutNode[]; sizes: number[] };

type CanvasLayout = { root: LayoutNode; focusedPaneId: string; zoomedPaneId?: string };
规则说明
每次修改后规范化只有一个子节点的切分用子节点替换；与父节点同向的切分并入父节点，权重相乘；权重重新归一并按最小尺寸夹紧
内容一个布局里只出现一次
迁移两格分组变成带原比例的 row 切分
空格列出标签栏的内容，点一下填入
焦点只有一格；键盘输入、关闭、贴靠快捷键和右侧栏上下文都跟随它
填满把一格铺满画布；其他格不卸载，只隐藏

标签栏里的分屏

分屏窗口只占一个标签，宽度与普通标签相同，和 Chrome、Arc 的分屏一样：焦点格的图标和标题、分屏缩略图（焦点格填深色）和格数。关闭按钮作用于整个窗口。

分屏里关掉一格而分屏仍在时，这一格在点击的同一 tick 移除，由画布播放关闭。焦点变化或刚合并成分屏时，图标和名字 200ms 上浮出现。

窗口总览

仿 macOS 调度中心和 iPad 后台切换。中间区域退成页面底色，标签栏里每个窗口都成为网格上的卡片，尽量放大，不超过区域宽度的一半。

卡片保持窗口的分屏，用同一棵树和同一套几何绘制。格子内部没有落点：在当前画面上，下半边和角落很难分清。

合并落地

只有一次放大，松手就开始。提交要等桌面端取消转移（约 50ms）和渲染分屏（约 40ms），若等待，这约 90ms 里小窗已消失而卡片没变。

  1. 松手时总览保持打开，记下落点和标签，设置 landing。目标卡片从网格位置在 340ms 内等比放大到中间区域，transform 动画贯穿等待。窗口在下面被激活，让位时各格已加载好。
  2. commitCanvasDrop 把合并交给 landOverview，后者先拿着并标记 landed。
  3. 已 landed 且放大已开始（约十分之一秒后），总览读出放大卡片里每格的矩形，换算到画布未缩放坐标，连同起点、曲线和进度交给 captureCanvasLanding。
  4. 总览关闭，在同一 tick 提交合并。兜底计时器也会提交，但无动画。
  5. 外壳播放记录：各格的真实几何进入分屏；并入的标签按最终尺寸从放下一侧进入（平移出去，用 clip-path 在画布边裁掉），同为 300ms，分界线一起移动，内容不重新换行。
  6. 未缩放状态量完后，画布根元素接过放大，用相同关键帧和卡片动画的 startTime，同一时钟，放大的是实时内容而不是会糊的 JPEG。
细节规则
startTime创建时显式设定：否则合成线程在播放而主线程仍是 pending
data-canvas-landing期间保持中间列周围为页面底色
其他卡片80ms 淡出；提示淡出但保留位置，网格不重新居中
合并失败桌面端保留标签：总览立即关闭

布局动画

窗口按钮、贴靠菜单、填满和还原上次布局造成的变化，像 macOS 移动窗口一样带动画（lib/tabs/canvas/canvas-transition.ts）。“减少动态效果”时跳过；拖动分隔线不做动画。

格子动画
留下真实几何（left、top、width、height），Web Animations，300ms，文字重新换行；内联 calc() 不动
新出现淡入
红灯副本淡出下沉 180ms，盖在接手的格子上。被保存提示拦住时，等标签真正关闭再播放。
黄灯神灯效果折进标签，600ms
黄灯，标签不在上方副本向标签缩小，340ms
绿灯、填满被遮挡的格子在放大的格子下淡出
播放方式
部分细节
记录变化前按 tab id 记下每格矩形并留静态副本。外壳在提交这次变化的 layout effect 里播放，首帧绘制之前。1.5s 内没有对应提交就作废。
对应按 tab id，会话从对等格换到单独聊天外壳也能连贯。隐藏的外壳在布局的同一 tick 切到留下的会话，不等几次渲染。
对话只有切换后才到达的行才淡入；单条消息只在到达后一秒内播放出现动画，重新挂载时直接显示
移动期间按拖动处理：网页显示快照，聊天只重排可见行；格子边框和分隔线淡出再淡回
神灯桌面端拍全分辨率静态图（captureRegion 带 full；最多等 160ms）。每帧按 2px 一行画到同一 canvas，拉伸到漏斗两边之间，颈口在标签底边。靠近标签的边先收窄，然后格子从颈口倾入并裁掉。标签按钮亮一下；接手的格子晚 90ms。
神灯，普通浏览器副本切成 6 到 20 条（越重越少），每条用 matrix3d 映射到四边形
从分屏收起新标签按钮从原标签旁滑出，后面的标签让位（260ms，只动 transform 和 opacity）；折叠瞄准按钮终点，晚 80ms 开始
折叠时钟每帧最多前进 34ms：主线程忙时暂停而不跳过

拖动的生命周期

画布以后要承载各种小窗口应用，每次拖动都要干净结束，不打扰其他格子。

情况处理
任何结束方式松手、Esc、pointercancel、窗口失焦或查找落点出错，都走同一个清理且只执行一次：移除标签和预览，恢复把手，释放捕获，清除 data-canvas-dragging。查找失败按无落点处理。
漏掉的松手在窗口拖动区、原生视图或别的应用上松手，页面收不到 pointerup。每个拖动向 setCanvasDragging(true, owner) 登记；第一次无按键的 pointermove 视为松手；新的按下先取消旧拖动。拖动期间没有 -webkit-app-region: drag。
把手状态data-pane-dragging 通过 CSS 隐藏，不写内联样式；新拖动清掉残留
原生网页先截图，拿到或 160ms 后隐藏，不闪“已暂停”
落点预览无背景模糊；120ms 缓出，无回弹

渲染和原生视图

  • 递归几何计算输出给稳定的内容宿主：改树和放大不会重新挂载文件编辑器、终端和会话。
  • 小于 150×110px 的格子显示标题、类型和放大操作。
  • 每个网页格子上报自己的 bounds（registerVisibleWebTabBounds）。拖动中、过小或超过 8 个可见原生视图时显示截图。选中暂停的视图会优先恢复。隐藏的视图保持存活，不终止进程。

持久化

窗口的标签数据保存每组的树、焦点和放大状态，只存标签引用。失效的引用变成空格。跨窗口数据校验独立限制树深度、节点数和序列化大小。Resources 绑定沿用现有后端归属操作。
