Pane recording

An Agent records one pane to a video of exactly that pane's rectangle, with actions of computer_use_agent. There is no menu, button or shortcut for a person. The App captures its own pages, so macOS never asks for Screen Recording and no approval is added.

What the Agent calls

Three actions on target browser, the target that already reaches the App and owns screenshot. Names and limits follow start_audio_recording and stop_audio_recording of target app.

computer_use_agent(target="browser", action="start_video_recording", args={"pane": "conversation"})
…
computer_use_agent(target="browser", action="stop_video_recording")

Recorded 12.4 seconds of tk3fa, 1600×1200 at up to 60 fps, saved to
~/.openprogram/computer-use/video/20261110-101500-conversation.mp4.

What the person sees

The outline is all a person gets: no pill, timer or button. It stays because recording starts without asking, so it must be visible. A whole-window recording has no outline.

AspectRule
Who may captureOnly a window's main page, only its own window's frames, only while a recording the worker asked for is running. Sites in web tabs stay refused as today.
SizeThe pane's CSS size times the display scale, rounded to even numbers. Left alone the stream comes out at screen size, so the size is set explicitly.
Web tabThe site's own frame, answered to the window's page; no joining
Why not window captureIt adds a system permission, and the App is not the identity that holds Screen Recording for workflow recording. It stays the later answer for native menus.
Why not the other twoFast enough, but no pointer, no frame times, and an encoder to write. capturePage stays what it is used for today: stills.

Effects

EffectHow
Pointer and click markThe Agent's actions move no real pointer, and its usual pointer lives in a separate window. The same pointer is drawn inside the recorded frame from the action events.
Automatic zoom to clicksAn export crops and eases toward each click, from a list of clicks kept beside the file
Padding, background, rounded frameThe export places the video on a backdrop

None of these is built. The export writes a second file; the plain recording is never altered.
