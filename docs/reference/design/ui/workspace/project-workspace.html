Project workspace: files, tabs and sessions

One layout, no workspace mode and no separate route: anything new becomes a tab, not a pane. The panes live in the persistent AppShell. Interactive sketch: prototype.

Tab model

TabToolbar and content
sessionProject, model, thinking and permission settings travel with the tab. Bookmark over the single chat surface: switching a tab uses the session-switch path.
fileBreadcrumb and view controls. Code and text with line numbers and highlight, Markdown rendered or source, images, PDF inline via /files/raw, anything else a download.
run (planned)Live graph of a program or workflow derived from recorded events (openprogram/runtime/execution/dag.py, openprogram/state/store/session/graph/builder.py). Workflows stay plain Python: no graph DSL, no instrumentation; click a node for inputs and outputs.
  • + opens a new-tab page: new session, run agent, project settings.
  • Tabs persist in localStorage.
  • File paths in transcript tool calls open in center tabs.
  • History, Context and Executions live in an overlay opened from the session toolbar; legacy DOM mounts and window.rightDock shims stay underneath.

Project file API

ActionRequest and reply
project_file_treeproject_id, path (relative, "" for root). One directory level.
project_file_searchNames and relative paths, paged by opaque cursor over immutable snapshots; skips ignored build directories, follows no symlinks.
project_file_read{content, size, mtime, truncated}, or binary / too_large
project_file_writeUTF-8 text, 5 MB cap, parent must exist. expected_mtime mismatch answers conflict.
project_file_create rename copy delete revealFile management; also project_file_info, project_folder_size, project_file_operation_status.
GET /files/raw?project_id=&path= Images, PDF inline, everything else a download. nosniff; CSP: sandbox except PDF.

Every path passes _resolve: known project, location check, no absolute paths, realpath inside the project root. Reads cap at 1 MB. Binary: NUL in the first 8 KiB. Dotfiles are listed; .git/, node_modules/, .venv/, __pycache__/ are not prefetched. Code: openprogram/interfaces/server/ws_actions/files/.
