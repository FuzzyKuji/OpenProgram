项目工作区：文件、Tab 与会话

只有一种布局，没有工作区模式，也没有单独路由：新东西都是 Tab，不是窗格。各栏都在持久的 AppShell 内。可点击草图：原型。

Tab 模型

Tab工具栏与内容
session项目、模型、thinking 和权限设置跟着 Tab。是聊天单例上的书签，切 Tab 走会话切换路径。
file面包屑和查看控件。代码和文本带行号和高亮，Markdown 渲染或源码，图片、PDF 经 /files/raw 内联，其余下载。
run （计划）由已记录事件（openprogram/runtime/execution/dag.py、openprogram/state/store/session/graph/builder.py）派生的 program 或 workflow 活视图。workflow 保持纯 Python：无图 DSL、无埋点；点节点看输入输出。
  • ＋ 打开新标签页：新会话、运行 Agent、项目设置。
  • Tab 持久化到 localStorage。
  • transcript 工具调用里的文件路径在中心 Tab 打开。
  • History、Context、Executions 在会话工具栏打开的覆盖层里；legacy DOM 挂载点和 window.rightDock shim 保留在下层。

项目文件 API

动作请求与应答
project_file_treeproject_id, path （相对路径，"" 为根）。一层目录。
project_file_search按名字和相对路径搜索，不透明游标在不可变快照上分页；跳过忽略的构建目录，不跟软链。
project_file_read{content, size, mtime, truncated}，或 binary / too_large
project_file_writeUTF-8 文本，上限 5 MB，父目录须存在。expected_mtime 不符时回 conflict。
project_file_create rename copy delete reveal文件管理；另有 project_file_info、project_folder_size、project_file_operation_status。
GET /files/raw?project_id=&path= 图片、PDF 内联，其余下载。nosniff；除 PDF 外 CSP: sandbox。

所有路径都经 _resolve：项目已知、位置检查、拒绝绝对路径、realpath 落在项目根内。读取上限 1 MB。二进制：前 8 KiB 含 NUL。点文件照列；.git/、node_modules/、.venv/、__pycache__/ 不预取。代码：openprogram/interfaces/server/ws_actions/files/。
