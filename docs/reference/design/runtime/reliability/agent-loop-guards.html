Repeated tool rounds

ToolLoopGuard counts consecutive rounds with the same calls, arguments and results. At TOOL_LOOP_REPEATS (8) the turn ends before the next request, with an error naming the call. The user's next message carries the conversation on.

Tool calls written as text

Deep into a long conversation a model may write calls in its chat template's shape instead of making them; nothing runs, the turn ends, and on "go on" it reads its own written call back and writes the next one the same way.

When a reply to a request that offered tools ends with no call, text_tool_calls.read_written_calls reads it from the first call-shaped tag.
