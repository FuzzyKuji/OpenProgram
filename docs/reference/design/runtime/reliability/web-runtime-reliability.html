Web runtime reliability

Out of scope: Agent reasoning, DAG storage semantics, provider protocols, permission models, multi-user identity. Topic pages keep their own detail; this page holds the shared contracts.

Error contract

Every failure that affects a request, durable state, a background task or a recoverable operation produces an observable record. Not every internal retry is a Toast, and no traceback, file content or credential reaches a browser.

{
  "type": "operation_error",
  "data": {
    "error_id": "err_opaque_unique_id",
    "request_id": "client_request_id_or_null",
    "scope": "session | job | settings | channel | agent | transport | system",
    "code": "stable_machine_code",
    "message": "safe user-facing summary",
    "action": "safe_action_or_null",
    "session_id": "session_id_or_null",
    "operation_id": "action_job_execution_id_or_null",
    "retryable": false,
    "severity": "info | warning | error | fatal",
    "correlation_id": "opaque log lookup id",
    "occurred_at": "ISO-8601 UTC"
  }
}

Nullable fields are null, never omitted.

Session loading

Initial cost follows visible content, not history. SessionDB and the DAG are the only durable authority; the wire carries projections.

Bounded session history

AspectRule
PageWhole turns: a prompt and everything it owns, caller descendants included. First page 6 turns and 128 KiB target; later pages 25 turns and 512 KiB (transcript/reader.py). One larger turn is sent alone.
CursorCaptured branch head plus a stable cursor; any message id on the branch finds its turn. An unavailable cursor gives an explicit retryable error, not a reconnect loop.
Side effectsNone: paging never edits history or model context, or changes focus, live head, execution state or question replay
FragmentsHistory and graph responses over the frame budget go as ordered, awaited fragments, reassembled before dispatch and ordered with later live notifications. Per connection: 64 Mi UTF-16 code units, 8 incomplete transfers, 1,024 logical responses (history-fragments.ts). Buffers die with the connection.
Wire sizeDuplicate promoted fields are dropped from extra. Tool previews keep authorized full-output expansion.
ClientPrepends older rows by identity without replacing newer content. Requests capture the load generation and are ignored after a reload, branch switch or socket replacement. Scroll stays anchored.
ReconnectLoads a fresh recent page; existing execution recovery continues
Long sessionsGraph depth: memoized parent-chain classification, then iterative preorder; no Python recursion. Nodes whose parent path enters a cycle stay independent roots. Forks, retries, spawned branches and call children keep order and offsets. Follow-up normalization indexes replies once; lane placement keeps per-lane widths and the largest column instead of rescanning.
ThreadsMessage aggregation, page preparation and Graph build run off the event loop; awaited sends stay on it. Snapshot and event order are unchanged. The in-memory session index remains authoritative; no persistent cache or migration.
LimitsThe full Graph stays for branch and compaction controls. Projection scans the captured session; initial Graph and store memory grow with session size. Storage indexing and lazy graph rendering are separate work.

  • Prebuild id → insertion_index, group siblings once by predecessor, read the session row once per request, serialize Graph summary apart from bodies.
  • Extend on-demand reads to context trees, runtime blocks, Graph-node content and attachment metadata. Legacy clients get upgrade guidance from payload caps, not unbounded frames.
  • Capture existing frame order first, then replace layers; never move a whole async handler into to_thread.

WebSocket delivery

openprogram/interfaces/server/ws_delivery.py. Browser WebSockets have no automatic backpressure (MDN), and client bufferedAmount cannot replace a server queue. Producer threads only enqueue, through event-loop-safe scheduling (asyncio.Queue).
