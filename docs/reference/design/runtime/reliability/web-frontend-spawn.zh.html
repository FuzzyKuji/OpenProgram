Web 前端子进程创建

worker 通过 openprogram/operations/worker/web.py 的 start_web_frontend 启动 Next.js，并在 .next/BUILD_ID 变化时重启。两处启动都传入 openprogram.host._platform.process_ownership 的 no_window_creation_flags()，各自在函数作用域内导入。

情况行为
POSIX 标志零
Windows 标志后台窗口
首次启动抛出 OSError报告错误，返回 None
重建后启动抛出 OSError报告错误，watcher 仍能看到下一次构建
关闭停止最新一个启动成功的子进程
验收与边界
  • 组件测试用假子进程调用公开启动入口，捕获生产 watcher 回调而不启动无界线程。临时 BUILD_ID 文件驱动连续重建。
  • 检查首次和重复启动的标志、关闭最新子进程、启动出错后的恢复。进程创建和端口回收都已隔离，不影响运行中的 App。
  • 命令构造、环境传递、端口回收和 manifest 补丁与这些标志无关。watcher 调度、关闭取消和其他平台行为不在范围内。
  • 不改依赖、API、配置和安全边界。
