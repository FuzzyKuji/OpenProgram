预览上限

  • 上限取配置值（默认 30,000 字符）与 2,000 字符最小值中的较大者，先于截断和存文件的判断生效。
  • 未超上限的结果原样返回一次，不加标记，不建文件。
  • 更长的文本保留互不重叠的首部（默认 70%）和尾部，省略字符数为正。尾部长度为零时不追加文本。
  • 共享 normalizer 对已注册函数和 Agent 方法使用同一规则。

完整结果文件

  • 配置档状态目录下 tool_results/ 中的文件属于其会话、执行和 qualified occurrence。Provider 原始 call ID 会重复，不是身份。
  • 文件名含该归属的摘要，排他创建使每次保存有独立路径，无作用域的调用也一样。
  • 同一 occurrence 再次保存可以新增文件，不能覆盖早先 receipt 引用的内容。
  • 完整写入并关闭后才返回路径。
  • 旧 receipt 和旧文件保持可读，不迁移。

失败信号

每个工具在自己的执行分支上给现有 ToolReturn 设置 is_error。公共 normalizer 不从文本推断失败，因此以 Error: 开头的成功结果仍是成功。

schema、注册名称、后端选择、路径、重试预算、usage 标签和取消语义全部不变。

执行前暂停

  • 在已完成操作之间接受的暂停，在下一次 Provider 或工具调用前处理。
  • 登记但未开始的操作记为 not_started，留在 Agent 恢复位置中待执行。
  • 首次操作前暂停的 live owner 从原有持久 admission 恢复，不生成虚构模型回复。
  • 结果持久化期间控制命令改变执行版本时，只在同一 attempt fence 下重试检查点发布，不重复外部操作。

达到委派上限时读取结果

  • 达到 agent.max_messages 时，job_output 仍可发现和使用。读取不创建执行、分支或投递，不消耗额度。
  • 会话和祖先所有权检查仍然生效，且在等待之前。
  • 耗尽的链仍隐藏 agent；send_message 保留投递时的检查。没有单独的取消工具。
