Agent 执行核心

差别只在循环前后的生命周期。不需要逐函数装饰器：Agent 自己给普通方法建作用域。agent()、agent_async() 和 Agent.arun 共用核心。

执行原语

原语含义持久会话DAG
llm()一次逻辑模型请求，支持结构化输出及其修复预算否，当前 Runtime一个 LLM Call
agent()一个任务内的模型与工具循环；返回最终文本或校验过的结构化值否，当前 RuntimeAgent Call，内含 LLM 和 Function Call
Workflow 角色role(prompt, context=) 跑工具循环；role.choose 选一项否，当前 Runtime入口节点的子节点，保存确切请求
goal Program、create_goal让目标在对话的多轮中保持生效，直到验证通过。需要对话。是，保存在所属会话多轮，再加一轮验证
run_agent_turn()内部会话生命周期，不是 Program 原语是会话分支上的独立 Agent Call

Workflow 代码只通过角色调用模型。契约见 Workflow；Agent 和 Context 的职责见 Agent 与 Context 契约。

agent() 的签名 
def agent(
    prompt: str | list[dict],
    *,
    model=None, effort=None, tools=None, tools_deny=None,
    response_format=None, choices=None,
    max_iterations=None, stop_after_tool_round=False, timeout_s=None,
    tool_choice=None, parallel_tool_calls=None, execution_kind="agent",
    runtime=None, return_raw=False, toolset=None, tools_allow=None,
    instructions=None, context=None, tools_source=None,
    on_retry=None, web_search=None, stream_fn=None,
) -> Any: ...

没有 session_id、branch_from、advance_head、archive_when_done 或 run_in_background：持久化属于执行环境。已保存的 Agent 配置走 Agent.from_spec，显式覆盖优先。

边界

不引入改用
第三种 Agent 抽象，或包在作业外的公开函数agent() 和 Agent
Workflow DSL 或图引擎Python 包；静态图来自 import 和入口身份
第二套配置系统或额外数据库现有 Agents 配置和存储
在界面显示隐藏思维链模型输出摘要

Program 不导入 runtime.conversation.sub_agent_run，子 Agent 工具（programs/tools/agents/agent、send_message）除外，它们是产品入口。

界面显示

层级折叠时展开后
Workflow名称、状态、时长、步数、完整结论按序的角色调用，含确切请求和回复
Agent标签、状态、迭代次数模型输出摘要、实际 Program 调用

子 Agent 会话可跳转的行切到子会话；返回时仍是同一行

普通函数不记录。子节点逐层展开，不一次全开。

失败处理

失败处理用户看到
没有原生结构化输出按能力回退到文本 JSON 加本地 schema 校验错误留在对应 LLM 或 Agent Call；Workflow 失败
programs check 失败不提交；聊天 Agent 读报告后修改聊天里的检查报告
Worker 重启会话和作业路径恢复。resumable 入口经 step() 恢复。其他 Program 内 Agent 随父调用结束。不残留运行中状态
用户取消同一令牌传到 Runtime、provider 和工具；子调用先于父调用结束已取消或已中断，绝不显示完成
工具或子 Workflow 失败保留错误内容、caller 和部分产物失败节点与结论一致

不变量

  • 只有 PROGRAM_ENTRIES 注册为工具，分类目录不注册。
  • 每次角色调用都是入口节点的子节点，Workflow 调用的每个 Program 都出现在 DAG 里。
  • 直接运行的 Workflow 不通过 predecessor 挂到上一条 assistant。
  • 同一 profile 的 App、Web 和 TUI 共用一个 worker。
