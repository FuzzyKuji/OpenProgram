聊天轮次运行时

openprogram/runtime/conversation/turn_runtime/ 是聊天轮次的执行路径。Agent.run_turn 和 Agent.resume_turn 负责公开契约；process_user_turn 和 process_agent_continuation 是经由 ChatAgent 的入口。

头指针不变量

模块写头指针
turn_writer.py在持久化用户消息和记录失败时写头指针，并提供 head_for_finalize，由 finalize.py 写入。执行 advance_head，同会话派生的轮次无法移动头指针。
forced_tool.py在强制单工具路径上写自己的头指针
slash_actions.py/spawn 或 /merge 后恢复之前的头指针

error_path.py 决定失败后的头指针，写入交给 TurnWriter.record_failure。其他模块不产生 head_id。

测试接缝

测试在包对象上替换 _resolve_model、_load_agent_profile、_run_loop_blocking 和 process_user_turn。

  • __init__.py 以模块全局名调用它们，因此替换在调用时生效。
  • 兄弟模块不用模块级导入固定它们。loop_runner.py 在函数内导入包，并调用 _dispatcher._load_agent_profile(...)。
  • 接缝之外的模块（如 finalize.py）以参数接收解析好的 profile 和模型。

公开接口

_wrap_agentic_runtime_block, dispatch_forced_tool_call, execute_continuation, execute_turn, process_agent_continuation, process_user_turn, trigger_compaction

约定
  • 较重的 provider 和上下文导入留在函数体内。
  • 拆分不改变轮次生命周期、错误分类、持久化结构和事件载荷，也不给阻塞路径引入 async。
  • 完成轮次的提交摘要取提示第一个非空行（去空白），最多 60 字符；为空时用 turn。成功、错误和影子文件提交共用此规则。失败的会话提交保持未确认。
