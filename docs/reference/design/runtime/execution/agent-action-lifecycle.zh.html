统一 Agent 动作生命周期

维度取值含义
权限allow / ask / deny当前权限下这个确切操作能否开始
结果not_started / succeeded / failed / unknown对执行情况的了解。失败可能有部分副作用。
送达pending / recorded / projected结果是否已持久化并反映到对话和界面

建立在现有 Agent 循环、权限服务、执行存储、持久等待和界面投影之上，没有第二个工作流引擎。动作 ID、执行 ID、工具调用 ID、策略版本和规范参数摘要绑定每个决定、审批、回执和恢复。拒绝是结果为 not_started 的已完成决定，不代表任务完成。只有 unknown 需要副作用对账。

权限准备和自动审查

  1. 解析已认证权限、策略版本、工具能力、项目绑定和确切参数；现有硬约束、权限检查、计划限制、deny 和 ask 规则及限定授权不变。
  2. 预检在发布派发意图前异步运行。自动审查得到完整的有界操作、可信工作目录和范围、所有者请求和限制。工具参数和仓库内容不可信。超长或无法解析的输入绝不凭截断前缀批准。
  3. 分类器超时、取消和 provider 失败不同于风险拒绝：绝不执行动作，计为无判定。
  4. 只为符合条件的交互式所有者发布持久审批等待。硬约束和显式拒绝不能变成提示。非交互运行报告限制，并可继续独立的工作。
  5. 派发前重新校验权限版本、参数摘要、审批身份和文件前置条件。模式变化使旧决定失效；授权绝不覆盖被修改的命令。
决定的限制
  • 自动审查不能改写自己的策略。工具、权限状态、项目绑定或限制变化时，缓存的决定失效；没有全局允许缓存。
  • 并非所有拒绝都是 not_started：执行器开始前的拒绝证明未执行，但沙箱尝试后被拒的升级可能已部分执行，需保留证据。

失败处理

失败响应
无效参数返回结构化校验详情；模型可修正影响执行的参数
权限拒绝记录 not_started，含原因、策略版本和允许的解决方式。权限不变时，不能靠改描述文字重试。
瞬时传输失败只有在证明未执行或支持幂等时才有界重试；绝不重放可能已完成的写入
确定性工具失败返回输出供诊断；重复需要改变输入或条件；其他工作可继续
未知副作用保留确切证据；必须对账，重试不算对账
基础设施或检查点失败与工具结果分开报告；有可恢复回执时保留
重复跟踪和拒绝计数
项目规则
最近失败表上限是 AgentCheckpointV1 强制的 16 项，循环和序列化器共用。淘汰只限制存储，不限制权限或执行预算。完整历史留在事件中；失败次数不会宣告任务完成。
身份按工具定义：排除 Bash description 这类仅展示字段，保留命令、工作目录和权限。其他工具名为 description 的字段保留。绝不推断 shell 程序等价。旧检查点可读；只有工具契约已知时才规范化旧键。
回退阈值连续 3 次或累计 20 次分类器拒绝时转为手动提示，使用现有的所有者审批等待；绝不覆盖显式拒绝
范围会话和所有者策略版本；权限版本变化开始新的周期
重置允许和批准的回退操作只重置连续计数；累计计数在阈值审批完成或周期变化时重置
不重复计数规范执行事件在现有 SQLite 事务中保留每个操作身份和判定
无判定两个计数都不变，也绝不授权执行；风险拒绝不消耗执行失败重复预算

回执和恢复

持久回执包含确切的工具调用身份、结果、执行开始证据、错误码、结果引用和摘要，独立于显示状态存储。检查点构造不能抹掉已知结果。外部操作和本地 SQLite 无法共用事务，因此不承诺外部副作用恰好一次。

恢复时发现动作
回执已记录，检查点缺失从记录的结果重建续写
检查点已记录，投影缺失只重放投影
有派发但没有可信回执现有的副作用对账
旧记录绝不从工具文本推断未执行；对账可信的权限事件、调用身份和已存命令。绝不把任务标记完成作为修复。

宿主集成

项目规则
执行开始在授权实现之前立即记录
结果已完成和未开始的结果在检查点序列化前封存；应用结果详情不算执行证据
工具可见性每次 provider 请求都按实时规则过滤面向模型的工具，不改变已存的执行契约；动态撤销在执行时强制
投影宿主结果进入实时事件和历史
人工 UI 操作保留已认证的人工来源；通过 HTTP 转发的 agent 动作不获得人工权限

Provider 响应事件

每个派发的模型请求有唯一的 request_id，恰好一个 started 和一个 completed 事件。completed 记录 completed、failed、cancelled 或 incomplete，包括传输异常和没有终止事件的 EOF。异常和取消原样传播；计账不重放工具也不授权重试。旧的部分文本仍是 incomplete，观察者不把失败的请求当作回答。

验收
范围必须成立
失败跟踪超过 16 个不同失败不产生 schema 错误；改描述不能绕过抑制；可执行参数变化保持区分；旧检查点可加载
预检被拒操作绝不调用执行器；能发现危险后缀；取消和策略变化不派发；确切审批在重启后恰好生效一次
拒绝回退交互和非交互行为明确不同；硬拒绝不变；计数在恢复和并行调用下正确
回执结果和检查点之间失败并重启，不再次调用有副作用的执行器；未知副作用保持阻塞
可见性撤销立即生效；隐藏工具不能被旧决定调用；界面和后端显示相同原因和恢复操作
