先做事，再决策：agent(choices=)

from openprogram import Agent, agent

class ExampleAgent(Agent):
    method_options = {"handle_ticket": {"tool": True}}

    def handle_ticket(self, ticket: str) -> dict:
        return agent(
            f"处理这个工单： {ticket}",
            toolset="default",        # 做事：工具和推理
            choices={                 # 收尾：必须选一项
                "refund":   issue_refund,
                "escalate": escalate_to_human,
                "close":    {"status": "closed"},
            },
        )

choices 交给 Runtime.exec，它把菜单和 DECISION_FINISH_INSTRUCTION 加进 prompt，跑一轮普通对话。最后一条回复必须是 {"call": ...} JSON，由 resolve_decision 解析。decision.make 相当于前面没有做事的这一过程。

选项

类型选中后schema 来源
函数执行，返回其返回值函数签名
值返回固定值无
schema模型按 schema 填写，返回 {"decision": name, **fields}自己声明
 
decision.make("...", {
    "retry":     retry_fn,                         # 函数
    "skip":      "SKIPPED",                        # 值
    "abort":     (AbortSignal(), "pick when it can't continue"),  # 值 + 说明
    "emit_plan": ("Produce a plan.", {             # schema： ("description", schema)
        "steps": [{"action": str, "target": str}],
        "rationale": str,
    }),
})

也可用列表。每项是可调用对象、(callable, "说明")、"name"、("name", "说明") 或 ("name", "说明", schema)。函数选项的名字取 __name__。

schema 字段含义
field: str（任意 Python 类型）该类型的标量
field: "说明"带说明的 str 标量
field: [子 schema]列表，元素符合子 schema
field: {子字段: ...}嵌套对象
field: {"type": T, "description": ..., "options": [...]}类型、说明和枚举

不需要分支、总是同一结构：用单选项的 decision.make，或 exec(response_format=...)。

从回复到结果

  1. render_options 生成菜单：签名、说明、参数、一行 Call: JSON 示例。只显示 source="llm" 的参数。
  2. 调用模型：runtime.exec(prompt + menu)，或 agent 本来要发的那一轮。
  3. parse_args 提取并校验 JSON。
  4. 失败时再选一次（max_retries=1，设 0 关闭）：runtime.exec 发送上次回复、错误原因和菜单，同样进 DAG。仍无效则抛 DecisionError。
  5. resolve_decision 执行函数或查出值。
校验规则
检查规则
JSON来自 json 代码块或原文，键为 call、action、function 或 tool
未知选项_ParseError("unknown_call")；没有 JSON 是 no_action；args 不是对象是 bad_args
字段类型str int float bool list dict，递归校验嵌套。bool 不算 int，float 接受 int。枚举用 options。
函数选项从 context 填 source="context" 参数，注入 runtime 参数，丢弃多余字段，要求无默认值的参数都在
值或 schema 选项schema 字段全部必填，多余字段丢弃
返回(chosen, kwargs)：函数，或选项名
菜单占位JSON 字面量：0 false [] {} "<str>"；枚举列出可选值
DecisionError

继承 ValueError，带最后的错误类型、消息和回复开头。except DecisionError 只捕获“模型始终没选出有效项”。框架不做兜底，由调用方决定。
