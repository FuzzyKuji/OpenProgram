Long runs across interfaces

All interfaces reach one Worker (WorkerLock), one session store and one event bus. Every action goes through the Worker; no interface keeps its own unsynchronized state.

Steering

agent_loop calls get_steering_messages at turn start, after a tool round and before follow-up. A new instruction takes effect at the next checkpoint; the current step finishes first. Interfaces send execution.steer, which saves the command first (controls).

Questions

QuestionRegistry is process-wide, thread-safe and claim-once, with an event-layer and a queue transport plus a subprocess bridge. The answer returns to the same registry from any interface. Open waits are replayed when a session loads.

Graceful stop

cancel_event runs end to end; subprocesses stop through request_graceful_stop in process_runner.py.
