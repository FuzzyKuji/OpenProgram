Agent 与 Context 契约

负责方职责
Agent配置化调用和持久轮次（run_turn、resume_turn、arun_turn、aresume_turn）、取消、事件、配置解析（from_spec）
Context会话写入器和分支、命名内容、provider、历史选择（None、"thread"、"chat" 或可调用对象）
ChatAgent对话默认值；生产聊天入口，经由 Agent
共享轮次运行时准入、模型和工具执行、压缩、流式、持久化、收尾。dispatcher 是它的导入别名。
执行控制持久的尝试归属、暂停、转向、检查点恢复。没有并行的作业注册表。

边界

情形行为
对话跨轮次保留会话图
普通辅助函数不加 DAG 节点
嵌套 Agent保留独立的图
Context 内容仍是用户内容，不授予权限；权限、记忆和沙箱限制照常
工具超时算工具错误，父轮次继续
用户取消传到所有活动工作
恢复复用持久化的模型上下文，不重复用户准入
