Agent and Context contract

OwnerResponsible for
AgentConfigured calls and persistent turns (run_turn, resume_turn, arun_turn, aresume_turn), cancellation, events, profile resolution (from_spec)
ContextSession writer and branch, named content, providers, history selection (None, "thread", "chat" or a callable)
ChatAgentConversation defaults; the production chat entry, through Agent
Shared turn runtimeAdmission, model and tool execution, compression, streaming, persistence, finalization. dispatcher is an import alias for it.
Execution controlDurable attempt ownership, pause, steering, checkpoint resume. No parallel job registry.

Boundaries

CaseBehaviour
ConversationKeeps its session graph across turns
Plain helperAdds no DAG nodes
Nested AgentKeeps an independent graph
Context contentStays user content: never grants authority; permission, memory and sandbox limits still apply
Tool timeoutA tool error; the parent turn continues
User cancellationReaches all active work
ResumeReuses persisted model context, repeats no user admission
