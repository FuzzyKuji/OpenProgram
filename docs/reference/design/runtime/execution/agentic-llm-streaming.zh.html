嵌套 LLM 流式输出

Agent 方法里的每个 llm() 或 runtime.exec(..., execution_kind="llm") 都走 execution_stream.v1，进程内和子进程在界面上结果相同。节点展开后的版式见嵌套 LLM 节点内容。

通道

载体内容边界
execution_stream单个 LLM 节点的尝试、内容块和文本。逐帧驱动。绝不写入助手回复内容
tree_update树结构、状态，以及来自检查点的 stream_preview。约 1.2 秒轮询一次。终态是关键帧
Call.output节点关闭时写入的最终输出流状态只是预览，不是最终结果

只有 result、error、retry_result 帧会结束聊天记录。嵌套流帧不会清除父运行、覆盖回复文本或刷新分支元数据。

attempt_started一次 provider 尝试开始。仍在运行的前一次变为 superseded。
block_started, block_delta, block_finished尝试中一个有序内容块
attempt_finished状态 completed、failed、cancelled 或 superseded，带校验结果
snapshot完整状态，替换客户端已有内容
node_finished终态决定，带完整快照
sync_required客户端需要重新同步
内容块类型、阶段和预算
内容块类型text, reasoning_summary, tool_ref, tool_arguments, parallel_group, refusal, unsupported. 不透明签名绝不累积为文本。
节点阶段created, running, retry_wait, validating, finalizing, completed, cancelling, cancelled, failed, paused, reconciliation_required
增量合并同一块，25 毫秒内且小于 16 KiB。绝不跨节点或跨块。
检查点写入 Call.metadata.stream，每 0.25 秒或每 64 KiB 新内容一次；临时流不写
帧大小目标 64 KiB，内联预览 32 KiB。父进程拒收超过 96 KiB 的子进程帧。
发送队列每连接 256 帧、4 MiB。同一块、修订连续的相邻 block_delta 会合并；其他操作是关键帧。

应用一帧

帧结果
代次更旧拒绝
代次更新且带快照即使修订更小也替换状态，节点已终态时除外
修订不高于当前视为重复，忽略
base_revision 与当前修订不同请求快照，绝不盲目追加
终态节点收到运行中更新拒绝，终态节点不回到同步中
sync_required，原因 owner_unavailable结束本次恢复并保留内容。不会触发同样的请求；之后的流事件可以再次请求。

浏览器存储是展示副本，按会话、执行和节点分键，并行调用互不混杂。subscribe_execution_stream 优先由活跃 owner 应答，否则取检查点。

执行树行
运行中正文来自流，其次 stream_preview，再次 output。思考来自 reasoning_summary。提示和参数留在短注释里，完整提示在详情中。
已结束output 或 raw_reply，带耗时
同步中注释显示“重新同步”
重试中注释显示“重试中（…）”，旧尝试仍可查看

失败和重连
用户取消阶段 cancelled；保留部分文本；之后的增量被拒
provider 错误阶段 failed；部分文本和错误保持可见
传输重试或结构化输出修复当前尝试结束，开始新尝试
刷新或重连先渲染已保存的快照，再继续活跃帧。不回放增量。
owner 不在用检查点快照；没有时返回 owner_unavailable
子进程路径

子进程不打开 WebSocket。它把帧放进现有的 event_queue；父进程校验 schema 版本、已知操作、会话、执行、代次不超过启动记录以及大小，然后转发。父进程不重新分配修订，也不写子进程的检查点。

不包含

  • token 级审计日志或可回放的增量记录
  • 改变顶层 stream_event.text；终端界面完全一致
  • 结构化输出的逐字段高亮；图片增量
  • 跨会话流订阅
  • 取代 tree_update
