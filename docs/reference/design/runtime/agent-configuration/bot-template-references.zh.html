Bot 模板参考

内置 Agent 的来源材料。

本设计采纳的内容

来源思路这里的做法
模板是粘贴到 Bot 里的 profile内置 Agent：agent_registry/builtin_agents.py 中的完整配置，安装成普通的已存 Agent
合约：职责、交付物、禁止清单、完成条件、工作方式、第一个任务每个职业 Agent 系统提示词的固定结构
自主等级用现有控件，不加字段：对应关系
默认起草，绝不发送autonomy: "report" 和每份提示词的禁止清单。hold_outbound 仍可用，安装时关闭。
几次运行良好才开例行任务不设固定间隔：已安装的职业 Agent 在用户开始对话前什么都不做，之后自己安排唤醒
产出和验证分开PR Producer 可以编辑。PR Verifier 没有 edit、write、apply_patch。各自在自己的对话里工作。
Bot 互相交接工作对话之间的 handoff(to, message)，有跳数上限
每个角色限定工具每个 Agent 一份 selected 工具策略，只含内置工具
内置 Agent来源
Chief of Staffgrok-bot-architecture 的 chief-of-staff 角色；grok-bot-templates 的同名模板
Spec Writer、Bug Reproducer、PR Producer、PR Verifiergrok-bot-profiles 的四个 profile
Research Deskgrok-bot-templates 的 Research Desk 模板
Inbox Triagegrok-bot-templates 的 Inbox Triage 模板；grok-bot-architecture 的 inbox 角色
Career Scoutgrok-bot-architecture 的 career 角色
Knowledge Keepergrok-bot-second-brain 的 Memory 和 Capture Bot
Writergrok-bot-architecture 的 publishing 角色；agent-org-chart 的起草角色

角色名和合约结构取自这些来源。提示词为本产品的工具而写，不是抄录。

舍弃的内容

舍弃原因
模板目录、选择器、就绪评分Agent 列表就是模板列表。新建 Agent 从空白开始。
团队对象、组织架构导入、创建名册的 setup Bot用户自己开对话，Agent 在对话之间交接。
大名册每个供应商或部门一个 Bot，是按组织架构摆放 Agent。Building agents: when to fold subagents into your main agent loop 建议默认一个循环，按上下文而不是问题类型拆分，只在可测量地更好时才单独设 Agent。十个职业 Agent 是供挑选的配置，不是一起运行的团队。
只路由到编程 CLI 的协调者这里的 Agent 本身就是编程 Agent。
领域包购物、打电话、交易、增长循环、退出流程都是 Agent 之上的技能和程序。支付和交易不属于内置范围。
托管账户上的网关和队列那些因产品运行在共享云电脑上才需要。这里的工作在用户机器上，通过 HTTP API 和渠道访问。

来源的共识

要点内容
一个 Bot 一个职责，写成合约职责、读取的来源、禁止清单、交付物、完成条件、第一个任务、工作方式。目录顺序：职责、边界、技能、例行任务、团队。
自主分级观察（读取并汇报）、起草（默认：产出待审内容）、批准后行动（聊天中批准后执行指定写操作）、定时（例行任务，带来源缺失时的策略）。运行两次良好才开启。
按结果拆分，不按技术结果、来源、工具、日程或审批边界变了，才需要新 Bot。
产出和验证分开构建者从不审查自己，两者不共用对话，"完成"需要他人的结论。
交接不是批准把草稿传下去不启动任何工作，用户批准具体版本。
失败有名字用 BLOCKED 和 HOLD 代替猜测，绝不编造日志、测试结果和链接。
小名册协调者加一个专家。有具体边界才加角色。
协调者不干活负责界定、分派、审查。长工作交给专家或编程 CLI。
外发和特权操作要等待发送、发布、支付、合并、部署都停在审批处。

一篇关于 Grok Bot 模板的中文社交帖子。其中的说法是帖子自己的，未经核实。

官方合集
SpaceXAI 免费发布 146 个模板；这类 Bot 通常卖 50 到 200 美元，帖子给整套估价 29,200
社区
GitHub 上 700 多个模板，包括整支团队、现成交接流程和独立审查角色
第一支团队
一个有明确终点的工作：研究简报、审查过的 PR 或一批完成的草稿
然后
看它承担了多少工作、产出花了多少钱。结果更好，大名册才值得。
提醒
配置可以免费，付钱让几个 Bot 查同一件事仍是亏损
