What it leaves out

Left outWhy
Template catalog, picker, readiness scoreThe Agents list is the list of templates. A new Agent starts blank.
Team objects, org-chart import, roster-creating setup BotsThe user opens the conversations; Agents hand work over between them.
Large rostersOne Bot per vendor or department organizes agents around the org chart. Building agents: when to fold subagents into your main agent loop recommends one loop by default, splitting by context rather than problem type, and a separate agent only where it measurably does better. The ten job Agents are configurations to pick from, not a team that runs together.
Coordinators that only route to a coding CLIAn Agent here is itself the coding agent.
Domain packsShopping, phone calls, trading, growth loops and opt-out procedures are skills and programs on top of an Agent. Payments and trades are out of scope for a built-in.
Gateway and queue over a hosted accountThose exist because the product runs on a shared cloud computer. Work here runs on the user's machine, reached through the HTTP API and channels.

What the sources agree on

PointDetail
One job per Bot, written as a contractJob, sources read, never-list, deliverable, done condition, first task, working style. Catalog order: job, boundary, skill, routine, team.
Autonomy in levelsObserve (read and report), draft (default: artifacts for review), approved action (named writes after approval in chat), scheduled (a routine, with a policy for missing sources). A routine starts only after two good runs.
Split by outcome, not technologyA new Bot needs a changed outcome, sources, tools, schedule or approval boundary.
Production and verification apartThe builder never reviews, the two share no conversation, and "done" needs a verdict from someone else.
A handover is not an approvalPassing a draft starts no work on it. The user approves a named version.
Failure has a nameBLOCKED and HOLD replace guessing. Logs, test results and links are never invented.
Small rostersCoordinator plus one specialist. Add a role only for a concrete boundary.
The coordinator does not do the workIt scopes, assigns and reviews. Long work goes to a specialist or a coding CLI.
Outbound and privileged actions waitSending, posting, paying, merging and deploying stop at an approval.

The post

A Chinese-language social post on Grok Bot templates. Its claims are its own and unchecked.

Official set
146 free templates from SpaceXAI; such a bot usually sells for 50 to 200 US dollars, so the post prices the set at 29,200
Community
700+ templates on GitHub, including whole teams, handoff flows and separate reviewer roles
First team
One job with a clear end: a research brief, a reviewed pull request, or a batch of finished drafts
Then
Check how much work it took on and what the output cost. A larger roster pays only with better results.
Caution
Configuration can be free; paying several bots to check the same thing is still a loss
