为什么用这些机制
依据结论
React 回调依赖响应式 setter 是依赖项。复用会话 store，绝不靠重新挂载输入框掩盖过期回调。
Python 执行器生命周期上下文管理器退出时会等待。不等待的关闭允许提前返回，但取消不了运行中的同步请求，所以保留传输期限，不新增异步供应商 API。
Jina 搜索需要认证访问，可用性跟随凭据

回归检查使用生产环境的 hook、socket 请求助手、工具执行器和解析器。
