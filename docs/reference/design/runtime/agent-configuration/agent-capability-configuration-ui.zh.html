策略模式与迁移

模式请求集合约束
inherit基础策略在发现前解析
all全部全局可用条目拒绝项和强制上限仍生效
selected显式名称与类别过滤取交集；Programs 也可改为引用一个预设allowed=[] 表示空；Programs 的预设与显式名称不能同时使用
none空延迟的显式名称加载也不能绕过
 
effective = requested ∩ global availability ∩ caller authority
            ∩ parent delegation ceiling ∩ environment restrictions − explicit denies
  • 缺失的引用保留存储，但不可调用。
  • 必需的 MCP 引用必须是生效服务的子集。矛盾的模式（含通配拒绝）被拒绝。
  • Skill 指令不能授权它提到的工具。

旧版空允许列表仅在 schema 迁移时为 all。类别生效时省略它，保持旧判断，而不是变成空白名单。目标 selected=[] 绝不走旧的“空即全部”语义。

在一个边界统一规范化，不在 UI、搜索和执行器中各做一次。目标策略对 Skills 和 MCP 也有显式模式。

发现、调用与变化

时机行为
保存存储意图
运行解析带版本的生效范围和目录/预设引用；完整 schema 清单不进入首个提示
tool_search只在生效范围内搜索，返回有限的匹配 schema。显式名称和嵌套工作流/程序调用使用同一策略
调用重新检查撤销、可用性和资源权限。全局禁用的条目在下一个边界即不可调用，排队或固定的运行也一样
MCP 故障可选：禁用该服务并显示状态。必需：阻止准入或启动。认证错误绝不自动连接到其他账号
缺失名称选择器一直显示，直到显式移除；保存不会清除
预设更新影响新解析的调用；进行中的快照保留原选择，但受撤销约束
记忆工具还受执行记忆策略收窄；允许列表不能覆盖记忆关闭或只读

编辑器

  • Programs、Skills 和 MCP 分开；每项显示模式、继承来源、生效数量、缺失数量和目录操作。
  • 目录只在打开时加载。类别和预设是选择器，不是副本。
  • MCP 增加必需标记和全局连接链接；凭据不进草稿。
  • 列表、树和检查器归Programs 选择器。
验收
selected 为空时搜索和调用都为空；被拒绝的显式名称失败；缺失必需服务在副作用前阻止；缺失引用在重新加载后保留；切换标签保持同一草稿；记忆关闭时记忆工具不能执行。
