程序访问选择器

Agents 配置访问范围，Programs 管理可调用实体。

界面

位置显示交互
Agent 面板策略，Functions、Workflows、Applications 计数，可折叠的生效条目展开只读结构，不改变任何东西。折叠列表开销很小。
选择器左栏类型和分类导航搜索、仅已选、仅问题
选择器中栏名称、描述、选中和可用状态复选框编辑 Agent 草稿，不改全局启用。打开浏览程序时才加载详细目录。
检查器入口签名、输入输出、直接依赖、验证证据到 Programs 看源码和完整图。最多展开两层。
Workflow 树稳定的圆形展开控件、连续的层级线可用键盘展开，遵守减少动态偏好。预览和编辑访问是两个动作。
MCP 条目不在程序选项里重复在 MCP 区管理。运行时工具仍走共享调用。

选择和失败

情形规则
模式全部、指定、无，遵循共享能力约定
预设是引用。预览显示展开后的名称和版本。切到显式选择只复制名称，不复制程序定义。
Selected=[]效果等同于无
条目缺失按存储名列在问题里，可删除，不可调用
目录失败与搜索结果为空分开显示
完成、取消完成保留本地草稿改动。取消恢复到打开选择器时的草稿。两者都不保存。
保存全局保存用同一个 expected_revision 提交所有分区
已验证标记绝不依据标题、源状态或过期的测试计数。证据与能力就绪分开显示。目录 API 提供所需元数据后，检查器才算完整。
首轮上下文常驻 schema 和限定范围的搜索指引，不含完整延迟清单
嵌套 Workflow遵守现有程序和信任边界。选择 Workflow 不授权隐藏的工具调用。
