Discovery, invocation and change

MomentBehaviour
SaveStores intent
RunResolves a versioned effective scope and catalog/preset references; no full schema inventory enters the first prompt
tool_searchSearches only the effective scope and returns limited matching schemas. Explicit names and nested workflow or program calls use the same policy
InvokeRechecks revocation, availability and resource permission. A globally disabled entry stops being callable at the next boundary, even in queued or pinned runs
MCP outageOptional: disables that service and surfaces status. Required: blocks admission or startup. Auth errors never connect to a different account

Memory toolsAlso narrowed by the execution memory policy; an allowlist cannot override memory off or read-only

Editor

  • Programs, Skills and MCP are separate; each shows mode, inherited source, effective count, missing count and a catalog action.
  • Catalogs load only when opened. Categories and presets are selectors, not copies.
  • MCP adds required markers and global connection links; credentials stay outside the draft.
  • The list, tree and inspector belong to the Programs selector.
Acceptance
Selected empty is empty at search and call; denied explicit names fail; a missing required service blocks before side effects; missing references survive reload; changing tabs keeps the one draft; memory-off tools cannot execute.
Status
Policy primitives exist. Target canonical modes and cross-entry enforcement are pending the implementation plan.
