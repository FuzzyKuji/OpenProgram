可配置 Agent

Agent 是保存的、可复用的执行配置，分八个分区编辑（常规、Programs、Skills、MCP、记忆、上下文、常驻、高级）；保存是原子的并检查修订。新 Agent 默认关闭记忆。

页面内容
编辑器和核心字段使用示例数据的原型，不改变实际配置
能力Programs、Skills 和 MCP 策略
Programs 选择器列表、树、检查器
实现计划阶段、迁移、场景细节

对象

对象身份和生命周期边界
AgentConfig一次解析的不可变值；可内联、可无名不隐式持久化，不分配会话或记忆
AgentSpec保存的 ID、显示名、修订和 AgentConfig 字段元数据和配置，不是运行中的 Worker
Execution运行或作业 ID 和不可变的生效配置一次调用；多次调用可引用同一 Agent
Session / DAG对话和执行历史历史复用与 Agent 选择分开决定
记忆空间带访问策略的稳定存储引用可选；绝不因显示名相同而推断

AgentSpec 是持久化外壳；AgentConfig 是其类型化投影，不是第二个注册表。角色、人设、专用模型、工作区、记忆和计划都是可选的。

  • 保持扁平的 AgentSpec 外壳。POST 接受名称加可选可执行字段；id、修订和时间戳由服务器分配，除非提供有效的显式旧 ID。
  • AgentConfig 只有可执行字段。导入导出排除服务器元数据并分配新身份。包在 agent 和 llm 旁导出 AgentConfig；带 Provider 的模型字符串规范化为 provider/id 对象。
  • 启用读取的模式至少需要一个授权读取空间；read_write 需要恰好一个可读写目标。关闭时绑定不生效；编辑器可在草稿中保留。
  • 未知字段、无效类型，以及同时出现在 reset_fields 和改动中的字段，在写入前拒绝。就绪状态与存储配置分开返回。

一个解析器

基础只来自一个来源，依次为：显式 agent_id、显式 config（与前者互斥）、环境 Agent、系统默认。会话覆盖只在同一 Agent 身份下生效；切换后不继承模型、提示、工具或记忆绑定。然后应用授权的调用覆盖；权限约束最后应用，并在每个有副作用的边界复查撤销。

值含义
省略 / UNSET继承；PATCH 省略时存储不变
空字符串清除提示或描述；清除模型用 reset_fields
空的 selected 列表显式空范围，绝不是全部
mode=none、memory.mode=off显式禁用，不是继承
reset_fields删除本地覆盖，露出基础值；拒绝 JSON null
列表、策略对象原子整体替换；不隐式合并
对象内标量字段修补指定叶子；提交前规范化为完整策略
冲突的覆盖拒绝同时通过旧关键字和 overrides 指定的字段
权限、配额取交集；拒绝优先；取最小的有限额度；绝不按后写决定

派发接受时固定生效快照、Agent 修订、策略版本和目录/预设版本（引用和哈希，绝无凭据）。排队、重试和恢复保留它并复查撤销；新的独立轮次重新解析。

给 agent() 和 llm() 增加 agent_id、config、overrides 和历史选择；不建并行执行器。校验和返回类型不变。

from openprogram import Agent

# Explicit history sharing; records stay in the same execution DAG.
agent(prompt, agent_id="reviewer", history="selected", context_nodes=[node_id])

class ExampleAgent(Agent):
    method_options = {
        'extract': {'tool': True},
        'classify': {'tool': True},
    }

    def extract(self, document):
        return agent(document, agent_id="my-agent",
                     overrides={"memory": {"mode": "off"}},
                     response_format=Result)

    def classify(self, document):
        return llm(document,
                   config=AgentConfig(model="provider:model", memory={"mode": "off"}),
                   response_format=Label)

_example_agent = ExampleAgent()
extract = _example_agent.extract
classify = _example_agent.classify

可选记忆

模式召回记忆工具后台写入
off无无不从这些节点摄取
read_only授权的 read_spaces读取和搜索不从这些节点摄取
read_write授权的 read_spaces另加一个授权的 write_space受写入策略和执行来源约束
inherit先解析为具体模式绝不未解析传入仅用于迁移
空间
保存 Agent 的 self 是它自己的命名空间，匿名配置不可用。已实现：self、legacy_global。目标：选定的项目或共享空间，可供匿名使用。write_space 必须可读。新 Agent 开启记忆时默认 self，不复制旧全局存储。
关闭不会
删除记忆、禁用会话历史或移除用户提供的指令文件。已在消息中的文本无法“看不见”，需开始干净上下文。待处理的召回在进入请求前作废。它不是文件系统沙箱：shell 或文件工具能读记忆文件时，UI 会说明。
失败
可选后端失败时显示记忆降级并继续；required=true 在模型执行前失败。写入失败保留任务结果，单独报告。
不提供
write_only。无法强制命名空间的后端不能启用作用域记忆；绝不靠提示模拟隔离。
写入资格
  • 每个执行节点带写入资格标签、空间引用和策略 epoch。会话结束写入、压缩抽取、来源导出和计划整理都过滤 off 和只读节点。
  • 禁用写入会阻止未结算的排队写入，重新启用时也不追溯摄取。已提交的记忆保留。
  • 派生输出和摘要带所含上下文中最严格的资格。拆分或切换 Agent 不能重新标记受限数据。off 传播禁写限制，但不禁止之后独立授权的读取。
  • 后台写入在提交时验证原授权和当前空间策略；撤销优先于固定配置。绝不用更宽的空间重试。无法取消的外部后端要写明。
  • 用户编写的指令和上传文档仍是输入，即使含个人信息；不声称能自动分类来源记录之外的文本。

上下文、指令与环境

来源处理
运行时和所有者策略在模型外强制；Agent 提示不能覆盖
用户、项目和作用域工作区指令现有权限和作用域规则；显示来源和冲突
Agent system_prompt、白名单文件可配置；文件是工作区路径引用，在受保护的执行存储中按内容或哈希快照
Skills在允许集合内按需加载
记忆、工具和网页结果带来源的数据，绝不提升为指令
  • clean 表示不继承对话消息，不是没有系统或项目策略。
  • selected 历史按调用方可见性校验；DAG 成员资格不等于授权。执行历史默认保留，没有无痕保证。
  • 工作区和项目 cwd 分开。cwd 不是访问边界。不兼容的宿主或沙箱请求明确失败。
  • 上下文长度用现有 Context Engine 限制；没有第二个摘要器。

能力范围与权限

目录拥有定义和凭据；Agent 策略拥有引用。详见 Agent 能力策略。准入、用量、取消和配额见资源治理。

  • 会话或调用可替换偏好，但不能扩大强制上限。委派限制在 agent_id 变化后仍生效。被拒绝的覆盖要说明。
  • Provider 原生搜索和其他原生操作受能力门控；仅 tools=[] 不是网络限制。
  • 账号通过凭据服务解析；AgentSpec、快照、导出和示例中没有原始密钥。Anthropic 连接使用官方 API 和合法获取的 API key，按 API 账户计费。
  • 宿主已授权的 Python 不受允许列表沙箱约束；工具和嵌套 agentic 调用在公开边界检查。

多 Agent 组合

分支、作业、消息和附着引用见协作契约、架构。配置并行复用时产生不同的运行，不产生新的保存 Agent。

操作契约
独立调用不自动带上一任务历史；一个 Agent ID 可服务多个会话
委派显式目标、输入和过滤后的上下文；父级取消和预算留在任务控制中
继续任务指向现有运行或分支；目标 Agent 不变
共享记忆显式绑定；并发写入用后端版本检查和幂等执行 ID
共享文件、浏览器冲突变更需要归属和串行化；Agent 名称不隔离
自动选择推迟到 P6；对现有合格配置排序，绝不创建 Agent 或扩大范围

一次成功的运行绝不持久化配置改动、技能或偏好；持久更新走显式写入机制。角色编排、自动拓扑和市场发布不在范围内。

原子持久化

一个规范的 agent.json，原子替换。小型恢复日志覆盖跨索引和资源的创建、默认和删除；多次 os.replace 不是事务。启动时先对账未完成的意图再提供写入。删除 Agent 绝不删除共享记忆、全局凭据或外部工作区。会话和 DAG 引用通过其存储枚举。

生命周期与失败

事件行为
匿名配置无侧栏条目、工作区或记忆目录。保存创建只初始化配置；指令文件在显式请求或旧版引导时创建
复制无会话、已学记忆、计划或凭据。共享引用可见。复制指令内容与复制引用分开
导出、导入可移植配置和可选指令文本；无记忆、历史、机器路径、凭据或自动计划。导入校验、解析引用、预览权限，不启动执行
删除枚举自有和引用的资源。私有记忆保留或显式删除；共享记忆绝不删除。墓碑 ID 不接受运行；未完成的清理可见可重试

内置 Agent

都是普通的保存 Agent：助手加决策、轻量助手和统筹规划，以及作业 Agent（见常驻 Agent）。没有模板目录：Agents 列表就是模板，新建 Agent 从空白开始。

Agent行为
三个专家Agent 类的固定参数，经 AgentSpec 和 Agent.from_spec；无角色提示。任务和指令来自调用点和 Context；空的保存提示不清除环境指令。模型可编辑；本地安装分配已配置的模型。角色不保证成本或质量。
决策Agent.choose 用选择解析器在一次无工具的 llm 请求中选出一个给定选项：无建议，不重选；返回选项 ID，拒绝无效回答。保留 Context 和 DAG 作用域。禁用工具。
轻量助手禁用工具
统筹规划检查证据并委派授权任务
页面布局
  • 保存 Agent 列表和全宽编辑器。二级导航用共享的 ManagePage 分栏布局和侧栏宽度 token。
  • 头部：名称、ID、对话操作。八个标签在任何宽度都保持横向，必要时滚动。
  • 常规只有名称、用途、模型和推理。手动指令留在高级。没有内层导航列、重复介绍或设置摘要。
  • 输入正常字重，标签中等字重；应用字体、中性表面、控件尺寸、蓝色选中。
  • 面板在标准内边距内填满编辑器，无固定最大宽度。编辑器独立滚动；保存页脚常驻并报告草稿状态。
  • 窄屏用选择框替代列表，身份字段堆叠。保存的无效推理选项保持可见；继承的不兼容设置不产生编辑前错误。

验收：内置项可见可编辑；新建 Agent 从空白开始；重复安装保留编辑；Agent.from_spec 能运行保存记录；草稿、冲突、复制和对话流程正常；桌面和窄屏布局在真实页面和 App 上检查。

配置 Agent

配置属于会话分支

会话共享项目和工作目录。每个分支各自保存 Agent、模型及服务商、思考强度、工具意图、搜索开关、权限模式及规则、Plan、沙箱覆盖和服务等级。

新分支复制来源分支的配置一次，此后各改各的。切换分支恢复目标配置，包括空覆盖；Rewind、Undo 和 Redo 保留它们。计划任务的分支在首次运行时复制选中分支的配置并取任务的 Agent；之后每次运行沿用这份记录，并重新取任务的 Agent。

分支引用保存配置；会话顶层字段镜像选中分支。切换时来源配置保存、目标配置恢复，与消息位置一次提交。旧会话以现有配置初始化一次分支，不重建缺失的历史。

执行接纳时，从这一轮的分支冻结 Agent、模型、思考强度、高速、工具意图、沙箱，以及权限模式和规则。所属分支取下列第一个：

  1. 请求点名的分支；
  2. 为这次运行的消息预留的记录（计划运行的）；
  3. 存活的同会话父任务的分支；
  4. 这一轮起点消息上的记录；
  5. 选中分支。

聊天、计划、后台或无界面的一轮落在未选中的分支上时，运行那个分支的 Agent 和权限。Job 保留给定的配置，同会话子任务继承父任务，试用 Agent 保留快照。

读写没有记录的分支以 branch_gone 回复，并带上选中分支。输入框读取会话显示的分支，把改动应用到它上面。

未获焦点的窗格在它的分支或该分支的 Agent 变化时重新读取模型设置。在未选中的分支上选模型或切换 Agent，不动正在运行的 runtime，也不广播，其他窗格和侧边栏仍显示选中分支的模型；窗格从回复里取模型及其控件。

每次读取模型设置都带上窗格的分支，所以任何广播之后，停在未选中分支上的窗格读回的是该分支的模型，而不是选中分支的。广播不指明是哪个对话，所以没有 chip 直接采用它带的模型：每个 chip 保持原样，直到自己的读取返回。

这次读取还带上该分支已存的思考强度和联网搜索开关。窗格采用它们，除非自己还有写入在途，所以从别的窗口或 API 改的设置不用刷新就到达已打开的窗格。
