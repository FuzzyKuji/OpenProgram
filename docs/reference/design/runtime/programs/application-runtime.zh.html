应用运行时

应用有自己的界面、业务逻辑、数据和依赖，从新标签页打开，不必回到创建它的对话。

价值与限度
  • 界面用标准 Web：HTML、CSS、JavaScript、编译后的 React 或 Vue，不是拼装固定的 OpenProgram 组件。HTML 是界面技术，不代表完整度；软件能做什么取决于后端、状态、契约和部署依赖。
  • 价值：按钮和 Agent 共用业务操作，模型调用进入现有执行记录，业务数据独立于聊天窗口。这是产品契约的组合，不声称独有。
  • 应用在 OpenProgram 内运行。将来仍可用最小运行时部署；去掉全部 OpenProgram 依赖需要替换模型、存储和执行实现，因此不承诺自动独立导出。
  • 浏览器可执行的 JavaScript、Canvas、WebGL 和 WASM 可用。系统 GUI、GPU 驱动、任意二进制和其他语言服务不可用，需要显式的运行时适配器和依赖契约。

术语与入口

术语含义
Program可调用能力；Tool 和 Workflow 保持原定义
Package容纳这些能力的安装单元，包括 harness。不是执行类型。
Application用户可打开的软件，有自己的界面、版本、数据和生命周期
宿主插件扩展宿主行为的安装单元，如工具或主题。单独管理；现有加载器不保证应用隔离，插件也不会自动适配成 Application。
目标入口结果与失败
查看能力Abilities → Programs每个应用目录一个普通文件夹，内置或已安装；来源、默认入口、调用结构。gui_agent 等名称不变。
安装、升级、卸载包openprogram programs install、install --upgrade、uninstall克隆到 ~/.openprogram/programs/<name>/。开发符号链接保持目标不变。未知目录绝不导入。
安装软件Applications → Install…显示声明、来源、版本、启用状态。Python 后端需要勾选明确信任。重复 ID、无效入口、依赖准备失败都返回错误，不覆盖现有内容。
打开新标签页按钮，或 Applications 上的 Open独立标签页，同一实例。项目应用绑定当前项目或选择器。没有 UI 的 Program 不增加按钮。
管理Applications：启用、显示或隐藏、更新、卸载停用阻止新的打开和操作，并取消进行中的操作；隐藏只移除按钮。错误显示在对应操作旁。刷新和重新打开读取最新目录。
从 CLI 或 Agent 调用openprogram programs list、run、status、cancel、check、install、uninstall、enable、disable与所有 Program 同一命令组，没有单独的应用命令。

应用契约

{
  "id": "local.paper-reader",
  "title": "Paper reader",
  "icon": "book-open",
  "version": "1.0.0",
  "ui": { "root": "web/dist", "entry": "index.html" },
  "backend": { "kind": "python", "entry": "paper_reader.app:operations" },
  "scope": "project",
  "capabilities": ["model.invoke", "storage.app", "files.project.read"],
  "dataSchema": 1,
  "operations": {
    "summarize": { "agent": true, "input": { "type": "object" }, "output": { "type": "string" } }
  }
}

静态应用省略 backend。id 是稳定的包身份，绝不是标题、路径或创建对话的 ID。字段规则和公开 API：应用。

对象内容
定义从来源读取的 manifest 加源码树的内容摘要，在加载和每次重新加载时计算
安装目录行：来源目录、设置、审核过的数据身份和信任。包上限 100 MiB，不允许符号链接或特殊文件。
实例应用 ID、owner、项目范围、业务数据位置。窗口不是数据库。
视图标签页、实例、UI 路由、显示的运行。可丢弃。
操作运行运行 ID、实例、定义、输入、请求键、状态、事件序列、结果。链接现有执行记录，不复制 DAG。
  • 操作有输入输出 schema。客户端不能选择导入路径、来源路径或 owner，由服务器解析。可信身份来自已认证的连接，不来自 JSON 字段。
  • 操作名只存在于 UI 和进程边界。Python 内部用普通 import，没有第二个字符串调度器。
  • 事件序列递增，客户端按游标恢复。结果和错误持久化。状态 JSON 最多 4 MiB，单个事件 1 MiB；大输出用引用。
  • 项目路径变化只更新绑定，不改变实例身份。Runtime 数据库保存执行事实，应用状态引用运行 ID。localStorage 只缓存可丢弃的视图偏好。
  • 用户数据绝不放在来源目录。
  • Python 环境：每个应用和固定依赖集合一个，首次使用时创建，绝不安装进主 worker。列表只读 manifest，不启动进程。静态应用不启动 Python。发布的 UI 用构建产物：不起开发服务器，不装最新依赖，不在点击时重新生成。

模型与业务操作

方面规则
共用路径按钮和 Agent 调用共用输入校验、权限和实现。只有 agent: true 的操作暴露，名为 <id>__<operation>；内部数据库方法绝不成为工具。Agent 调用绑定实例，不能切换项目数据。
模型调用runner 按 manifest 的模型名或宿主默认值创建 Runtime，绑定运行记录（runs/ 下的 SessionNodeWriter）。上下文是操作输入和显式提供的应用数据，与活动聊天无关。点按钮前不需要聊天。
凭据页面只拿到进度和结果，绝不拿到 provider 密钥
问题context.ask() 发出问题事件；回答绑定运行和请求 ID，只对当前待答问题生效。没有第二个 ExecutionStatus。
提交普通代码在事务提交前校验模型输出。自然语言的“已保存”不是证据。
重试请求键对提交去重；相同键配不同输入被拒绝。非幂等的外部效果要检查现有记录或询问用户；网络超时绝不重复执行。

生命周期

路径顺序
打开读取已验证定义 → 选择 → 解析实例和项目 → 复用或创建标签页 → 按摘要加载资源 → 连接能力端口 → 读取状态和活动运行。不导入业务代码，不发模型请求。
任务持久化输入、请求键和 accepted 事件；现有 Attempt 管理运行；持久化问题；以 completed、failed 或 cancelled 结束。Stop 终止拥有的进程树，清理后才报告 cancelled；迟到的结果不能覆盖终态。进程树所有权持久化，父进程退出后子进程也会结束。并发写需要事务或版本检查，不是禁用按钮。
重启重新打开恢复视图和状态。worker 重启后，未完成的运行按 owner 丢失规则变为 interrupted，或完成已请求的取消。输入、进度和结果保留。Python 栈不恢复；应用可读取保存的状态并提交新操作。
更新install --replace 或 Update from source：校验 manifest 和目录树，在单独进程检查后端，复查摘要，检查 dataSchema 和 scope，然后原子切换目录行。来源变化时以新摘要重新加载。从旧摘要的视图提交会被拒绝并提示重新打开。
卸载取消操作，隐藏应用，保留来源目录、数据以及 schema 和 scope 身份。兼容的重新安装恢复实例。没有业务数据删除 API。

不兼容的 dataSchema 或 scope 被拒绝；需要备份、校验和明确恢复的自动迁移尚未实现。

隔离与可移植性

  • iframe 使用 sandbox="allow-scripts"、严格 CSP 和不透明源。宿主和页面通过校验过的 MessageChannel 握手通信。现有同源插件页面不能证明隔离；CORS 不是认证。
  • 资源按摘要寻址，限于发布的 UI 目录，凭据只允许读取 UI。桥拒绝页面提供的 owner、URL 和其他实例的运行。页面访问不到 /api/*。能力按操作重新检查；停用或卸载即撤销。
  • 独立的 Python 进程隔离依赖和崩溃，不隔离宿主文件和网络。后端是明确信任的本地代码，manifest 能力不是恶意代码沙箱。不受信的远程代码需要平台限制或容器，覆盖子进程、安装脚本和继承的环境。
  • 普通应用只在自己的标签页渲染，拿到一个小而稳定的 API，而不是 React store 或会话管理器。全局工具栏、聊天编辑器、主题和系统服务属于受信任的宿主扩展。
运行模式依赖承诺
纯静态浏览器和自身资源可独立托管；数据迁移由应用负责
在 OpenProgram 内UI、后端、OpenProgram Runtime当前实现
独立部署，同一运行时包、最小运行时、配置、存储边界已预留；适配器和验收完成前不可用
跨宿主 MCP AppsMCP 服务器、兼容宿主共享 UI 和工具契约；OpenProgram 后台 API 不可移植
完全不依赖 OpenProgram替换模型、任务、存储不保证；单独构建和测试

采用、调整、推迟

选择依据处理
采用：标准 Web 界面MCP Apps、OpenAI Plugins前端自由构建，主题组件可选，宿主 API 稳定
采用：显式贡献与生命周期Hermes Desktop Plugin SDK、DeepSeek Harness应用只在自己的页面内贡献；全局插槽仍是受信任插件的能力
采用：状态与页面分离LangGraph、AgentOS持久化状态和运行记录；localStorage 和聊天历史都不是数据库
调整：MCP AppsMCP Apps预留标准桥适配，先做本地契约。持久任务用显式宿主扩展，不声称是标准。
调整：UI 事件流AG-UI沿用现有事件语义；需要跨框架集成时加适配器
可选：声明式 UIA2UI适合确认和常见表单，不强制
推迟：宿主内任意动态代码宿主稳定性、隔离代码注册前先成为可审查的构建；eval 不是发布方式
推迟：市场、其他语言 runner、原生 GUI 嵌入安装、打开、操作、恢复都不需要不是当前版本的依赖

MCP Apps官方文档工具与 ui:// 资源关联；JSON-RPC / postMessage。沙箱 Web UI，可选择前端框架。兼容的是 UI/工具交互；不负责本地安装、业务数据库与后台任务。
AG-UI官方文档Agent 与 UI 的事件通信。不规定 HTML、原生组件或页面框架。解决流式交互，不是应用包、权限系统或部署器。
A2UI官方文档生成结构化 UI 描述，由受信组件目录渲染。限制在可用组件与 renderer 合同内。可跨平台渲染；不等于运行任意生成前端代码。
证据限度
  • “官方仓库描述”指阅读公开描述，不是审计仓库。没有实测的兼容不算验收。链接只支持相邻的说法，不背书整个实现。
  • 相关的 DSH 发行版、worktable 和 OpenProgram 代码已检查；其他项目依据当前官方文档、公开示例或仓库描述。并非每个产品都安装测试过。
  • “未验证”表示证据不足，不表示不支持。Cursor 和 Windsurf 内部未知。AutoGen 和 Semantic Kernel 放在 Microsoft Agent Framework 的演进中讨论。
  • 列表并不封闭：商业产品、社区分支和私有 harness 未穷尽。相关的 Qwen Code 和 Strands 页面无法获取；Trae、Kimi CLI 和云端软件生成服务不在矩阵内。这些缺口限制的是独有性声明，不是这里的需求。
  • DSH 细节依据已安装发行版 0.1.5-rc.1，worktable 源码 0.3.3。两者都没有完整兼容验收；一个版本的演示不能作为另一个版本能力的证据。
影响选择的机制
项目发现
dsh-worktable宿主服务、UI 插槽、React 分栏；不是独立软件。生成的窗口从 artifact 清单读取 HTML、URL 或文件。只用自身资源的页面可单独托管；依赖 DSH 路由、会话或插件服务的页面离开 DSH 就失去它们。
DSH 动态 Cordis 插件宿主部分注册处理器；客户端部分在宿主内运行并调用后端。有真实逻辑，但受支持的 API、加载生命周期和代码格式约束。Node vm 不是操作系统级隔离。
Hermes窗格、页面、侧栏、状态栏和命令面板贡献；本地插件直接在宿主内加载，不同于隔离的 HTML 预览；Dashboard 有页面和插槽。采纳：显式贡献和生命周期，但不把宿主内部对象交给生成的应用。
Pi自定义 UI 用终端组件：并非所有插件界面都是 HTML。
OpenClaw 小组件面板只做渲染。宿主操作和 A2UI 属于 Control UI 和会话 dashboard；同叫 canvas 不等于能力相通。
MCP Apps、AG-UI、A2UI可移植 Web 资源和宿主通信；Agent 到 UI 的事件；从组件目录声明式渲染。都不提供安装、数据迁移或后台生命周期。
LangGraph、AgentOS、OpenHands应用可独立部署但仍需库和服务：离开桌面客户端不等于去掉所有依赖。
Chainlit 自定义 React 前端完整应用可以带自己的前端作为服务部署。

验收
  • 示例应用：不用模型的计算器、保存批注并从粘贴文本生成摘要的论文阅读器、显示进度和重启中断的批量文件分析。
  • 通过公开入口（API、CLI、真实浏览器）检查：安装、更新、停用、卸载后重装、失败、重复点击、重新打开和重启。默认 App 检查：harness 在 Applications 下、管理页和菜单复用同一实例、笔记和分析结果保留、菜单隐藏和恢复、重启后恢复标签页和结果。
  • 集成测试覆盖模型成功和失败、取消、重复提交和中断；离线测试不保证真实模型可用。
  • 性能目标：列出新标签页不启动业务进程；重复打开不产生第二个同范围实例；打开不触发代码生成或模型请求。不做未测量的延迟承诺。
