Direct communication

SystemConnection and delivery
Ourssend_message(to=) from any agent to any unarchived branch, same path across sessions, no ownership check. Busy targets queue in the session inbox.
Claude CodeSendMessage. to: teammate or subagent name, main, an agent ID, or another session’s name; a local session’s inbox address starts with uds:. No broadcast: one message per recipient. Teammates use file mailboxes ~/.claude/teams/{team}/inboxes/{name}.json. Sending to a finished subagent resumes it.
codex-clisend_message, followup_task, straight to the target thread. Absolute paths let siblings address each other. Delivery queues, or wakes the recipient for one turn.
openclawsessions_send, off by default: a config switch and pairwise allowlist. A bounded back-and-forth loop. Children cannot use it and return through the parent's announcement queue.
opencodeParent to child only, which may append to a running child. No messaging tool in the registry.
hermes-agentChildren report to parents only; send_message is on the never-for-children list. Board workers, one process per card, exchange card comments in a shared database; the root card holds a conventional shared area.
pi-monoOne prompt at spawn, stdout on exit. Sequential mode substitutes the previous output into the next task, the only sibling channel.
pi-aiNo agents
weclaw@a @b message sends one message to several agents, each replying to the human with a prefix. Agents cannot see each other.

Beyond one process: Claude Code reaches other local sessions and machines, ours any session, openclaw by session key.

Loop prevention

SystemControls
OursOn: 4 concurrent, inbox 50 with oldest evicted, 60 s duplicate window, self-delivery rejected. Optional, off by default: depth, per-chain messages, per-turn fan-out. No tool-round cap on chat turns.
Claude CodeDepth 3 and concurrency 20 by default, no total spawn cap; a fork cannot fork; teammates cannot spawn teammates. Cross-session messages: rate-limited per sender, identical repeats dropped within a short window, at most 50 queued.
codex-cliDepth (V1 1, V2 none); concurrency 6 global, 4 per V2 session. No dedup, count, rate limit or cycle detection, so with sibling addressing nothing stops two agents delegating forever.
openclawDepth 1 (to 5); 5 children per agent (to 20); concurrency 8 and 4; conversations 5 rounds (to 20); 2 s steering limit; 3 announcement retries; child-key dedup; tool-loop detector, off by default.
opencodeDepth by injected permission. Same tool with identical arguments 3 times prompts for permission. Steps unlimited by default.
hermes-agentDepth 1 (to 3); 3 concurrent; 50 iterations per child; 600 s timeout plus heartbeat; a global spawn pause; delegation toolset removed from leaves. No dedup or count.
pi-monoFan-out 8, concurrency 4, 50KB output per task. No depth, dedup, rate or round cap; recursion is unbounded.
pi-aiNo tool loop
weclawDedup: WeChat ids for 5 minutes, names within a broadcast. No return channel, so no cycles.

Depth limits are nearly universal; only three systems count messages.

Restricting child tools

A: remove from the list
The model never sees it. Definitions differ by level, so prompt caches split.
B: keep, reject at call
Definitions stay byte-identical and caches hit. An attempted call wastes a turn.
SystemApproachWhat and when
OursA by remaining allowance, then refusalOnly agent, only when the message budget is out (delegation_budget_left), since every dispatch costs a message. Spent generations do not remove it: work can still go to existing agents. Everything else stays. Deliberately binary: a per-level set would shred the prompt cache.
Claude CodeA and BAgent is withheld at the depth limit; a fork keeps it and gets an error at call.
codex-cliV1 A+B, V2 ATool list omits collaboration tools at the limit; V1 handlers also reject. Roles overlay configuration files, not allowlists.
openclawA+BAll children lose gateway, agent listing, session status, scheduled tasks and cross-agent messaging. Leaves also lose subagent listing, session listing, history and spawning. Spawn rechecks depth.
opencodeA or BDeny with "*" removes from the schema; a specific pattern keeps it and throws at call, returning the matched rule.
hermes-agentA, per toolsetRequested ∩ parent-owned, minus delegation, user-question, memory and code execution. Gap: the never-for-children list only generates docs, so a child inheriting the messaging set still gets send_message.

What we took from this

DomainToolsHolds
Plantodo_create, todo_update, todo_listA checklist; editing runs nothing
Executionread_conversation, close_agentOne id, one status, guaranteed return, cascading cancel
Entityagent, list_agents, send_messageAn agent is a branch in the session graph
Communicationsend_message, read_conversationMessages without task records; any branch's transcript
ChoiceAgainstWhy
Tool names agent, list_agents, send_messageClaude CodeModels already know them
Planning is todo_*Differs from Claude CodeIts TaskList is a plan board; ours keeps running work and plans apart
Address a branch, not a processLike codex-cli paths, openclaw keys(session, head) identifies it without an agent table
Any agent may message any agentLooser than openclaw; like codex-cli V2, Claude CodeA message makes no task and cannot cascade; the worst outcome is silence
One message tool: send_message always makes a JobCodex send_input, Claude Code SendMessageReturn, cancel and cascade belong to Jobs; one tool removes the choice between three addressing forms
Per-chain message budget; 8 when set, counting return flowOnly openclaw also countsDepth alone cannot stop existing agents delegating to each other. 8 sits between openclaw's 5 and 20 because we also charge spawns and dispatches. A return rebinds the count, so one round trip costs 1; generations restore to the dispatcher's, so a coordinator can dispatch the next batch.
Depth 1 when set, not 3openclaw, codex-cli V1, hermes, opencodeDepth 3 suits nesting with a human watching. Our unattended path is run_in_background=True.
Per-turn fan-out; 8 when setOnly openclaw has a true fan-out capA spawn leaves the parent's counters alone, so neither chain counter sees siblings. openclaw's 5 live children (1–20) is the reusable unit; hermes's 3 and pi-mono's 8 are batch arguments and agent makes one child. 8 is two pool widths: fill it, queue a batch, then refuse the ninth and name the existing eight.
No steering rate limit or child hard timeoutopenclaw 2 s; hermes 600 sopenclaw's limit guards steer, which aborts the child's turn; ours queues and interrupts nothing. Hermes's timeout is a caller-side wait that abandons the thread. job_output(timeout=) is that wait, and execution.cancel also terminates the runtime and forces a terminal state after 30 s.
Remove tools by allowance, binaryOthers remove always or by depth tierTiers invalidate prompt caches
Extra tools close_agent, read_conversationCodex close_agent; Claude Code TaskStopStop and retire a helper in one call, read history without raw session files

Rationale for each number sits beside its constant. Limits ship off, so the job pool bounds concurrency and the owner chooses depth. Open gaps: implementation status.
