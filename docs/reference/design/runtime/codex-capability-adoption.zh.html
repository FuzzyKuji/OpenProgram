已采纳

子系统决定和原因
openprogram permissions check、test用原匹配器只读解释和自测权限规则，不改变执行判定。
命令网络域名可选，仅 macOS：带认证的本地代理加 Seatbelt。默认联网不变，拒绝私有地址，Linux 和 WSL 在域名模式下拒绝执行。
execution.prevent_idle_sleep默认关闭。每个活动执行持有一个句柄，完成、出错或取消时释放：macOS 是 IOKit 断言，Windows 是 system-required 电源请求，Linux 是 systemd-inhibit 对空闲和睡眠的锁。不影响显示器休眠；Linux 上用户主动发起的睡眠也会等待。下次执行时读取。获取失败记警告，任务继续。只在调度执行外包一层资源生命周期。
bash 会话见下表 execution。
executionbash 按 unified_exec 的 exec_command 工作：等待 yield_time_ms 后返回，还在运行的命令作为会话继续，由 write_stdin 轮询、中断或输入（tty），并沿用 Codex 的 64 个会话上限和最久未用淘汰。会话跑在现有的受管进程 supervisor 上，worker 重启后仍在。不采用 zsh fork 和 Shell 快照。见命令会话。
network原有 Shell 沙箱只有网络总开关；safe_http 保护受管 HTTP 客户端，不能约束任意命令的套接字。保留可选的 macOS 命令域名限制，默认行为不变。
power原有 runtime、桌面端和脚本中未发现电源断言或防休眠实现。采用独立可选的运行时电源断言，不唤醒显示器或修改永久电源设置。

未增加：上下文、补丁、环境过滤、项目指令层级、剩余上下文工具。现有实现不变。

重叠，保持不变

子系统决定和原因
context已有上下文投影、摘要、预算和占用统计。算法或供应商端点不同属于重叠实现，保持原样。
patch已有补丁编辑、文件变更记录和工作树。移动语法、模糊匹配、行尾保留和流式补丁进度属于现有功能扩展，不纳入本批。
runtime已有持久执行、程序化工具调用和取消。JavaScript/V8 或另一种传输方式属于重叠实现。
history已有持久化、分支、可恢复执行和会话 UI。Codex 存储迁移与压缩针对不同格式，不重写我们的存储。
memory已有持久记忆、源资料归档与整理。外部记忆导入和被动屏幕记忆属于该系统扩展，本批不改。
permissions已有规则执行、审批和模型审查，保持不变。仅保留独立的只读规则解释与自检 CLI。
sandbox已有 Seatbelt 与 bubblewrap/WSL 隔离。原生 Windows 和 Landlock 属于替代实现，不纳入。
providers已有模型发现、凭据、代理 HTTP、故障切换与传输。OpenAI 专用压缩和无界重试属于重叠或供应商特有行为，不替换。
multiagent已有子 Agent、消息、持久任务和目标。不会增加第二套协作或目标系统。
mcp已有 MCP 工具、资源、认证和资源接口。协议版本、MCP Apps 和端点覆盖属于集成扩展，不自动迁移。
discovery已有工具发现、市场安装、插件 hooks 和技能。推荐、分享和依赖安装属于系统扩展，保持不变。
interaction已有提问、用户回复、后续消息和消息渠道。异步变体和提及 UI 属于重叠交互。
web已有网页搜索、图像查看、浏览器工具和 GUI 控制。供应商特有的外部浏览器或完整 CDP 变体不作为独立缺口。
media已有图像、附件、语音输出、听写和画布。全双工语音和图像预算算法与现有媒体系统重叠，不替换，也不声称能力一致。
desktop已有 worker 管理、聊天、调度和更新。传输与守护进程变体保持不变。
diagnostics已有用量记录、执行观察和健康诊断。套餐用量历史与内部 Responses 元数据属于供应商特有或重叠功能。
hooks已有 hooks 与 gate 系统，保持不变；本批不增加压缩 gate。
guidance已有 Agent 工作区指令、时间环境上下文、渲染指导和文档依赖。项目规则层级与上下文余量工具与现有能力重叠，已撤回候选改动。
wait已有等待、轮询与调度，不增加重复的 sleep 工具。
