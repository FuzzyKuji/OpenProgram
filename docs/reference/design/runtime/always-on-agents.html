Always-on Agents

Internal check-in prompts and their reply/call subtrees are omitted from the conversation DAG using their runtime speaker identity, including older stored turns. Reports and ordinary user messages remain visible; the original execution records are retained.

Always-on is the always_on section of a saved Agent (AgentSpec); no assistant object, no other settings. Every conversation using the Agent is one assistant, with its own Goal, check-ins, open work and reports. openprogram/runtime/conversation/always_on/ decides only which conversations wake, when, what a wake does, and where reports go.

Which conversations wake

Owner conversation
Not archived, and a web chat (source empty or web), channel conversation, or older home conversation (source always_on). Never agent or imported.
Joined
Has wake state, updated after enabled_at, or just switched to the Agent (POST /api/sessions/{id}/agent calls join())
First wake
One interval after joining; without one, the ladder's first step (one hour)
Stopping one
Archive it. Every archive path also pauses its Goal of origin always_on, check_in, handoff or scheduled under the Goal lock (chat.pause_always_on, reason conversation_archived). Unarchiving restores it and its next wake is now; with no Goal to restore, a wake already past is rescheduled from now. An ordinary Agent's or sub-agent's conversation is left alone.
Turned on again
A next_wake_at before the new enabled_at restarts from that moment
Older home conversation
When enabled_at is first recorded, _adopt_home() copies applied_goal, last_check_in_at, last_wake, next_wake_at from <agent dir>/always_on/state.json

Ticker

ticker.py starts with the worker. Per enabled Agent, each tick:

  1. Record a missing enabled_at.
  2. List conversations (at most 500).
  3. Finish any check-in an earlier worker left.
  4. Join newly eligible ones.
  5. Wake those past next_wake_at.

Disabled Agents: automatic Goals paused with reason always_on_off, then enabled_at cleared; a Goal whose lock is held keeps it set and is retried next tick. The first tick after turning on restores them. A Goal stopped both ways waits for the last undo. A restart keeps the saved schedule; a per-conversation lock prevents concurrent wakes.

Wake

wake(session_id, reason), for a due conversation or Wake now. Records the outcome and next wake. First match wins. Unknown or non-owner conversation, which includes a Try chat (agent_trial): WakeRefused. The ticker reads the conversation itself before joining or waking it, so an index row older than the flag changes nothing.
