标签页归属

启动器在解析 Program 前记下选中的标签页和聊天。旧请求、取消、切换聊天或标签页都不会在别的视图打开表单。

选中的视图成功后
活动 session保留草稿和运行中的任务
新标签页原地变成草稿 session
其他视图打开单独的草稿，保留其标签页

草稿先被选中并初始化，然后打开表单。目录失败时视图不变并显示错误。显式发送前不运行也不提交。

验证
  • 在新标签页点击真实的侧栏收藏，编辑任务字段后不提交关闭。
  • 保留另一个活动任务及其草稿。标签页变化时取消目录解析。
