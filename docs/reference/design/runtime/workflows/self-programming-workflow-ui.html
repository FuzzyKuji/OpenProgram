Tab ownership

The launcher captures selected tab and chat before resolving a Program. An older request, cancellation, chat switch or tab switch opens nothing in another view.

Selected viewOn success
Active sessionKeeps its draft and running task
New-tab pageBecomes a draft session in place
Any other viewOpens a separate draft and keeps its tab

The draft is selected and initialized before its form opens. A catalog failure leaves the view intact with an error. Nothing runs or submits until an explicit send.

Verification
  • Click a real sidebar favorite on a new-tab page, edit its task field and close without submitting.
  • Preserve another active task and its draft. Cancel catalog resolution when the tab changes.
  • Program launcher unit tests, rendered launcher browser tests, Web unit and source checks, TypeScript, production export, repository contracts, documentation links. Installed-App acceptance is a separate gate.
  • Runtime and browser APIs are retained; external product parity and dependency upgrades are excluded.
