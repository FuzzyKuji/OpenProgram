Branch walk

get_branch follows predecessor only, with no caller or seq guesses. A node with no predecessor must be a legal end, or the data is broken and the walk raises.

Legal ends
Spawn branch root, the ROOT node, a code node opening a run branch, the session's first node, a compaction summary covering the session start
Chat display
active_branch_chain filters the tool-aggregated rows to the ids get_branch returned; a stale or empty head falls back to a predecessor walk or all rows
Attach pointers
Hang off a message by predecessor without joining the chain and are written with advance_head=False, so they never move the head; splice_attach_pointers inserts them inline
