The two often differ. A top-level user node hangs off ROOT but follows the previous reply, and a spawn root has a caller but no predecessor. One name for both once let a helper read the wrong edge.

No compatibility layer

Only these two key names exist: no alias, no backfill in from_dict or the message adapters, no unused parent field in GNode. The backend graph dict and frontend are one protocol, so a key rename lands on both sides at once.
