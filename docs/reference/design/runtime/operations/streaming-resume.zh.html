重连

加载会话先返回已保存的行，再为正在运行的任务发送 running_task：

{ "type": "running_task",
  "data": { "session_id", "msg_id", "func_name", "execution_id", "status_version",
            "started_at", "display_params", "partial_tree": null,
            "stream_events", "status", "reason_code", "run_seq" } }

帧按会话下发；run_seq 决定先后，迟到的帧不能让已关闭的运行槽复活。

行和实时树以编号的 transcript_update 变化到达：函数运行的树是 row_patch，模型调用的树在其回复的 callRoots 里。重新加载的标签页先读取，再跟随更新；漏掉一次更新，或文字帧超过行里已有的文字，就再读一次。

Worker 重启

新 worker 没有在运行的工作，所以启动时在后台线程核对所有会话，包括已归档的。没有时间阈值。

节点结果
running变为 interrupted
cancelling，所有者已退出变为 cancelled
cancelling，所有者存活继续取消
有未结束的持久等待保持可恢复
execution 仍在活动交给 execution

重启后继续某个 execution 由 openprogram/runtime/execution/restart.py 负责，受 execution.auto_resume_window_seconds 限制。
