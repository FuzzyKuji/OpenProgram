DAG 边字段

callerpredecessor
回答谁调用了我聊天顺序上我跟在谁后面
边子调用对话链
字段Call.callerCall.predecessor
例子调用工具的那个 LLM第二轮 user 跟在第一轮回复后
决定子调用缩进、内部节点分叉：一个 predecessor 有多个子节点

两者常常不同。顶层 user 节点挂在 ROOT 下，却跟在上一轮回复后；spawn 根有 caller，没有 predecessor。两者同名时曾让辅助函数读错边。

没有兼容层

只认这两个键名：没有别名，from_dict 和消息适配器不回填，GNode 没有闲置的父字段。后端图字典和前端是同一协议，键名改动必须两边同时落地。
