聊天进度恢复

生成进行时，dispatcher 把有序的思考、文本和工具块持久化到所属助手占位消息的 extra.blocks。会话加载用与已完成轮次相同的方式读取。

情况行为
流监听只接受所属会话和消息身份；嵌套运行时事件保留自己的存储
文本增量在相邻块内合并
工具结果更新对应的块
成功最终持久化仍然权威
出错元数据与已存进度合并；块保留，并附加错误提示
During a read该会话的 stream_event 和 transcript_update 帧排在读取回复之后按序到达，所以先前捕获的读取不会撤销错误。错误作为 transcript 更新到达那一行；终态 chat_response 只结束运行
Reasoning只包含已实时显示的思考事件

重试可见性

项目规则
事件每次自动续写或 provider 重试都发出关联的流事件，含次数、上限、原因，以及已知的延迟
显示轮次活跃时助手气泡显示重试状态，即使已有文本
清除之后的成功、终止性失败或取消
绝不创建第二个用户轮次或把该轮标记为完成

没有仅浏览器存储，也不重放截断的事件缓冲。
