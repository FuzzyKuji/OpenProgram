分支遍历

get_branch 只沿 predecessor 走，不靠 caller 或 seq 猜测。没有 predecessor 的节点必须是合法终点，否则数据有误，遍历抛错。

合法终点
spawn 分支根、ROOT 节点、开启运行分支的代码节点、会话首节点、覆盖会话开头的压缩摘要
聊天显示
active_branch_chain 用 get_branch 返回的 id 过滤已聚合工具的消息行；head 过期或为空时退回 predecessor 遍历或全部消息行
Attach 指针
通过 predecessor 挂在某条消息上，但不进入对话链，写入时用 advance_head=False，不会移动 head；由 splice_attach_pointers 插入显示列表

DAG 节点聊天消息
服务对象运行时：render_context显示：消息列表、工具调用卡片
工具调用每个工具一个节点折叠进 assistant 的 tool_calls[]
Thinking在 extra 字段里提取到 blocks[]
结构{role, name, input, output, predecessor, caller, seq}{role, content, tool_calls, blocks, predecessor, caller}
构建时机写入时加载时，由 aggregate_tool_messages 完成

_msg_adapter.py 只从 Call 的顶层字段取 predecessor，metadata 里的多余副本不能覆盖它。
