Session DAG design

Arrows point at the edge's target. One node per user message, model call, function or tool call. Transcript and call tree are two views of this per-session, append-only record; any past call re-renders as the model saw it.

ItemDetail
Graph ownerEach Agent execution (ownership)
Ordinary helpersNo durable nodes; semantic operations are still recorded completely
Permission, cancellation, file checkpointsOriginating execution, whoever owns the graph
Inherited ContextDoes not turn computation into history

ItemDetail
Both edgesDirected, acyclic, orthogonal
callerConnects top-level nodes to ROOT
predecessorChat order and forks, which caller plus seq cannot give. Only this top-level field; no metadata mirror or legacy read
Write (session_store/shared.py)A mislinked branch is unrepairable, so a ROOT-level user or llm node with no real caller needs a predecessor, else PredecessorMissingError

Context rendering

A node renders if and only if its nearest ROOT-level ancestor (up caller) lies on the predecessor chain of head_id, and the frame and expose rules admit it.
