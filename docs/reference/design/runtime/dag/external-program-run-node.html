External program run nodes

A function run directly from Programs, fn-form or another outside entry is one node under ROOT and one chat record. No User or LLM node is invented for it.

LayerStoredShown
PersistenceOne role=code node. caller empty; predecessor is the HEAD at creation, or ROOTUnchanged by any view

Run statusThe same node, updated at start and endSame place and tile; only the tile's state and status text change

The node is the ordinary call tile in Layout specification. Arguments and output belong in Details.

Model for a direct run

The run belongs to the current session. Before the function process starts, the server resolves one provider and model and passes that pair in; with none it refuses with no_model.

  1. The session's provider_override and model_override
  2. The conversation Agent's configured model
  3. The last used model
