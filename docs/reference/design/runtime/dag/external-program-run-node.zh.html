外部 Program 运行节点

从 Programs、fn-form 或其他外部入口直接运行的函数，是 ROOT 下的一个节点和一条聊天记录。不为它虚构 User 或 LLM 节点。

层存储显示
持久化一个 role=code 节点。caller 为空；predecessor 是创建时的 HEAD，或 ROOT任何视图都不改动它
归属只由 caller 决定；predecessor 只记时间顺序caller 为空或 ROOT：顶层 Program。caller 是 assistant：放进该消息的 runtimeChildren
DAG 总览不新增任何内容projectTopPrograms 通过派生的 _overview_parent 把它放到 ROOT 泳道、tier 1；内部调用归入同一泳道
重试retry_of保留分叉泳道，不做 ROOT 投影
运行状态开始和结束都更新同一节点位置和节点不变，只变节点状态和状态文字

节点就是布局规格里普通的调用节点。参数和输出放在 Details。

聊天记录

部分（按顺序）行为
头像 ƒ标明这是一次运行，不是 assistant 消息
标题行ExecutionStrip 加一行摘要；切换执行区
执行区参数、执行树、用量。沿用现有 RuntimeBlock 和 TreeStep，Details、Copy、Retry、Edit & re-run、版本导航不变
答复在折叠区之外，用普通聊天字体，没有引用样式
页脚始终在最后，不折叠；普通的时间和操作行

折叠状态跟随会话的转录视图，读者点击后以点击为准，后续更新不覆盖。过长的标题保持一行并显示箭头，完整文字留给辅助技术。
