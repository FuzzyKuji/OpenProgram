Context

session_context (openprogram/runtime/conversation/session_context.py) installs the per-turn ContextVars and resets them on exit, in reverse order.

A session that does not exist is created here: one of the three creation entry points. _call_id belongs to the Agent method wrapper.

Session boundaries

Caller intentPassBehaviour
Run a new taskNo session_idNew <id_prefix>_… session; the id is on the handle
Continue the same taskThe id from last timeReused, history continues
Start something unrelatedNothing, or a different idA separate session

The call count never decides. A session has no close: exit only resets the ContextVars, and the same id keeps writing later.
