AuthorityWho is askingAuthenticated principal and a fixed capability ceiling on every request; nested Agents never widen it
PermissionMay this operation runOne shared decision under the session's mode; the mode can change mid-turn and the next tool check uses it. See Permission decision and refusals.
SandboxWhat an approved process can touchSeatbelt (macOS) or bubblewrap (Linux). Off unless the conversation's Sandbox switch is on.

The same contract covers Web, CLI, ACP, channels, nested Agents, scheduled tasks and continuation.

Mode resolution

The conversation's setting, then the project's default, then Bypass permissions (DEFAULT_PERMISSION). The resolved mode drives admission and UI acknowledgements. The modes are defined with the decision.

Protected writes

A sandboxed command escapes by writing a file that something outside the sandbox runs later. The worker starts in home, so a conversation with no project folder has home as its writable root. host/sandbox/protected_writes.py keeps these read-only on top of every policy; no configuration removes them.

Failures and known limits

  • Missing authority, stale versions, invalid modes, denied capability, explicit rules, classifier failure and sandbox refusal stay distinguishable. No failure silently becomes owner or Bypass permissions.
  • Host process visibility may block ps, top or lsof. Docker sockets are not exposed automatically. Linux wildcard masking has limits. Browser and remote networking have separate controls.

Acceptance
  • Live changes: chat admission and a safe tool; inherited Bypass permissions; running ask-to-Bypass permissions and back; waiting approval continuation; explicit ask and deny; Plan transitions; owner and session isolation; stale versions; reload and reconnect; unchanged Sandbox denial.
  • File writes: dispatcher import without fcntl; changed or deleted targets; existing and new files; exact UTF-8 bytes; replacement and link races; repeated writes. The Windows installation smoke imports the dispatcher; platform CI runs the approval regressions before the unit suite.
