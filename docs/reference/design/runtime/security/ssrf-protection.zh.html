传输与策略规则

方面规则
公网请求只允许注册表声明的方法、scheme 和端口。所有解析地址必须是全局地址。拒绝：元数据、回环、私网、链路本地、CGNAT、组播、保留、未指定、文档和测试、映射、歧义、畸形地址。DNS 失败按拒绝处理。
连接同步和异步 httpcore 后端只连接已批准的 IP 元组，校验实际 socket 对端，并保留规范化主机名用于 Host、SNI 和证书校验
连接池标识包含消费者、信任等级、规范化来源、已批准 IP、代理身份
重定向手动处理，每一跳重新判定。已配置服务的跨源重定向失败；公网凭据被剥离。
隐私拒绝 URL userinfo。日志和公开错误不保留 query、fragment、令牌路径、cookie 或对端响应体；错误只含来源。
限制头、MIME、内容编码、解码后字节数，connect、read、write、pool 和总超时，临时文件
下载完整校验、flush、fsync 和可安全清理的收尾之后才替换目标

Owner 例外和策略代理

Owner 例外
已注册消费者加恰好一个规范化来源，或规范的私网或本地 CIDR。拒绝通配符、后缀、凭据、未知字段、公网和默认路由网段、元数据、链路本地，以及该消费者不允许的形式。只能通过 Owner 认证的设置修改。
策略代理
只有 Owner 配置 enforces_target_policy: true 时可用。Runtime 先评估目标，单独约束代理对端，通过 doctor 和审计报告委托，绝不直连重试。

设计选择

选择机制原因
采用单一纯 URL 和 IP 策略；所有 DNS 答案都须通过；每次重定向重新评估；错误只含来源；限制解码后响应体一致覆盖目标、重定向、凭据和资源边界
采用区分信任等级Owner 配置的本地服务可用，公网消费者拿不到私网访问
采用权限与网络分层（Claude Code、CodeBuddy）、结构化拒绝原因（Codex）、固定频道媒体白名单（CodeBuddy）权限回答谁能请求；传输策略回答哪个对端拿到连接和凭据
修改Hermes 进程级 allow_private_urls 改为精确的消费者加来源或 CIDR元数据和链路本地目标不可例外
修改OpenClaw 浏览器拦截和 Codex 全进程代理浏览器控制是独立的门；策略代理可选、由 Owner 声明、约束对端、在 doctor 可见、无直连回退
拒绝只查 URL 字符串、单次 DNS 预检、隐式重定向、继承环境代理、关闭 TLS 校验、裸回退每一项都留下目标、重绑定、凭据或绕过路径
拒绝用户确认或主机名 allow、deny 作为目标强制都不校验每个解析地址，也不约束对端
拒绝所有客户端一律仅限公网破坏已配置的本地模型端点、MCP 服务器和内网服务
拒绝把 Origin 和 Host 检查、CORS、Owner 认证、浏览器检查或沙箱网络算作本防护它们防护的是其他方向或执行边界

项目URL 获取依据网络或权限边界取用
Hermes共享 url_safety，覆盖网页、浏览器、视觉、网关媒体。DNS 失败关闭；拒绝回环、RFC1918、链路本地、CGNAT、元数据、保留、组播、未指定；逐跳检查重定向；URL 脱敏；流式限制。allow_private_urls 同时放宽多个入口；应用层检查不能替代 OS 隔离。共享的失败关闭校验、完整地址集、重定向检查、脱敏、限制。全局开关改为精确例外。
OpenClaw默认拒绝私网、内部和特殊用途目标，精确或通配例外，在导航、交互触发的加载和最终 URL 前检查。文档指出预测导航和子资源风险。请求拦截不是网络防火墙：重定向、弹窗、Service Worker 和后台资源仍可能需要出口隔离或策略代理。严格默认和显式例外。浏览器拦截是独立边界。
Claude CodeWebFetch(domain:...) allow 和 deny。主机名先发给 Anthropic 安全黑名单，缓存五分钟，Owner 可关闭。Bash 沙箱使用子进程继承的 Seatbelt 或 bubblewrap HTTP 和 SOCKS 代理。信任客户端主机名，不检查 TLS，宽域名和域前置仍有风险。分层工具授权、子进程出口策略。拒绝把主机名权限当作连接时依据。
Codex不用单个 WebFetch 字符串检查代替网络边界。codex-network-proxy：HTTP 和 SOCKS5、精确或受限通配域名、拒绝私网解析、有限只读方法、MITM 头钩子、Unix socket 控制、结构化审计；OS 沙箱限制回环绕过。结构化拒绝原因、审计、托管策略概念。保留区分消费者的安全客户端。
CodeBuddy 2.109.3WebFetch 应用 Security Center 域名策略，拒绝 IP 字面量、localhost 和部分私网段。企业微信媒体：官方 CDN 白名单，禁止重定向。沙箱 allowedDomains 与 WebFetch 权限取交集。完整 A/AAAA 校验、对端绑定和逐跳重定向未确认。固定频道白名单、权限与网络策略取交集。拒绝只查 IP 字面量。
Gemini CLI文档说明 web_fetch 可访问 localhost 和私网；Plan Mode 可要求确认。core 0.35.3 有 IP 和 DNS 工具，但不构成通用边界。确认是权限判定，不约束对端。明确写出风险。拒绝用确认代替强制。
OpenCodewebfetch 权限作用于完整 URL：allow、ask、deny。文档未说明私网 IP 分类、完整 DNS 结果、逐跳重定向或对端绑定。shell 使用主机用户的网络；字符串规则只是尽力而为。统一的资源权限。获准的 URL 仍要过传输策略。
pi-mono未确认内置任意 URL 获取；网络来自 shell、安装器、扩展。未确认 OS 出口策略。第三方 pi-sandbox 不计入。不作 SSRF 参考。支持把第三方代码留在本防护之外。
pi-ai协议参考源码，没有 Runtime URL 消费者。不适用。排除。
weclaw连接外部 Agent 的消息桥；未确认独立的 URL 获取。继承所启动 CLI 的工具和网络。相关边界是频道媒体和进程启动；不作安全 HTTP 参考。
cc-internal、cx-internal、gm-internal包装上游启动器或复用 Gemini CLI；未确认独立加固。继承上游行为；增加认证或端点不构成 SSRF 边界。只审计额外端点、凭据转发和配置差异；不算独立设计。
OWASP区分已知服务白名单和任意公网校验，限制协议，校验每个 A/AAAA 结果。单次 DNS 预检仍有 pinning 和检查时间差风险；也建议网络控制。区分信任等级、连接时约束对端。拒绝单次预检。
