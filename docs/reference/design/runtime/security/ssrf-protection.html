Owner exceptions and policy proxy

Owner exception
A registered consumer plus exactly one normalized origin or canonical private or local CIDR. Rejects wildcards, suffixes, credentials, unknown fields, public and default-route networks, metadata, link-local ranges, and forms the consumer does not allow. Changed only through owner-authenticated settings.
Policy proxy
Usable only with owner configuration enforces_target_policy: true. Runtime evaluates the target first, constrains the proxy peer separately, reports delegation through doctor and audit, and never retries direct.
Static checks and inventory exclusions

scripts/check_runtime_http.py fails on an unregistered raw call, an active unmanaged SDK transport, a registry entry without a classified consumer, or a stale exclusion. doctor labels: runtime-http-registry, runtime-http-owner-exceptions, runtime-http-policy-proxy, runtime-http-recent-denials, runtime-http-unmanaged-transport.

ModifiedOpenClaw browser interception and Codex's whole-process proxyBrowser controls are a separate gate; a policy proxy is optional, owner-declared, peer constrained, visible in doctor, with no direct fallback
RejectedURL-string-only checks, one DNS preflight, implicit redirects, inherited environment proxies, disabling TLS verification, raw fallbackEach leaves a target, rebinding, credential or bypass path
