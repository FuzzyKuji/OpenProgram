外发暂扣

邮件、聊天消息、评论会送到没有向 Agent 提过任何要求的人面前。暂扣打开后，这类调用在任何权限模式下都先作为草稿，等用户批准。

哪些调用被暂扣

mcp/adapter.py（sends_on_behalf）在注册时对每个 MCP 工具判定一次，结果存为 AgentTool 上的 _sends_on_behalf。原始名称按标点和驼峰拆词。

暂扣生效的位置

方面行为
顺序在 permission_decision 中，位于 deny 规则、Plan 拒绝和 ask 规则之后，allow 规则和模式之前。见权限判定与拒绝。
结果ask，代码 RULE_OUTBOUND_HOLD，与模式无关，有 allow 规则也一样。无法批准的轮次得到 NO_ONE_TO_APPROVE。
哪个 Agent该轮的 req.agent_id，缺省为 main。未知 Agent 不暂扣。带 profile_snapshot 的轮次（如试运行未保存的草稿）在快照开启暂扣时同样暂扣；快照不能解除已保存 Agent 的暂扣。
批准one_shot_approval 覆盖所有发送工具，无论是否暂扣：不提供“始终允许”，不写 allow 规则。每条消息单独批准。
草稿审批卡片上的工具名和完整参数；approval._approval_detail 不截断一次性调用。
拒绝并附言附言作为工具结果返回模型。模型的下一次调用是新草稿，再次询问。

配置

agent.json 顶层布尔值 hold_outbound，由 Agent 常驻标签页的最后一个复选框设置，PATCH /api/agents/{id} 也接受。只有显式 true 才打开；AgentSpec.hold_outbound 默认 false。关闭时调用和其他工具一样遵循对话的模式和规则。Worker 的一次性迁移把存量 true（来自早期默认值）改写为 false。
