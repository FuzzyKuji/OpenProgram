新增规则

  1. 在 openprogram/runtime/proactive/policies/ 写一个类，定义 on、lane、cooldown_s。
  2. 写 evaluate。
  3. register_policy 注册（同名重复注册被忽略）。

引擎、事件流和折叠都不用动。打扰预算和自动熔断不在范围内，cooldown_s 是唯一的旋钮。gate 机制见事件层。
