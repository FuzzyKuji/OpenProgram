Webhook

POST /hooks/{task_id} is the one HTTP path OwnerAuthMiddleware passes without login, only for POST of exactly that shape; Host and Origin checks still run. It reads at most 64 KB and calls hooks.receive on a worker thread.

StatusMeaning
202Run started
404Unknown task, another type, or wrong key, indistinguishably
409Paused
429More than one call per task in 10 s, per process

Creation stores a random 24-byte URL-safe hook_key; the tool result prints the URL (hooks.url, from the active Web access snapshot) and the key. It is accepted from X-OpenProgram-Key or as the HMAC-SHA256 secret of X-Hub-Signature-256 (GitHub), compared in constant time.
