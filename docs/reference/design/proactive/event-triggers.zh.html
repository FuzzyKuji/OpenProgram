Webhook

POST /hooks/{task_id} 是 OwnerAuthMiddleware 唯一不要求登录就放行的 HTTP 路径，且只限这个形状的 POST；Host 和 Origin 检查照常。最多读 64 KB，在工作线程调用 hooks.receive。

状态码含义
202运行已启动
404任务不存在、类型不符或密钥错误，三者不可区分
409已暂停
429每任务每进程 10 秒内超过一次

创建时保存随机 24 字节 URL 安全的 hook_key；工具结果打印 URL（hooks.url，来自当前 Web 访问快照）和密钥。接受 X-OpenProgram-Key，或作为 X-Hub-Signature-256（GitHub）的 HMAC-SHA256 密钥，常量时间比较。

事件以数据形式到达运行

主体类型传递方式
promptevent_note 把文本放进 <event source="…" trust="untrusted">，转义其中的 </event>，并附一行说明它是数据。普通非交互调度轮次（source="scheduler"，会话的权限模式）：需要审批的调用被拒绝。
reminderreminders.fire 把 event 加进 reminder.fired。唤醒型提醒写明来源并带同样的说明；_wake 调用 start_owner_turn，审批在该会话中等待。
command环境变量：OPENPROGRAM_EVENT、OPENPROGRAM_EVENT_SOURCE

任务日志记在 # started by <source>: 下。
