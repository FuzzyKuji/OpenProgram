主动层

agent 工作时框架自己看着，该出手就出手：拦危险命令、提醒补测试、发现模型卡住。发生的每件事都成为事件，规则订阅事件并判断。

部分是什么状态
事件基础层一条统一的、谁都能订阅的事件流。主动层是第一个消费者运行中：总线开启，两类来源都在发事件，tool.before 带同步问询点，Web UI 是普通订阅者
主动规则规则订阅并出手。与基础层解耦代码在 openprogram/runtime/proactive/，worker 启动时未安装

简短回答

新框架还是补丁？
独立的一层，复用事件总线、工具审批和后台任务。
规则用什么写？
普通 Python 类。没有配置文件或 DSL。
有多重？
事件、状态、规则、出手。防篡改、离线回放校验、对抗安全在 _research_archive/。
日志在哪？
常开。~/.openprogram/projects/<project-id>/chats/<sid>/events.jsonl，会话之外是 ~/.openprogram/logs/events.jsonl。
