Proactive layer

While the agent works the framework watches and steps in: blocks dangerous commands, reminds about missing tests, notices a stuck model. Everything that happens becomes an event; rules subscribe to events and decide.

Short answers

New framework or patch?
A standalone layer reusing the event bus, tool approval and background tasks.
Rules are written in?
Plain Python classes. No config file or DSL.
How heavy?
Events, state, rules, stepping in. Tamper resistance, offline replay verification and adversarial safety are in _research_archive/.
Where is the log?
Always on. ~/.openprogram/projects/<project-id>/chats/<sid>/events.jsonl, or ~/.openprogram/logs/events.jsonl outside a session.
