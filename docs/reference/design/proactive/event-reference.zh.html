总线调用

调用说明
get_event_bus() → EventBusworker 单例。
create_event_bus()独立实例；不写盘。
make_event(type, origin, payload, metadata) → Event填充 id、ts、session 和 turn。
emit_safe(type, origin, payload=None, metadata=None)构造并发送；事件层故障被吞掉。
emit_ws_frame(frame)发送 ws.frame。
subscribe(handler, *, types=None) → unsubscribetypes=None 接收所有类型事件。
subscribe_gate(type, fn) → unregisterPython gate。
emit_gate(event, timeout_s=None) → GateOutcome询问所有 gate。
subscribe_transform(type, fn) → unregister改写者。
emit_transform(event, value)返回最终值。
register_tool_gate(gate) → unregistertool.before 的快捷入口。
示例 
from openprogram.runtime.events import get_event_bus

def on_file_changed(event):
    print(event.payload["path"], event.metadata.get("session"))
unsubscribe = get_event_bus().subscribe(on_file_changed, types={"file.changed"})

def guard(event):
    if event.payload.get("tool") == "bash":
        return "policy denied this tool call"
    return None
remove = get_event_bus().subscribe_gate("tool.before", guard)

未注册类型

类型情况
credential.cooldown、credential.rotated、credential.exhausted由 bridges.py 从 AuthEvent 翻译而来，载荷 {provider, profile, credential, detail}。总线容忍并每类型警告一次。
proactive.inject、proactive.prepare_requested主动引擎的派生事件；引擎当前未安装。
question.replied、question.rejected、programs:changed只是 ws.frame 内的帧类型，不是类型事件。spawn、attach 卡片、报告、通知、合并和删除以 transcript_update 送达打开的对话。
