Event

@dataclass(frozen=True)
class Event:
    id: str
    ts: float
    type: str
    origin: str      # user / agent / tool / system / proactive
    payload: dict
    metadata: dict   # {"session": …, "turn": …, "lane": …}

make_event fills id, ts and session and turn from the store ContextVars; explicit metadata keys win. Session and turn are metadata because they are external correlations with no meaning for half the events, such as auth and channels. The framework has no Turn object.

Admission

A type enters EVENTS only when a real consumer subscribes to it. Adding a type changes only its emit site; adding payload fields is safe; changing existing ones can break subscribers.

Emitting an unregistered type warns once per type and never raises. test_every_emitted_type_is_registered covers every emit_safe type.

The top-level hooks key of config.json. install_config_hooks() registers gate kinds as synchronous shell gates and notify kinds as background runners (daemon thread, exit code ignored). Edits apply at the next worker restart.

The command runs in /bin/sh on macOS and Linux and in bash on Windows, falling back to PowerShell with one notice when there is none. An entry may say "shell": "powershell", or give args to run command directly with no shell (which shell runs a hook). The event arrives on standard input as UTF-8 JSON.

The turn.stop continuation loop
  • continue_stop_hook_turns asks the gate after each completed top-level chat turn. Failed or cancelled turns return without asking.
  • A denial launches one more ordinary turn (dataclasses.replace, source="hook_continue", INHERIT_PARENT), then the gate runs again.
  • No numeric cap: stop_hook_active is true on every ask after the first, so a hook knows to allow the stop, as in Claude Code and Codex.
  • Goal rounds stay out of this path: goal() owns their completion judge and /goal clear can stop them.
  • Head movement stays with the normal TurnWriter path.

Gate events and the log row

A gate event passed through emit for typed observers defers its disk write; the same Event must then reach emit_gate, which writes the one row with the verdict. emit alone writes none. emit_gate alone is complete, without observers, and is what turn.stop uses.
