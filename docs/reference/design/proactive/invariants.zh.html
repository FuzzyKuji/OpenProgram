不变式

不变式规则否则
不自我触发成环框架自己引起的事件不能再启动动作Prepare 引出 Prepare：无休止地花钱和打扰
护栏不被自动静音今后的自动静音只适用于 observer 提醒反复拒绝就能在真正危险的命令到来前关掉护栏

由框架核心强制。规则不能关闭或绕过。对抗性安全见威胁模型。

唯一允许的链

  1. 普通事件（用户、Agent 或工具）到达 observer。
  2. observer 启动一次 Prepare。
  3. Prepare 完成，产生就绪事件。
  4. 这个事件只能决定是否 Notify 一次。不再 Prepare，也不注入。
def allow_action(event, action):
    if event.started_by_framework:
        return action is Notify and chain_within_one_hop
    return True

实现状态

引擎在规则看到之前丢弃所有 origin="proactive" 或 metadata["root_origin"]="proactive" 的事件，所以环无法形成。单跳 Notify 尚未实现，因为 Prepare 还没有执行者。唯一的打扰控制是 cooldown_s，DangerousCommandGuard 为 0。
