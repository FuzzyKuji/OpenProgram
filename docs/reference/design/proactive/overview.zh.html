主动层

概念是什么详情
事件“刚发生了某事”的记录，只追加事件层
规则（Policy）一个 Python 类：盯哪些事件、如何决定。新能力就是新类。规则与运行方式
车道gate 事前拦截，必须快；observer 事后观察，可以慢。时序要求相反，所以分开。规则与运行方式
动作固定几种：拦截、放行或询问；提醒；注入提示；后台准备三条模板规则
状态由事件折叠出的当前状况事件与状态

状态是它不止于钩子的原因。只看眼前一刻的规则什么都不需要。“同一工具连续失败三次”需要记忆，用钩子的话，每条这样的规则都要自己写计数器、重置逻辑和会话隔离。
