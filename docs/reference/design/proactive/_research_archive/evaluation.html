Supporting evaluations

  • L1 and L2 inference separately: 100–200 annotated examples each for path-prefix → touched_modules (error-prone in monorepos), claimed_completion and similar; report accuracy separately.
  • When policy precision is poor, separate state errors from decision errors.
  • Ablations: no breaker; all-synchronous or all-asynchronous; L1 only. Measure precision loss and added latency. Added turn latency from synchronous observers supports the two channels.
  • L2 cost: dollars and latency for at most two inferences per turn, against prompt-only.

Dataset release

Replay and annotations as a dataset: opportunity taxonomy, two annotators, fire and no-fire cases, should-have-fired set. Apply the redaction schema first (threat model §5: events contain secrets and private code). Release augmented-mode L2 caches and model fingerprints to reproduce the annotation set, not the inference.
