Event reference

Source of truth: EVENTS in openprogram/runtime/events/registry.py. Paths are under openprogram/. The label under an event is its origin, after its kind unless it is notify.

Bus calls

CallNote
get_event_bus() → EventBusWorker singleton.
create_event_bus()Independent instance; no disk writes.
make_event(type, origin, payload, metadata) → EventFills id, ts, session and turn.
emit_safe(type, origin, payload=None, metadata=None)Builds and emits; event-layer failures are swallowed.
emit_ws_frame(frame)Sends a ws.frame.
subscribe(handler, *, types=None) → unsubscribetypes=None receives every typed event.
subscribe_gate(type, fn) → unregisterPython gate.
emit_gate(event, timeout_s=None) → GateOutcomeAsks every gate.
subscribe_transform(type, fn) → unregisterRewriter.
emit_transform(event, value)Returns the final value.
register_tool_gate(gate) → unregisterShortcut for tool.before.
Examples 
from openprogram.runtime.events import get_event_bus

def on_file_changed(event):
    print(event.payload["path"], event.metadata.get("session"))
unsubscribe = get_event_bus().subscribe(on_file_changed, types={"file.changed"})

def guard(event):
    if event.payload.get("tool") == "bash":
        return "policy denied this tool call"
    return None
remove = get_event_bus().subscribe_gate("tool.before", guard)

Unregistered types

TypeState
credential.cooldown, credential.rotated, credential.exhaustedTranslated from AuthEvent by bridges.py, payload {provider, profile, credential, detail}. The bus tolerates them and warns once per type.
proactive.inject, proactive.prepare_requestedDerived events of the proactive engine, which is not installed.
question.replied, question.rejected, programs:changedFrame types inside ws.frame, not typed events. Spawns, attach cards, reports, notices, merges and deletions reach an open chat as transcript_update.

Reading the log

tail -f ~/.openprogram/logs/events.jsonl

A top-level turn usually shows user.prompt_submitted, turn.start, model.response_started, tool.before, tool.after, model.response_completed, turn.end. Failure, cancellation, tool calls and stop hooks change the order.
