折叠

state = empty_state()
for event in stream:
    state = update(state, event)

从头折叠是定义。StateStore.apply 增量更新，结果必须相同。

性质规则
事件流有序、只追加，任意时刻都能重新算出。事件定义见事件层。
并发每个 metadata["session"] 一份状态。子 Agent 折叠在一起，会把一个的改动和另一个的情况配对。
origin框架自己引起的事件不折叠，也不交给规则：不变式。
深度只有机械事实（L0）。启发式层和 LLM 层等规则需要时再加。

读取状态

class StuckToolWatcher(Policy):
    on = {"tool.after"}
    def evaluate(self, event, state):
        tool = event.payload["tool"]
        if state.tool_fail_count.get(tool, 0) >= 3:
            return Notify(f"{tool} has failed repeatedly, may be stuck")
