Occupancy and compaction

Ring, panel and compaction report read one view: what the model receives next turn. Compaction does not move HEAD, so an unchanged HEAD does not mean an unchanged graph.

One measurement

rendered_history is the effective summary plus the uncovered tail.

Symptom of a cache keyed on HEAD alone: /compact reports 40.7k while the panel still shows Messages 125k. The summary was stored; the snapshot is old.

Compaction outcomes

  1. Prepare: build the prompt from rendered history, calculate budget_pct.
  2. Compact at 80%: the model writes a summary, a summary node is appended.
  3. Prepare again: the request reads summary and tail.
OutcomeConditionEvent
StartedDecision to call the summary modelcompaction_started
SucceededSummary stored, summarised_count > 0compaction_finished
Nothing to compactFewer than 4 messages, cut at or below the protected head, automatic retry held, or the summary covers nothingcompaction_finished with no_op: true. Known before the model call: no started event, no request
FailedSummary-call or pipeline exception; or history kept with a reason: summary too long, no reduction, cancelled, context changed, invalid range, insert returned nothingcompaction_failed; with a kept history also no_op: true

Triggers: /compact or the panel button; budget at 80% before a request; recovery from 413 or prompt_too_long. A session has at most one active summary. insert_summary_node retains old turns.

System messages

Automatic and manual compaction share one branch in chat-handlers.ts. Messages are bilingual.

EventText
StartedCompacting context…
FinishedContext compacted: covered N older messages. On the transcript's event slot: Context compacted here: covered N messages, estimated X → Y tokens
FailedContext compaction failed[: error]
Finished with no_opContext unchanged; no smaller summary was applied.

Acceptance

  • After success, ring and panel totals drop and match compaction_finished.tokens_after.
  • Re-compacting does not call the summary model and reports nothing to compact, never "covered 0 messages, X → X".
  • No suggestion border at any occupancy.
  • During compaction the ring is busy and the button disabled; completion restores both.
