统计口径

每次响应一份快照

  1. 读取当前分支：压缩后的渲染历史、最新系统提示词、冻结的工具集。
  2. 本地分类：消息结构、工具 schema、Skills、Memory；从父类中减去嵌套项。
  3. 校准：结合同一 HEAD 的最新供应商总量，算出未分类差额。

每次 API 响应只计算一次分类。若在一次响应内重读动态工具注册表，分类与 estimated 可能描述不同时刻。

互斥分类

分类来源边界
Messages渲染历史：可见文本、思考、工具输入与结果、记忆预取未持久化的原始图片计入差额
System prompt最新记录的完整系统提示词先算全量，再减去 Skills、常驻 Memory 和延迟目录
Skills、Memory注入系统提示词的索引和常驻块属于系统提示词的组成部分，不再重复计入总量
System tools、MCP tools本轮冻结工具集的供应商 schema由 _mcp_server 决定归入哪一类
Deferred tools系统提示词中的工具名目录只计实际发送的名称，不计完整描述或 schema
Other context（估算）provider total - classified estimate未持久化图片、供应商包装开销、临时界面提示词。显示出来，不隐藏

计算

classified = system_other + skills + memory + tools + mcp + deferred + messages
other = max(0, provider_total - classified)
displayed_used = provider_total if measured else classified
free = max(0, window - displayed_used)

优先用实测输入 token，没有实测时才用本地估算。本地估算超过实测时，保留供应商总量，显示的分类按比例缩小；响应保留原始估算和校准系数。差额不会为负。

验收

  • estimated 与原始分类总和来自同一次计算。
  • 实测时显示的分类之和等于 total_used，估算时等于 input_used。
  • 切换分支或图变化后，不沿用旧 HEAD 的实测值。
  • 切换模型后立即使用其上下文窗口，并以新估算替换旧实测；下一次请求完成后使用新实测。
  • App 和 Web 读取同一个 /api/sessions/{id}/context，不各自估算。
