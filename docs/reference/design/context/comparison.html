Context design comparison

Design: Composition. Rows are in wire order within a layer: more stable first, because cache-prefix matching makes order matter. Scattered means present but not assigned to a layer.

Hermes layer, by stabilityOpenProgram
stable: identity, tool guidance, skills, model, platform and environment hintsL0
context: caller system_message, context filesL1 project layer
volatile: memory snapshot, USER.md, external memoryL1 project memory, L2

opencode, claude-code, openclaw and pi-mono each carry fewer components than Hermes.
