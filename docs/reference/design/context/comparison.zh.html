上下文设计对比

设计：组成。各行按层内线上顺序排列：越稳定越靠前，因为缓存前缀匹配让顺序有意义。“分散”表示有但没有归入某层。

Hermes 的层，按稳定性OpenProgram
stable：身份、工具指导、skill、模型、平台和环境提示L0
context：调用方 system_message、上下文文件L1 项目层
volatile：记忆快照、USER.md、外部记忆L1 项目记忆、L2

opencode、claude-code、openclaw、pi-mono 的组件都比 Hermes 少。
