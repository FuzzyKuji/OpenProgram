Reading order

  1. Understand the system: framework overview → repository structure.
  2. Trace an execution: call flow → execution control → session storage.
  3. Change a subsystem: pick a topic below, read its design and implementation-status appendix, then verify source ownership and acceptance requirements.

Maintenance rules

  • Every page has one sidebar category. Register pages and reading order in scripts/docs_site/nav.py; unclassified pages stay visible under Uncategorized. Category changes preserve URLs.
  • One current design per topic. Diagrams, comparisons and records state their relation to it without copying its body.
  • English by default, with synchronized Chinese. See documentation conventions.
  • Documentation claims, source presence, passing tests, publication and installed-App acceptance are separate states. Categories do not indicate completeness.
