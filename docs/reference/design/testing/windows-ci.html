Windows CI completion

Native x64 and ARM64 jobs run platform contracts and the complete unit suite with four workers. A blocked diagnostic process and ordinary failed tests must each emit their details and exit unsuccessfully.

Those two legs set PYTHONUTF8=1, the mode the released launchers start Python in. A third x64 leg sets PYTHONUTF8=0 for the processes the product still starts in the system code page.
