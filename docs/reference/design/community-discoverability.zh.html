社区可发现性

入口作用
.github/CONTRIBUTING.md唯一的贡献指南，含安装和验证命令
.github/ISSUE_TEMPLATE/Bug 和功能表单；关闭空白 Issue；提问转到 Discussions
.github/SECURITY.md通过 GitHub Security Advisories 私下报告，不走公开 Issue
Contributor Covenant、支持路由、Pull Request 模板完整的社区档案；每位贡献者收到相同的验证提示
落地页页脚链接到 Discussions 和贡献指南

不建论坛、聊天服务器、表单服务或机器人：GitHub 已经够用，也不必多一个审核渠道。

约定
  • 所有仓库 URL 使用 FuzzyKuji/OpenProgram。
  • Issue 表单 YAML 可解析，含 GitHub 要求的 name 和 description，并把支持和安全报告送到正确入口。
  • 贡献、安全和 Issue 模板链接可访问。
  • 仓库设置中开启私密漏洞报告，这一点无法只从仓库文件看出。
