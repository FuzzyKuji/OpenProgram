CLI 与 TUI

openprogram 运行与桌面应用和 Web UI 相同的 agent。其他能力都有子命令，遵循同一命名规则，能从已知命令猜出新命令。

各只有一份方式
后端一个常驻 Python worker 在一个端口服务所有前端。Ink 终端界面（apps/cli/）由 openprogram/interfaces/cli/ink.py 启动，通过 worker.pid 和 worker.port 找到它并走 WebSocket，所以终端对话就是 Web UI 显示的会话。
设置 schema每个设置只声明一次；openprogram config、TUI 面板和 Web UI 共用。每次写 config.json 都走同一个原子加锁入口。
斜杠命令注册表内置命令、插件命令、MCP prompt 和 skill 合并成一种格式，/ 在 TUI 和 Web 输入框中列出相同内容。

在终端里，工具调用折叠成一行，ctrl+o 打开完整记录，文件编辑显示为 diff，运行时的输入会排队。
