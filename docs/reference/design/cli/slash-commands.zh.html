斜杠命令

所有界面共用一个注册表、一种文件格式、一个菜单。别的项目怎么做：参考实现。

来源层

层，优先级从低到高来源作者重新加载
L0 builtin源码OpenProgram重启
L1 plugin~/.openprogram/plugins/<pkg>/... 下的 entrypoints.commands插件作者插件重载
L2 mcp已连接服务器的 list_prompts()MCP 服务器会话重连、/api/commands?refresh=mcp
L3 skill~/.openprogram/skills/<name>/SKILL.mdskill 作者、用户watcher
L4 user~/.openprogram/commands/**/*.md当前用户watcher
L5 project<cwd>/.openprogram/commands/**/*.md项目维护者watcher
  • 同名时后面的层胜出。被覆盖的命令仍可用 /(plugin)name、/(mcp:linear)name、/(skill)name、/(user)name、/(project)name 调用。
  • 同一来源内，相同 realpath 只加载一次。
  • 菜单里的冲突：主条目标 (+2 more)；⇥ 切换来源。
  • 来源标签始终由 loader 写入；frontmatter 不能自称。

文件格式

---
name: review              # 默认：文件名
aliases: [r, rev]
description: 按团队规范审查当前 diff
when-to-use: |
  用户想对未提交的修改做一轮风格和 bug 审查时使用。
hidden: false
arguments:
  - name: target
    description: 文件路径或目录；默认当前 diff
    required: false
argument-hint: "[target]"
type: prompt
context: inline
agent: general-purpose    # 仅 context: fork 时生效
model: inherit
effort: medium
allowed-tools: [Read, Grep]
paths: ["src/**/*.{ts,tsx}", "**/*.py"]
requires:
  any-bins: [git]
  config: [openai_api_key]
hooks:
  PreToolUse: ...
version: 1.0.0
---
请审查 {{target}} 的代码。

补充上下文：
$ARGUMENTS

最近提交：
!`git log -5 --oneline`

当前 diff：
@`git diff --staged`
字段类型默认含义来自

aliasesstring[][]同样受覆盖规则约束claude-code
descriptionstring""一行，显示在菜单通用
when-to-usestring""详情面板claude-code
hiddenboolfalse不进补全，仍可触发claude-code
argumentslist[]位置参数声明。数字名被拒绝：与 $0 冲突opencode
argument-hintstring自动生成菜单里的灰色提示claude-code
typeenumprompt执行模式claude-code
contextenuminlineinline 或 forkclaude-code
agentstringgeneral-purposefork 时的 subagent_typeclaude-code
modelstringinheritinherit、opus、sonnet、haiku 或完整 idclaude-code
effortenum、intinheritlow、medium、high、max 或数字claude-code
allowed-toolsstring[]inheritfork 模式的工具白名单claude-code
pathsstring[]null按 glob 条件激活claude-code

user-invocablebooltruefalse 时只有模型能调用claude-code
shellenuminheritbash 或 powershell，用于 ! 块claude-code

未声明的字段进入 extras 字典，不报错。

正文模板

语法含义来自
$ARGUMENTS命令后的全部文本claude-code
$0..$9第 N 个位置参数；缺失为空opencode
{{name}}arguments: 声明的命名参数opencode
${OPENPROGRAM_COMMAND_DIR}命令文件所在目录claude-code
${OPENPROGRAM_SESSION_ID}当前会话 idclaude-code
${OPENPROGRAM_CWD}当前工作目录OpenProgram
!`cmd` 或 ```! 代码块在宿主 shell 执行，stdout 拼入；2 秒超时claude-code、hermes
@`path`拼入文件内容OpenProgram
<<command-name>>name<</command-name>>展开另一个命令，最多 3 层OpenProgram

参数按 shell 规则切分，失败时按空白切分。

执行

模式效果
type: prompt（默认）渲染后的模板作为用户消息，走正常 agent 循环
type: local调用宿主的 handler；用于 /compact、/clear、/new、/web、/model 等内建命令
type: local-jsx接口预留给服务端推送的结构化事件
context: inline（默认）渲染结果进入当前会话
context: fork作为一次 agent(prompt=...) 子 agent 运行：agent 决定 subagent_type，allowed-tools 决定工具。最终消息作为命令结果，主上下文保持干净

MCP prompt 是 prompt 和 inline，在其服务器上渲染。

条件和 hook

条件不满足时命令从补全中隐藏。手动输入会再次检查，并给出明确错误。

字段通过条件
paths会话最近接触的文件或用 @file 指明的文件匹配
requires.any-binswhich 至少找到一个；否则提示 “needs git / rg, please install first”
requires.configprofile 配置了该键
requires.platform匹配，如 [darwin, linux]
 
hooks:
  PreToolUse:
    - matcher: Bash
      command: !`echo "blocked by /review" >&2; exit 2`
  PostToolUse:
    - matcher: Edit
      handler: built-in:auto-stage

只在该命令执行期间生效。事件名复用 runtime/events/registry.py。! 块：stdout 进日志，退出码决定放行或拒绝。built-in:<id>：已注册的 handler。schema 先固定，日后启用不算破坏性变更。

安全

输入规则
命令文件realpath 后必须落在所扫描的受信根内（~/.openprogram/、$cwd/.openprogram/）
YAMLyaml.safe_load
Globfnmatch；禁用 .. 和绝对路径
! 块除非 commands.allow_shell: true 否则关闭；MCP 上下文中关闭；2 秒超时；禁 fork 炸弹；stdout 上限 64 KB
@ 引用在受信根内，或 --allow-file <abs>

实现

openprogram/runtime/commands/ 下的文件作用
loader.py扫描用户和项目目录
frontmatter.pyYAML 和字段解析
template.py正文渲染
registry.py合并表、冲突索引、MCP 同步
dispatch.py解析并渲染；纯函数，结果由宿主执行
_plugin_adapter.py、_skill_adapter.py把插件和 skill 投影到注册表
  1. 用户输入/review xxx
  2. dispatch.invoke(text, session_id, cwd)registry.resolve，再渲染模板
  3. 按 kind 返回prompt：宿主发送文本。local：运行 handler。mcp_prompt：从服务器获取。
端点返回
GET /api/commands合并列表；?source=、?include_hidden=
GET /api/commands/{name}单条，含正文
POST /api/commands/invoke请求体 {text, session_id, cwd}：解析并渲染，不发送
POST /api/commands/reload强制重扫
GET /api/commands/conflicts同名多来源
GET /api/plugins/commands旧的仅插件列表
前端读取注册表的方式
Web composer（use-slash-menu.ts）/api/commands，/api/plugins/commands 作回退；渲染文本落入输入框
Rich REPL（repl/handlers.py）_handle_slash 和 dispatch.invoke。register_repl_builtins 用标记字符串注册本地动作，_LOCAL_ACTIONS 映射回去。存在性、别名和 /help 读 list_all()
Ink TUI（apps/cli/src/commands/registry.ts）只硬编码 TUI 本地动作。GET /api/commands 供补全、Ctrl+K 和 /help；POST /api/commands/invoke 展开
有意不做
来源设计原因
openclawi18n（descriptionLocalizations）只有英文和简体中文
openclawprovider 路由（Slack、Mattermost）单宿主
hermesplatforms 过滤由 requires.platform 取代
hermes134 条提示注入检测属于独立扫描器
claude-codelocal-jsx React 组件Web UI 用结构化事件；CLI 没有
pi-mono纯硬编码反例
版本
  • version 和来源仓库的 git hash（如有）一起存入注册表。
  • L0 跟随 OpenProgram 版本。L1 走插件自动更新。L3 走 skill 发现差异。L4、L5 由用户编写，不自动更新。
  • 从参考项目发现的新设计作为字段加到这里。frontmatter 是稳定契约：上游改名时，frontmatter.py 里的别名让新旧写法都能解析。
