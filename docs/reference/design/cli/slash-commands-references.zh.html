各项目

claude-code

公开的 Skills 文档

方面细节
位置企业、个人 ~/.claude/skills/、项目 .claude/skills/、嵌套、--add-dir、插件
重名时企业优先于个人，个人优先于项目；.claude/commands/ 让位于 skill
符号链接、重载多个位置指向同一目标时只加载一次。监听 skill 目录，改动在运行中的会话里生效
正文$ARGUMENTS、$N、$name、${CLAUDE_SKILL_DIR}、${CLAUDE_SESSION_ID}、${CLAUDE_PROJECT_DIR}、${CLAUDE_EFFORT}、!`cmd` 和 ```! 块。命令失败则中止本次调用
参数引号让多词参数保持完整。没有占位符接收的参数以 ARGUMENTS: <value> 追加
模式内联；context: fork 在 subagent 中运行
Frontmattername、description、when_to_use、argument-hint、arguments、disable-model-invocation、user-invocable、allowed-tools、disallowed-tools、model、effort、context、agent、background、hooks、paths、shell
opencode

references/opencode/packages/opencode/src/config/command.ts

方面细节
来源glob {command,commands}/**/*.md，绝对路径。Effect Schema 校验并与内容合并。无去重、watch 或条件激活
frontmattertemplate（必填）、description、agent、model（ConfigModelID）、subtask（boolean）
模板纯文本展开，$ARGUMENTS、$0-9；arguments: 声明列表
特色五个中类型安全最强；subtask: true 是简化的 fork；MCP skill 返回惰性 Promise
openclaw

references/openclaw/src/auto-reply/commands-registry.*

方面细节
来源数据驱动的硬编码注册表，无文件系统扫描，按 provider 映射（Slack、Mattermost）
ChatCommandDefinitionkey、nativeName、nativeAliases?、description、descriptionLocalizations?、scope（text 或 native）、args?、acceptsArgs
特色resolveNativeName 和 pluginProvider hook；i18n；参数选择菜单（CommandArgChoiceContext），类似 Discord 下拉
SkillSKILL.md frontmatter 含 emoji、requires.anyBins、requires.config、install[]
hermes-agent

references/hermes-agent/tools/skills_tool.py、agent/skill_commands.py、agent/skill_preprocessing.py

方面细节
来源单目录 ~/.hermes/skills/：内置、hub 安装和编辑过的条目共存；get_external_skills_dirs() 扩展。trusted_roots 带路径穿越防护
frontmattermetadata.hermes.config（变量）、platforms；metadata.hermes.* 优先于顶层字段
正文_substitute_template_vars、_expand_inline_shell（超时）、注入 [Skill config: ...]
特色平台过滤、134 条提示注入模式、_secret_capture_callback
pi-mono

references/pi-ai/packages/coding-agent/src/core/slash-commands.ts

硬编码内建（settings、model、export、import、fork、clone），不扫描。SlashCommandSource 有 extension、prompt、skill，实际只用 builtin。代表完全没有扩展机制的取舍。
