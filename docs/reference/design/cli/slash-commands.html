Slash commands

Every surface shares one registry, file format and menu. How others do it: reference implementations.

Source layers

Layer, lowest priority firstSourceAuthorReload
L0 builtinSource codeOpenProgramRestart
L1 pluginentrypoints.commands under ~/.openprogram/plugins/<pkg>/...Plugin authorsPlugin reload
L2 mcplist_prompts() of connected serversMCP serversSession reconnect, /api/commands?refresh=mcp
L3 skill~/.openprogram/skills/<name>/SKILL.mdSkill authors, usersWatcher
L4 user~/.openprogram/commands/**/*.mdCurrent userWatcher
L5 project<cwd>/.openprogram/commands/**/*.mdProject maintainersWatcher
  • Same name: the later layer wins. The overridden command stays reachable as /(plugin)name, /(mcp:linear)name, /(skill)name, /(user)name, /(project)name.
  • Within one source, the same realpath loads once.
  • Conflict in the menu: primary entry tagged (+2 more); ⇥ switches source.
  • The source label is always written by the loader; frontmatter cannot claim one.

Execution

ModeEffect
type: prompt (default)Rendered template becomes a user message, normal agent loop
type: localCalls the host's handler; for /compact, /clear, /new, /web, /model and other builtins
type: local-jsxInterface reserved for a server-pushed structured event
context: inline (default)Rendered prompt enters the current session
context: forkRuns as one agent(prompt=...) sub-agent: agent sets subagent_type, allowed-tools the tools. Its final message is the command result; the main context stays clean

MCP prompts are prompt and inline, rendered on their server.

Conditions and hooks

An unmet condition hides the command from completion. Typing it runs the check again and gives a clear error.

FieldPasses when
pathsA file recently touched in the session, or named with @file, matches
requires.any-binswhich finds at least one; else "needs git / rg, please install first"
requires.configThe profile has the key
requires.platformMatches, e.g. [darwin, linux]
 
hooks:
  PreToolUse:
    - matcher: Bash
      command: !`echo "blocked by /review" >&2; exit 2`
  PostToolUse:
    - matcher: Edit
      handler: built-in:auto-stage

Effective only during that command. Event names reuse runtime/events/registry.py. ! block: stdout to the log, exit code allows or denies. built-in:<id>: a registered handler. The schema is fixed ahead of use so enabling it later breaks nothing.

Versioning
  • version is stored in the registry with the source repository's git hash, if any.
  • L0 tracks the OpenProgram version. L1 uses plugin autoupdate. L3 uses skills discovery diff. L4 and L5 are user-written and do not auto-update.
  • New designs from the references become fields here. Frontmatter is a stable contract: if upstream renames a field, an alias in frontmatter.py keeps both spellings parsing.
