REST 端点

POST /api/function/{name}
{"session_id": "...", "project_id": "...", "kwargs": {"task": "..."}}

{"session_id": "...", "msg_id": "..."}
字段规则
session_id可选。省略时服务端创建会话。
project_id已有会话可选；待定的 Project 选择需要在首次调用前绑定时必填。执行使用所选 Project 目录，否则用配置的默认 Project。
扁平参数旧调用方可能把函数参数放在顶层。服务端把它们移入 kwargs，并忽略 session_id、project_id 这类控制键。

没有 /run API

名称状态
输入的 /run ...保持普通用户文本，不会变成 action="run"
/api/run/{name}、WebSocket action="run"不存在
React 函数调用和重试 UI调用 POST /api/function/{name}
遗留措辞

有些注释和类型名还写着 /run 或 runtime block，因为 UI 组件名早于这个端点。它们不定义第二条路径。查找：

rg "/run|api/run|action=run|action=\"run\"" openprogram apps/web
rg "runtime block|RuntimeBlock" apps/web openprogram
