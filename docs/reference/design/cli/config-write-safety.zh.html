配置写入安全

config.json 是一个文件，被多个界面和进程修改。没有覆盖整个读改写的锁，后写入者会丢掉先写入者的改动。

from openprogram.state.config import update_config

def mutate(cfg):
    cfg["ui"]["web_port"] = 8101

result = update_config(mutate)          # returns the resulting config
update_config(mutate, expected_revision=revision)  # with a revision check

openprogram.state.config.update_config 是修改部分配置的唯一正确方式。以 0o600 写回。调用方不会跨锁边界持有配置字典。read_config 和 write_config 保留用于只读和整体替换；两者配对使用会产生竞争。

锁覆盖
_config_write_lock (threading.Lock)worker 线程：TUI 工具开关和网页保存 key
config.json.lock，经 _private_atomic_update其他进程：openprogram config 和 openprogram setup 与 worker 并发

两把锁都不可少。模块私有锁不能替代：storage.py 的 _cache_lock 只保护该模块的缓存。

范围仅限写入原子性。schema 和校验属于 state.settings（redesign），格式仍是 JSON。
