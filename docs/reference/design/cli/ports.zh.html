operations/worker/ports.py 的检查方式
存活：port_in_use(port)裸 TCP 连接
身份：backend_is_ours(port)检查受管 worker 的 PID、端口文件和 profile 下仅属主可读的 web/access.json，向 /api/auth/challenge 发随机 nonce，本地验证 token-HMAC 证明。绝不发送属主 token 或 Bearer 头，外部监听者拿不到凭据。可选的 expected_revision 把证明绑定到升级目标的版本。
归属：describe_port_owner(port)、port_owner_hint(port)lsof 或 netstat + /proc、ps、Windows CIM：PID 和命令行，自己的还是外部的
为什么是 18100
  • 低于 49152，不在系统分配给出站 socket 的临时端口范围。
  • 18xxx 段少有开发工具使用，不像 3000、5173、8000、8080。
  • 固定：地址可收藏，浏览器状态（localStorage、service worker 作用域）跨重启保留。
