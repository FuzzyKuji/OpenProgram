Why 18100
  • Below 49152, so never in the OS ephemeral range handed to outbound sockets.
  • The 18xxx block is rarely used by dev tooling, unlike 3000, 5173, 8000, 8080.
  • Fixed: a bookmarkable URL, and browser state (localStorage, service worker scope) that survives restarts.
