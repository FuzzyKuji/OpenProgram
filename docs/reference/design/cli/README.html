CLI and TUI

openprogram runs the same agent as the desktop app and Web UI. Other capabilities have subcommands named by one rule, so a new command can be guessed from known ones.

One of eachHow
BackendA long-lived Python worker serves every front end on one port. The Ink terminal UI (apps/cli/), launched by openprogram/interfaces/cli/ink.py, finds it through worker.pid and worker.port and talks WebSocket, so a terminal chat is the session the Web UI shows.
Settings schemaEach setting is declared once; openprogram config, the TUI panel and the Web UI use it. Every config.json write goes through one atomic, locked entry point.
Slash-command registryBuilt-ins, plugin commands, MCP prompts and skills merge into one format, so / lists the same in the TUI and Web composer.

In the terminal, tool calls fold into one line, ctrl+o opens the transcript, edits render as diffs, and input during a run is queued.
