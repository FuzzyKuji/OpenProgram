CLI and TUI configuration surface

One schema describes every setting; every surface renders it. A new setting is one SettingSpec and appears everywhere, with no per-surface code. No setting is web-only.

Schema

@dataclass(frozen=True)
class SettingSpec:
    key: str             # stable id, e.g. "ui.web_port"
    path: tuple[str, ...]  # dot-path into config.json
    group: str           # "Ports", "Memory", ...
    label: str
    widget: str          # "number", "toggle", "enum", "text", "json"
    apply: str           # "live" or "next_start"
    default: Any = None
    choices: Callable[[], list[str]] | None = None
    validate: Callable[[Any], str | None] | None = None  # error or None
    help: str = ""
    secret: bool = False
    minimum: int | None = None
PartDesign
SETTINGSThe ordered list; source of truth
get_settings()Reads config.json once, resolves values, computes choices() lazily, masks secrets
set_setting(key, value)Validates, then writes through the key's typed helper when one exists (set_ui_ports for ui.*), else a generic dot-path write. Returns {applied, value} or {error}

Dynamic keystools.disabled.<name> toggles a tool, live. providers.* status rows are read-only
Applylive: re-read per use. next_start: read once at bind time (ui.web_port, memory.backend). The surface says so at the moment of the edit

TUI panel

/config, also from the Ctrl+K palette: a persistent editor over live state, built on Picker with group, field and editor levels. Enum fields reuse Picker; number and text use LineInput.

AreaBehaviour
Schema groupsPorts, Models, Memory, Search, Tools, Execution, Security, Voice and the rest of SETTINGS, in registry order
Action rowsModel, thinking effort, permission mode, theme and Claude accounts launch /model, /effort, /permissions, /theme, /login instead of duplicating them
Portsconfig set adds the holder from with_port_owner_note. The panel reports rather than seizes
ThemePreviews on cursor move, rolls back on ESC; no Apply step
Providers, channelsStatus and an action, never inline secret entry; OAuth is not reimplemented in a text box

Ctrl+K renders the slash-command registry (name and description) through the same Picker, with keybind hints; /config, /model and /theme surface there uniformly. It changes no grammar.
