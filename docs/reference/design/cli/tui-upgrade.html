TUI transcript rendering

Tool calls collapse without losing information, Ctrl+O shows everything, diffs are structural, messages queue while the agent is busy, and keybindings can be found and overridden. Mid-run questions: user input requests.

ElementDesign
Tool shellOne per-tool render hook set (use-line, progress, result, error) in one shell. Dot: dim queued, blinking running, green done, red error. Bold name, parenthesized argument summary, result under a ⎿ gutter. Two glyphs, no boxes
Truncation3 lines, then … +N lines (ctrl+o to expand). One hidden line is shown instead. Huge output is pre-truncated by characters and the rest estimated
SummariesQuantified: Read 52 lines, Added 5 lines, removed 2 lines plus a diff, Found 8 files, Done (12 calls · 48k tokens · 2m 10s)
Ctrl+OA separate Screen: freezes the message list, re-renders expanded, exit hints in the footer. Ctrl+E inside shows everything untruncated. Safe as a global key: flow control uses Ctrl+S and Ctrl+Q
SpinnerOne composite line, progressive width gating
Busy inputTyping queues the message (dim, above the input), ↑ recalls it, the queue flushes between turns
DiffIn-house: line numbers, add and remove colours, three context lines; for edit results and /diff
Markdownmarked-terminal, memoized by streaming state, text and width per text segment; the cell-grid renderer redraws every frame

Density follows Claude Code; interaction below follows opencode. The vendored hermes-ink renderer stays: it has mouse tracking and ScrollBox, so OpenTUI buys nothing.

Commands and interaction

ElementDesign
Command registryEach command declared once (name, title, category, keybind, slash-name, enabled); drives keybindings, Ctrl+K, slash commands and footer hints, so registry and handlers cannot drift
Keybind tableDefaults and descriptions declared once, generate the config schema. User overrides under ~/.openprogram. Unknown keys are errors; "none" disables. ? help comes from the same table
PromptsQuestions and approvals occupy the input slot instead of a modal; the transcript stays scrollable and esc keeps one meaning
DangerDestructive picker actions confirm in the row: press again, the row turns red. No nested confirm layer
PickersMove from the pickerKind enum to the ModalProvider and Form kit, one at a time
