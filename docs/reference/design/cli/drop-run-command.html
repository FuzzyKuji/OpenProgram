FieldRule
session_idOptional. Omitted: the server creates a session.
project_idOptional for an existing session; required when a pending Project selection must be bound before the first call. Execution uses the selected Project directory, else the configured default Project.
Flat parametersOlder callers may post function parameters at the top level. The server moves them into kwargs and ignores control keys such as session_id and project_id.
