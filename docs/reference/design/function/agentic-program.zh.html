Agent 类、Program 与工具

在 OpenProgram 里，一个 agent 就是一个 Python 类。继承 Agent，把模型和指令写成类属性，再写普通方法：self(...) 是一次模型调用，它周围的一切——分支、循环、重试、检查——都是普通 Python。调用方法时，它会被记入会话的执行 DAG，方法里的模型调用自动拿到正确的上下文，不需要装饰器，也不需要手动构造上下文对象。方法只有在显式登记后才成为模型可以调用的工具；由这样的类和函数组成的包就是一个 Program。

from openprogram import Agent

class Researcher(Agent):
    model = "configured-model"
    method_options = {"research": {"tool": True}}   # 把这个方法暴露为工具

    def research(self, question):
        text = self.prepare(question)
        answer = self(text)                          # 一次模型调用
        if "TODO" in answer:                         # 用代码写的检查
            answer = self(f"Finish this answer: {answer}")
        return answer

    def prepare(self, text):                         # 普通的、不记录的帮助函数
        return text.strip()

result = Researcher().research("A topic")

编写与上下文

Agent 子类使用普通方法。框架自动建立调用作用域并派生 Context。模型配置（model、effort、instructions、tools）属于 Agent；父继承、命名内容、求值和历史可见性属于 Context。Agent 实例只持有配置，不拥有对话；历史是否延续由执行作用域决定。

统一 Agent 与 Context 契约定义公共类 API 与执行生命周期。本页只定义 Program 和工具范围，不重复该契约。

工具与入口登记

方法被记录不等于成为工具。类属性 method_options 通过 tool=True 显式登记方法，也可以设置它的公开名称、描述、输入形式和可见性。已登记 Program 源码通过 PROGRAM_ENTRIES 列出公开入口。显式元数据保留公开名称与输入表单。

通过 function() 登记的确定性工具使用同一个 registry。授权与调用记录、历史可见性分别处理。

Skill 与普通代码

Skill 提供指令，不自行创建可执行入口身份。Program 提供源码与已登记调用入口。普通帮助函数保留 Python 行为：签名、返回值、异常和 import 都不变，帮助函数也不往 DAG 里添加节点。

方法行为

method_options 还为需要的方法携带入口元数据、工具登记和显式持久步骤（resumable）。没有选项的方法仍是普通的、会被记录的 Agent 方法。
