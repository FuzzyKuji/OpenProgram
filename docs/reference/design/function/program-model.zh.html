Program 模型

Agent 能用的一切都是 Program。Program 在 PROGRAM_ENTRIES 列出可调用入口（可选 ENTRY_OPTIONS），每个入口成为共享注册表里的一个工具。未列出的普通函数不被记录。

应用包

两种形式之一，或同一目录兼有：

  • Python：__init__.py 带 PROGRAM_ENTRIES、ENTRY_OPTIONS，可选 setup(ctx)。
  • 声明式：application.json、UI（index.html 或 ui/），可选 backend.py，其操作由 manifest 声明。

programs/_host/ui/loader.py 的 mount(ctx, root) 挂载声明式包，内置（manifest id 即目录名）或已安装都一样。它读取 manifest，计算目录摘要，并注册：

  • UI，按该摘要从应用自己的目录提供。
  • 资源 provider application.<id>。
  • 每个标 agent: true 的操作一个入口，名为 <id>__<operation>，[A-Za-z0-9_-] 之外的字符替换为 _。接收 input（项目作用域的应用还有 project_id），经 worker 的应用服务运行，每个操作一个进程并做 manifest 能力检查，返回完成的运行。延迟、需审批、不在 DEFAULT_TOOLS。agent: false 没有入口。

已安装：按源目录记录在 ~/.openprogram/programs/catalog.json，不复制。在 worker 启动时、安装启用禁用后、watcher 发现变化时加载。禁用即 dispose context；源变化时 dispose 后用新摘要重新加载。

内置：一条 builtin-application 行（{"id": "browser", "enabled": false}），由 catalog.builtin_enabled 读取。registry.sync_builtin_application 每次加载时对齐，所以设置在每个进程和重启后都成立；PATCH /api/applications/<id> 实时生效。重新启用的入口仍是同一工具，toolset 和层级不变。

ProgramContext

唯一的注册接口；每个应用包和插件各一个。每次注册都记录撤销操作，ctx.dispose() 从新到旧执行，恢复宿主状态。它写入宿主已有的注册表。

方法注册
ctx.tool(fn)、ctx.tools_from(module)PROGRAM_ENTRIES 作为工具，归 ctx.owner
ctx.on、ctx.gate、ctx.transform事件总线订阅
ctx.context(name, build, ...)上下文段 <owner>:<name>：系统提示（L0、L1）或单次调用提示（L2）
ctx.provide、ctx.service命名服务。核心用 services.lookup(name)，没有时为 None
ctx.resource(provider)resource 工具的 provider；application.<id> 为保留名
ctx.command、ctx.skills、ctx.mcp_server、ctx.provider_root、ctx.api_provider斜杠命令、skill 根目录、MCP server、provider 目录、模型 wire 实现
ctx.effect(dispose)其他任何东西，附带给定的撤销操作
 
def setup(ctx):
    @ctx.tool
    def word_count(text: str) -> int:
        '''Count the words in a text.'''
        return len(text.split())

    ctx.on("tool.after", lambda event: ctx.log.info(event.payload["tool"]))
Owner 与重新加载
Owner（_program_owner）对应
tool:<name>TOOL_PROGRAMS 里的工具包
application:<name>内置应用
包名用户 Program
external:<package>外部 harness
plugin:<name>插件

tool:、plugin: 之外的 owner 都是应用，通过其 context 注册的入口初始为延迟。

注册表保存 owner → context。再次加载复用它，不重复记录。卸载或热重载（programs/_host/watcher.py）调用 dispose_program(owner)，重载用新 context 注册。

插件

只指 Claude Code、Codex、OpenCode 或 Hermes 格式的声明式包：manifest 描述的 skills、斜杠命令、agents、hooks、MCP server 和 provider 目录。plugins/manifest.py 读取，并通过 plugin:<name> 的 context 挂载。Hooks 是经 ctx.gate、ctx.on 订阅的 shell 命令。插件代码不在 worker 里运行。

manifest 指向代码（python、module、setup、main、tools、client、web、sidebar、module:name hook 映射、Hermes __init__.py）时，安装和加载都会拒绝：请用 application.json 打包成应用，并运行 openprogram programs install <dir>。插件运行时

窗口打开期间常驻

信号是会话的应用绑定（programs/_host/ui/bindings.py，表 resource_bindings）。指明会话的 open 绑定一个实例：App 窗口经 POST /api/applications/<id>/open 带 session_id，或 Agent 经 application.<id> 调用。release 或 POST /api/applications/<id>/close 解除。

每轮开始 TurnBindings 读取 open_application_ids(session_id) 并安装（_runtime.install_open_applications）。split_tools_for_dispatch 和 tool_search 读 resident_now：常驻入口、用 tool_search 加载过的延迟入口、owner application:<id> 处于打开状态的延迟入口，都进入 tools 数组。注册层级不变；单次请求的副本是 as_resident。

用户目录

每个 profile 一个，由 openprogram/state/program_directory.py 解析，不导入注册表。命名 profile 用 ~/.openprogram-<profile>/programs/。

~/.openprogram/programs/ 下内容
<name>/Program 源码：Python 包、应用目录或两者兼有。以 . 或 _ 开头的名称、符号链接和普通文件不扫描
catalog.json按源目录记录应用及设置。源在别处的（如 examples/applications/）保留 enabled、hidden、display_title
.runtime/data/、runs/、environments/、staging/、state.sqlite、versions/（只在应用源丢失时读取）
.removed/openprogram programs uninstall 移走的目录

.runtime/、.removed/ 下的文件不是源码：从那里发起的 role 调用没有调用点。

各类如何加载
  • 包：_host/packages.py，以目录名加载（须是不遮蔽其他模块的 Python 标识符）。每个包是自己的 Git 仓库；只加载干净、已提交的 checkout，所以 openprogram programs check 通过后改动才可调用。有未提交改动时继续提供上次加载的版本。
  • 应用：worker 里的 loader.mount。没有目录行的目录在下一次 loader.sync 被记录（catalog.adopt_user_applications），除非需要信任（Python 后端或 files.project.write）：那要等 openprogram programs install <dir> --trust。已卸载的行不会被重新记录。
  • Harness 克隆（带 <package>/agentics/__init__.py 的仓库）从 git 安装：记录在 program-sources.json，owner 为 external:<package>。

一次扫描（program_directory.program_dirs）服务两个加载器。Watcher 对顶层、每个包的文件和 Git 状态、目录及每个已启用应用的源取指纹，变化时重新发现。

list [--json]每个 Program：类型、owner、加载状态、目录、启用状态、入口和层级

改变状态的应用命令走 owner API（/api/applications/*）；list、check 不需要 worker。REPL 的 /programs 列出同样的行。代码：openprogram/interfaces/cli/commands/programs.py。
