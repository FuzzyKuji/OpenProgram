Only composition roots import an interface: openprogram/__main__.py runs the CLI; openprogram/operations/worker/runner.py starts the Server, its runtime and frontend. The core interface import contract scans every module, function-local and string imports included.

Installer, dependencies and the installed App
  • scripts/install-release.sh stays the public installer entry; its implementation is under scripts/release/.
  • The root npm workspace and lock coordinate Web, Desktop and CLI. Do not assume a separate lock or install below an application.
  • A dependency patch keeps the application manifest, root lock and installed version aligned. Integrating duplicate dependency branches keeps both ancestries without duplicating the version change.
  • The lock keeps transitive entries installed consumers need, optional graphs included. A clean installer exit does not prove consumers load, so public consumer import checks accompany cold installation, and the combined source runs the shared verification manifest before publication.
  • The default runtime uses port 18100 and ~/.openprogram. Layout changes preserve packaging and installed imports as well as source-checkout execution.

Verification

uv run --locked --extra dev python -m pytest -q tests/contracts/repository/test_repository_layout.py

The contract checks directory ownership, application locations and compatibility, not runtime behaviour. An implementation change also exercises the affected public CLI or HTTP/WebSocket entry, builds a wheel and checks imports outside the checkout, and verifies affected packaging. Contributor checks and the test-system design select the gates.

Documentation changes rebuild first, because the checker reads docs/_site/:

python -m scripts.docs_site.build
python -m scripts.docs_site.checklinks

Module organization and file-operation safety

Feature modules own their types, state and private helpers. Directory size is a review signal, not a reason for layers. Large files split at independently testable responsibilities; public entries stay stable; no wildcard forwarding, duplicate implementations or dynamic source execution to meet a line count.

File-operation contract

OperationRule
ClipboardEntries identify their source project; cross-project paste is unavailable until an explicit transfer operation exists
MutationActs on the selected entry. Symbolic-link targets are never implicitly renamed or deleted; unsafe paths fail without changing either entry
DeletionRecoverable where supported. Exporting an unsaved draft does not authorize erasing the only confirmed copy; an unconfirmed browser download keeps the local draft
RefreshRepeats the active search with its unchanged query, with request-generation isolation

Public WebSocket regression tests cover symbolic links; mounted Web tests cover clipboard ownership, active-search refresh and draft preservation.
