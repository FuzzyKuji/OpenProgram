  • One schema for Settings, CLI and TUI.
  • Each change posts to POST /api/settings at once; there is no Save button. A rejected write restores the old value and shows an inline error.
  • Enable Memory explains the restart in its description, with no "Next start" badge: the API has no pending-restart state.
  • No external API permission controls.

Agent mode

Agent · On demand runs no automatic BM25, embedding or hybrid query. The Agent reads with memory_get, and memory_search falls back to exact line matching.

Embedding install

  1. POST /api/memory/embedding/install refuses at once on Intel macOS, with a message naming BM25 or a supported platform.
  2. In a worker thread, install sentence-transformers and torch, then download the fixed encoder configuration, tokenizer and safetensors weights.
  3. Verify the packages resolve and every required file exists and is non-empty, without constructing the encoder.

A failure returns 502 with the error and leaves the recall method alone. Semantic and Hybrid stay disabled until packages and snapshot are present; saving either repeats the full availability check. See Recall.

Loading

GET /api/settings?scope=memoryThe memory.* rows. Its failure shows an error and leaves controls disabled.
GET /api/memory/status?settings=trueworkspace_path, embedding_available, embedding_packages. Skips store.ensure() and the workspace inspector; checks files and package specs without importing numerical code or loading weights.
/api/models/enabledWriter choices. Runs in FastAPI's worker thread, off the event loop.

The page appears once, whole, after all three settle. A failed status or model request does not block the settings rows. No agent runtime settings are requested.

Layout and neighbouring pages
  • Lifecycle cards keep their intrinsic height in the scrolling column and never flex-shrink behind overflow: hidden.
  • A long writer-model label shrinks inside the control cluster, not the left title or description.
  • Entering Settings prefetches only Token Usage and System. Providers, Search and Channels request their data when opened.
