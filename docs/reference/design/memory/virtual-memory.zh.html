提炼

触发时机做什么
会话结束空闲 30 分钟以上提炼新轮次
每日03:00批量整理、消歧、矛盾检测、重建 Core.md
压缩前上下文接近上限把关键信息写回实体层
  1. Collect：从会话 git 和项目 git 拉取上次之后的提交；读全部 DAG 节点（user、llm、code，以及 reads 边）。
  2. Extract：模型一遍提取事件、实体和关系，每条带出处。最贵的阶段，可以先用规则版。
  3. Link：与图谱做别名消解（worker、后端、daemon 合成一个节点）。
  4. Reconcile：检测矛盾，标记旧边。
  5. Project：core.md、实体视图、时间轴分片。
