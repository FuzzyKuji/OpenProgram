路由显示
/memory标准 64px 标题栏，带 Memory settings 链接。Topic 树上方是 Topics、Timeline、Recent、Core。还没有 Topic 时显示带设置链接的空状态。
/settings/memory生命周期摘要和下列控件，使用设置页共用的头部、边距、分区和行样式。摘要是唯一专属 Memory 的结构。

生命周期摘要：采集、写入（写入模型）、存储（本地 + Git，或已关闭）、检索（方法；需要的 embedding 缺失时警告）。720px 时分区列表、树和内容纵向堆叠，Memory 导航保留。

Agent 模式

Agent · 按需查看不运行自动的 BM25、embedding 或混合查询。Agent 用 memory_get 读取，memory_search 退回精确行匹配。

Embedding 安装

  1. POST /api/memory/embedding/install 在 Intel macOS 上立即拒绝，提示使用 BM25 或受支持的平台。
  2. 在工作线程中安装 sentence-transformers 和 torch，再下载固定的编码器配置、分词器和 safetensors 权重。
  3. 验证依赖可解析、每个必需文件存在且非空，不构造编码器。

失败返回 502 和错误，不改变检索方法。依赖和快照都就绪前，语义和混合保持禁用；保存这两项时会重新做完整可用性检查。见检索。

加载

进入时的请求约定
GET /api/settings?scope=memorymemory.* 各行。失败时显示错误，控件保持禁用。
GET /api/memory/status?settings=trueworkspace_path、embedding_available、embedding_packages。跳过 store.ensure() 和工作区检查；只查文件和包 spec，不导入数值计算代码，不加载权重。
/api/models/enabled写入模型选项。在 FastAPI 工作线程运行，不占事件循环。

三个请求都结束后页面一次完整出现。状态或模型请求失败不妨碍设置行。不请求 Agent 运行时设置。

布局与相邻页面
  • 生命周期卡片在滚动列中保持固有高度，不会 flex 收缩到 overflow: hidden 之后。
  • 过长的写入模型标签在控件区内收缩，不挤压左侧标题和说明。
  • 进入设置只预取 Token Usage 和 System。Providers、Search、Channels 打开时才请求数据。
