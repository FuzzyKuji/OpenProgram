Virtual memory

A compact index distilled from the concrete layer (session DAG and project git), not a replacement for it. Every memory points back to its source, records event_time and ingestion_time, and is never deleted: a conflict tags the old record superseded_by. Designed, not built; see status.

Session endIdle 30 minutes or moreDistills new turns
Daily03:00Consolidation, disambiguation, contradiction detection, Core.md rebuild
Pre-compressContext near its limitFlushes key information to the concrete layer
  1. Collect: commits since the last pass from session git and project git; every DAG node (user, llm, code, plus reads edges).
  2. Extract: one model pass for events, entities and relations, each with provenance. The costliest stage; a rules-based version can come first.
  3. Link: resolve aliases against the graph (worker, backend, daemon become one node).
  4. Reconcile: detect contradictions, tag old edges.
  5. Project: core.md, entity views, timeline shards.
