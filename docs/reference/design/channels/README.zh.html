渠道

在 Telegram、Discord、Slack 或个人微信上发给机器人的消息会为绑定的 agent 开始一个回合，回复回到同一会话。渠道运行在后台 worker 中。不需要公网 webhook：所有适配器都向外连接（Telegram 长轮询、Discord Gateway、Slack Socket Mode、微信 iLink 长轮询）。

步骤作用
解析openprogram/interfaces/channels/implementations/ 中的适配器把原生事件解析成一个 ChannelMessage：文本、附件元数据、引用文本。
门禁base.Channel.handle_inbound 运行配对门禁（未知发送者获得一小时有效的配对码，只有所有者能从 CLI 或回环 Web UI 批准）、下载附件、加引用块。
分发dispatch_inbound 根据绑定选 agent，计算会话 key，在按会话的锁内运行回合，并广播给 Web UI 和 TUI。
发送一个传输模块负责分块、按平台格式化（Telegram HTML、Slack mrkdwn、微信纯文本）、限流重试和文件上传。平台允许编辑时，进度流入一条占位消息。

脚本、定时任务和 agent 方法无需 worker，可用 outbound.send(...) 一次性发送。账号、配对和路由：openprogram channels setup、accounts、access、bindings。
