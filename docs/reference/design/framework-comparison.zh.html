结论

发现结果
最强会话是图，代码执行记录成节点。
最弱有标准本地入口，没有稳定的远程控制契约。
意外Codex code mode：模型写代码调用工具。
最强：证据
  • 十二家中，没有确认第二家把函数调用树记入对话历史。
  • 模型工具结果，以及持久化成功的 Agent method 调用（会话 DAG 记录开启且 expose 不是 hidden），都是 code 节点。它们和 user、llm 节点共用 caller、predecessor 边，写在该会话的追加日志里。多个 head 指向不同历史分支。
  • OpenClaw Control UI 有 fork、rewind、branch；pi-mono 的 JSONL 带 parentId，/tree 切换分支。OpenProgram 多出的是横跨 user、llm、code 节点的一张 DAG，code 节点同时承载工具结果与嵌套调用。
  • 对话分支与 worktree 相互独立。Agent 分支共用工作目录；只有绑定 worktree_id 的 job 才隔离文件改动。

runtime/context/git/dag.py · state/store/session/session_store/ · runtime/agent/call_state.py

最弱：证据
  • 已有：内置、动态社区与自定义 provider，MCP client，skills，plugins，供外部调用工具的认证 stdio MCP server，驱动会话的 ACP server。
  • 未确认：OpenAI 兼容端点、稳定的版本化远程控制 SDK、完整公开的 headless 事件协议、自维护 IDE 扩展。Owner 认证的 WebSocket 与 Python 库入口属内部或内嵌接口，不承诺外部兼容。
  • OpenProgram 和 OpenClaw 都把 agent 指引放在 agent workspace。OpenClaw 有 migrate-claude、migrate-hermes；Codex 桌面版与 CLI 能导入 Claude Code、Cursor 的配置和近期工作。OpenProgram 没有外部会话、配置或 skills 的导入器。

extensions/mcp/server/server.py · interfaces/acp/server.py · interfaces/cli/commands/mcp.py · runtime/agent_registry/workspace.py

意外：证据
  • 模型写 JavaScript，在当前轮调用工具。CodeModeOnly 下可见工具只有 exec 和 wait。由四个 crate 和一个 V8 运行时实现，功能台账默认关闭，只看默认行为会漏掉。
  • OpenProgram 让模型生成工作流包，经静态校验和原子发布后运行版本化 Python 工作流。它没有逐轮 code mode，也没有收缩成 exec、wait 的工具面。

codex-rs/features/src/lib.rs · code-mode、code-mode-host、code-mode-protocol、code-mode-runtime、v8-poc

按场景分。编程：三个 core Python、TypeScript LSP 工具（diagnostics、references、definition）；没有自维护 IDE 扩展、格式化器集合、tree-sitter 索引或 GitHub Action。通用 harness：OpenClaw、Hermes 的接入远多于 OpenProgram 的四个渠道。

OpenProgram

面向单个本地用户的通用 Python agent harness：openprogram 命令加端口 18100 上的常驻 worker。

入口
TUI（Ink、React）、Web（Next.js）、Electron 桌面、四个渠道：Telegram、Discord、Slack、微信
轮次处理
各入口共用 ChatAgent().run_turn；Python 库经 Agent 或 Runtime 直接进 agent_loop。上下文组装 L0、L1、L2；超预算先压缩；tool.before gate 可拒绝；finalize 回填 ContextCommit 并做 Git 提交
线程
Web、TUI：每轮一个 daemon 线程。JobRunner：有界线程池。Dispatcher：每轮一个 asyncio loop。Scheduler：线程与进程
会话存储
每会话一份追加日志为事实来源，三种角色（user、llm、code），caller、predecessor 边，分支 head。context/commits/ 存每轮上下文记录
其他存储
usage.db：SQLite 用量账本。记忆：Markdown 加可重建的内存 BM25、embedding 索引，后台写入，三个 memory_* 工具
工具
四个域的动态注册表（todo、task、agent、message）；延迟目录加 tool_search
扩展
MCP client 与 server、ACP、skills、plugins、34 个事件、agent.json；内置、动态与自定义 provider
认证
Web、WebSocket：owner_auth，每次启动一个 token，按 profile 区分 cookie。渠道：配对与 allowlist（interfaces/channels/_access.py），是独立的来源身份边界。不是多租户服务
