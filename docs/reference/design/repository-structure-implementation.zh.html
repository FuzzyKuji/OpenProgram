核心到接口层的端口

核心绝不导入接口层，只调用接口层加载时注册的端口。

端口承载由谁注册；未注册时
openprogram/host/resources/desktop_link.py桌面窗口和 Page：绑定、解析、捕获、关闭，向一个确切连接发送命令ws_actions/webtab.py。agentic 子进程在同一端口安装父进程桥，不加载 Server 就能转发 Page 请求。未注册：视同没有客户端连接。
openprogram/runtime/interface_link.py客户端通知（目标、待办、未完工作、标题、分支列表、原生窗口和执行流帧、上下文环）、Server 的内存会话、需要更新它的 HEAD 移动、会话迁移的忙碌检查、随附的文档页server_runtime/interface_link.py，由 server.py 注册。未注册：视同没有客户端连接。
openprogram/runtime/channel_link.py向频道会话发送（提醒、常驻报告）、常驻投递读取的账号和对端绑定、chat_send 投入的运行中频道轮次interfaces/channels/link_registration.py，导入 openprogram.interfaces.channels 时注册。未注册：抛出 ChannelsUnavailable，记录为发送失败。
openprogram/runtime/speech_link.pycomputer-use 录音的语音转文字interfaces/speech/link_registration.py，导入 openprogram.interfaces.speech 时注册。未注册：抛出 SpeechUnavailable（一种 TranscriptionError），工具报告为未转写。

Worker runner 在作业调度器启动前导入频道和语音包，Server 在加载时导入，CLI 轮次在进程内运行工具前导入。

只有组合根导入接口层：openprogram/__main__.py 运行 CLI；openprogram/operations/worker/runner.py 启动 Server、其运行时和前端。核心接口导入契约扫描每个模块，包括函数内导入和字符串导入。

安装器、依赖与已安装 App
  • scripts/install-release.sh 仍是公开安装入口，实现在 scripts/release/。
  • 根 npm 工作区和 lock 协调 Web、Desktop 和 CLI。不要假设某个应用下有单独的 lock 或安装。
  • 依赖补丁让应用清单、根 lock 和已安装版本保持一致。集成重复依赖分支时保留两边祖先，不重复版本改动。
  • lock 保留已安装使用方需要的传递条目（含可选依赖图）。安装器成功退出不代表使用方能加载，所以冷安装要配公开使用方导入检查，合并后的源码在发布前运行共享验证清单。
  • 默认运行时使用端口 18100 和 ~/.openprogram。布局改动要同时保持打包、已安装导入和源码检出执行。

验证

uv run --locked --extra dev python -m pytest -q tests/contracts/repository/test_repository_layout.py

该契约检查目录归属、应用位置和兼容，不检查运行时行为。实现改动还要运行受影响的公开 CLI 或 HTTP/WebSocket 入口，构建 wheel 并在检出外检查导入，验证受影响的打包。贡献者检查和测试体系设计决定要跑哪些门禁。

文档改动要先构建，因为检查器读 docs/_site/：

python -m scripts.docs_site.build
python -m scripts.docs_site.checklinks

模块组织与文件操作安全

功能模块自带类型、状态和私有工具。目录大小是评审信号，不是分层的理由。大文件在可独立测试的职责处拆分；公开入口不变；不为行数引入通配转发、重复实现或动态执行源码。

文件操作契约

操作规则
剪贴板条目标明来源项目；在有显式传输操作前不能跨项目粘贴
变更作用于选中的条目。绝不隐式重命名或删除符号链接目标；不安全路径直接失败，两个条目都不变
删除在支持处可恢复。导出未保存草稿不等于授权删除唯一确认的副本；浏览器下载未确认时保留本地草稿
刷新用不变的查询重复当前搜索，保持请求代隔离

公开 WebSocket 回归测试覆盖符号链接；挂载的 Web 测试覆盖剪贴板归属、活动搜索刷新和草稿保留。
