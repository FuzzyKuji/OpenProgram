包装工具

MCP tools/list 返回这些包装工具。名为 tools_list 的包装工具返回过滤后的 Runtime 工具。两份契约，分开断言。

工具输入成功载荷
sessions_list无最多 100 条最近的 {id,title,updated_at}，按会话存储顺序
session_getsession_id活动分支的 {id,role,content,timestamp}
prompt_sendprompt，可选 session_id{session_id,text,assistant_msg_id,failed}。无 id 时用 agent main 新建 mcp_<uuid>；未知 id 无效
prompt_cancelsession_id{session_id,cancelled}；只有同连接的活动 MCP 轮次为 true
tools_list无{name,description,inputSchema}，按配置顺序去重
tool_callname，可选对象 arguments（默认 {}）转换后的 AgentToolResult 内容和错误状态
web_use浏览器服务的 schema只在浏览器应用提供服务时列出

字符串不能为空白。schema 设 additionalProperties: false，用 Draft202012Validator 校验；输入被复制，不被修改。结构化载荷是一个 UTF-8 JSON TextContent。文本、图片映射为 MCP 文本、图片；其他内容按执行错误失败关闭。

错误

情形结果
包装工具名不在列表内McpError METHOD_NOT_FOUND
schema 失败、底层参数无效、传入未知 session_idMcpError INVALID_PARAMS
底层工具未知或未暴露相同的方法级错误，不泄露是否注册
已配置但缺 paired 权限；硬约束或审批拒绝；工具执行失败CallToolResult(isError=True)
prompt_send 被取消SDK 标准的 JSON-RPC 取消错误，绝不是工具结果

失败来自 AgentToolResult.is_error，由规范化、MCP 客户端适配、审批 _denied、超时和异常设置，绝不从文本推断。details 保留 denied、timeout、reason_code 等诊断。

令牌

  • 文件 <state>/mcp_server_token，POSIX 0600；serve 从不生成。启动 stdio 上下文前用 hmac.compare_digest 比较 OPENPROGRAM_MCP_TOKEN。
  • client id：sha256(stored_token) 前 16 个十六进制字符，绝不含令牌文本。
  • create_token：secrets.token_urlsafe(32)，目标已存在则拒绝，独占 0600 临时文件，fsync，再不覆盖地安装（POSIX 用 os.link，绝不覆盖并发写入者）。
  • 认证失败：非零退出，stdout 为空，stderr 已清洗，不读 stdin。

提示生命周期

运行
同步轮次放到工作线程，abandon_on_cancel；finally 里注销该取消事件。被放弃的工作线程不能发布迟到结果。
prompt_cancel
普通工具：只限同客户端、同连接的活动轮次；别人的或已结束的轮次失败关闭。
取消
设置线程和工具取消事件，标记会话已取消，杀掉子进程和运行时，取消会话提问，注销事件，移除活动记录，审计 mcp.request.cancelled（含请求、会话、客户端指纹，无提示和令牌）。幂等。重新抛出，由 SDK 产生错误。
进度
服务层上报有序消息；请求带 progressToken 时，线路层才转成单调 MCP 进度。
线路
显式 CallToolRequest 处理器让包装名和参数错误保持为 MCP 错误。stdout 只有 JSON-RPC。

端到端验收（用 SDK 客户端）
  1. 令牌文件缺失、权限错误、环境变量缺失或不匹配，都在 initialize 前退出。
  2. 有效令牌在 2025-11-25 完成初始化；改 clientInfo 不改变身份、列表或结果。
  3. tools/list 按序返回包装工具；tools_list 只返回交集。
  4. 每个包装工具返回固定形状；未知包装工具和无效参数是 MCP 错误。
  5. 未知与未暴露的底层名不可区分；权限、硬约束、审批失败是 isError；被拒工具不执行。
  6. 审批或提问都不阻塞 MCP 调用。
  7. 当且仅当请求带 progressToken，进度单调到达。
  8. 取消 prompt_send 得到 SDK 错误；后续副作用停止，状态清空，审计存在。
  9. prompt_cancel 取消不了别人的或已结束的轮次。
  10. stdout 只有 JSON-RPC。

一起审查：先看 schema；身份与令牌看是否复用 owner 凭据、空列表是否回退；拒绝与取消看失败关闭的顺序。用 SDK 客户端，不用手写帧。Runtime 共享类型变化时回归：权限身份、权限规则、派生硬约束、提问、ACP 服务端、工具运行时。
