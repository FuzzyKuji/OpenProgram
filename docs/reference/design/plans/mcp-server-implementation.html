Wrapper tools

MCP tools/list returns these wrappers. The wrapper named tools_list returns the filtered Runtime tools. Separate contracts, separate assertions.

ToolInputSuccess payload
sessions_listnoneUp to 100 recent {id,title,updated_at}, in session-store order
session_getsession_idActive-branch {id,role,content,timestamp}
prompt_sendprompt, optional session_id{session_id,text,assistant_msg_id,failed}. No id creates mcp_<uuid> with agent main; an unknown id is invalid
prompt_cancelsession_id{session_id,cancelled}; true only for a same-connection active MCP turn
tools_listnone{name,description,inputSchema}, configured order, de-duplicated
tool_callname, optional object arguments (default {})Converted AgentToolResult content and error state
web_usebrowser service's schemaListed only while the browser application provides the service

Strings are non-blank. Schemas set additionalProperties: false and validate with Draft202012Validator; input is copied, never mutated. Structured payloads are one UTF-8 JSON TextContent. Text and image map to MCP text and image; other content fails closed as an execution error.

Errors

CaseResult
Wrapper name outside the listMcpError METHOD_NOT_FOUND
Schema failure, invalid underlying arguments, unknown supplied session_idMcpError INVALID_PARAMS
Unknown or unexposed underlying toolIdentical method-level error, so membership does not leak
Configured tool lacking paired scope; hard-constraint or approval refusal; executed tool failureCallToolResult(isError=True)
Cancelled prompt_sendThe SDK's standard JSON-RPC cancellation error, never a tool result

Failure comes from AgentToolResult.is_error, set by normalization, the MCP client adapter, approval _denied, timeouts and exceptions, never inferred from text. details keeps diagnostics such as denied, timeout, reason_code.

Token

  • File <state>/mcp_server_token, POSIX 0600; serve never generates one. OPENPROGRAM_MCP_TOKEN is compared with hmac.compare_digest before the stdio context opens.
  • Client id: sha256(stored_token), first 16 hex characters. It never contains token text.
  • create_token: secrets.token_urlsafe(32), refuses an existing target, exclusive 0600 temporary file, fsync, then a no-clobber install (os.link on POSIX, so a concurrent writer is never overwritten).
  • Authentication failure: nonzero exit, empty stdout, sanitized stderr, stdin unread.

Prompt lifecycle

Runs
Synchronous turn on a worker thread with abandon_on_cancel; the exact cancel event is unregistered in finally. An abandoned worker cannot publish a later result.
prompt_cancel
An ordinary tool: only a same-client, same-connection active turn; foreign or finished turns fail closed.
Cancellation
Sets the thread and tool cancel events, marks the session cancelled, kills its subprocess and runtime, cancels session questions, unregisters the event, removes the active record, audits mcp.request.cancelled with request, session and client fingerprint but no prompt or token. Idempotent. Re-raised so the SDK produces the error.
Progress
The service reports ordered messages; the wire layer turns them into monotonic MCP progress only when progressToken is present.
Wire
An explicit CallToolRequest handler keeps wrapper and parameter faults as MCP errors. Stdout carries JSON-RPC only.

End-to-end acceptance, with the SDK client
  1. Missing token file, wrong mode, missing or mismatched environment exit before initialize.
  2. A valid token initializes at 2025-11-25; changing clientInfo changes no identity, list or result.
  3. tools/list returns the wrappers in order; tools_list returns only the intersection.
  4. Every wrapper returns its fixed shape; unknown wrappers and invalid parameters are MCP errors.
  5. Unknown and unexposed underlying names are indistinguishable; scope, hard-constraint and approval failures are isError; no denied tool executes.
  6. No approval or question blocks an MCP call.
  7. Progress arrives in monotonic order if and only if the request supplies progressToken.
  8. Cancelling prompt_send yields the SDK's error; later side effects stop, state clears, the audit exists.
  9. prompt_cancel cannot cancel a foreign or finished turn.
  10. Stdout holds JSON-RPC only.

Review together: schemas first; identity and token for owner-credential reuse and empty-list fallback; denial and cancellation for fail-closed order. Run the SDK client, not hand-written frames. Shared regressions when Runtime types change: authority, permission rules, spawn hard constraints, questions, ACP server, tools runtime.
