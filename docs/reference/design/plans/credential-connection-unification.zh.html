凭据连接统一

一个 CredentialData 取代六个 payload 类。一个 resolve_connection() 把请求所需的一切交给请求层，因此一把 key 可以带自己的 base URL。设计来源：凭据连接统一。

@dataclass
class CredentialData:
    kind: str
    auth_value: str = ""            # 发送什么
    base_url: str = ""
    headers: dict = field(default_factory=dict)
    data: dict = field(default_factory=dict)   # refresh token、文件路径、流程 id

@dataclass
class ResolvedConnection:
    kind: str
    auth_value: str
    base_url: str | None
    headers: dict

扁平存储为 {kind, auth_value, base_url, headers, data}，没有 __type__。_payload_from_dict 只接受这种结构。Credential.metadata 和展示信息留在 Credential 上。

解析

凭据resolve_connection 的结果
cli_delegated此时读外部文件，拿磁盘上最新的 token
credential_process运行辅助程序，缓存 cache_seconds；失败抛 AuthCredentialProcessError，不让别的凭据顶替
sso抛 AuthConfigError：没有登录流程实现它
没有认证值None，调用方回退
不支持的 provider；Anthropic 的 oauth、device_code、cli_delegated；任何 sk-ant-oat 值None。Anthropic 需要 API key

空 base_url 变为 None，区分“未指定端点”和“指定了端点”。acquire_pooled(provider_id, account_id=None) 返回 (ResolvedConnection, str, str) | None。_extract_token 保留为它之上的薄读取。

请求层以凭据为先，目录补缺：

base_url = (conn.base_url if conn and conn.base_url else None) or model.base_url
headers  = {**(opts.headers or {}), **(conn.headers if conn else {})}

OAuth 判断读 conn.kind，不嗅探 token 字符串。

部分规则
