把主动层接入代码

设计在 主动层，冲突时以设计为准。openprogram/runtime/events/bus.py 是事件层；埋点放在本来就知道事情发生的源文件里。Event 有三个核心字段加开放的 metadata，turn、session 放在里面，没有轮次概念的来源无需编造。

Prepare

设计上用 JobRunner.spawn_job，白名单排除 bash、写入和网络工具，单独的 1–2 并发池，可被用户任务抢占，遇 429 让路。目前引擎只发出 proactive.prepare_requested 和 proactive.inject 事件，还没有真正启动任务或落地 steering 消息。

已知缺口

@function 工具执行不写 DAG 节点，只有 Agent 方法写。DAG 作为因果记录不完整，审计依靠 events.jsonl 里的完整事件集。
