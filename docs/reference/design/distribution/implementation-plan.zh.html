谁得到绝不

开发者完整产品，加上可编辑源码、测试、诊断、本地前端构建，以及显式配置的感知、OCR 或浏览器叠加层（模型资源由叠加层负责）隐式安装被排除的依赖
发布组装、源码 checkout、第三方扩展环境可以构建或安装 wheel作为用户路径展示

运行时内容

项目约定
能力web、providers、mcp、memory、channels、search、tui.ink、browser.playwright
锁定版本scripts/release/product-runtime.json 中的 CPython 3.12.10 和 uv 0.11.16
Program不捆绑。电脑操作是内置工具，无需捆绑模型。
拒绝的发行包PyTorch、torchvision、OpenCV、EasyOCR、sentence-transformers、triton、nvidia-*、cuda-*
宿主要求Session 和 Memory 历史需要系统 Git；启动器都不捆绑 Git
排除操作系统凭据库集成；Chrome 或 Edge 扩展安装；发行版原生 deb 或 rpm 包
verify-product-runtime.py 检查什么
  • 启动无头 Chromium 页面；产物只有在 --allow-deferred-browser 下才能把 browser_probe 记为 deferred。
  • 导入 channel 和 search 依赖，检查 Web 资源。
  • 对生成的 PDF 运行两条内置提取路径，探测 Rich 渲染。
  • 要求已安装的 OpenProgram 元数据版本等于运行时 manifest 版本。
  • Manifest schema 2 记录每项能力的 present 和 verified、产品 manifest 和锁文件哈希、确切的发行包、平台和架构。

发布验收

每个目标在原生 runner 上构建，由推送 v* 标签或对现有标签手动触发。

  1. 源码、锁文件、桌面和安装器版本一致。
  2. 按平台和架构组装、归档并校验运行时。
  3. 桌面任务嵌入同一运行时、签名，并在上传前校验。
  4. CLI 安装器任务校验校验和、解压、能力、worker 冷启动、原子切换 current 和启动器版本。
  5. 发布任务写入发布 manifest，要求 .github/release-notes/<tag>.md 为英文且标题正确，绝不覆盖已公开的发布。
流水线依赖的打包事实
事实处理
semble>=0.5.3，其 semble-grammars 为每个目标发布所需的原生 wheel
Intel macOS 与 torch没有打过补丁的 torch wheel，所以 embedding extra 排除该平台
架构命名运行时归档用 x86_64，electron-builder 用 x64（release-matrix.py）
运行时 manifest格式化 JSON，shell 解析容忍空白
pypdf、rich锁定的基础依赖；Ink 启动失败时进入捆绑的 Rich REPL
打包版 Electron只从 process.resourcesPath 解析 Python，运行 -I -B -m openprogram worker start；不回退到 PATH，不往已签名的 App 写字节码
Wheel资源暂存后构建，含 openprogram/interfaces/server/_frontend，无需 Node.js 即可提供 /chat
Linux 冒烟linux-release-smoke.yml 只能手动运行，不需要签名或 PyPI 凭据，产物留在 CI

公开安装器

curl -fsSL https://openprogram.io/install | sh
部分约定
根脚本解析最新稳定发布，校验三段数字版本，下载不可变的带标签安装器并转发版本。没有第二个安装器；校验和、能力和冷启动检查不变。
指定版本在 sh 进程上设 OPENPROGRAM_VERSION=X.Y.Z
脚本scripts/install-release.sh 是已发布的兼容 URL，从同一标签下载 scripts/release/install-release.sh
发布docs/_static_root/install.sh 重命名到站点根的 /install；/docs/install/ 仍是文档目录

本地 App

部分约定
入口npm --prefix apps/desktop run dist 构建一个完整的临时 App，用打包运行时冒烟验证，只替换 /Applications/OpenProgram.app
刷新版本scripts/refresh-local-app.sh 要求 bundle、运行时 manifest、Python 元数据、Python 源码和桌面源码版本一致，升级到更新的源码除外
降级install-app.sh 在加锁前和对暂存副本各拒绝一次更旧的候选，都在停 worker 和改文件之前。数字段按任意精度十进制比较；没有覆盖开关，没有预发布排序。
路径上是无效 App保留并拒绝，绝不当作不存在
激活失败保留旧 App 的唯一副本；Launch Services 注册后失败时恢复并重新注册，保留原始错误
launchd真正的 unload 失败在改 App 前停止；过期的 plist 可以替换
并发跨 worktree 的每用户打包锁（~/Library/Caches/OpenProgram/app-package.lock）；目标 Applications 目录里的原子安装锁。竞争者在任何改动前失败。
清理移除随机 App 目录、暂存运行时、wheel 构建、Web 输出、复制的前端和锁；保留 App 数据、源码、依赖和用户状态
图标apps/desktop/build/AppIcon.icon 是分层源：四个 1024 x 1024 透明画布矢量 SVG，一个 cell 和三个扁平圆，不画外轮廓。icon.icns 入库作为 Electron 输入。两者由 check-icon.sh 强制。
