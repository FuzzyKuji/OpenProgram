Community discoverability

SurfaceRole
.github/CONTRIBUTING.mdOne canonical guide with setup and validation commands
.github/ISSUE_TEMPLATE/Bug and feature forms; blank public issues off; questions go to Discussions
.github/SECURITY.mdPrivate reports through GitHub Security Advisories, never public Issues
Contributor Covenant, support routing, pull-request templateComplete community profile; same verification prompts for every contributor
Landing page footerLinks to Discussions and the contribution guide

No forum, chat server, form service or bot: GitHub already covers this, without another moderation channel.

Contract
  • Every repository URL uses FuzzyKuji/OpenProgram.
  • Issue form YAML parses, has the name and description GitHub requires, and routes support and security reports to the right surface.
  • Contribution, security and issue-template links resolve.
  • Private vulnerability reporting is on in repository settings, which repository files alone cannot show.
