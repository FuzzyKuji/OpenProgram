独特机制

两个带来额外能力。四域工具的差别主要在命名。

机制定义最接近的对应物结果
会话 DAG：分支是 head 指针创建节点、补写 output 或 metadata、删除节点，以及 head、分支、标题和归档，各是日志里的一行。每份日志一个写入者，状态在内存里折叠得到OpenClaw：Control UI 的 transcript fork、rewind、branch。pi-mono：parentId；/tree 还能摘要废弃分支。opencode：fork 建新会话。codex：agent graph 记录 agent 关系已确认的差异：transcript 分支、统一 DAG、每会话日志三者合一。单有 transcript 分支并不独特
Agent method：流程写成代码调用按结论里的条件成为 code 节点没有直接对应。pi-mono 扩展、opencode tool/*.ts、hermes skills 能注册工具，但历史里只有入参和返回值。互补方向：Codex code mode持久化的内部步骤可随对话回看。顶层手动函数可经 Retry/Edit 分支。恢复或重放嵌套步骤未实现
四域工具：todo、task、agent、messagetodo 管计划，task 管运行中的工作，agent 管执行者，message 管通讯；每个工具只操作自己的名词opencode：task、todowrite。hermes：delegate、看板。claude-code：Agent、TaskCreate、TaskStop、SendMessage。codebuddy：TaskCreate/Get/Update/List/Stop/Output，不分域差别在命名。实质差异见 Agent 协作：八家里只有 OpenProgram 按剩余消息预算限制子 agent 工具；防环机制与 OpenClaw 相当
