Anthropic API authentication

The official Anthropic Messages API, with API keys and API-account billing. All use complies with applicable service terms and usage policies.

PartBehaviour
LoginStores the API key in the credential store
RequestsThe resolver supplies the key to the Anthropic SDK; API-key authentication
Discovery, validationSame credential requirements as inference
Compatible third-party APIsKeep their own endpoints and credentials
Unsupported credential types and providersRejected before network access
UICredentials stay masked
Entry pointsProvider, account, login and model list all enforce API-key authentication and agree on what is supported
TestsSynthetic credentials, no real provider requests

Anthropic authentication and credential requirements. External CLI account management is outside this integration.
