Capability

providers/settings/fast.py fast_capability, shared by the agent-settings projection and dispatch; supports_fast is its boolean form.

  1. Row fast: false: unsupported
  2. openai-codex: Model.fast from the account catalogue
  3. Row fast: true: supported
  4. xAI declarations above
  5. models.dev speed_modes with priority or fast: supported
  6. Otherwise unknown

Model.fast: a row's fast wins; enabled_models.default_fast fills rows with none.
