Anthropic 的 429 "Usage credits are required for fast mode" 是账号问题，原样显示。没列出不代表供应商没有快速档。界面约定：输入框速度控制。

能力判断

providers/settings/fast.py fast_capability，代理设置投影和派发共用；supports_fast 是它的布尔形式。

  1. 配置行 fast: false：不支持
  2. openai-codex：账号目录的 Model.fast
  3. 配置行 fast: true：支持
  4. 上面的 xAI 声明
  5. models.dev speed_modes 有 priority 或 fast：支持
  6. 否则 unknown

Model.fast：配置行的 fast 优先；没有时由 enabled_models.default_fast 回填。

Codex 来源

GET https://chatgpt.com/backend-api/codex/models?client_version=<ver>，带订阅 bearer 和 chatgpt-account-id。

字段提供
service_tiers 含 id:"priority"快速档
supported_reasoning_levels思考档位选择
context_window真实的订阅值

请求和派发都用 originator: codex_cli_rs 和 version：后端按客户端灰度 gpt-5.6-luna 这样的 id，换 originator 能看到模型，派发却 404。models.dev 跟踪的是 API 平台，不是这个入口。
