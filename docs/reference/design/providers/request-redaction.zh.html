恢复

每个事件都复制并换回真实值：partial、text_end 和 thinking_end 内容、toolcall_end.tool_call、done 或 error 消息。工具用真实值运行，对话记录也存真实值。

占位符可能被拆到多个 delta（"[["、"SECRET_"、"1]]"）。_DeltaRestorer 按内容块保留可能是占位符开头的尾巴（距末尾 len("[[SECRET_99999]]") 内有 [，且没有 ]]），拼到下一个 delta 前。*_end 事件把它作为最后一个 delta 冲出。delta 的 partial 也在这样的尾巴前截断。

生命周期

每次提供商调用一个 vault，只在内存里。下一次调用从真实值的历史重新构建。

限制

  • 没有可识别形态或键名的自由文本密钥会原样发送。
  • 模型改写占位符（例如 [[SECRET 1]]）时，该文本原样返回。
  • 只有提供商侧工具才见到的值（例如托管网页搜索）不经过 Context。
