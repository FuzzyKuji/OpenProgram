Request authentication

Without a key: an explicit SDK placeholder prevents environment fallback, and each Chat Completions request omits the Authorization header. The omission must be per request, because the SDK authentication validator ignores removal of a default header alone. With a key: the configured server key. Cloud requests still need their own credential.
