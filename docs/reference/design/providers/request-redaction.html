Restoring

Each event is copied with real values: partial, text_end and thinking_end content, toolcall_end.tool_call, the done or error message. Tools run with real values and the transcript stores them.

A placeholder can split across deltas ("[[", "SECRET_", "1]]"). _DeltaRestorer keeps, per block, a tail that may be the start of one ([ within len("[[SECRET_99999]]") of the end, no closing ]]) and prepends it to the next delta. The *_end event flushes it as one last delta. A delta's partial is cut before such a tail too.

Lifetime

One vault per provider call, in memory only. The next call builds a new one from the real-valued history.

Limits

  • A secret in free text with no recognisable shape or key name is sent as is.
  • A model that rewrites a placeholder, such as [[SECRET 1]], gets that text back unchanged.
  • Values only a provider-side tool sees, such as hosted web search, never pass through the Context.
