Outbound network proxy

A direct, peer-pinned connection cannot reach services available only through the user's proxy. Fake-IP proxies such as Clash also answer local DNS from 198.18.0.0/15, which a local-resolver policy refuses as NON_GLOBAL_ADDRESS though the real resolution happens in the proxy.

The route is chosen before the target policy, for every request and redirect hop. A NO_PROXY match, or no route, connects directly with the full local address check.

The decision carries requires_proxy; building a direct pool or socket for it raises PROXY_ROUTE_REQUIRED. Fixed audited services also accept fake-IP on direct connections, since TLS verifies a hostname the caller cannot choose. Untrusted public URLs never do.

Which proxy

  1. Explicit security.outbound_url.policy_proxy, with its enforcement requirement; ordinary routing is then unused.
  2. OPENPROGRAM_PROXY_URL, keeping NO_PROXY.
  3. Standard variables through HTTPX, with Python's macOS and Windows system settings as fallback. Loopback is always bypassed.

Acceptance
  • Sync and async public entries use HTTP, HTTPS and SOCKS5 routes.
  • web_fetch behind a fake-IP resolver reaches the target by hostname.
  • IP literals, local names and real private answers stay refused when proxied; NO_PROXY hosts keep the direct check.
  • A proxy-resolved decision never opens a direct socket.
  • NO_PROXY and override precedence hold; shared clients are replaced when routes change.
  • Unauthorized target and proxy addresses are rejected before network activity; service and proxy credentials stay apart; policy-proxy behaviour and cleanup are retained.
How OpenClaw does it

Sources: references/openclaw/src/infra/net/proxy-env.ts, proxy-fetch.ts, src/infra/net/proxy/, its proxy docs.

  • One environment resolver mirroring undici's EnvHttpProxyAgent: lowercase first; HTTPS prefers https_proxy, then http_proxy; ALL_PROXY as fallback. A full reimplemented NO_PROXY matcher with IPv4 CIDR gates every decision.
  • One override: --proxy-url, proxy.proxyUrl, OPENCLAW_PROXY_URL, optional --proxy-ca-file, over undici ProxyAgent, with a managed proxy lifecycle.
  • Provider helpers route through these; the SSRF guard uses the same matchesNoProxy.

OpenProgram borrows one documented reading of the standard variables and adds a separate policy-proxy boundary. OpenClaw's proxy lifecycle validation is not needed here.
