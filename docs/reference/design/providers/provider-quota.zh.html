供应商额度

每个已连接供应商一份状态：健康、额度、30 天花费、默认模型和密钥健康。额度先从 OpenProgram 已经收到的回复里取；端点只在少数事件上读取，从不定时。

一个模型，四种类型

一条 QuotaLimit 是一个账户的一项限制：键、标签、单位（percent、usd、tokens、requests）、已用、上限、剩余、窗口、重置时间，以及来源 source（headers、frame、endpoint）和 fetched_at。一个供应商的报告属于一种类型：

rate_limit每分钟请求数或 token 数OpenAI 和 Anthropic API 响应头

状态
用到 80 % 警告，95 % 危险，100 % 或没有剩余为用尽。窗口类限制只有在用量跑在窗口已过时间前面时才提前警告。

读取端点

只在以下情况读取端点：

  • 打开状态页，且这个账户上次读取超过 10 分钟，不管当时回了什么（先应答，再在后台读）。被拒的读取（401、5xx、解析不了的响应体）也算：否则拒绝这个密钥的端点每次打开都会被再问一遍；
  • 用户要求刷新；
  • 回复因 402、429 或额度消息失败（每个账户每 10 分钟最多一次）；
  • 刚添加了密钥。

每个账户同时只有一个读取；额度端点返回 429 时，该账户按 Retry-After 暂停，没有就暂停 5 分钟。读取用已配置的安全 HTTP 客户端，固定在端点的源上，以探测类型 quota 记录。

每次读取按供应商和账户记在 usage.db（quota_reads），Worker 和每次 CLI 运行都按这条记录判断：

  • 记下：发出时间、HTTP 状态、失败原因、429 暂停、失败回复上次触发读取的时间；
  • 所以被拒的读取不会在下一次 providers status 或 Worker 重启后再发；
  • 读取失败时，之前的值保留各自的观测时间；状态在它们下面写一次失败原因（read_error、read_at），直到有一次读取成功。

花费

来自用量账本，每个供应商 30 天：调用数、费用、标价、各部分 token、缓存占比（缓存读取除以提示 token）以及 30 个点的每日序列。订阅供应商的花费显示为 Included，旁边保留标价。默认模型是最后用过的，否则是用得最多的。

DeepSeek 的回复曾显示缓存 token 多于总 token。原因：记录器的兜底路径写了 total_tokens = input + output，漏掉了缓存 token。现在记录器取上报总数和各部分之和中较大的一个，所有汇总都按各部分相加，修复前写入的行也读得正确。

usage.db 新增 quota_snapshots（每个供应商、账户、限制的最新值）、quota_samples（每 15 分钟一个样本，保留 90 天）和 quota_reads（每个供应商、账户最近一次端点读取）。

健康和失败原因

关于一个密钥有两份记录：调用失败时写下的凭据状态（status_at，即凭据池的 updated_at），和它额度端点的最近一次读取（read_at）。较新的那份说了算；时间相同时，401 优先于已存的欠费停用或限流。

  • 比状态新的 401 读取：invalid_key（"quota endpoint answered 401"），直到读取成功或用这个密钥的调用成功。
  • 在 billing_blocked 停用之后成功的读取推翻这个停用，由这次读取的余额决定。

健康取最好那个密钥的状态，被用尽的限制覆盖：ready、rate_limited（带重置时间）、no_credit、invalid_key、signed_out 或 unknown。

限流只持续到冷却结束。凭据池在下次成功前保留密钥的 rate_limited 状态，但冷却一过就会再选它，所以健康把这样的密钥读成 ready，不会显示“限流到一个已经过去的时间”。

CLI 表格只打印将来的时间（until 14:05、resets Nov 19 02:22），已经过去的时间不打印。表格适应终端宽度：进度条先减少格数，最少 5 格，再把重置时间移到下一行。输出到管道且没有 COLUMNS 时不折行。

失败的回复在错误原因旁带一个 cause，从供应商错误一路传到轮次结果、事件（cause）和保存的占位消息（error_cause）：

原因来自
quota_exhausted402、insufficient_quota、usage_limit_reached；已知时写明用尽的限制和重置时间
invalid_key401 或密钥被拒的消息
not_available地区或套餐拒绝（403 JSON、套餐不含该模型）
unreachable异常链中任何一处的 DNS 或连接失败

普通 429、5xx、超时和网络边缘返回的 403 网页不带原因；错误卡片照旧绘制。
