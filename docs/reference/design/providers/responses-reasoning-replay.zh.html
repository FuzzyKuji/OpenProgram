Responses reasoning 重放

SDK 输出对象可能把缺失的可选字段序列化为 null，兼容端点在重用时对 content: null 返回 HTTP 422。所有 Responses 适配器共用的 convert_responses_messages 在发出边界处理。

项目转换时
null 的 content、encrypted_content、status从 reasoning 项中省略
非 null 值、summary 数组、不透明的加密内容保留
服务器分配的 ID、跨模型签名沿用现有处理
已存历史绝不改写，逐字节不变
载荷绝不解密
权限、失败的外部操作不改变，不重试

不新增队列、provider 回退或重试策略。已安装 OpenAI SDK 的 ResponseReasoningItem 把这些字段声明为可选；其输出序列化与输入要求不同。
