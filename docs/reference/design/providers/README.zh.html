Providers

方面当前设计
厂商每个厂商一个适配目录，在 openprogram/models/providers/adapters/ 下，由 provider.json 声明模型、线路 API 和登录方式。包括 Anthropic、OpenAI、Google Gemini、Amazon Bedrock、Azure OpenAI、xAI、DeepSeek、Mistral、Groq、OpenRouter、GitHub Copilot 等，以及本地的 Ollama、LM Studio、vLLM、llama.cpp。
请求运行时交来完整的 Context（system、messages、tools）。适配器翻译成线路请求，并应用该厂商的提示缓存。上层不知道厂商格式。
账号凭据按 (provider, account) 池存放，来自 API key 或订阅 OAuth。一个账号生效；可开启轮换和故障转移。
失败所有错误映射到同一分类，按类别重试或故障转移，受超时约束，以结构化错误到达界面。
目录来自 provider.json、订阅目录和 models.dev。思考强度和 Fast 档按厂商声明。
管理openprogram providers（login、list、use、status、doctor、accounts），或 设置 → Providers
