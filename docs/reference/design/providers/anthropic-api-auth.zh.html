Anthropic API 认证

使用官方 Anthropic Messages API、API key 和 API 账户计费。所有使用遵守适用的服务条款与使用政策。

部分行为
登录把 API key 存入凭据存储
请求解析器把 key 交给 Anthropic SDK；API key 认证
发现、校验与推理使用相同的凭据要求
兼容的第三方 API保留各自的端点和凭据
不支持的凭据类型和 provider在访问网络前拒绝
界面凭据始终掩码显示
入口Provider、账户、登录和模型列表都强制 API key 认证，并对支持范围保持一致
测试使用合成凭据，不发真实 provider 请求
