其余情况匹配 _RETRY_PATTERN 则是

空消息算可重试，因为流断开时往往还没收到错误体。_RETRY_PATTERN：overloaded、rate limit、too many requests、429、500、502、503、504、service unavailable、server error、internal error、connection error、connection refused、other side closed、fetch failed、upstream connect、reset before headers、terminated、retry delay。

Runtime.exec

异常动作
ExecInterrupt、TypeError、NotImplementedError、ImportError、StructuredOutputError直接抛出
retryable=False，或命中 _PERMANENT_ERROR_MARKERS放弃，“failed permanently”
transport_exhausted、已过期限、次数用尽、Retry-After 超上限放弃
等待会越过期限按 TIMEOUT 放弃
其他等待后重试

标记：not a valid image、invalid image、image data is not、login expired、login failed、re-auth、unauthorized、invalid api key、invalid_api_key。

各层合起来

传输重试只算一次：AgentSession 和提供商流共用一个 RecoveryState。用尽时消息被标记 error_transport_exhausted，exec 不会用新的工具上下文重启本次调用。

网关认证失效（openai-codex 登录过期或失败）永久错误；批量运行前先登录
上下文溢出压缩
TypeError、NotImplementedError改代码
