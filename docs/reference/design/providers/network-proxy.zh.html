出站网络代理

直连并校验对端的连接到不了只能经用户代理访问的服务。Clash 这类 fake-IP 代理还会用 198.18.0.0/15 回答本地 DNS，只信本地解析的策略会按 NON_GLOBAL_ADDRESS 拒绝，而真正的解析发生在代理里。

谁走代理

使用方例子路由
任意公网 URLtool.web_fetch、tool.image_result.download、频道附件和资源普通代理
固定且审计过的 HTTPS 服务搜索 API（含 DuckDuckGo）、图片 API、更新器、技能目录、office 资源、频道 API、TTS普通代理
提供商provider.*、webui.model_listing.*仅当确切 origin 在提供商 API 或 OAuth 清单里时走普通代理
自定义 origin、回环回调所有者例外放行的私有服务直连，校验对端

路由在目标策略之前选定，每个请求和每一跳重定向都如此。命中 NO_PROXY 或没有路由时直连，并做完整的本地地址检查。

由代理解析的目标

目标决定
IP 字面量直接检查；私有、回环、保留、fake-IP、元数据地址一律拒绝
单标签、localhost，或 .localhost .local .lan .home.arpa .internal .intranet .corp .home查询前就拒绝
元数据主机名METADATA_ADDRESS
本地答案是真实的私有、回环、链路本地、保留或元数据地址拒绝
本地答案是 fake-IP（198.18.0.0/15），或查询失败交给代理
答案格式错误拒绝

决定里带 requires_proxy；为它建直连池或 socket 会抛 PROXY_ROUTE_REQUIRED。固定审计服务的直连也接受 fake-IP，因为主机名调用方选不了，且 TLS 会校验。不可信的公网 URL 从不接受。

用哪个代理

  1. 显式的 security.outbound_url.policy_proxy，保留其强制要求；此时普通路由不用。
  2. OPENPROGRAM_PROXY_URL，保留 NO_PROXY。
  3. 经 HTTPX 读标准环境变量，macOS、Windows 上回退到 Python 读系统设置。回环地址总是绕过。
方面行为
连接池httpcore 代理池加感知决定的 backend，支持 HTTP、HTTPS、SOCKS5
转发HTTPS 目标用 CONNECT 按主机名建隧道；明文 HTTP 用绝对形式
代理地址所有者选定；禁止元数据和链路本地地址
凭据代理认证只进握手；重定向不跨 origin 转发凭据
校验TLS 校验原服务主机名；Host 由校验过的 origin 生成
失败绝不回退直连
客户端缓存路由表在客户端内不可变，并计入缓存身份；路由变化后的新调用淘汰旧客户端
显式传输安全对象不继承环境路由
取舍和残余风险
取舍决定
环境解析复用 HTTPX 的解析和 URLPattern 优先级，不再实现第二个 NO_PROXY 匹配器
PolicyProxyConfig与普通路由分开：普通 Clash 代理不执行 URL 策略，所以本地检查仍在它前面
不做新增 profile、关闭 URL 保护、改 OAuth、让自定义服务走普通路由
CA 证书仍由出站安全配置控制
风险立场
最终解析走代理时归代理
真实答案是私有地址的公网主机名只有本地解析返回真实答案时才拦得住；在 fake-IP 解析器后面，或检查与代理查询之间发生 DNS 重绑定时，由代理规则决定
仍然生效只读方法、不可信 URL 的 80/443 限制、凭据剥离
要严格保证配置强制策略代理，或把主机列入 NO_PROXY
验收
  • 同步和异步公网入口都能走 HTTP、HTTPS、SOCKS5 路由。
  • fake-IP 解析器后面的 web_fetch 按主机名经代理到达目标。
  • 走代理时 IP 字面量、本地名称和真实私有答案仍被拒绝；NO_PROXY 主机保留直连检查。
  • 由代理解析的决定绝不打开直连 socket。
  • NO_PROXY 和覆盖优先级成立；路由变化时共享客户端被替换。
  • 未授权的目标和代理地址在联网前被拒绝；服务凭据与代理凭据隔离；策略代理行为和清理保留。
OpenClaw 的做法

来源：references/openclaw/src/infra/net/proxy-env.ts、proxy-fetch.ts、src/infra/net/proxy/、其代理文档。

  • 一个环境解析器，跟随 undici 的 EnvHttpProxyAgent：小写优先；HTTPS 先 https_proxy 再 http_proxy；ALL_PROXY 兜底。自己实现完整的 NO_PROXY 匹配（含 IPv4 CIDR），把关每次决定。
  • 一个覆盖入口：--proxy-url、proxy.proxyUrl、OPENCLAW_PROXY_URL，可选 --proxy-ca-file，基于 undici ProxyAgent，带托管代理生命周期。
  • 提供商辅助函数都走这里；SSRF 防护共用 matchesNoProxy。

OpenProgram 借鉴标准变量只有一种解释，并增加独立的策略代理边界。OpenClaw 的代理生命周期校验这里不需要。
