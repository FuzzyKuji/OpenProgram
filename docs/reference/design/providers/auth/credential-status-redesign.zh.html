凭据状态

status原因恢复
valid可用无
rate_limited429，短暂限流自动：下次成功，或窗口结束后报告 valid
billing_blocked402，余额不足，无计时充值后 Validate，或一次成功调用
needs_reauth401 或 403，被拒绝重新添加 key 或登录
revoked永久失效更换

状态列就是全部答案。账号记录没有 cooling 字段。

哪些响应影响凭据

响应凭据池
429短暂 cooldown_until_ms；轮询跳过，单 key 仍发送
402、401、403停用；轮询视为不健康
404、400、422（request_error）不动
5xx、网络错误不动

聊天里以红色错误气泡显示供应商原话。账号面板只用于诊断。

为什么没有冷却窗口

404 会连累这个 key 上的其他模型，402 等待也不会恢复，5xx 说明不了 key 的好坏。只有订阅和配额账号才真的要等重置。
