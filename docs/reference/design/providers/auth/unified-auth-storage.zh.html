AuthStore（models/auth/store.py）：~/.openprogram/auth/<provider_id>/<account_id>.json，原子写入、跨进程锁，文件被外部改动时重新加载。CredentialProvider 只提供磁盘上已有的内容，不重新发现；导入是显式步骤。

登录注册表

auth/login/login_method_registry.py 是唯一的 provider → [method] 表；第一项为默认，CLI、网页、TUI 都按它显示。处理器在 auth/methods/ 和 auth/login/。Google Code-Assist OAuth 内嵌 OpenProgram 不能分发的 client secret，所以该供应商保持委托；Anthropic 没有公开第三方 OAuth client。

步骤行为
写入（credentials/io._atomic_write）被替换的文件是合法 JSON 时保留为 <file>.bak（state/last_good.keep_previous）
读到非法 JSON（last_good.load_json）把原字节复制一次到 <file>.bad-<UTC 时间>-<摘要>，返回合法的 .bak，否则返回空
使用方read_config、update_config、认证存储
备份（operations/backup.py）排除 .bak 和 .bad- 副本，脱敏不会被绕过
