Credential connection

Never reduced to a bare key string. OAuth comes from kind, not a token prefix. One key can reach another endpoint: a Bailian key stores https://…maas.aliyuncs.com/compatible-mode/v1, under the same openai-completions protocol, with no extra model list.

Wire rules

api_key  = conn.auth_value if conn else opts.api_key
base_url = (conn.base_url if conn and conn.base_url else None) or model.base_url
headers  = {**(model.headers or {}), **(conn.headers if conn else {}), **(opts.headers or {})}
is_oauth = bool(conn and conn.kind in ("oauth", "device_code"))

Same in openai_completions, openai_responses and anthropic.

Old format and migration

Runtime accepts only the current structure; old JSON with __type__ is an error. auth/_migrate_payload.py rewrites each ~/.openprogram/auth/<provider>/<profile>.json atomically, on the first AuthStore load or through openprogram providers migrate. It skips current payloads and files with no credentials, such as _rotation.json. No new login.
