账号与轮询

概念含义
账号一个 profile：~/.openprogram/auth/<provider>/<profile>.json 一个凭据池。OAuth 刷新轮换要求每个池最多一个 OAuth 凭据，所以只有这个模型能覆盖所有供应商。
account_id运行时分配的稳定 ASCII 键（default、account-2……），永不改变
labelUnicode 显示文字；可随意改名；允许重复

新登录的 label：手填、OAuth 邮箱、供应商显示名、稳定 id，依次取。身份来自凭据 metadata、嵌套 OAuth 数据或 id_token claims。旧凭据读取时推导。

机制行为
当前账号auth/account/account_selection.py：get_active_account、set_active_account、get_active_pin。acquire 和解析器默认用它；聊天和执行进入 auth_scope。默认仍是 default。
结果上报auth/usage.py 和 openai_completions.stream_simple 每次请求获取并上报；429 冷却这个 key，外层重试换下一个。没有真实 AuthStore 池时不起作用。
对话亲和流式调用运行在 conversation_affinity(session_id) 里；pool.pick 让对话继续用上次的健康凭据，前提是 1 小时内活跃（AFFINITY_IDLE_MS），这样供应商缓存不用重复付费。凭据冷却或吊销后对话换走，不再回来。每进程最多 4096 个（AFFINITY_MAX）。沿用 magpie（yetone/magpie，MIT）。
策略fixed、fill_first、round_robin、random、least_used；auth/pool.py 跳过冷却；auth/credential_provider.py 处理 fallback

REST

位于 /api/providers/{provider}/accounts：

路由效果
GET{active, accounts:[{id,label,name,email?,status,kind,is_active,is_fallback}]}、策略、add_mode（code_paste 或 login）。name 是 label 的别名。
POST /use {id}固定账号；"" 交还 fallback（default），它的开关不能单独关闭
POST /rename {id,name}只改显示文字
POST /remove {id}移除
POST /add、/keys {api_key,name?,validate?}新账号；名字留空自动取
GET /{name}/reveal、POST /{name}/update完整 key；替换
POST /{name}/validate、/validate-all校验一个或全部
POST /rotation {enabled,strategy?}关：只用当前账号。开：冷却、跳过、换下一个。默认关。
POST /reorder {order}轮询优先级
POST /enabled加入或移出轮询
POST /{name}/retry清除冷却

登录添加复用 /api/providers/{id}/login/{start,poll,submit,cancel}，可带 label；id 由运行时分配。多 profile 和诊断：routes/identity/credentials.py（/profiles、/pools、/doctor、SSE /events）。
