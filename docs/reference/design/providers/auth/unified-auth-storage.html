Auth storage

AuthStore (models/auth/store.py): ~/.openprogram/auth/<provider_id>/<account_id>.json, atomic write, cross-process lock, reload when the file changes underneath. CredentialProvider serves what is on disk and never re-discovers; import is an explicit step.

methods/cli_import.py has mode="link" (default) and mode="copy", which builds a writable store-owned oauth credential.

Login registry

auth/login/login_method_registry.py is the one provider → [method] table; the first entry is the default, and the CLI, web and TUI all render it. Handlers are in auth/methods/ and auth/login/. Google's Code-Assist OAuth embeds a client secret OpenProgram cannot ship, so that provider stays delegated; Anthropic has no published third-party OAuth client.
