凭据校验

models/listing/credentials.py 的 validate_credential 服务保存、验证、连通性检查、CLI、TUI 状态行和安装向导。不指定模型就不会运行模型。

层问题成本运行时机
0 存在有凭据、不是掩码、OAuth 未过期？离线总是
1 认证认证端点接受吗？一次 GET，0 token常规检查
2 模型现在能访问这个模型吗？一次推理 ping仅传 model= 时

ok 和绿色标记只代表 valid。第 1 层 200 只证明认证，不证明余额：只有 OpenRouter GET /key 有余额、第 2 层 ping 或真实聊天 200 才能写 valid。OAuth needs_reauth：openprogram providers login <pid>。自定义端点返回非 JSON 的 200 不算有效。

结果按供应商和是否指定模型缓存 60 秒；use_cache=False 或 refresh=True 绕过。密钥不存也不返回。这不是配额面板。

添加供应商

在 _kind_for 声明 kind；openai_bearer 不用声明。Anthropic 协议的第三方要三处一致，由 test_model_fetch_routing.py 固定：

  • _kind_for 返回 anthropic_compat
  • catalog/metadata.py default_api_for 解析出 anthropic-messages
  • listing/fetchers/__init__.py 走认 base URL 的 Anthropic 拉取器
