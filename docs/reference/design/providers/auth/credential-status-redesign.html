revokedpermanently deadreplace

The status column is the whole answer. The account record has no cooling field.

What touches the credential

ResponsePool
429Short cooldown_until_ms; rotation skips it, a single key still sends
402, 401, 403Stopped; unhealthy for rotation
404, 400, 422 (request_error)Untouched
5xx, networkUntouched

Chat shows the provider's own message in a red error bubble. The accounts panel is for diagnosis.

Why no cooling window

A 404 would punish every other model on the key, a 402 does not end by waiting, and a 5xx says nothing about the key. Only subscription and quota accounts truly wait for a reset.
