唯一注册表 openprogram/state/settings.py 驱动 setup 向导、TUI 和 Web 设置。由它生成的全部设置：设置键。日常使用：配置与数据目录。

常用设置

端口

键含义默认生效
ui.web_portAPI、WebSocket 和 Web UI 共用的唯一 worker 端口18100下次启动
ui.open_browseropenprogram web 自动打开浏览器true下次启动

搜索、记忆、工具、Agent

键含义默认生效
search.default_providerauto 选优先级最高的已配置项auto立即
memory.backendlocal，或 none：无提示记忆、回忆、自动写入、整理器和记忆线程local下次启动
memory.writer.model后台写入可选 provider/model；空则用默认聊天 agent 的空立即
tools.disabled.<name>单个工具开关；写入 tools.disabled 列表全部启用立即
agent.output_style回复风格，追加到系统提示。输出风格default立即
providers.<name>只读状态行。用 openprogram providers login 或 Web UI 配置。——

沙箱

sandbox.mode本地模型驱动的命令
off默认。除非对话在输入框菜单开启，否则不用沙箱。
auto后端可用时所有对话都用沙箱；否则不用沙箱继续运行
workspace-write写入限于工作目录和配置的根目录，屏蔽 deny-read 路径，禁用网络
danger-full-access完整用户权限
键含义默认生效
sandbox.writable_roots额外可写目录，JSON 列表[]立即
sandbox.deny_read不可读 glob，默认含凭据路径。Linux 无法执行 **/.env 这类中间通配符：请用确切路径或目录规则，如 /absolute/path/to/secrets/**。openprogram config get sandbox.deny_read立即
sandbox.deny_write不可写 glob，另加始终屏蔽的函数监视目录和受保护启动文件[]立即
sandbox.network网络访问false立即
sandbox.pass_env内置白名单之外传入的环境变量名[]立即
sandbox.unavailable_policyrefuse：后端缺失或无法隔离时命令失败；warn：不用沙箱运行refuse立即

后端：macOS Seatbelt，Linux bubblewrap，Windows 通过默认 WSL2 发行版的 bubblewrap。Docker 不是自动回退。

环境变量

在启动 openprogram 或 worker 的 shell 中设置。

路径与实例

变量用途代码
OPENPROGRAM_PROFILE等同 --profile；~/.openprogram-<name>/openprogram/state/paths.py
OPENPROGRAM_HOME认证账号的替代基础目录openprogram/models/auth/account/accounts.py
OPENPROGRAM_WORKDIRagent 默认工作目录，优先于 default_workdiropenprogram/state/paths.py

端口与网页

变量用途代码
OPENPROGRAM_WEB_PORT唯一 worker 端口（默认 18100）；低于命令行参数，高于已存偏好openprogram/operations/worker/lifecycle.py
OPENPROGRAM_NO_WEB1：worker 跳过前端构建检查，不提供 web UIopenprogram/operations/worker/runner.py
OPENPROGRAM_DOCS_BASE文档挂载路径（默认 /docs/；须以 / 开头和结尾）scripts/docs_site/build.py

LLM 调用

变量用途代码
AGENTIC_PROVIDER, AGENTIC_MODELdetect_provider() 最先选用openprogram/models/providers/catalog/registry.py
OPENPROGRAM_MAX_RETRIES瞬态失败重试次数（默认 6）openprogram/runtime/agent/runtime/shared.py
OPENPROGRAM_RETRY_BACKOFF_BASE退避基数秒（默认 1.5）openprogram/runtime/agent/runtime/shared.py
OPENPROGRAM_EXEC_TIMEOUT_Sruntime.exec 默认墙钟预算（未设或 0：不限）openprogram/runtime/agent/runtime/shared.py
OPENPROGRAM_FALLBACK_MODELS覆盖 model_fallback 设置。未设：按该设置（默认关闭）。same-provider：该 provider 其他已启用模型，最多两个。off 或 none：关闭。逗号分隔的 provider/model 列表：按顺序，可跨 provider。openprogram/models/providers/utils/failover.py
OPENPROGRAM_PROVIDER_STREAM_RETRIES每个流式请求的尝试次数，含第一次（默认 5）。连接重试有独立额度，为此值减一。openprogram/models/providers/utils/stream_retry.py
OPENPROGRAM_NETWORK_WAIT_MAX_S重试用尽后等待不可达端点，每 5 至 30 秒检查（默认 1800；0 立即失败）。取消回合会结束等待。openprogram/models/providers/utils/stream_retry.py
OPENPROGRAM_RETRY_AFTER_CAP_S重试愿意等待的最长 Retry-After（默认 300）。更长则立即失败，让回退模型、其他账号或用户接手。0 取消上限。openprogram/models/providers/utils/stream_retry.py
OPENPROGRAM_CODEX_WEBSOCKET0：ChatGPT 登录的 Codex 回合用 HTTP 而不是 WebSocket。WebSocket 默认开启，接续的回合只发送新输入openprogram/models/providers/adapters/openai_codex/websocket_transport.py
OPENPROGRAM_CODEX_ZSTD0：Codex HTTP 回合不压缩（默认 zstd）openprogram/models/providers/adapters/openai_codex/request_compression.py
OPENPROGRAM_STRICT_TOOLS0：关闭严格工具 schema（默认开启）openprogram/models/providers/schema/__init__.py
OPENPROGRAM_FORCE_IPV41：强制 IPv4 源地址openprogram/models/providers/utils/http_client.py

内部变量

HTTP 和 SSE 超时 OPENPROGRAM_HTTPX_*、OPENPROGRAM_SSE_*；TCP keepalive OPENPROGRAM_TCP_*；按 provider 的重试 OPENPROGRAM_<PROVIDER>_MAX_RETRIES；OPENPROGRAM_JOB_WORKERS；OPENPROGRAM_IMAGE_DIR。完整列表：grep -rn "OPENPROGRAM_" openprogram/。
