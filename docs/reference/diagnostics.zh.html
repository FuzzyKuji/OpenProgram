诊断包

openprogram diagnostics                           # ./openprogram-diagnostics-<date>.zip
openprogram diagnostics --output /tmp/report.zip

命令会打印写入的文件。

内容

文件内容
version.jsonOpenProgram 和 Python 版本、Python 可执行文件、平台、机器
config.json你的 config.json，形似凭据的值已替换
credentials.json有凭据的 provider 及账户数，只有名称和数量
environment.jsonopenprogram doctor 的检查项、Web 构建状态、状态与日志目录权限
logs/worker.log、logs/runtime.log、logs/ink-startup.log各自最后 2000 行，已脱敏；日志不存在则没有
manifest.json每个文件、来源和大小

移除的内容

层替换为 [secret removed]
键名键名包含 api_key、token、password、client_secret、authorization、cookie、auth、credential、session_id 等，所以 openai_api_key 和 github_token 都会命中。整棵子树一起替换。
值的形状，文本中任何位置sk- 密钥、Bearer 和 Basic 请求头、GitHub ghp_ 等令牌、Slack xox 令牌、AWS access key id、Google AIza 密钥、JWT、URL 里的凭据
凭据文件从不读取。credentials.json 来自列出认证存储下的目录名。

两层都作用于每个文本文件，包括日志和堆栈。它们无法判断路径、项目名或提示词片段对你是否敏感：贴到公开 issue 前先读一遍 zip。
