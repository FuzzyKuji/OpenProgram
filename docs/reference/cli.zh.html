CLI 命令参考

完整参数：openprogram <command> -h、openprogram logs tail -h，或每个命令的生成页。

全局

命令作用
openprogram打开对话。直接运行时先询问终端界面或网页界面，没有 worker 时自动启动。
--print PROMPT一次性提示：打印回复后退出
--json-schema PATH要求 --print 按 JSON Schema 输出；- 从 stdin 读
--resume SESSION_ID恢复会话；id 见 openprogram sessions list 或 Web UI 侧栏
--profile PROFILE状态目录 ~/.openprogram-<name>/，等同 OPENPROGRAM_PROFILE
--no-alt-screen内联 TUI，保留终端回滚
--screen-reader内联辅助技术模式，无鼠标跟踪
--version打印版本

对话与运行

命令作用
tui (alias chat)在 Windows、macOS 或 Linux 上直接启动 Ink 终端界面；不支持 raw input 的终端回退到 Rich。接受 --print、--json-schema、--resume、--no-alt-screen、--screen-reader。
web启动服务并打开 http://localhost:18100。--web-port（仅本次；默认已存偏好，然后 18100）、--no-browser。web auth-url 打印已认证链接。
acpAgent Client Protocol 服务。--agent、--permission。

后台服务

命令作用
status是否运行：PID、端口、运行时长
stop停止
restart代码或配置改动后重启
upgrade更新代码，确认可用才重启。--check、--dry-run、--channel、--no-restart、--yes、--json；upgrade status。
子命令作用
worker run前台运行用于调试，Ctrl-C 停止
worker start后台启动后返回
worker stop已安装的服务保持停止，直到下次启动或登录
worker restart停止并启动新实例
worker status是否运行、PID、端口、运行时长
worker install登录服务：macOS launchd、Linux systemd --user、Windows 任务计划程序。登录时启动，崩溃后重启。
worker uninstall移除服务

安装与配置

命令作用
setup首次运行向导。menu 打开选择器；分区名直达：model、tools、agent、skills、ui、memory、profile、search、tts、channels、backend。
configlist（值、分组、生效方式）、get <key>、set <key> <value>
ports查看或保存唯一的 Web UI 端口。--port PORT，默认 18100。
completion打印 shell 补全脚本：bash、zsh、powershell、pwsh
recordings录制和回放 provider 调用：status、record、replay、off、list、show、delete、prune
environments对话运行的位置（本机、SSH、Docker）：list、add、rm、default、test
permissionscheck 解释一次操作，test 校验预期的规则决定

providers

别名 secrets。不带子命令时显示全部凭据的状态表。

子命令作用
login <provider>--api-key、--api-key-stdin 非交互提供 key；--account；--method 强制登录方式
logout移除 provider 凭据
list按账号列出凭据池
available (search, catalog)所有可配置 provider；可加 QUERY
statusprovider 当前凭据
useprovider 使用的账号
discover, adopt扫描外部凭据来源并导入
doctor过期、刷新、冷却、冲突
setup交互式首次配置
aliasesprovider 短名
accountslist、create、delete
migrate把已存凭据迁移到当前格式

mcp

子命令作用
token create创建并打印本地 stdio 服务的 token
serve本地 stdio 认证 MCP；需要完全匹配的 OPENPROGRAM_MCP_TOKEN
list, show服务器和状态；单个服务器的工具和 schema
addstdio 命令服务器；写入 mcp_servers.json 并启动
rm停止并删除配置
restart, enable, disabledisable 停止但保留配置
edit已移除；提示改用 add/rm 或 MCP 设置页
test临时启动配置以检查工具列表；不写磁盘
 
openprogram mcp token create
export OPENPROGRAM_MCP_TOKEN="<paste the token printed above>"
openprogram mcp serve

token create 打印一次原始 token，不会设置变量。已有 token 时复用已保存的。

browser

子命令作用
install源码 checkout：Playwright 与 Chromium、patchright、camoufox。打包版本拒绝此命令，并已包含默认后端。
status安装状态、sidecar Chrome、已存登录数
refresh在主 Chrome 登录新站点后重新复制配置
reset结束 sidecar，清除配置、登录和端口文件
list, rmbrowser-states/ 下的已存登录

内容管理

agents

子命令作用
list, show, add列出、查看、创建
rm删除 agent 及其全部会话
set-default设为默认 agent

sessions

子命令作用
list所有 agent 的会话
archive, unarchive从默认列表隐藏或恢复，不删除
resume回答等待中的会话
attach, detach把渠道用户路由到会话或移除。必需 --channel、--peer；可选 --account、--peer-kind。
aliases所有会话与渠道用户的别名
export导出 Markdown 或 HTML：--format、--output
import导入 Claude Code 和 Codex 对话；重复运行只增加新内容

subagent

子命令作用
spawn在会话中新建分支。必需 --session、--prompt；--parent-msg、--label、--agent（默认 main）、--context inherit|clean 或 --clean、--no-json。
merge以新回合合并到目标。必需 --target、可重复的 --branch SID；--message、--agent、--base N、--no-json。
list, show会话内的 Job 资源视图

programs

子命令作用
list类型、所有者、加载状态、目录、暴露层级
run <name> [operation]在本进程调用入口，或在服务中启动应用操作。--arg key=value、--input、--project、--request-key、--provider、--model。
status, cancel应用操作的运行
check校验；测试并提交包，使其可调用
install, uninstall目录、git URL 或 owner/repo。--upgrade、--replace、--trust。
enable, disable应用的界面、资源、服务和入口。工具不能禁用。

skills

子命令作用
list已发现的 skill
search, install从发现源，默认 ClawHub
update比较 SKILL.md 哈希，重新拉取过期 skill
remove仅限项目、用户或远程缓存的 skill
doctor扫描 skill 目录

plugins

子命令作用
list, search已安装插件；已配置市场
install从 npm、git 或路径安装声明式插件；声明代码的 manifest 被拒绝
uninstall, update移除；从 npm 重新安装
enable, disable, reloadreload 重新读取 manifest 和文件
inspect插件可包含什么、拒绝什么、每个条目的暴露层级

channels

子命令作用
list各平台启用和配置状态
setup向导：选渠道、登录（二维码或 token）、绑定 agent
accounts机器人账号：list、add、rm、login、set、group-users
bindings把入站消息路由到 agent
accesslist、approve <code>、allow <user_id>、revoke <user_id>。未知发送者走配对；allow 直接添加已知用户。见聊天渠道。

memory

每个实例一个工作区，所有 agent 和对话共享，包括渠道。

子命令作用
status内容、修订、写入器健康度、待处理回合
recall QUERY...打印匹配段落
show PATH, edit PATH单个文件；edit 用 $EDITOR，校验通过才生效
sleep立即整理主题文件。--model MODEL。
exporttar+gzip 打包目录。--out PATH，默认 ./openprogram-memory-<date>.tar.gz。

内容恢复

命令作用
trashlist、restore：可恢复的本地删除，不覆盖
backupcreate、list、restore、prune：<state>/backups/ 下的 tar.gz 快照

执行

命令作用
executionpause、continue、step、steer、cancel、fork、retry、wait-answer、wait-decline
jobslist、get：Job 资源视图
scheduler-worker (cron-worker)前台循环，触发一次性、周期和监控任务。守护进程 tick 失败时把警告和 traceback 写到 stderr，然后在下一分钟继续，不重放失败的 @reboot 初始 tick。--once 运行一次并传播失败；--list 显示匹配状态。

维护

命令作用
doctor端到端健康检查。--json、--repair、credentials。
rescue诊断问题，打印修复命令
diagnostics脱敏的支持 zip。--output PATH，默认 ./openprogram-diagnostics-<date>.zip。见诊断包。
logslist；tail [name] 带 -n、-f；path [name]。名称：worker（默认）、runtime、ink。
self-updatestatus、repair：查看或恢复对话内 App 更新。见升级。
devstatus、deploy、open、copy-models、auth-url、promote。见升级。
update遗留命令，目前抛 ImportError。请用 upgrade。
