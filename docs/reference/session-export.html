Session export

FromDo
CLIopenprogram sessions export <session-id>--format md|html, default md--output PATH, default ./<session-id>.<format>
Web UIRight-click a conversation in the sidebar, or its ⋯ button, then Export and a format
HTTPGET /api/sessions/{session_id}/export?format=md|html, owner-authenticated, answers with Content-Disposition: attachment

Session ids: openprogram sessions list or the Web sidebar.

What lands in the file

PartRule
ScopeThe active branch only, walked back from its head as in the Web transcript
Each turnRole, local timestamp, text, not truncated
Tool calls, under their turnName, ok or failed, arguments, result
ArgumentsCut at 1,000 characters, marked … [+N chars truncated]
Tool resultsCut at 4,000 characters, marked the same way
HTMLOne file: inline styles, no scripts or external requests, follows light or dark through prefers-color-scheme

Redaction

Title, session id, role label, tool name, turn text, arguments and results all pass through remove_secret_values (openprogram/models/providers/recording/recording.py), before clipping. The stored conversation is not changed.

MatchesBecomes
Secret-named fields: api_key, authorization, token, password, …[secret removed]
In free text: bearer tokens, sk- keys, credentials in URL query or userinfo[secret removed]
Arguments nested too deeply to redact safely[arguments omitted: nesting too deep]

This covers known credential shapes only. Read an export before sending it somewhere public.
