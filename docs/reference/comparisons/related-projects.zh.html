相关项目

多个团队独立得出同一思路——用类型化 Python 写 agent：docstring 就是提示，签名就是契约。

项目共同点差异
NVIDIA NOOA (Apache-2.0)Agent 是 Python 对象；... 方法体由 LLM 实现；docstring 是提示，类型注解是契约状态在 self 上；模型把 Python 写进 Jupyter 式 REPL（CodeAct）。OpenProgram 让模型在已注册函数中选择：动作空间更窄，更易沙箱化和回放。
DSPy (MIT)类型化 Signature 取代手写提示按指标优化提示。我们保持提示固定可读，把精力放在执行结构：DAG、重试、上下文作用域。两者互补。
Marvin (Apache-2.0), Mirascope (MIT)装饰函数的 docstring 和返回注解驱动结构化调用专注单次类型化调用。OpenProgram 增加跨调用的部分：共享 DAG、spawn、分叉、单次上下文预算。
LangGraph (MIT)运行应是可检查、有检查点的图图要预先声明。我们的图从调用栈记录：写普通 Python，DAG 就是实际运行的轨迹。见对比。
smolagents (Apache-2.0)通过代码而不是死板的工具 JSON 行动在沙箱中写代码的 agent。我们在编写时通过 Agent 方法绑定代码，确定性部分在运行前可审查。
Scriptorium可读的 agent 记忆；Markdown 笔记；事实引用来源消息；为 Claude Code 提供 MCP模型把记忆写成普通文件：可打开、diff，把每条事实追溯到消息

描述有误或有遗漏？请提 PR 或 issue。
