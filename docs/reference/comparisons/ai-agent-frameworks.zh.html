LangGraph节点和边的 Graph API，或带 @entrypoint 和 @task 的 Functional API显式状态图或标准 Python 控制流，同一 runtime需要持久执行、持久化、流式和人在回路的状态控制。它是底层 runtime；其概述建议用 LangChain agent 获得预置架构。
