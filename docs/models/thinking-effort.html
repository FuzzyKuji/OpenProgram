Thinking effort

One slider over each vendor's own parameter; the provider translates the level before each request.

off · minimal · low · medium · high · xhigh · max

The UI shows the levels the model supports. Opus 4.8 has five, low to max; DeepSeek reasoner is not adjustable; GitHub Copilot has none. Levels come from the thinking block in provider.json, with per-model overrides; Fetch refreshes them where the endpoint reports capabilities (Anthropic /v1/models, Codex subscription models).
