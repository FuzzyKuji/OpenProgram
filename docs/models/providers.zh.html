自定义 Provider

设置 → Provider：必填显示名称和 base URL；不填 id 时由名称生成。https://api.example.com 解析为 /v1；明确的路径如 /compatible-mode/v1 保留。Fetch models 浏览端点的 /models。存为 providers.<id>，带 source: "custom"。

回退模型

用于被限流、过载、宕机或不可达的模型。在设置 → 系统 → 模型里设置，或：

openprogram config set model_fallback.mode same-provider
openprogram config set model_fallback.models '["anthropic/claude-sonnet-5-5", "openai/gpt-5.5"]'
model_fallback.mode发生此类失败时
off（默认）显示错误
same-provider按设置中的顺序尝试该 Provider 其他最多两个已启用模型。不联系其他 Provider。
list按顺序尝试 model_fallback.models，可跨 Provider

只在回复还没有任何文本时切换。认证错误、无效请求、上下文已满和内容策略拒绝不重试。OPENPROGRAM_FALLBACK_MODELS 覆盖此设置。

请求脱敏

默认关闭。设置 → 系统 → 模型里的 Redact secrets in requests，或 openprogram config set privacy.redact_requests true。每次请求前，这些内容换成 [[SECRET_1]]、[[EMAIL_2]] 这样的占位符：

  • 形状可识别的 API 密钥和 token：Anthropic、OpenAI、GitHub、AWS、Google、Slack、JWT
  • 私钥块
  • password=…、api_key: …、Authorization: Bearer … 等赋值里的值
  • 邮箱地址

回复及其工具调用先还原真实值，所以用 [[SECRET_1]] 写的命令会带着真密钥运行。映射只在内存里保留一次请求。自由文本里没有赋值形式的密码会原样发送。

作为库使用

from openprogram.runtime.agent.runtime.factory import create_runtime

runtime = create_runtime()                                        # 第一个可用的 Provider
runtime = create_runtime(provider="anthropic", model="claude-sonnet-4-6")  # Anthropic API 密钥
runtime = create_runtime(provider="openai", model="gpt-4.1")               # OpenAI Responses
runtime = create_runtime(provider="gemini", model="gemini-2.5-flash")      # Google Generative AI
runtime = create_runtime(provider="openai-codex")                          # ChatGPT 订阅
runtime = create_runtime(provider="gemini-cli")                            # Gemini CLI 登录

这五个有专门的行为。其他 Provider 按模型协议路由，与聊天相同。
