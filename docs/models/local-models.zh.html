本地模型

OpenProgram 连接你运行的服务。模型下载、GPU 分配和服务生命周期由该服务管理。

设置 → Provider 里的预设默认 API Base URL
Ollamahttp://localhost:11434/v1
LM Studiohttp://localhost:1234/v1
vLLMhttp://localhost:8000/v1
llama.cpphttp://localhost:8080/v1
本地 OpenAI 兼容服务http://localhost:8000/v1
  1. 用服务自己的工具启动并加载模型。
  2. 启用该 Provider，保存 API Base URL。
  3. 点 Fetch models，启用一个模型。
  4. 在聊天输入框选择它。

localhost 指运行 Worker 的机器；远程 Worker 要填它能访问的地址。只有主机和端口时补 /v1；明确的路径保留。保存新 URL 会改变已启用模型后续的发现和推理。

情况做法或结果
服务需要密钥在 Provider 账户面板添加。没有密钥时，发现、检查和推理都不带 Authorization；云端 OpenAI 密钥绝不会发送。
多个服务Add custom provider：名称、URL、Local server (API key optional)。普通自定义云 Provider 的凭据要求不变。
检查服务Connectivity：能列出模型说明接口有响应；测试具体模型还会检查推理。服务不可用、密钥被拒或响应无效都报失败。
无法发现Add model by id，填准确的标识符。也可更新已有模型的限制。
Token 限制填与部署及其配置的上下文大小一致的值。未知时默认上下文 4,096、输出 1,024。模型宣称的训练上下文不算数。

本地模型使用 OpenAI Chat Completions，流式、取消和工具调用走与其他兼容 Provider 相同的传输。工具、图片、推理和严格 JSON 取决于模型和服务。启用状态和限制保存在标准配置里。
