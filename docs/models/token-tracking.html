Token tracking

Each assistant message carries one Usage record.

FieldMeaning
inputNon-cached input. Excludes cached tokens, as Anthropic does; inclusive vendors are converted by subtraction.
outputOutput tokens
cache_readServed from the prompt cache
cache_writeWritten to the prompt cache (explicit caching only)
total_tokensVendor-reported total
costUSD, from the enabled model's per-million prices
