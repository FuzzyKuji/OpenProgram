API keys are imported into the credential store: Authentication. Every provider streams. Multimodal input is per model; trust the UI. Prompt caching is verified in code only where noted.

Custom providers

Settings → Providers: a display name and base URL are required; an id is derived from the name if omitted. https://api.example.com resolves to /v1; an explicit path such as /compatible-mode/v1 is kept. Fetch models browses the endpoint's /models. Stored as providers.<id> with source: "custom".

Fallback models

For a model that is rate limited, overloaded, down or unreachable. Set under Settings → System → Models, or:

openprogram config set model_fallback.mode same-provider
openprogram config set model_fallback.models '["anthropic/claude-sonnet-5-5", "openai/gpt-5.5"]'
model_fallback.modeOn such a failure
off (default)The error is shown
same-providerUp to two other enabled models from that provider, in settings order. No other provider is contacted.
listmodel_fallback.models in order; other providers allowed

A switch happens only before any reply text. Authentication errors, invalid requests, a full context window and content-policy refusals are not retried. OPENPROGRAM_FALLBACK_MODELS overrides the setting.

Redacting secrets in requests

Off by default. Redact secrets in requests under Settings → System → Models, or openprogram config set privacy.redact_requests true. Before each request these become placeholders such as [[SECRET_1]], [[EMAIL_2]]:

  • API keys and tokens with a recognizable shape: Anthropic, OpenAI, GitHub, AWS, Google, Slack, JWTs
  • Private key blocks
  • The value in password=…, api_key: …, Authorization: Bearer … and similar
  • Email addresses

The reply and its tool calls get real values back first, so a command written with [[SECRET_1]] runs with the key. The mapping lives in memory for one request. A password in free text with no assignment is sent as is.

Library use

from openprogram.runtime.agent.runtime.factory import create_runtime

runtime = create_runtime()                                        # first available provider
runtime = create_runtime(provider="anthropic", model="claude-sonnet-4-6")  # Anthropic API key
runtime = create_runtime(provider="openai", model="gpt-4.1")               # OpenAI Responses
runtime = create_runtime(provider="gemini", model="gemini-2.5-flash")      # Google Generative AI
runtime = create_runtime(provider="openai-codex")                          # ChatGPT subscription
runtime = create_runtime(provider="gemini-cli")                            # Gemini CLI login

Those five have bespoke behavior. Every other provider routes by the model's protocol, as in chat.
