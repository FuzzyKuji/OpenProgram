Model config can set fast: false to disable or fast: true to declare route support. Support is never inferred from a model's name; calls are validated against their own route.

Fast can increase usage or cost; xAI priority has a 2× token-price premium (xAI pricing). The gauge is the requested mode, not a speed guarantee. Completions and Responses keep the actual returned tier in usage; absent metadata stays unconfirmed. xAI's reported request cost is kept separately when available.
