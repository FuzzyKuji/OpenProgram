Token 统计

每条助手消息带一条 Usage 记录。

字段含义
input非缓存输入。与 Anthropic 一样不含缓存 token；包含缓存的厂商相减换算。
output输出 token
cache_read由提示词缓存提供
cache_write写入提示词缓存（仅显式缓存）
total_tokens厂商报告的总数
cost美元，按已启用模型的每百万 token 价格计算

各协议报告什么

取自厂商的最终事件或最后一个分块。
