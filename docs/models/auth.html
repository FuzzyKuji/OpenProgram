Authentication

OpenProgram requires safe, lawful and compliant use of Anthropic services: the official API, legitimately obtained API keys, API-account billing, and calls that comply with Anthropic's terms of service and usage policy.

Storage

~/.openprogram/auth/<provider>/<account>.json, mode 0600. With --profile <name> the root is ~/.openprogram-<name>/.

Runtime reads the store only. A key in an environment variable must be imported first, and later changes to the variable do not affect it. Exceptions, detected at runtime: Amazon Bedrock (AWS_PROFILE, access keys, bearer token and so on) and Google Vertex (ADC).

While the external CLI is present a pointer is stored and its file re-read on every call. Otherwise the token is copied and OpenProgram refreshes it.

Helper command

For tokens issued by a CLI such as aws, sso-helper or token-fetcher: in Settings → Providers add type credential_process.

FieldMeaningDefault
commandArgv list, run without a shellrequired
parsesjson, or text for stripped stdoutjson
json_key_pathKeys to walk, such as ["creds", "token"]. Empty: the document must be a string[]
cache_secondsToken reuse. 0 runs on every call300
timeout_secondsLimit per run60

The login smoke test runs it once. A failure (non-zero exit, timeout, bad output, missing key path) fails the request with the command and its stderr, and never falls back to another credential. Fix the helper, or remove it to use another source.

Enterprise SSO (sso) is not implemented; the API and resolver reject it.

Manage

Commands: Configure models.

Every provider supports named accounts, and an account's pool can hold several API keys. A key returning 401, 402, 429 or 503 cools down and the next healthy key serves the following request. Strategies: fill_first (default, backup key), round_robin, random, least_used. Rotating across whole accounts is a separate per-provider switch, off by default.

Codex sign-in
  • Program calls use the provider's active account, including one set with openprogram providers use openai-codex <account>. A script can pin another: create_runtime(provider="openai-codex", profile="<account>").
  • Terminal authentication failures and errors marked non-retryable stop after one request, keeping their category through the Program runtime. Other callback failures keep the Program's bounded recovery.
  • The callback listener starts before the authorization page. Keep the provider panel open until it reports success.
