已启用模型

聊天里的模型选择器只显示已启用的模型；只有凭据还不够。

启用方式
设置向导勾选
设置 → Provider勾选。Fetch models 更新目录。
订阅登录自动启用一组默认模型
事项规则
存放在~/.openprogram/config.json（用 --profile 时为 ~/.openprogram-<name>/）的 providers.<id>：enabled 标志和 models 行（上下文窗口、价格等）。手动添加的模型带 source: "manual"。
读取方openprogram/models/providers/catalog/enabled_models.py，启动时读取；配置变更在重新加载时生效
空选择允许，包括关掉最后一个模型；重新加载和重启后仍为空
新聊天没有默认模型。从顶层 last_used_model 开始，即上次选择或发消息用的模型。全新安装时会询问。关掉该模型会清除记录。
其他用途标题、记忆写入、MCP sampling 和 Auto 权限审查在没有自己的对话时使用该模型
Provider 设置打开时用已保存的模型和缓存目录，不等远端接口
品牌图标随产品打包；自定义或未识别的 Provider 显示首字母
