认证

OpenProgram 要求安全、合法、合规地使用 Anthropic 服务：官方 API、合法获取的 API 密钥、按 API 账户计费，所有调用遵守 Anthropic 的服务条款和使用政策。

存放位置

~/.openprogram/auth/<provider>/<account>.json，权限 0600。用 --profile <name> 时根目录是 ~/.openprogram-<name>/。

运行时只读凭据库。环境变量里的密钥要先导入，之后改变量不影响已导入的凭据。例外，运行时自动检测：Amazon Bedrock（AWS_PROFILE、访问密钥、bearer token 等）和 Google Vertex（ADC）。

辅助命令

适用于由 aws、sso-helper、token-fetcher 这类 CLI 签发的 token：在设置 → Provider 添加类型 credential_process。

字段含义默认
commandargv 列表，不经 shell 运行必填
parsesjson，或 text 取去空白的 stdoutjson
json_key_path逐层取键，如 ["creds", "token"]。为空时整个文档必须是字符串[]
cache_secondstoken 复用时长。0 每次调用都运行300
timeout_seconds单次运行上限60

登录冒烟测试会运行一次。失败（非零退出、超时、输出无法解析、缺键路径）时请求失败并给出命令和 stderr，绝不回退到其他凭据。修好辅助命令，或删除它改用其他来源。

企业 SSO（sso）未实现；API 和解析器都会拒绝。

管理

命令见配置模型。

每个 Provider 支持多个命名账户，一个账户的池可放多个 API 密钥。返回 401、402、429 或 503 的密钥进入冷却，下一个健康密钥处理后续请求。策略：fill_first（默认，备用密钥）、round_robin、random、least_used。跨整个账户轮换是单独的 Provider 开关，默认关闭。

Codex 登录
  • Program 调用使用 Provider 的当前账户，包括用 openprogram providers use openai-codex <account> 设定的账户。脚本可固定另一个：create_runtime(provider="openai-codex", profile="<account>")。
  • 终端认证失败和标记为不可重试的错误在一次请求后停止，错误类别在 Program 运行时中保留。其他回调失败仍走 Program 的有界恢复。
  • 回调监听在授权页打开前启动。保持 Provider 面板打开，直到显示成功。
