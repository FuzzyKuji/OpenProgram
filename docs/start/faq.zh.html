常见问题

运行

端口 18100 被占用 
openprogram ports                 # 当前端口
openprogram ports --port 18110    # 持久化，下次启动生效
lsof -ti:18100 | xargs kill       # 释放残留进程占用的端口，然后重启

仅本次运行：OPENPROGRAM_WEB_PORT。

页面打开了，但 Provider、模型和 Agent 全是空的

页面没有登录：手动输入地址打开时，所有列表为空，Local 标记变红，顶部有提示。安装没有缺东西。运行 openprogram web。要在其他浏览器打开，用 openprogram web auth-url 打印登录链接。服务每次启动都会生成新的登录，停止或重启后要重新通过 openprogram web 打开。

openprogram web 打开的页面加载不出来

打开 http://localhost:18100。release wheel 自带 Web 导出；缺失时重新安装对应版本。源码 checkout 中运行开发安装脚本重建。

服务没起来或行为异常 
openprogram status
openprogram restart
openprogram doctor
openprogram rescue     # 诊断并打印修复命令
查看日志 
openprogram logs list
openprogram logs tail            # worker 日志最后 50 行
openprogram logs tail -f
openprogram logs tail runtime    # worker、runtime 或 ink
一台机器运行两个 OpenProgram

可以：profile 隔离状态和端口。

Provider

Provider 没被检测到，或 "No provider available" 
openprogram providers            # 已存凭据
openprogram providers discover   # Claude Code、Codex、Gemini CLI 等
openprogram providers doctor     # 过期、刷新、冷却、冲突
openprogram setup                # 重新运行向导

环境中的 key 必须导入：环境中已有 key。重启服务不会导入。

同一 provider 有多个账户或密钥

多账户与 key 轮换。openprogram providers list 标出当前账户。

数据与更新

数据在哪里

~/.openprogram/，用 --profile 时是 ~/.openprogram-<name>/：config.json、projects/（对话和记忆）、logs/、usage.db（token 用量）。完整列表。

找回之前的对话

openprogram sessions list，再 openprogram --resume <session_id>，或用 Web 侧栏。

更新
安装类型方式
桌面版之后的版本在设置中出现
CLI、服务器、源码 checkoutopenprogram upgrade，按安装类型选择路径

stable 安装只移动到已发布版本。0.7.0 是从 v0.6.6 的一次性迁移。升级。

为什么 release 下载较大

包含托管 Python 和 Playwright Chromium，不包含 PyTorch 或 EasyOCR。正常安装不再单独下载产品组件。

扩展

已安装的 agent Program 没出现

openprogram programs list，然后重启 OpenProgram 或在 Programs 页点刷新。没有条目时，OPENPROGRAM_DEBUG_REGISTRY=1 openprogram programs list 显示原因。目录约定。

Chrome 或 Edge 浏览器扩展

不支持。商店页面作为普通网页打开：没有安装按钮、CRX 下载、导入或扩展管理器。Electron/Chromium 只支持部分 Chrome Extensions API，OpenProgram 不为此维护分支或第二套浏览器运行时。随附的 Playwright Chromium 是自动化后端：不承载桌面 Browser Pane，也不承载扩展。

要扩展 OpenProgram 本身：插件、Skill、MCP 服务器、Program 或 agent 工具。
