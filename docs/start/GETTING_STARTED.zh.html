快速开始

1. 安装

curl -fsSL https://openprogram.io/install | sh        # macOS、Linux
irm https://openprogram.io/install.ps1 | iex          # Windows x64（v1.2.0 起），PowerShell
主题事实
已包含Python 和 Web UI；不需要 Node.js
Gitv1.0.0 需要，用于会话和 Memory 历史；openprogram doctor 会报告
AppmacOS 是 DMG，Linux 是 deb 或 AppImage；Windows 从 v1.2.0 起提供
Windows 沙箱执行是单独的

平台、App 和开发 checkout：安装。

2. 连接 provider

命令作用
openprogram首次运行打开设置向导：导入 Claude Code、Codex 或 Gemini CLI 登录，或粘贴 API key，结束后进入终端聊天
openprogram setup重新运行向导
密钥已在环境变量里 
export OPENAI_API_KEY=sk-...
openprogram providers discover
openprogram providers adopt env:OPENAI_API_KEY

其他 provider 用对应的 env:<VARIABLE>，或把密钥通过管道传给 openprogram providers login <provider> --api-key-stdin。openprogram providers 列出已存内容。

3. 打开 Web UI

openprogram web 启动 worker 并以已登录状态打开 http://localhost:18100。总是用这种方式打开：手动输入的地址未登录，列表都是空的。用 openprogram ports --port <p> 改端口。

4. 发送消息

在终端聊天或 Web 输入框里输入，或在 shell 中：

openprogram --print "用一句话介绍你自己"
openprogram --resume <session_id>           # id 来自 openprogram sessions list 或 Web 侧栏

5. 添加 Program

release 不捆绑 agent Program。

openprogram programs install <目录、git URL 或 owner/repo>
openprogram programs list
