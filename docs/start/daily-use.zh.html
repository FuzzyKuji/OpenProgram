日常使用

入口

命令打开
openprogram终端聊天
openprogram web浏览器 http://localhost:18100，已登录
openprogram --print "…"一问一答后退出
openprogram status、restart、stop后台服务：状态、代码或配置改动后重启、停止

两个界面共用一份历史，存放在 ~/.openprogram/projects/<project-id>/chats/<session-id>/。没有项目的会话属于主项目（id 为 default，以你的主目录命名）。工作文件夹只放项目文件，不放对话仓库。

会话

命令效果
openprogram sessions list所有 agent 的所有会话
openprogram --resume <session_id>在终端继续
openprogram sessions resume回答正在等待输入的会话
openprogram sessions attach把 channel 用户（Telegram、Discord、Slack、微信）的消息路由到某会话
openprogram sessions detach回到默认路由
openprogram sessions aliases列出会话与 channel 用户的绑定

Web UI 中

历史是对话 DAG，类似 git 的提交和分支。消息操作在悬停时出现。

操作位置效果
复制全部复制内容
重新生成回复生成回复的新版本
固定为章节回复左侧消息轨上的刻度变长、变粗、变色，并保持操作行显示。取消章节移除
编辑消息你的消息修改并重新生成；文件不变
回退到这里你的消息把对话、文件或两者退回到此消息之前，并填回输入框；撤销回退可找回对话
从这里分叉你的消息从这里开启新对话，这段对话不变
控件效果
消息旁的上一个、下一个箭头编辑或重新生成后切换版本
顶栏分支菜单列出并切换分支
选中文本，添加到聊天引用消息的一部分
右上 ⋯ 的复制对话新建同样历史的对话，之后独立运行
右侧栏DAG：用户消息、LLM 调用、函数调用。随聊天滚动；点节点滚动到对应消息

涉及文件的分支在隔离的 git worktree 中运行，并行分支不会争抢同一份源码树。
