Getting started

1. Install

curl -fsSL https://openprogram.io/install | sh        # macOS, Linux
irm https://openprogram.io/install.ps1 | iex          # Windows x64 from v1.2.0, PowerShell

2. Connect a provider

CommandDoes
openprogramFirst run opens a setup wizard: import a Claude Code, Codex or Gemini CLI login, or paste an API key. Ends in the terminal chat
openprogram setupRe-runs the wizard
Key already in your environment 
export OPENAI_API_KEY=sk-...
openprogram providers discover
openprogram providers adopt env:OPENAI_API_KEY

Use the matching env:<VARIABLE> for other providers, or pipe a key to openprogram providers login <provider> --api-key-stdin. openprogram providers lists what is stored.

3. Open the Web UI

openprogram web starts the worker and opens http://localhost:18100 signed in. Always open it this way: the bare address typed by hand is not signed in and shows empty lists. Change the port with openprogram ports --port <p>.

4. Send a message

Type in the terminal chat or the Web input, or from the shell:

openprogram --print "Introduce yourself in one sentence"
openprogram --resume <session_id>                         # ids: openprogram sessions list, or the Web sidebar

5. Add programs

A release bundles no agent programs.

openprogram programs install <directory, git URL or owner/repo>
openprogram programs list
