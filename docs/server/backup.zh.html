备份与恢复

目标命令
立即快照openprogram backup create
查看已有备份openprogram backup list
查看恢复会覆盖什么openprogram backup restore <name> --dry-run
恢复openprogram backup restore <name>-y 跳过确认
只保留最新 N 个openprogram backup prune --keep 5默认 5，小于 1 被拒绝。不会自动清理

归档：~/.openprogram/backups/<profile>-<timestamp>.tar.gz。每条命令只作用于当前 profile；--profile alpha 时是 ~/.openprogram-alpha/backups/，恢复不能跨 profile。

含凭据的归档要像凭据本身一样保管。换机器时重新登录通常更安全。backup-manifest.json 只记录实际包含、脱敏或排除的类别，以及 credential_policy 下的永不备份规则，不含密钥值。

恢复

  1. 检查运行中的进程。有 worker 或 Web 服务在运行就拒绝恢复。先运行 openprogram stop。
  2. 确认。列出将被覆盖的内容，等待 y。
  3. 安全快照。当前状态存为 <profile>-pre-restore-<timestamp>.tar.gz。归档含凭据时快照也含，命令会说明。
  4. 替换归档中有的条目。缓存和日志不动。混合文件省略或脱敏的密钥字段保留本机的值。
归档与恢复的安全性
  • POSIX 使用 0600。Windows 源码 checkout 保留状态目录继承的 NTFS ACL。
  • 归档写入唯一临时文件，刷盘后原子发布；POSIX 还会刷新目录。
  • 整个归档在任何内容可见之前校验：包含关系、成员类型、每个登记密钥文件的 JSON 结构。符号链接、硬链接和路径穿越成员被拒绝，被拒绝的归档不改变任何东西。
  • 文件经 owner 专用原子写入器发布，每次发布都记日志。崩溃或磁盘满中断的恢复，在下一次恢复开始时自动回退。
  • POSIX 使用基于描述符的遍历。Windows 没有 dir_fd，在每次路径操作前校验包含关系，并拒绝符号链接、junction 和其他重解析点。
