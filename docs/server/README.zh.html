Worker 概览

控制

运行 openprogram 时，如果没有 worker 会自动在后台启动。OPENPROGRAM_NO_AUTO_WORKER=1 让终端 UI 只连接已有的 worker。

命令效果
openprogram worker start后台启动并返回
openprogram worker run前台运行，用于调试；Ctrl-C 停止
openprogram worker status、openprogram status是否运行、PID、端口、运行时长；顶层命令还显示日志路径和服务是否安装
openprogram worker stop、openprogram stop停止。已安装的服务保持停止，直到下次 start 或登录
openprogram worker restart、openprogram restart停止并重新启动，用于代码或配置变更后
openprogram web在当前终端启动并打开 http://localhost:18100
 
$ openprogram status
openprogram: running (PID 82472, port 18100, up 48m)
  logs: ~/.openprogram/worker.log

端口

优先级设置方式
1openprogram web --web-port <p>
2OPENPROGRAM_WEB_PORT
3openprogram ports --port 8101，持久化
4默认 18100

日志

命令效果
openprogram logs list所有日志、大小、最后更新
openprogram logs tail [name]-n LINES，默认 50-f 跟随最后若干行
openprogram logs path [name]绝对路径
名称文件
worker（默认）~/.openprogram/worker.log
runtime~/.openprogram/logs/runtime.log
ink-startup~/.openprogram/logs/ink-startup.log，终端 UI 启动日志

支持前缀：logs tail ink。worker 日志超过 16 MB 时在启动时轮转到 worker.log.1，最多到 .3。

登录服务

openprogram worker install 让 worker 在登录时启动、崩溃后重启；uninstall 移除。

平台服务说明
macOSlaunchd，~/Library/LaunchAgents/ai.openprogram.worker.pliststop 卸载任务，崩溃重启不会把它拉起
Linuxsystemd --user每个命名 profile 有独立 unit
Windows 源码 checkout最小权限的按用户任务计划条目一个任务 OpenProgram Worker 服务所有 profile

macOS 和 Linux 上，start、stop、restart 走已安装的服务，不会另建脱离的进程。start 和 restart 还会用当前 CLI 运行时重新生成 plist 或 unit，升级后不会继续启动旧版本。
