What openprogram doctor checks

Python, Node and git; skill and plugin loading; provider credentials; MCP servers; disk cache; whether the worker is listening on 18100.

The command shell, whether it is sandboxed, and one test command that must return UTF-8 text and its exit code (a failure is advice and blocks nothing).

On Windows, also long-path configuration and a read-only Defender performance advisory. It never changes the registry, Defender exclusions or file ACLs.

Developing from source
  • Set up with uv sync --locked --extra dev. External harness development: Installing programs.
  • Some tests skip on bare CI because they need a configured provider in $HOME, so a Mac with credentials runs more. Search for pytest.mark.skipif.
