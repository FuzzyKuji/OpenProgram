自更新验收计划

self_update(action="prepare") 接受可选的 verification_plan，包含在 owner 审批中并与不可变请求一起保存。省略时保留 HTTP-only 验收，不增加权限。

{"schema":1,"checks":[{"id":"diagnostics","assertion_id":"acceptance-1","entry":"/api/diagnostics","timeout_seconds":10,"max_output_bytes":65536}]}
字段规则
schema整数 1
checks1–32 条，每条 assertion（acceptance-1、acceptance-2 等）恰好一条
id唯一，字母、数字、下划线、连字符，以字母或数字开头，最多 64 字符
timeout_seconds整数 1–60
max_output_bytes整数 1–262144；ui:main 为 1–1572864
entry/api/commands、/api/diagnostics、/api/doctor、/healthz、/chat、已安装文档站页面（如 /docs/install/upgrade.html）、cli:version、cli:help、test:python、ui:main

所有字段必填。任意 URL、查询参数和未知字段在创建更新前被拒绝。

检查如何运行

方面规则
verifier 调用self_update_observe(check_id="diagnostics")，不传 entry 或执行参数。执行层应用批准的限制和原总期限。签名证据必须匹配 check 和 assertion。
模型任何对话模型。没有原生结构化输出时，答案仍按该阶段 schema 校验；不通过则结论 inconclusive，更新回退。请求无结果结束时，该阶段立即停止。
Job验收、诊断和修正收到相同的计划、迭代策略和本次超时。修复后的 child 保留目标、assertion、check ID、限制、模型和权限，不能刷新期限。诊断和修正只有读取工具。

cli:version、cli:help

方面规则
运行已安装 App 的 Python，-I -B -m openprogram 加 --version 或 --help，不接受模型提供的命令，也不查 PATH。
需要原生沙箱、兼容的 runtime manifest 和匹配的包与 App 构建 revision 标记。
访问私有临时目录；无网络，不写 App 或源码，不读必需 runtime 和临时路径之外的 owner HOME。
进程单进程：沙箱禁止创建进程，包括分离子进程、fork 和 posix_spawn。也适用于 test:python；不适用于源码修正测试或构建。
证据绑定 runtime 身份、调用和退出状态。非零退出、超时、取消、身份变化、输出超限或清理失败都不能通过。只证明启动和帮助。

test:python

{"id":"source-test","assertion_id":"acceptance-1","entry":"test:python","argv":["tests/verify_feature.py","expected"],"timeout_seconds":30,"max_output_bytes":65536}
方面规则
argv1–32 个字符串，每项最多 4096 字符，无 NUL。只有此 entry 需要
第一项相对候选根目录、已提交的普通 .py 文件；不能是符号链接、绝对路径、父目录跳转或解释器选项。以 ASCII 字母、数字或下划线开头，其余为字母、数字、下划线、斜杠、点、连字符，最多 511 字符
其余项预先批准的原样参数
运行方式已安装候选 Python，-I -B SCRIPT ARGS，在登记的 worktree 根目录执行。隔离模式不把根目录加入导入路径，测试需要导入候选代码时须自行处理
访问登记的候选路径即使在 HOME 下也可读且只读，其他 HOME 数据不可读。临时数据写入私有 TMPDIR 或 HOME。不安装依赖。上述 CLI 限制同样适用
证据源码缺失、变脏、未登记或脚本变化会阻止验收。记录源码 revision、脚本摘要和调用。candidate_test 结果只证明源码测试执行，不证明已安装 App 行为

安装前，候选包和回退包都须具备该协议及匹配的截图、后端和前端绑定。

方面规则
需要打包的 UI 验收描述、runtime 身份和恰好一个已连接的 Desktop 主窗口。旧包不能使用此计划。
输出verifier 收到图片和树，不是路径。上限覆盖包含 base64 数据的整个截图 JSON。PNG 为非交错 8-bit RGB 或 RGBA，每边最多 16384，总像素最多 3200 万。
模型必须声明图片输入。准备阶段拒绝纯文本模型；重启恢复和已排队 Job 运行前再查；能力丢失时记录错误，不改用纯文本。
绑定活动 Job、候选 revision、worker、会话路由和主窗口连接。
失败条件过期、取消、重放或不匹配的请求，用户输入、导航、窗口变化、截图资源冲突、输出超限或清理不完整。
不允许任意 URL、JavaScript、目标窗口、点击、导航、数据修改或其他副作用。
截图期间该窗口的新网络请求、原生 IPC 和外部导航被拒绝。带标记的 HTTP 请求被后端拒绝，包括认证 bootstrap 和过期标记。其 WebSocket 只接受观察回执和取消确切的 verifier Job。
释放证据上传前释放，失败时也释放。不影响其他窗口和已在执行的请求。
滚动截图显示滚动后状态；证据记录前、后和恢复后的位置。成功前恢复位置，不持久化。失败时在目标和期限有效时恢复自己的滚动；用户中断时取消且不恢复。目标变化或恢复失败不能通过。在边界位置不变，仅此不证明任何事。
视图从可见的原对话开始，使用真实控件，截图，成功前恢复对话和滚动。开始时已选中 DAG、控件缺失或被替换、中断或恢复失败不能通过。session 不切换，不能证明切换。
视图状态不持久化，后台标签更新也不保存。中断时保留用户的选择。恢复失败时可能停留在请求的视图，并报告失败。
证明范围只支持对所捕获状态的断言；未观察到的交互仍为 inconclusive。HTTP 响应（包括 /chat HTML）不证明实际渲染。
