openprogram upgrade in a source checkout

Validates a Git target, updates dependencies and built assets only when their sources changed, probes the new checkout, and restarts the worker only after the probe succeeds. openprogram update (--check, --force) is a separate leftover that currently raises ImportError; upgrade is the update command.

openprogram upgrade --check
openprogram upgrade --dry-run
openprogram upgrade

macOS signing and public releases
ModeWhat happens
Local iterationscripts/refresh-local-app.sh uses a persistent local certificate and sends nothing to Apple. Keep its signing state outside the repository; do not delete it to fix a permission prompt.
Public releaseThe Release workflow runs for a v* tag or manually for an existing immutable tag. It signs the App and native components with Developer ID, waits for notarization, staples and validates tickets, runs the packaged-runtime checks, then publishes checksummed artifacts. Branch pushes do not trigger it.
  • Repository Secrets: MAC_CSC_LINK (base64 encrypted PKCS#12), MAC_CSC_KEY_PASSWORD, APPLE_ID, APPLE_APP_SPECIFIC_PASSWORD, APPLE_TEAM_ID. Repository variable: MAC_SIGNING_IDENTITY. Keep them in GitHub settings, never in source. CI imports them into a temporary keychain removed when signing exits.
  • Rebuild a reviewed tag with Release → Run workflow or gh workflow run release.yml -f tag=vX.Y.Z. Tag, package versions and release notes must agree.
  • Do not recreate a certificate or app password per release. If one expires or is revoked, update its Secret and retry.
  • The submission ID is in the signing job log. In Progress: Apple is not done. Accepted: publication allowed. Anything else stops publication. The 45-minute wait timeout does not cancel the submission.
  • Inspect with xcrun notarytool info SUBMISSION_ID --keychain-profile PROFILE and xcrun notarytool log SUBMISSION_ID --keychain-profile PROFILE. After fixing the cause, rerun the failed workflow for the same tag; a new build may create a new submission.
  • A Developer ID App has a different identity, and local refresh refuses to overwrite it. Switching modes can require fresh macOS permission consent. Agent bypass settings do not control macOS permissions.
