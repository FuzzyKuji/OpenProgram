http://localhost:18200
启动openprogram webopenprogram --profile dev web
查看openprogram statusopenprogram --profile dev status
登录服务openprogram worker installopenprogram --profile dev worker install

实例之间不共享数据。每个 profile 有自己的登录服务，worker start、stop、restart、status、uninstall 只作用于当前 profile，停止或升级 dev 不影响默认 worker。

选择 profile 或端口的其他方式
方式示例
全局参数，放在子命令前；优先于环境变量openprogram --profile dev sessions list
openprogram --profile dev worker restart
用环境变量选 profileOPENPROGRAM_PROFILE=dev openprogram
本次运行的端口OPENPROGRAM_WEB_PORT=18200 openprogram web
仅这一次 openprogram web 的端口openprogram web --web-port 18200
