macOS

  1. 打开 DMG，把 OpenProgram 拖到 Applications。
  2. 从 Applications 打开。
问题答案
Apple 芯片还是 Intel？苹果菜单 → 关于本机。"芯片：Apple M…" 是 Apple 芯片；"处理器：… Intel …" 是 Intel。终端安装会自动识别。
没有管理员密码把 App 拖到自己主目录下的 Applications：mkdir -p ~/Applications。之后更新也放在这里。终端安装不需要管理员。
文件名以 -unsigned 结尾先打开一次 App，再到系统设置 → 隐私与安全性 → 仍要打开。

Linux

v1.1.0 起适用。uname -m 告诉你该选哪个文件：x86_64 或 aarch64。

deb：Ubuntu、DebianAppImage：其他 glibc 系统
安装sudo apt install ./OpenProgram-X.Y.Z-linux-amd64.deb
Arm 上把 amd64 换成 arm64		chmod +x OpenProgram-X.Y.Z-linux-x86_64.AppImage
Arm 上把 x86_64 换成 arm64
启动应用菜单，或 openprogram-desktop./OpenProgram-X.Y.Z-linux-x86_64.AppImage
依赖apt 全部装好fuse3 和下面的库
 
# AppImage on Ubuntu 22.04, Debian 12
sudo apt install fuse3 libgtk-3-0 libnotify4 libnss3 libxss1 libxtst6 xdg-utils \
  libatspi2.0-0 libsecret-1-0 libgbm1 libasound2 libcurl4

# AppImage on Ubuntu 24.04 or newer, Debian 13 or newer
sudo apt install fuse3 libgtk-3-0t64 libnotify4 libnss3 libxss1 libxtst6 xdg-utils \
  libatspi2.0-0t64 libsecret-1-0 libgbm1 libasound2t64 libcurl4t64

# Without FUSE
APPIMAGE_EXTRACT_AND_RUN=1 ./OpenProgram-X.Y.Z-linux-x86_64.AppImage

Ubuntu 24.04 及更新版本上，只有 deb 会配置 Chromium 需要的沙箱规则；AppImage 在这些系统上启动时没有 Chromium 沙箱，建议用 deb。两者都可选装 bubblewrap，用于沙箱内执行命令。终端安装发现缺库时会打印对应的 apt 命令。不支持 Alpine 等 musl 系统。

Windows

  1. v1.2.0 起，从最新版本下载 OpenProgram-X.Y.Z-win-x64.exe。
  2. 运行它。只安装给当前账户，不需要管理员。
Windows 提示怎么做
Windows 已保护你的电脑，文件名以 -unsigned.exe 结尾更多信息 → 仍要运行
被智能应用控制阻止Windows 不提供单个应用的例外。改用终端安装；如果 Windows 也拦下它，只能到 Windows 安全中心 → 应用和浏览器控制关闭智能应用控制。

在命令提示符里：curl -fsSL https://openprogram.io/install.cmd -o install.cmd && install.cmd

安装器做了什么
  • 短脚本查到最新稳定 GitHub Release，确认它有这个系统的安装包，再运行该版本 tag 上的安装器。
  • 打印大小，先检查磁盘空间，显示进度，下载中断后下次运行接着下。
  • macOS、Linux：安装到 ~/.openprogram/runtime/cli/releases/<version>，创建 ~/.local/bin/openprogram，并在 shell 配置文件里加一行带标记的内容，把该目录放进 PATH。
  • Windows：安装到 %USERPROFILE%\.openprogram\runtime\cli\releases，创建 %LOCALAPPDATA%\OpenProgram\bin\openprogram.cmd，并把该目录加入用户 PATH。默认的脚本策略不变。
  • 由每用户锁串行化。不解析产品依赖，不克隆仓库，不构建 JavaScript。
  • 切换 current 前依次验证架构匹配的 manifest 和内置 Ink TUI，再验证 Web、provider、MCP、memory、channel、search、Ink 和 Chromium，然后冷启动 worker，在系统分配的回环端口上检查健康状态。激活与失败。
  • openprogram doctor 报告还缺什么，比如 provider 凭据。

一个版本包含什么

项目说明
包含托管 CPython、OpenProgram、预构建 Web UI、私有 Node.js、编译好的 Ink 应用、provider、channel、search、Playwright Chromium；Desktop 另加 Electron。每个版本都包含相同的 product runtime，只有启动外壳不同。
不含product runtime 明确不含 PyTorch、OpenCV 和 EasyOCR，不捆绑任何 Program。
不需要系统 Python、Node.js、npm
Gitv1.1.0 起自带。v1.0.0 需要自行安装，用于会话和 Memory 历史；由 openprogram doctor 检查。

Program 用 openprogram programs install 添加（安装程序），存放在只读 runtime 之外。

开发者附加项

可编辑的 Program 源码、诊断工具、本地前端构建，以及替换 OCR 或浏览器后端。只有用到 runtime 未包含的库的 GUI 感知路径才需要替换，且不改变 runtime manifest。

开发 checkout

给贡献者用，v1.2.0 之前的 Windows 也用它。不定义 stable 通道。

平台命令
macOS、Linuxgit clone https://github.com/FuzzyKuji/OpenProgram.git
cd OpenProgram
./scripts/install.sh
Windows PowerShellgit clone https://github.com/FuzzyKuji/OpenProgram.git
Set-Location OpenProgram
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -Yes
Windows 开发安装器
  • 创建隔离的 .venv，按 npm lockfile 安装前端 workspace，构建浏览器 UI 和完整 Ink 终端 UI，并安装可选的 Browser 和 Channel 依赖。
  • 缺少的 Python 和 Node.js 通过 winget 安装。
  • 在 %LOCALAPPDATA%\OpenProgram\bin 下创建 openprogram.cmd，并把该目录加入用户 PATH，新的 PowerShell 无需激活环境。
  • 需要 Node.js 22.12 或更高；验证过的主版本是 Node.js 22 LTS。-Minimal 只装 Python CLI 和服务器，不安装也不构建前端依赖。
  • 安装可编辑的 CLI、服务器源码和浏览器 UI。Windows Desktop 由 Desktop workspace 的 dist:win 命令单独打包。
  • release 和开发安装都包含 Ink 终端 UI，并以 Python Rich 界面作为能力回退。
  • Windows 沙箱可选：缺少 WSL2 和 bubblewrap 时，auto 让原生命令继续可用；显式 workspace-write 策略要求该后端。

移除

安装方式删除
macOS AppOpenProgram.app
Windows App在已安装的应用中卸载
Linux debsudo apt remove openprogram-desktop
Linux AppImage.AppImage 文件
macOS、Linux 终端安装~/.local/bin/openprogram 和 ~/.openprogram/runtime/cli
Windows 终端安装%LOCALAPPDATA%\OpenProgram\bin 和 %USERPROFILE%\.openprogram\runtime\cli
用户数据备份后显式清除 ~/.openprogram

~/.openprogram 存放配置、会话、日志、Program 和缓存。替换或移除应用不会删除它。
