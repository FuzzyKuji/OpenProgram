Read and edit Memory

Open History → Memory and select a topic. Documents and Core source records open in Preview; Edit changes the Markdown. There are no save controls.

AspectBehaviour
SavingEach edit goes to this browser's draft storage and is queued for file persistence. Writes are serialized, so an earlier response cannot overwrite newer typing.
UndoCmd+Z or Ctrl+Z. Redo: Cmd+Shift+Z, Ctrl+Shift+Z or Ctrl+Y. Autosave keeps undo history while the app stays open.
Conflict or rejectionThe draft stays and the error shows. Review latest compares saved text with the draft in History; Replace latest with this draft retries against that version. A further concurrent change is still rejected.

A write that fails its checks changes neither files nor history.

History lists revisions newest first with local time; selecting one shows added and removed lines. Restore this version records the current state, then the restoration as a new commit, so it can be reversed. It keeps valid source references and refuses to break links from other Memory documents.

Format checks

Every Topic paragraph ends in a footnote citing its chat message: [keyword](/s/<session>#<message>). Memory keeps no copy of the conversation.

FootnoteResult
Missing on a substantive paragraphINVALID_TOPIC_FORMAT before any write; a rejected batch commits nothing
New citation of a message the chat does not hold, or one not a person's or the assistant's words, such as a tool resultSame
Definition written twice, or left behind by a moved or deleted paragraphRemoved, not rejected

The background writer runs these checks after every file it changes and fixes breaks before its turn ends.

Clicking a footnote shows the message with the turns around it, and Open original session jumps there. If the session was deleted the view says Original session deleted and the memory remains. Archiving hides a session, keeps content and links, and never deletes it by age or capacity.

Workspaces with a sources folder

On first use, an older workspace's sources/ footnotes are rewritten to chat links and the folder is removed, in one commit, memory: cite chats directly. Git history keeps the old copy.
