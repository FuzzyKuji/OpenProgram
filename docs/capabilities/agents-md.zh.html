用 AGENTS.md 写指令

每个 Agent 都会读取。只给某个 Agent 用的指令，写在其高级页的系统提示词（配置 Agent）。

文件作用范围读取时机
~/.openprogram/AGENTS.md所有项目每轮最先
项目根（包含 .git 的文件夹）的 AGENTS.md这个项目每轮其次
从项目根到工作目录各级的 AGENTS.md该文件夹及其下每轮按序
比工作目录更深或在另一个项目里的 AGENTS.md该文件夹及其下首次在那里读、写或编辑时；附在那次工具结果后，每个对话一次

后面的文件离工作更近，冲突时以它为准。项目根以上的文件夹不读。没有 .git 时只读工作目录自身的文件。工作目录是对话的项目文件夹或 worktree，否则是 OPENPROGRAM_WORKDIR 或 ~/.openprogram/config.json 的 default_workdir。

限制行为
全局和项目文件每轮共 32 KB超出时最深的文件被截断，提示词里标出截断处
看起来像提示词注入的内容仍会加入，前面带警告

查看哪些文件生效

Agents → 高级 → AGENTS.md 列出工作目录、全局文件路径（尚未创建时也显示）和下一轮读取的每个项目文件。用复制路径在编辑器里打开。

以前每个 Agent 的工作区文件

~/.openprogram/agents/<id>/workspace/ 下的 AGENTS.md、SOUL.md、USER.md 和 TOOLS.md 不再读取。worker 启动时，未改过的模板被删除；改过的文件追加到该 Agent 的系统提示词（标题 ## From workspace <file>），并移到 workspace/.retired/。
