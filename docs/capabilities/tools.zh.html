由模型发布生成的文档
  • write(file_path="/absolute/final.docx", source_path="/absolute/staged.docx") 发布单独的临时结果，用于 Word、PowerPoint、PDF、图片等二进制文件。source_path 和 content 互斥；来源是不超过 64 MiB 的普通本地文件。已存在的目标要先读取；二进制读取返回元数据并建立同样的新鲜度检查。
  • 在该轮文件历史里记录完整的前后字节，重新打开和重启后仍在。撤销和重做拒绝覆盖之后的冲突修改。新文件也能撤销。不需要 Git 仓库。本地生成器用同一接口。
  • 之后的历史提交失败时保留之前发布的版本。写入中断时报告结果未确认并阻止精确恢复。历史损坏时阻止继续记录，不用空记录替换。首次失败后先重新读取再试。版本遵循该轮的保留策略。
  • 二进制版本保留格式和媒体；Review 不比较版式，也不显示 Word 修订。Shell 直接覆盖最终文件不被记录，未记录的版本无法从卡片或输出重建：写单独结果再发布。
手动编辑和历史
  • 项目文件的编辑独立于对话保留前后字节。每次成功写入立即发布。同一编辑器的修改最多合并五分钟；关闭合并或中间有外部修改就开始新版本。
  • History 列出保留的版本，可恢复所选版本，检查当前修订后创建新条目。
  • 保存失败或外部修改时，草稿保留用于重试、导出或明确放弃。关闭文件等待未完成的修改；保存失败时标签保持打开。
  • History 合并项目相对路径文件的手动编辑和已确认的模型修改。模型条目从原会话检查点读取保留的字节，不另存归档。恢复只改动这个文件。
  • 归档会话保留文件历史；永久删除后其模型版本不可用；手动历史独立。
  • 较早的历史分批索引：继续加载历史。不完整或无法验证的会明确标注。旧路径只有能确定项目归属时才列入。
  • 项目移动后历史跟随，磁盘断开时仍可读；写入和恢复需要可用位置。
  • 文档 API 接受最多 64 MiB 的二进制内容，这本身不提供各种格式的编辑器。
  • PDF、PSD、TIFF 解码器最多接受 64 MiB，限制渲染尺寸，都在本地，打开对应格式时才加载。预览历史版本用其保留的字节。
Office 编辑（ONLYOFFICE）
  • 内置应用 office_editor，所有 Office 格式共用的可选本地安装，不随默认 App 和 runtime。在应用页禁用时，文件只提供下载，什么都不安装。
  • 没有组件时显示安装或取消，选择前不下载。约 699 MiB，含资源、字体、许可和源材料。文件在本地处理。
  • 选择完整版本前验证固定的压缩包和所有资源。失败可重试，已有安装保留。成功后无需重启即打开文档。取消保留下载，安装选项可重新选择。
  • 远程应用访问下不可用。查看 PDF 不需要它。
  • 居中状态显示准备和打开进度。启动时关闭会取消；失败提供重试。
  • 原生编辑器可写后开始编辑，自动保存。标签、分栏和 History 保留编辑器及撤销历史。关闭等待未完成的输入；写入失败时保留文档以便重试。
  • 历史预览只读，恢复创建新版本。没有语义化 Office 修订。编辑器无法加载时仍可下载。
图片编辑限制

最多 64 MiB、1600 万像素、每边 16,384 像素。通过文档历史控制器保存；预览、History、标签和路由保留撤销重做。发布失败保留草稿；关闭等待导出。导出的是渲染像素，嵌入的元数据可能不保留。

执行

工具作用
bash运行 shell 命令，返回输出和退出码。等待结束后仍在运行就作为会话继续。
write_stdin等待该会话的更多输出、中断它或向它输入
execute_code在全新的隔离子进程运行 Python。返回 stdout、stderr、退出码。退出码 0 才算成功；非零或超时是错误，部分输出保留。

持续运行的命令

bash 最多等 yield_time_ms（最小 250，默认和最大 30000），然后返回 Process exited with code N 或 Process running with session ID <id> 和已有输出。不需要单独的启动步骤。

write_stdin 的 chars效果yield_time_ms
空返回新输出，结束后返回退出码5000–300000，默认 5000
"\u0003"中断，相当于 Ctrl-C默认 250
其他原样输入；用 "\n" 结束一行250–30000，默认 250
限制、通知和审批
  • 输入需要 bash(..., tty=true)（伪终端，macOS 或 Linux 本地后端）。否则 stdin 关闭，等输入的命令会结束，只接受中断。
  • 每次调用最多保留 1 MiB 输出：过长时保留首尾各一半。
  • 后台命令结束而没人看到时，对话收到一个通知轮次，含命令、退出码和最后输出，排在进行中的轮次之后。你自己停止的不通知。
  • 显示在资源的 Terminal 下的 Background terminal，可查看输出和停止，也在 Activity 里。记录和输出在结束或状态变未知一天后删除。
  • 每个对话最多 64 个。再启动会停掉最久未用的，绝不停最近用的八个，结果会点名。取消轮次会停掉第一次等待中的命令，已在后台的继续运行。
  • 轮询和中断从不询问。输入和 bash 一样遵循权限模式。

workdir

每次 bash 调用是新 shell：bash(command="npm test", workdir="apps/web")。cd 和 export 不延续。它不改变 worktree 绑定或文件工具的基准，也不是桌面终端（那是 terminal_use）。

路径规则
  • 相对路径从绑定的 worktree 解析，没有绑定时从宿主进程目录。绝对路径可用。按字面处理：不展开 ~、变量或表达式。省略时用原默认值。
  • 不存在、不是目录或被拒绝时不运行，不创建也不回退。
  • 选择目录不授予访问。本地沙箱策略下必须满足工作区策略，包括符号链接和额外授权根，执行仍在原边界内。配置了却不可用的沙箱不会被绕过。
  • SSH 和 Docker 按后端的 POSIX 路径解释。相对远程路径需要绝对 POSIX worktree 绑定。受保护的切换在目录不可用时阻止命令列表运行；Docker 不通过 -w 创建目录。宿主有沙箱策略时，显式远程 workdir 被拒绝，直到有后端原生授权。
  • 结果包含本地起始 cwd，远程路径是 requested_cwd。不代表结束目录或持久状态。
  • 这是工具调用写法；Python 导出是 AgentTool，不是 shell 函数。
