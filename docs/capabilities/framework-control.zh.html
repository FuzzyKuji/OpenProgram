工具操作

HTTP 操作

framework(action="describe", operation="settings")
framework(action="invoke", operation="GET /api/settings")
参数内容
path具名路径参数
query查询参数
bodyJSON
content_base64、content_type二进制端点
arguments={"offset": 50}发现结果分页；结果给出 next_offset

使用发现返回的准确 operation ID。结果包含 HTTP 状态；失败不代表修改操作可以安全重试。

WebSocket 命令

framework(action="commands")
framework(action="command", operation="rename_session",
          arguments={"session_id": "EXACT_SESSION_ID", "title": "Research"})

经过命令自身校验后，结果包含响应帧。长时间工作仍归 worker，进度和完成情况读取其执行或会话状态。文件操作保留原有的 request ID、幂等键和版本检查。

不用屏幕自动化操作窗口

framework(action="interface")
framework(action="interface", operation="tabs.list",
          arguments={"window_id": "EXACT_WINDOW_ID", "arguments": []})

目录声明了标签页、分组、分栏、侧栏、资源视图、外观、书签和 Desktop 原生命令及其参数 schema。

  • 命令指向一个已认证并连接的窗口。窗口缺失或不明确时明确失败，丢失的响应不自动重试。
  • 原生历史、下载、浏览器导入和更新控制沿用现有 Desktop 功能。浏览器窗口把仅原生能力报告为不可用。
  • 窗口呈现需要已连接的视图；后端业务操作和已安装应用的操作不需要渲染前端。
  • 未保存的文件标签页须先保存或丢弃，才能自动关闭。
  • 网页用 resource(provider="web", action="open"/"close") 创建和关闭。原生 Page 呈现命令还需要当前 web 观察结果里的 arguments.web_session_id，并保留 Page 租约、会话访问和启用工具策略。
