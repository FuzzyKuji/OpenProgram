When something changes

  • The first check records the baseline and runs nothing; changing the command starts a new baseline.
  • The run receives a diff of the output.
  • The command runs in the task's sandbox and must finish within 2 minutes. A check that fails or times out runs nothing, keeps the baseline and shows as a failed run.
  • A change found while the previous run is still going is not lost: the next check sees it again.

When a service calls

POST http://127.0.0.1:18100/hooks/<task id>
X-OpenProgram-Key: <key>

The key can also be a GitHub webhook's secret. GitHub signs with it (X-Hub-Signature-256) and the run is told the event name.

ResponseWhen
202Started
404Wrong key or unknown task
409Task is paused, or previous_run_active: its last run has not finished, so call again later
413Body over 64 KB
429Within 10 seconds of the last start

The run receives the first 8,000 characters of the body. The URL is on this computer; a service on the internet needs a tunnel or a public Web address.
