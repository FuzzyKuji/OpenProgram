Tool spec description falls back: description, then placeholder as "e.g. …", then name and type only. render_options reads only description and options. Neither reads a docstring Args: section, so legacy Args: runs but is dead text there.

Tool registration and gating options

name, description, toolset, unsafe_in, requires_approval, check_fn, available_if, defer: see function-calling design. cache and cache_ttl memoize on name and arguments. timeout stops the body after N seconds with an error result.

Fields that do not exist yet

effects, permissions, idempotent, latency_hint and cost_hint are not implemented: no consumer exists. Gating already has its own options above.
