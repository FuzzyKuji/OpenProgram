Choosing the next step

Picking the right one per task is the core skill.

MechanismWho picksUse when
Fixed-order callsPython calls sub-functions in a set orderOrder known ahead of time: draft, review, revise
Tool callingThe model, each turn, by provider-native tool use, until it answers in textOpen-ended work: the model decides which calls and how many
Next-step decisionThe model, from a text menu: decision.make(prompt, options) or agent(prompt, choices=...). The pick resolves into the next result.Routing and finite branches; options may be plain values; no provider tool use needed
