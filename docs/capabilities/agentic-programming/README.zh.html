选择下一步

按任务选对机制是核心技能。

机制谁来选适用于
固定顺序调用Python 按既定顺序调用子函数顺序事先已知：起草、评审、修改
工具调用模型每轮通过 Provider 原生工具调用选择，直到用文本回答开放式工作：由模型决定调用什么、调用多少次
下一步决策模型从文本菜单选择：decision.make(prompt, options) 或 agent(prompt, choices=...)。选择直接解析成下一步结果。路由和有限分支；选项可以是普通值；不依赖 Provider 工具调用
