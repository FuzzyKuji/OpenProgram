调整记忆

设置 → 记忆。修改立即保存，下一轮生效；只有启用 Memory 需要重启。配置键见配置键中的 memory.*。

后台写入

设置作用
写入模型写入并整理 Memory。自动：默认 Agent 的模型，没有时用最近使用的模型。
自动写入把已结束的对话变成 Topic 记录
写入频率累积约 8K、16K 或 32K token 后写入
写入后校验针对刚记录的一条事实提问，在 Memory 副本中查找，找不到就修复 Topic。默认关闭：每次写入至少多三次模型调用，每次修复再多三次。

openprogram memory status 在 verification 下报告：通过、已修复、未修复、出错的数量和最近一次。

检索

设置作用
检索方法Agent：不自动加入，模型用工具读取。关键词：BM25。语义：embedding。混合：两者合并。
混合权重关键词优先 70/30，均衡 50/50，语义优先 30/70。自动：消息含日期、引号短语或名称时偏向关键词，否则均衡。仅混合时生效。
同主题加权一个 Topic 有多段匹配时提高排名。默认开启。仅混合时生效。
检索数量每轮最多加入的记录数：3、5、8 或 10
语义和混合所需的 Embedding 模型

需要模型以及 sentence-transformers 和 PyTorch，App 不自带。Embedding 模型旁的安装会一起下载：包约 1 GB，模型约 90 MB。包装在 ~/.openprogram/extras/embedding/，App 更新后保留。

项目记忆

设置作用
项目记忆项目内的会话同时读取 ~/.openprogram/projects/<project>/memory。检索、Memory 工具和核心记忆覆盖两层，项目优先。默认开启。
写入项目记忆项目会话写入项目 Memory 而非个人 Memory。需要开启项目记忆。默认开启。
  • 项目之外的会话只读个人 Memory，即 home 项目的 ~/.openprogram/projects/default/memory。
  • 项目 Memory 写入内容后才算存在。不会写进项目自己的文件夹。History 中在其 Memory 标签页显示。
  • 两层都在时，Memory 工具在路径中标明层：project:topics/api.md。
  • 一轮只写入一层，切换写入开关不会把会话复制到另一层。移到其他项目的会话只把之后的轮次写过去，已有记录留在原处。
