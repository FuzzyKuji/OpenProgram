Language server 工具

三个工具向 language server 询问类型检查器对当前工作树的了解，无需跑测试。

工具参数回答
lsp_diagnosticsfile该文件的错误和警告
lsp_referencesfile、line、column该位置符号的每一处使用
lsp_definitionfile、line、column该符号的声明位置

file 是绝对路径。line 和 column 从 1 开始，与 read 和 traceback 显示的一致，必须指向符号本身。结果过长时停在 50 条并给出剩余数量；请缩小问题。

3 references

tests/unit/test_loop.py:31:11    monkeypatch.setattr(loop, "dispatch", fake)

lsp_definition 同样是 path:line:column 形式。路径相对于 workspace 根。

装 server

语言扩展名可执行文件安装
Python.py、.pyipyright-langservernpm install -g pyright
TypeScript / JavaScript.ts、.tsx、.js、.jsx、.mts、.ctstypescript-language-servernpm install -g typescript-language-server typescript

工具总是注册。没有 server 时回答 unavailable: install … 并给出命令。其他扩展名会得到相应说明。

Server 怎么跑

  • 每种语言每个 workspace 一个 server。workspace 是最近的含 pyproject.toml、setup.py、package.json、tsconfig.json 或 .git 的祖先目录。
  • 首次使用时启动，进程内缓存，OpenProgram 退出时关闭。
  • 配置的沙箱同样适用。sandbox.mode 默认 off，除非会话打开沙箱，server 不受限制。workspace-write 下，它读取 workspace，不向外写入。
