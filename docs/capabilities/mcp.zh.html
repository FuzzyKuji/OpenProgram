MCP

每个已连接 server 的工具在聊天中显示为 <name>__<tool>。其资源和 prompt 通过内置工具中的 mcp_meta 工具提供给模型。

openprogram mcp add drawio -- npx -y @drawio/mcp
openprogram mcp list
openprogram mcp show drawio
命令作用
openprogram mcp add NAME COMMAND…添加 stdio server，立即生效。--env KEY=VALUE（可重复）、--timeout（启动和单次调用秒数）、--disabled（只写配置不启动）。
openprogram mcp list每个 server 的状态
openprogram mcp show NAME其工具和完整 schema
openprogram mcp rm NAME停止并删除配置
openprogram mcp restart NAME停止后重新启动
openprogram mcp enable、disable NAME切换；禁用保留配置
openprogram mcp test启动临时 server，确认能返回工具列表，不写磁盘
openprogram mcp edit仅为兼容：提示原始编辑已移除，因为会暴露存储的密钥。请用 add、rm 或 MCP 设置页。

管理命令与后台 worker 通信：openprogram worker start、openprogram status。worker 启动时 server 在后台连接，App 和核心 API 不受影响。就绪前其工具不可用，mcp list 和设置页显示状态。

配置

~/.openprogram/mcp_servers.json（使用 --profile <name> 时为 ~/.openprogram-<name>/mcp_servers.json）：

{
  "servers": {
    "drawio": {
      "type": "local",
      "command": ["npx", "-y", "@drawio/mcp"],
      "env": {},
      "enabled": true,
      "timeout_seconds": 30
    },
    "linear": {
      "type": "http",
      "url": "https://mcp.linear.app/mcp",
      "auth": {"kind": "oauth", "client_name": "OpenProgram"},
      "enabled": true
    }
  }
}

传输与认证

type传输字段
localstdio 子进程command、env
httpStreamable HTTPurl、headers、auth
sse旧版 SSEurl、headers、auth
auth.kind需要
none无
bearertoken
oauthOAuth 2.1 PKCE。支持动态客户端注册的 server 无需配置，其他需要 client_id 和 client_secret。

OAuth 只需授权一次

时机行为
首次连接打开授权页，并在 localhost 捕获回调
保存令牌、客户端注册和发现的端点，存到 ~/.openprogram/mcp_tokens/<server>.json（权限 0600）
之后的连接直接复用，过期令牌静默续期
refresh token 被拒绝再次打开浏览器，管理界面显示该 server 需要重新认证
切换账号POST /api/mcp/servers/{name}/auth/clear 清除状态并重启 server

通过 MCP 提供 OpenProgram

openprogram mcp token create
export OPENPROGRAM_MCP_TOKEN="<粘贴上面打印的 token>"
openprogram mcp serve

token create 把 token 打印成一行原文，不设置环境变量。已有 token 时复用。serve 拒绝缺失或不匹配的 token。
