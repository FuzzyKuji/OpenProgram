技能

技能是模型按需加载的领域知识：一个包含 SKILL.md 的目录。

---
name: my-skill
description: 一行说明什么时候该用它——模型靠这句话做匹配。
---

正文是自由 markdown：操作步骤、规则清单、示例……

front matter 是 key: value 的 YAML 子集。较长的值可以在 >- 或 | 之后用缩进的行续写。缺少 name 或 description 的目录被跳过。模型按 description 匹配。

如何加载

  1. 启动时扫描每个技能目录下的 <slug>/SKILL.md。
  2. 所有名字和描述写进系统提示的技能块；agentic runtime 的 <available_skills> 还带每个文件的绝对路径。
  3. 任务匹配时，模型用 skill 工具加载全文。全文绝不自动注入。

技能本身不执行任何东西。旁边的脚本、参考资料和数据通过 bash 或 execute_code 使用。

在聊天中使用

输入效果
/<name>插入技能正文
/skill <name> [request]运行一轮。模型先读文件再看你的请求，对话显示你输入的内容。allowed-tools 限制该轮工具。未知、歧义或被屏蔽的名字会收到回复，不运行。

Routine

对 Agent 说“把这个存成 routine”“每周一 9 点做这个”或“以后就这样做”。save_routine 工具写入 ~/.openprogram/skills/routines/<name>/SKILL.md：

  • 一行描述，下次能认出请求；
  • 实际做过的步骤，不看原对话也能重复；
  • 你的修正，作为优先于步骤的规则。
方面行为
定时要求时，在同一对话建一个重复的唤醒 Agent 的提醒。每次以“Run the saved routine routines/<name>”开始。保存时的回复给出下次运行时间。
修正“下次去掉机器人账号”，运行中或事后都行。以同名保存会重写该技能、加入修正、保留定时；之前的修正保留。
管理普通技能：openprogram skills list、/skill <name>，也可手动编辑或删除文件。在 Scheduler 暂停或取消定时，或让 Agent 做。
谁可以只有所有者或替所有者工作的 Agent 能安排。

命令

命令效果
openprogram skills list按来源列出技能
openprogram skills doctor扫描目录问题
openprogram skills search <q>搜索发现源（默认 ClawHub）
openprogram skills install <spec>slug（ClawHub）、clawhub:<slug> 或 github:owner/repo。--source：clawhub://、GitHub 仓库或 JSON 索引。
openprogram skills update --all比较 SKILL.md 哈希并重新拉取过期的，或指定一个名字
openprogram skills remove <slug>只限项目、用户或远程缓存
