Agentic Programming编程范式：Python 控制流程，LLM 负责推理。把任务拆成函数调用图；不需要推理的节点是普通 Python，需要理解、生成或判断的节点是调用 llm(...) 的 Agent 方法。顺序、状态和重试都是可单元测试的普通代码。指南、设计理念
Agentic 工作流基于该范式的完整工作流（代码里称 harness 或 agentic program），每个都是一个 git 仓库。其函数可在聊天里作为工具触发，也可直接运行。概览、安装程序
扩展机制不写 harness 也能增加能力。见下
 
openprogram programs install <source>
openprogram programs list
openprogram programs run <name>
