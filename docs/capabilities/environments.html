A channel only decides where messages are mirrored. Binding one never moves where tools run.

Pick one for a new chat

The first chip above the message box. The choice is pinned by the first message; to work elsewhere, start a new chat. New chats and conversations older than environments use the default.

Add one

In Settings → Environments, or from the terminal. The page also has Test, Make default and Remove. openprogram setup has a Default environment step.

CommandEffect
openprogram environments add ssh devbox --target me@devbox --workdir ~/work--target is user@host or a host from ~/.ssh/config. --workdir is an absolute or ~ path; blank is the remote home.
openprogram environments add docker sandbox --image python:3.12 --defaultDefault image ubuntu:24.04. --default also makes it the default.
openprogram environments listAll, with the default marked
openprogram environments test devboxChecks it can run a command
openprogram environments default <id>Sets the default
openprogram environments rm <id>Removes it

IDs are lowercase letters, digits, - or _. --name sets a display name.

Requirements

Needs and behaviour
SSH sign-inSystem ssh with BatchMode=yes: nothing may prompt. Use a key your SSH agent or ~/.ssh/config provides. New host keys are accepted once, then checked. Connections are shared for five minutes.
SSH hostA POSIX shell, find and grep; rg when installed
Dockerdocker on the PATH and the daemon running
Docker containerOne per conversation, openprogram-<environment>-<conversation>. The first command starts it, later ones reuse it, so installed packages persist. Recreated if the conversation's folders change. Removed with the conversation.

Limits

  • A turn's undo does not cover files changed on an SSH host; files on this computer are still restored.
  • In SSH a file must be read before it is edited, and an edit is refused if it changed since that read.
  • The local sandbox applies only to Local. SSH and Docker have the permissions of the remote account or container.
  • If the environment is removed its tools stop with an error, never falling back to this computer. Add it back with the same ID, or start a new chat.
