在另一台机器上运行会话

运行环境命令在哪运行文件在哪读写
本地（始终存在）这台电脑这台电脑
SSH远程主机，从它的远程文件夹开始远程主机
Docker这个会话专属的容器这台电脑；会话的文件夹按相同路径挂载进容器

渠道只决定消息镜像到哪里，绑定渠道不会改变工具运行的位置。

为新会话选择

消息框上方的第一个按钮。第一条消息发出后固定；想换地方就开新会话。新会话和早于运行环境功能的会话使用默认环境。

按钮图标与 worker 的连接
黄色连接中或已暂停
红色已断开

添加

在设置 → 运行环境，或在终端。页面上还有测试、设为默认、删除。openprogram setup 有 Default environment 步骤。

命令作用
openprogram environments add ssh devbox --target me@devbox --workdir ~/work--target 是 user@host 或 ~/.ssh/config 里的主机名。--workdir 是绝对路径或 ~ 路径；留空为远程 home。
openprogram environments add docker sandbox --image python:3.12 --default默认镜像 ubuntu:24.04。--default 同时设为默认。
openprogram environments list列出全部并标记默认
openprogram environments test devbox检查能否运行命令
openprogram environments default <id>设为默认
openprogram environments rm <id>删除

ID 由小写字母、数字、- 或 _ 组成。--name 设置显示名称。

要求

需要与行为
SSH 登录系统 ssh 加 BatchMode=yes：不能有任何提示。使用 SSH agent 或 ~/.ssh/config 已提供的密钥。新主机密钥首次接受，之后校验。连接共享五分钟。
SSH 主机POSIX shell、find、grep；安装了 rg 时使用
Dockerdocker 在 PATH 上，daemon 正在运行
Docker 容器每个会话一个，名为 openprogram-<environment>-<conversation>。第一条命令启动，后续复用，安装的包保留。会话文件夹变化时重建，删除会话时移除。

限制

  • 一轮的撤销不覆盖 SSH 主机上改动的文件；这台电脑上的文件仍会恢复。
  • SSH 中文件必须先读取再编辑；读取后主机上有变化时，编辑被拒绝。
  • 本地沙箱只作用于本地环境。SSH 和 Docker 的权限是远程账号或容器的权限。
  • 运行环境被删除后，工具报错停止，绝不回退到这台电脑。用相同 ID 加回来，或开新会话。
