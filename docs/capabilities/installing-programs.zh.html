安装程序

发行版不捆绑程序：内置工具和应用之外的一切都这样安装。用户要求安装 agent 没有的程序时，按本页操作。

openprogram programs install https://github.com/<owner>/<repo>
openprogram programs install <owner>/<repo>
openprogram programs install ~/work/my-program
openprogram programs install file:///path/to/checkout

openprogram programs list
openprogram programs install <source> --upgrade
openprogram programs uninstall <name>

运行中的 worker 会拾取克隆；新进程在启动时加载。已安装的程序出现在能力 → Programs → Applications 下，文件夹以目录命名，内含其 Agent 入口。

来源可以是什么

来源结果
git URL（https://、ssh://、git@、file://）浅克隆到 Programs 目录，然后检查
GitHub owner/repo展开为 https://github.com/owner/repo 并克隆
本地应用目录（application.json）记录到 catalog，原地加载，不复制
本地包仓库（__init__.py 和 .git）像 git URL 一样克隆。先提交；不是 Git 仓库的目录会被拒绝。
已在 Programs 目录中的包无需安装；openprogram programs check <directory> 使其可调用

Programs 目录：~/.openprogram/programs/<name>/，命名 profile 下为 ~/.openprogram-<profile>/programs/<name>/。旧版放在 openprogram/programs/packages/ 或 openprogram/programs/applications/ 的检出，在新版 worker 首次启动时移过去，名称和来源不变。

克隆会成为什么

一个仓库可以同时是多种。都不是时会报告，不加载任何内容，也不影响其他程序。

形态判断依据结果
Package克隆根目录有 __init__.py按仓库名转成合法导入名（My-Tools → my_tools）。通过 openprogram programs check 后加载。PROGRAM_ENTRIES 和检查见 Workflow 自动化。
Applicationapplication.json记录到 catalog，见应用。--trust 授权审查过的 Python 后端；--replace 接受变化的 digest。
Harness<package>/agentics/__init__.py从 pyproject.toml/setup.py（优先）或 requirements.txt 安装它自己声明的依赖，并记录为 owner 批准的来源。下次扫描后 PROGRAM_ENTRIES 出现在聊天、Programs 页和 openprogram programs run。

升级、卸载、校验

命令作用
openprogram programs install <source> --upgradegit pull --ff-only，重新解析依赖
openprogram programs uninstall <name>目录名：把克隆移到 ~/.openprogram/programs/.removed/，可手动恢复，绝不删除。应用 id：取消注册并保留数据，兼容的重新安装可恢复。
openprogram programs list [--json]所有 Program 及状态，含 harness
OPENPROGRAM_DEBUG_REGISTRY=1 openprogram programs list显示损坏的 harness 为何没加载。PowerShell：$env:OPENPROGRAM_DEBUG_REGISTRY=1; openprogram programs list
openprogram programs run <fn> -a key=value运行函数；聊天中同样可调用

同名的开发符号链接：install 校验 harness 契约并记录链接，不改动目标。同名但不是 git 克隆的目录被拒绝。对符号链接 uninstall 只移动链接。

没有 GitHub 访问，或正在开发程序

镜像：

git clone <repo-url> /path/to/Program-Name
openprogram programs install file:///path/to/Program-Name

命令把来源克隆到 Programs 目录并记录；只有已记录且满足契约的目录才加载。

你自己的检出：安装后添加为远程，再 git pull work main。拉取的提交在下次重启生效。

openprogram programs install file:///path/to/your/Program-Checkout
cd ~/.openprogram/programs/Program-Checkout && git remote add work /path/to/your/Program-Checkout
平台说明
  • CLI 和服务器 release 运行在 macOS、Linux 上，v1.2.0 起也运行在 Windows x64 上，Windows App 同样从 v1.2.0 起提供。Windows 上的沙箱命令可选用 WSL2 加 bubblewrap。
  • 不需要符号链接：安装器记录真实检出。
  • 程序自身代码可以限定平台，请查看其 README 和依赖。
  • OpenProgram 的工具都是 UTF-8 且基于 os.path，程序也应如此。

故障排查

症状处理
重启后没有 harness 函数确认 <pkg>/agentics/__init__.py 存在并导出 PROGRAM_ENTRIES。用 OPENPROGRAM_DEBUG_REGISTRY=1 运行。
[!] … neither a package (__init__.py), an application (application.json) nor a harness仓库不符合这三种形态
harness 依赖 ModuleNotFoundError依赖安装失败。重新运行 openprogram programs install <source> --upgrade 并查看错误。
harness 内 from <pkg>.x import y 失败包文件夹名必须等于导入名，并有 __init__.py
已有开发符号链接没加载运行一次 openprogram programs install <git-source> 校验并记录
Windows 上安装或运行失败查看程序的 README 和依赖标记；它可能只提供 macOS/Linux 后端

编写可安装的 harness

<Harness-Name>/                仓库，名称不限
├── pyproject.toml             只声明 harness 自己的依赖
└── <package>/                 可导入的包，ascii 名称
    ├── __init__.py            保持轻依赖
    └── agentics/
        └── __init__.py        PROGRAM_ENTRIES = [...]

启动时 OpenProgram 导入 <package>.agentics 并注册 PROGRAM_ENTRIES。根目录可附带其他包：发现机制找到含 agentics/ 的包，并把根目录加入 sys.path，from <package>.foo import bar 可解析。

# <package>/agentics/__init__.py
from openprogram import Agent


class ExampleAgent(Agent):
    method_options = {
        'my_tool': {'tool': True},
    }

    def my_tool(self, text: str = "") -> str:
        "One line: what this does (shown in catalogs)."
        return text.upper()


_example_agent = ExampleAgent()
my_tool = _example_agent.my_tool

PROGRAM_ENTRIES = [my_tool]
# pyproject.toml
[project]
name = "my-harness"
version = "0.1.0"
requires-python = ">=3.10"
dependencies = []          # 只写 harness 自己的依赖，绝不写 openprogram

两条硬性规则

  1. 绝不把 openprogram 声明为依赖，pyproject.toml 和 requirements.txt 都不行。openprogram @ git+… 会让 pip 从 git 重装宿主，覆盖用户的安装。
  2. 保持 <package>/__init__.py 轻依赖，并保护重导入。 发现机制每次启动都导入 <package>.agentics，包括没装可选依赖的机器。顶层导入 cv2 或 torch 会破坏整个注册表加载。放到函数体内导入，并保护入口：
# agentics/__init__.py
try:
    from my_package.main import my_tool
    PROGRAM_ENTRIES = [my_tool]
except ImportError:
    PROGRAM_ENTRIES = []
