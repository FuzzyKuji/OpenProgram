会议

录制你参加的通话（Zoom、Teams、浏览器或其他应用），得到转写稿和包含决定、行动项、待解决问题的摘要。

第一次开会之前

需要原因
macOS 13 或更高版本上的 OpenProgram通过 ScreenCaptureKit 录制电脑声音。其他系统只录麦克风。
ffmpeg转换音频用于识别。brew install ffmpeg 或用包管理器，然后重启。缺失时窗口会提示。
语音引擎在设置 → 语音中选择，与语音输入共用：OpenAI 或 Groq（需 API key），或本地 whisper.cpp
聊天模型默认 Agent 写摘要，使用新对话的模型
可选：meetings extra区分其他说话人，见谁说了什么

录一场会议

  1. 从新标签页磁贴打开会议，或在应用页点打开。
  2. 可选：填写名称并选择语言（默认自动识别，记住上次选择）。按开始录制。
  3. 首次：允许窗口请求的麦克风，以及 macOS 为 OpenProgram App 请求的录屏与系统录音。不录制屏幕内容。
  4. 窗口显示已录时长和已上传、已转写的分段数。可以切到其他标签页或窗口。
  5. 按停止录制。转写最后的分段、写摘要，会议出现在过往会议。

录制不会自行开始。不戴耳机时麦克风会听到对方；重复电脑声音的行会被丢弃，但耳机的转写最干净。设置 → 语音的语言只影响语音输入。未选语言时每段单独识别，录制卡片和过往会议显示所选语言或“检测”。

如果处理
拒绝了麦克风隐私与安全性 → 麦克风：允许 OpenProgram，重新开始
无法录制电脑声音只录麦克风并提示。若缺权限，在隐私与安全性 → 录屏与系统录音中允许 OpenProgram 并重新打开 App。没录到的历史会议在转写稿下注明。

存储

~/.openprogram/meetings/<id>/
  meta.json          名称、开始时间、时长、进度、摘要会话、
                     是否录到电脑声音、是否区分了说话人
  tracks/mic/…       麦克风，30 秒 WebM 分段
  tracks/system/…    电脑声音，30 秒 WAV 分段
  transcript.json    合并后的转写稿
  summary.md         摘要，末尾附完整转写稿

位于状态目录下，默认 ~/.openprogram。OpenAI 或 Groq：每段发送给该服务。whisper.cpp：音频留在本机。区分说话人始终在本机进行。

限制

  • 同时只能录一场，最长 4 小时，到时自动停止。
  • 只在停止后区分说话人。声音相近的人可能共用编号；同一人声音变化大时可能有两个编号。
  • 静音分段跳过。无法转换或转写的分段在转写稿下报告，其余继续。

关闭会议

应用页的开关，或 openprogram programs disable meeting，会停止正在进行的录制。openprogram programs enable meeting 重新开启。见应用。
