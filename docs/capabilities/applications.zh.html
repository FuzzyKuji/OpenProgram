从新标签页打开应用

应用是带自己界面的 Program：标准 HTML、CSS 和 JavaScript，可选 Python 操作作后端。它出现在文件、新对话、浏览器和终端旁边；点击在标签页打开，再次打开选中同一实例，关闭标签页不取消它的操作。

在哪里看到

位置显示
侧栏的 Applications（应用）所有应用的图标、标题、版本、作用域和描述。筛选全部、内置、已安装。每行：有窗口时打开、启用开关、⋯ 菜单（在能力中显示、从新标签页隐藏或在新标签页显示、从来源更新、卸载）。安装… 打开安装表单。
能力 → Programs纯文件夹视图，每个应用目录一个文件夹，按名称排序（browser、calculator、auto_research），里面是真实子文件夹和源文件。Applications 下是应用和没有界面的已安装程序，Tools 下是内置工具。
在那里选中应用相同的图标、标题和描述，目录名、类型、版本；打开，单一 Agent 入口时有在对话中使用；启用开关；Agent 入口及说明；位置、窗口和权限。调用逻辑折叠在底部。工具显示参数；源文件直接显示调用逻辑。
这些视图的细节
  • 卸载先询问，并保留应用数据。从来源更新显示来源目录并打开预填的安装表单，提交前请审查来源。
  • 安装表单要求对 Python 后端和 files.project.write 明确信任。
  • 已安装包内的应用是该包的子文件夹，如 auto_research/app。它的调用逻辑是其注册的 Agent 入口的并集。
  • Agent 不能调用的应用用一行说明：纯界面应用只作为窗口打开；只导出 Python 函数给其他 Program 的包是 Python 库。
  • 新标签页在获得焦点时和每十秒刷新应用列表。

安装与打开

命令作用
openprogram programs install /absolute/path/to/application记录目录，应用从原处加载，目录不要移动。需要 worker 在运行。
… --trust授权 Python 后端和 files.project.write。先审查源码和依赖。
openprogram programs install owner/repo --trustgit URL 或 GitHub owner/repo 克隆到 ~/.openprogram/programs/<name>/ 并记录
openprogram programs listid、状态（enabled、disabled、error）、目录、Agent 入口及层级（应用入口为 deferred）。不需要 worker。--json 每行带 tiers 映射。
openprogram programs check DIRECTORY校验 manifest、包结构和声明的后端操作，不记录
openprogram programs disable ID移除界面、资源、服务和 Agent 入口，取消活动操作。保存在 catalog.json，重启后保持。
openprogram programs enable ID重新加载
openprogram programs uninstall local.notes移除入口并取消操作，保留数据和 schema/作用域身份。兼容的重新安装恢复数据；不兼容的在激活前拒绝。

Python 后端以你的操作系统账号运行受信任的本地代码。files.project.write 允许它在绑定项目里创建和替换文件。直接放在 ~/.openprogram/programs/ 的目录不用 install：worker 下次扫描时记录；需要信任的显示为 needs trust，直到用 --trust 安装。

存放位置内容
~/.openprogram/programs/<name>/ 或任何地方应用目录
~/.openprogram/programs/catalog.json来源目录、启用、隐藏和显示标题；不复制内容
~/.openprogram/programs/.runtime/业务数据、运行记录、Python 环境
内置应用作用禁用后失去
browsercomputer_use_agent 操作的内置浏览器浏览器目标；桌面目标照常工作
workflow_recording录制 Workflow；其窗口不经输入框就能开始录制输入框的录制 Workflow 和相关路由
office_editor（ONLYOFFICE）在文件窗口打开 Word、Excel 和 PowerPoint；其窗口在当前项目顶层新建空白文件并列出已有 Office 文档这些文件只提供原文件下载
meeting会议：录制通话、转写，在新对话中总结会议

browser、office_editor、workflow_recording 和 meeting 也可 enable、disable，效果与启用开关相同。工具（bash、read、goal …）始终提供给 Agent，不能禁用。来自 Claude Code、Codex、OpenCode 或 Hermes、带工具或界面的包按应用安装：加一个 application.json，见插件。

作用域实例
全局当前 owner 共用一个实例
项目每个项目一个，业务数据分开。打开时使用选中的项目；更改会话项目不会重新绑定。没有当前项目时，单个已保存绑定直接复用；首次使用或多个绑定时打开选择器，也可选新文件夹。

示例：计算器、PDF 编辑器（读取、批注和整理项目里的 PDF，只在你要求摘要时使用模型）

应用包

{
  "id": "local.notes",
  "title": "Notes",
  "description": "Keeps notes per project and summarises them on request.",
  "icon": "notebook-pen",
  "version": "1.0.0",
  "scope": "global",
  "dataSchema": 1,
  "ui": {"root": "ui", "entry": "index.html"},
  "capabilities": ["storage.app", "model.invoke"],
  "backend": {"kind": "python", "entry": "backend:operations"},
  "operations": {
    "summarize": {
      "agent": true,
      "input": {"type": "object"},
      "output": {"type": "string"}
    }
  }
}
字段规则
application.json放在包根目录
title、description显示在新标签页、应用页和能力页。描述写成一句平实的话、一行、最多 300 字符。没有 application.json 的 Program 用 README.md 的第一个 # 标题 和下面第一句，或目录名。
icon这些页面和标签页上的图标。其他名称或不填时，显示按 id 取色的通用方块。
ui.root、ui.entryroot 相对于包，entry 相对于 root。Python 和私密配置放在 ui.root 之外。
backend导出可调用对象的字典，接收 (input, context)，同步或异步返回 JSON
backend.dependencies精确版本，如 ["package-name==1.2.3"]。每组依赖一个 Python 环境，首次使用时创建，也使用已安装的宿主框架。
operations输入输出为 JSON Schema。只有 agent: true 能通过 Program 客户端调用。
图标名称

calculator、book-open、file-search、file-text、file-pdf、telescope、notebook-pen、table、chart-column、database、image、music、video、map、calendar、globe、code、terminal、mail、message-square、list-checks、languages、pen-tool、palette、sigma、flask-conical、briefcase、bot、sparkles

能力授予后端
storage.appcontext.load() 和 context.save()：实例自己的已保存状态
model.invoke供 llm() 和 agent() 使用的环境 Runtime
files.project.read绑定项目内的 context.read_file(relative_path)
files.project.write绑定项目内的 context.write_file(relative_path, content)；需要 Python 后端和 --trust

能力限制的是宿主桥，不是受信任 Python 的操作系统权限。后端注册前在独立进程中检查；仅列出应用不会导入其代码。

沙箱
  • Web 界面运行在 opaque origin 的沙箱 iframe 里，不必使用 OpenProgram 组件。
  • 前端依赖打包在本地，资源 URL 用相对路径，包括 JavaScript 模块导入。
  • 阻止：远程脚本、直接访问 owner API、嵌套 frame 和表单导航。
  • 资源 URL 只授权读取该应用打开时那个 digest 的界面目录，不是 owner 凭证。

浏览器与 Python API

window.openprogramApp作用
load()返回 {value, version}
save(value, version)仅当版本仍是当前版本时保存；并发写入报错后重新加载
run(operation, input, requestKey)返回持久运行记录。重试时复用 key；同一 key 配不同输入会被拒绝。
runs()最近的运行
status(id, after)状态、结果、错误、待回答问题、游标之后的事件
cancel(id)取消执行
answer(id, requestId, answer)回答当前问题

其他实例的运行无法通过此桥访问。

Python context作用
load()、save(value, expected_version=...)实例状态
progress(value)报告进度
ask(question)应用的提问。需要预声明持久等待的 Runtime workflow 交互仍按原要求。
read_file(relative_path)需要声明能力和绑定项目
write_file(relative_path, content)文本或字节。拒绝解析到项目之外的路径（含符号链接）和 .git 内路径。先写临时文件再重命名，读者不会看到部分内容。返回 path 和 bytes。

启用模型的操作可调用 llm() 和 agent()，凭证留在后端。

Program 使用同样的操作：

from openprogram.programs._authoring.application_client import run, status

job = run("local.notes", "summarize", {"text": "..."}, request_key="summary-1")
print(status(job["id"]))

持久化与生命周期

事件结果
加载计算目录的内容 digest，忽略 .git、node_modules、__pycache__、.venv
源码被编辑以新 digest 重新加载；重新打开的页面和新操作使用新内容。编辑前的页面或资源 open 被拒绝，需重新打开。运行中的操作继续。
编辑改了 dataSchema 或 scope，或在未信任时加入 Python 后端或 files.project.write停止加载，直到重新安装
安装时 schema 或作用域变化激活前拒绝。不支持自动数据迁移。
worker 停止未完成的 Python 函数在重启后报告为中断，不会恢复。保存增量进度，审查后再启动新操作。
项目被移动实例和数据不变
项目缺失、被替换或未验证阻止新操作；已保存数据可读。启动前和读取项目文件前都会解析绑定 ID。
旧注册从记录的来源加载；该目录不在时才使用 .runtime/versions/ 里的副本
限制值
状态每实例 SQLite，JSON 值 4 MiB
事件1 MiB
执行状态现有执行存储；模型调用记录由 session-node writer 写在应用运行存储下
Owner API作用
PATCH /api/applications/{id}enabled、hidden、display_title。隐藏不取消任务，禁用会取消。

未实现：独立部署、非 Python 后端适配器、MCP Apps 兼容、嵌入原生 GUI 窗口。

将应用作为资源使用

已启用的应用以 application.<id> 出现在 resource(action="describe") 中，安装、禁用、更新、卸载无需重启即生效。资源视图和顶部标签页在同一沙箱 frame 中打开同一实例。

动作行为
open项目作用域接受 project_id。把实例关联到调用的会话。返回要使用的 instance_id 和 digest；更新后旧 digest 被拒绝。
observe实例状态和最近运行
act声明的 Agent 可见操作和稳定的 request_key
status、cancel、answer运行必须属于该实例
save声明 storage.app 时使用期望的存储版本
release移除会话关联，保留实例、数据和运行中的操作。隐藏视图同样不停止操作。
Agent 入口规则
名称<id>__<operation>，字母、数字、_、- 以外的字符替换为 _：local_notes__summarize
输入操作输入放在 input，项目作用域加 project_id。等待运行并返回。等待提问的运行返回其 id，供 status、answer 或 cancel 使用。
暴露和 resource 一样需要审批。deferred：模型只看到名称，需要时用 tool_search 加载 schema。应用在会话中打开也不加载：目录注明它已打开，由模型按名字加载入口。
agent: false没有入口

窗口的 owner API：POST /api/applications/{id}/open 带 session_id 建立关联；POST /api/applications/{id}/close 带 instance_id 和 session_id 释放。
