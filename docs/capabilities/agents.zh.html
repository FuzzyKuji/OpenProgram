配置 Agent

在侧栏打开 Agents。Agent 保存一份可复用的配置，不要求对应某种专门任务。

保存和模型选择
  • 所有分区共用一份草稿，保存写入全部。切换 Agent 或执行破坏性操作时可选保存、放弃或取消。保存失败会保留草稿。
  • 其他编辑器先保存时，先比较再选择。保留草稿不会覆盖较新版本，需复核后再次保存。
  • 模型选择器读取 Provider 目录，不改变其他对话。上次使用的模型让每个对话使用你最近用过的模型。
  • 不可用的模型或不支持的思考强度会保留显示，直到你修改。缺少必需的 MCP 服务器时，在模型请求之前停止执行。

内置 Agent

保存成普通卡片的完整配置：可编辑、复制或删除。服务器启动时安装本实例从未有过的内置 Agent；删除后不会重建。没改过的内置 Agent 会自动跟上新版本；改过的保持你改的样子。

离开时继续工作，常驻开启

管家是通用的常驻 Agent：全部工具，记忆读写。告诉它要关注或持续推进什么；那个会话会在有事到期时醒来，没有安排时按检查节奏醒来，只汇报值得注意的内容。

每个都有提示词，写明职责、产出、绝不做的事、完成条件、工作方式和首个任务；只有需要的工具；记忆在自己的空间。没有固定间隔：各自安排醒来时间，没安排时按检查节奏。没有会话就不会醒来，也不产生费用。

  • 实现和评审分开，写改动的 Agent 不能自己通过。
  • 处理邮件或帖子的 Agent 止于草稿，提示词禁止发送。
  • 它们通过交接协作：每个 Agent 一个会话，标题清楚；告诉负责规划的会话谁做什么。
从 Python 调用 
from openprogram import Agent
from openprogram.runtime.agent_registry import manager

helper = Agent.from_spec(manager.get("utility"))
result = helper("Extract the city from: the event is in Singapore.")

selector = Agent.from_spec(manager.get("decision"))
selected = selector.choose("Classify this message.", {"A": "Question", "B": "Statement"})
  • choose() 返回所选 ID，使用当前 Context 和 DAG，禁用工具和网页搜索，不重复询问。无效答案抛 DecisionError。模型和推理由调用方配置。__call__() 仍可用。
  • openprogram.runtime.agent_registry.builtin_agents 的 create_builtin_agents() 安装从未安装过的内置 Agent，更新没人改过的副本，改过的不变。助手最先安装，所以全新安装时是默认 Agent。服务器启动、setup 和 openprogram chat 会运行它；读取注册表不会安装。

情况效果
未发送的对话从第一条消息起生效。每个未发送的对话保留自己的 Agent 和覆盖项；首条消息被拒时保留选择。修改模型只影响该对话。
已开始的对话立即切换，运行中的回合除外。之后的回合使用新 Agent 的指令、能力和记忆，以及它设置的模型。之前的消息不变。
保存指令、能力或记忆的修改对该 Agent 之后的执行生效
已有对话的模型沿用开始时或上次切换 Agent 时的模型，以及明确选择的思考强度。未设强度时跟随 Agent 默认值。明确的覆盖项保持有效。

未完成事项

什么算承诺

当前任务完成后，Agent 在这个对话里还欠你的事：等待的回复、承诺的检查、没有回应的草稿。

未完成项说明
显示在每回合的指令里，以及活动面板
由谁修改Agent 用 open_work 工具。可在对话里让它增删改，或在面板标记完成。
已完成项最近 50 个保留在历史中，并离开指令

不同于任务列表，后者规划当前任务并随之结束。其他会话也要知道的内容放进记忆。

复制和删除

复制会以新 ID 复制配置，不复制对话或私有记忆。self 记忆引用指向新 Agent 的空间；明确的旧版共享引用仍指向共享库。默认 Agent 要先把别的 Agent 设为默认才能删除。
