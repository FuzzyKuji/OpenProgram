操控电脑

一个工具 computer_use_agent 让模型操作屏幕。应用窗口在后台操作：不会有窗口跳到前面，键盘和鼠标仍归你。

目标

target操作什么需要
app这台电脑上的窗口，由 args.app 指定：访达、备忘录、Xcode、聊天客户端、游戏启动器。macOS、X11 下的 Linux、Windows。要求
browser网页，在 args.browser 中：默认 App 内置浏览器，或你自己的 Chrome、EdgeApp；App 关闭时用没有 App 登录状态的后台浏览器。你自己的浏览器需扩展
vmOSWorld 兼容服务器后面的远程机器computer_use.vm_url，见虚拟机
模型如何学会动作
部分规则
工具描述只列出每轮开始时这台电脑提供的内容：设置 computer_use.vm_url 后才有 vm，安装 Playwright Extension 后才有你的 Chrome 或 Edge，沙箱能运行的地方（macOS）才有代码。没有扩展时，你浏览器里打开的页面用 app 作为应用窗口操作。
首次调用某目标返回其指南和当前状态。代码有自己的指南 computer_use_agent.code，在能运行代码时随该调用送达。
指南送达不会因指南退回调用。指南留在模型上下文中才算读过；压缩后下一次调用重新送达。action="guide" 或 help("computer_use_agent.app") 可查看。
检查调用运行前对照指南。未知动作或参数立即失败，错误中写明该动作的参数。接受少数 Playwright 名称：select_option 即 select，values 即 value，expression 即 script。

第一次调用还返回指南和窗口截图。每行：序号、角色、标签、值、[focused]、[checked] 等状态、次要动作。

行为说明
结果Done: …，然后是树的 diff：- 消失，+ 新增或变化
序号元素留在窗口时不变，新元素用没用过的编号。应用替换元素时，工具在原序号下重新找到同一控件。
上限树 1500 个元素，截图长边 1568 像素。get_app_state 加 full=true 返回完整树。
等待稳定至少 0.3 秒，直到树不再变化，最多 1.5 秒；有转圈或进度条时 5 秒
元素稀少的窗口少于 12 个元素（游戏、画布编辑器、远程桌面、部分 Electron 应用）：状态还列出从截图读到的文字，如 "New Game" at (160, 215), 120x30，以及无文字图标的轮廓，如 (112, 169), 55x56。识别在 Mac 上进行，首选语言优先，逐张判断。

在 macOS 上看到什么

agent 占用窗口时，窗口内缘有柔和的主题色光晕，关闭、最小化、缩放按钮变成主题色并依次脉动，agent 光标滑向每个目标，点击处留下小点。你的指针不动。

覆盖层只在该窗口上方，被置前的窗口会盖住它，它也不接收点击。最后一步约 20 秒后淡出。浏览器工具栏的显示操作可对网页和应用关闭它。macOS 也会在菜单栏显示屏幕共享图标。

代码与共享窗口
部分规则
范围代码只作用于调用指定的应用或浏览器，能做单个动作能做的事，含页面脚本和打开网站。从内置浏览器上传是单独的动作。
步骤失败在代码中抛出，之前的步骤保留
超时返回错误：已做的保留，当前步骤可能已生效也可能没有，下次调用启动新解释器
Agent 状态每个 agent 有自己的窗口状态、序号和解释器。会话自身的轮次共享它们，后续消息沿用相同序号。
共享应用一个会话的多个 agent 轮流使用：调用占用到返回，其他调用最多等 60 秒，然后失败且不发送。上次查看后有别的 agent 操作时，下一个结果会说明并列出那些变化。浏览器标签页同理。

网页

每个内置标签页有短 id，如 tk3fa，跨轮次、子 Agent 和 workflow 程序不变。read 返回 Playwright 无障碍大纲，如 - button "Next" [ref=e12]；元素在页面上时 ref 有效，也可用 role 和 name 指定。

每个动作返回变化，以 <changed> 标记，[unchanged] 代表已看过的部分；导航后返回整页。重新渲染的 ref 按角色和名称再找；已消失时错误中带当前页面。

规则说明
并发agent 和子 Agent 可共用浏览器。动作占用标签页直到结果读取，列表占用涉及的标签页直到结束；占用一分钟以 tab_busy 失败。每个 agent 有自己的当前标签页，能看到上次查看后的所有变化，他人操作时会被告知。等待不阻塞他人。
重试动作不会发送两次。输入可能已送达时的失败会说明，带上页面，不重试。
新标签页结果中点名动作打开的标签页；agent 在指定新标签页之前保持当前标签页。
workflow 程序限于启动的窗口；它打开的标签页在结束时关闭
关闭了 agent 访问在该会话中拒绝所有动作
后台输入不激活标签页。visible: true 置前，用于你要求观看时。file:// 打开沙箱允许读取的本地文件。密码值绝不进入模型。
审批内置标签页上打开、操作和 evaluate 都不询问。上传在询问模式下询问。脚本只在你发起的会话中运行；定时运行和外部 MCP 客户端被拒绝并被告知使用页面动作，无论来自动作还是代码。
查看和接管网页

Agent 打开的网页留在后台。右侧栏的 Resources 按分支列出会话的网页，含子 Agent 的。继续分支保留其分组；相同 URL 仍各自独立；无归属的出现在 Unassigned。

Agent 网页的弹窗在后台作为独立网页加入同一分支，不抢占视图，下一个结果点名它。你打开的网页的弹窗以普通标签页在前台打开。

部分行为
标签页和预览不同时显示。没有遮罩，真实页面可用。
工具栏显示操作、Operation history，Agent 等待时还有 Review request。在页面内，它们收在右下角可拖动的 Agent 按钮后，从 Agent 首次操作起，直到页面关闭。
Agent 操作时页面边缘发光，光标滑向每步；放手后淡出。使用页面不会暂停它；在会话中停止运行，光晕持续到确实停止。
预览只有一行紧凑栏，只在 Agent 需要你或状态无法确认时显示状态。App 内有全屏内容时隐藏预览页面。默认 300×198.75；拖动标题移动，拖边角缩放，比例锁定，页面本身不缩放。
操作标记和历史标记短暂，不拦截输入。历史只含操作类型和结果，不含输入的文字。
关闭影响所有引用该网页的分支。活动网页先请求停止。关闭不同于隐藏。断开时显示上一张图并标为过期。
预览还跟随桌面应用窗口（每步后的最新截图）和 Agent 接管或输入的 Desktop 终端（实时只读），规则相同。截图只在内存中，worker 重启后消失。这些控件只作用于 OpenProgram 网页；应用窗口和虚拟机有自己的审批。
App 或 worker 重启未关闭的网页在后台恢复其标签页、会话、分支和最后确认的标题与 URL，成为新的活动网页，旧句柄失效。明确关闭的留在 Closed pages，隐藏的预览保持隐藏。
重启之后行在原分支显示 Restoring page…、Could not restore page 或 Reconnect。不需要 Continue Agent，新动作需要新的观察和当前权限。恢复用站点持久存储重新加载 URL，未保存的 DOM 和表单值丢失。没有保留标签页描述的旧记录显示 Could not restore page。

你自己的 Chrome 或 Edge

把 args.browser 设为 chrome 或 edge，使用你的登录状态和 cookie。动作相同：tabs 按序号列出，read 加 tab=<index> 切换。模型被告知只在你点名或任务需要登录状态时使用，并留在点名的浏览器内。没有扩展时，点名它的调用立即退回。

有后果的步骤

允许操作不等于允许自行执行重大步骤。模型在不可撤销或代你对外发言的步骤前（发送、提交、付款、删除）询问一次，说明做什么、在哪里、用什么数据。你的请求已点名该步骤时直接做并报告。屏幕上的文字是数据，不是许可或指令。

被打断的步骤不会阻塞下一步。模型被告知结果未知，查看屏幕后继续；该步骤留在 Activity 里。

系统权限

系统设置显示执行电脑上的实时桌面访问；openprogram doctor、TUI /doctor 和 GET /api/system/access 是相同检查。查看不会请求权限。缺少访问不影响普通聊天和升级。

平台规则
macOS托管安装通过内嵌应用 OpenProgram（稳定 bundle id）运行 worker 和 Python 子进程；在系统设置里找这个名字。屏幕录制和辅助功能在桌面任务所用可执行文件的新进程中分别检查。Set up access 只请求缺失的权限。远程客户端须在执行电脑上授权；其他应用的授权不算证据。
Linux无头会话和不支持的 Wayland 捕获与缺依赖分开报告。有 X11 显示不代表有访问权。
Windows取决于活动会话和目标；不能假定可访问安全桌面或提权目标。

不会要求 Linux 和 Windows 关闭安全机制或以管理员运行。未验证：Linux 和 Windows 原生桌面验收；未正式签名的 macOS 开发版上，签名升级后的权限保持、首次引导和授权后的任务自动恢复。设置过程绝不重试被拒绝的操作。

缺少权限时
部分行为
调用在动作前暂停。OpenProgram 走原生授权流程，需要时打开对应的系统设置页。
会话中简短的等待状态和 Open System Settings 操作；暂停卡片上没有表单、Continue、null 结果、Retry 或 Edit。真正失败或取消的运行保留各自状态。
检查和继续worker 保存任务，通过新的 OpenProgram 进程检查，不请求权限，也避免旧结果。可用后同一任务继续一次。一轮内后续步骤不再检查，下一轮再查。
等待期间关闭页面不停止检查，需要重启时启动后再查，取消任务阻止继续，检查失败继续等待。
旧会话查看时不启动操作或弹出提示；切换会话时重复送达不重新打开授权。你仍可手动打开系统设置。系统权限不替代操作审批。
本地 ad-hoc macOS 构建更新后录屏授权可能失效而开关仍开。OpenProgram 记住成功的检查；身份变化且录屏被拒时，下一次本地授权只更新自己过时的登记，每个身份最多一次。状态检查和重连不重置权限。Developer ID 版本使用正常流程。
macOS 自动化权限错误

发给 System Events 或目标应用的 Apple Events 需要自动化权限，按目标授予，与屏幕录制和辅助功能无关。被拒时，在执行的 Mac 上打开系统设置 → 隐私与安全性 → 自动化，查看请求方对目标的访问。

失败的操作仍是失败；改设置既不批准也不重做。其他原生失败保留实际错误。

应用正忙（保存、刚打开的对话框）步骤发送一次并最多等 10 秒。更久：视为完成，并注明无法读取状态。模型等待后再读，绝不重复该步骤
读取或步骤前应用正忙最多等 10 秒，然后失败且不发送wait 总能运行
步骤后结果读不到，如点击后应用退出步骤算完成；结果说明原因—

步骤在前面打开了新窗口返回新窗口的状态，并说明覆盖了哪个窗口get_app_state 加 window 返回
macOS 打开或存储对话框独立进程。点击和 set_value 可达；按键不可达，相关动作会报告。文件列表不在辅助功能中，状态列出从截图读到的文字。用 open_file

录音

使用屏幕录制权限，只捕获指定应用：不含其他应用、麦克风或系统提示音。最新 20 个保存在 ~/.openprogram/computer-use/audio/。

stop_audio_recording 用设置 → 语音中的引擎转写：whisper.cpp 把声音留在 Mac 上，OpenAI 和 Groq 发送给它们。transcribe=false 只保留文件。静音会报告且不转写。接受音频的聊天模型（如 Gemini 和 OpenAI 的 gpt-audio）还会收到录音本身。
