周报

~/.openprogram/programs 里的五个包，各自独立版本；源码检出不包含它们。共用辅助函数：openprogram.programs._authoring.reports。

入口用途外部写入
personal_weekly_report(task)个人飞书草稿、查看、填写、提交、更新记录填写只改字段不保存；提交或更新需明确要求
personal_chat_weekly_report(task)本人发到微信群的三段文字：进展、讨论话题、下周计划，中文本地草稿；从不发送
group_weekly_report(task)收集组内周报、跟踪缺交、准备汇总从不发送
tencent_weekly_report(task)给领导的约 100 字腾讯进展本地草稿
weekly_report(task)选择所需 Workflow 并转发完整请求；导入其他四个与子项相同

个人微信和飞书草稿默认返回完整 Markdown 正文，无需写文件；返回文本不提交任何东西。明确的 Markdown 路径保留文件交付，已有的文件交付恢复请求仍可用。

weekly_report

在 Abilities 里选择。自然语言交给路由 agent；JSON requests 直接指向子项，不经路由推断。

{
  "requests": {
    "personal": {
      "week": "2026-W37",
      "materials": [{"id": "p1", "week": "2026-W37", "text": "Experiments remain in progress; next week we will check the results."}]
    },
    "tencent": {
      "week": "2026-W37",
      "materials": [{"id": "t1", "week": "2026-W37", "text": "Tencent evaluation is still in progress. No final performance conclusion is available."}]
    }
  }
}

材料按受众分开。个人和腾讯输入需要匹配的 ISO 周和唯一来源 ID。证据不足时请求输入或审核，绝不编造进展。

路由规则
选择按含义和否定选一到四个目标；原始请求完整传给每个
绝不按标点拆分、提取材料、强制草稿、指定共同周次、请求澄清
默认没提飞书的一般进展草稿是 personal_chat；未指定受众是未发送的个人微信草稿
结果一个：原样返回。多个：按受众标注
超时路由、组内解析和个人模型调用继承 OPENPROGRAM_EXEC_TIMEOUT_S
子项失败异常保留之前完成的结果，不重新运行。浏览器访问失败向上传递。

腾讯周报

选择 tencent_weekly_report，输入 Prepare this week's Tencent weekly_report。用 Asia/Shanghai 的当前 ISO 周，目标 80–120 个非空白字符、争取 100，面向周五下午。不建定时、不发送；定时运行需另行配置确切时间和材料来源。

顺序证据
明确提供的材料优先
1. reports 目录当前周的原始腾讯证据；可选 report_roots 选最多五个目录
2. 其他报告来源接着查看
3. 最近的 OpenProgram 会话本人原始消息，保留日期和会话/消息引用。最多 20 个会话，每个最后 200 条。
4. 带日期的记忆生成的笔记只作查找线索，不是已验证事实
排除助手草稿、无归属消息、其他周、只有年月的日期、待定记忆记录、不可信的原始记忆、测试记录
其他受众需要带确切引文的来源选择

带日期的请求或计划只是候选，不是证据。合并上下文最多 30 条、18,000 UTF-8 字节。来源不足时在该范围内请求澄清，这不代表别处没有相关工作。

输出、超时和失败
  • 成功返回报告正文。来源、字符数和模型调用留在本地草稿。JSON 任务里的 "result_format": "structured" 返回状态、产物路径和恢复对象；路由原样转发明确的子项选项。
  • 生成和验证用低推理强度、每次 180 秒、保留重试预算。请求解析继承部署超时。每个 JSON 阶段声明 schema 并复用 Runtime 格式修复。
  • 模型失败不产生成功草稿，保留类型化的失败和恢复任务，绝不当作缺少输入。

组内周报

Prepare the group report 就够了：群身份、名单、材料和作者证据来自记忆、本地记录和识别出的微信群。提供的正文保留。没指定周期时用当前 ISO 周并记录这一假设。

情况结果
默认来源auto；source: "supplied" 限于提供的材料
未确定的作者明确标为未验证
缺少证据部分草稿，带诊断
微信控件不可用记录下来；用本地证据继续，明确标为部分草稿
微信访问失败本地来源仍可用
原生收集验证群并保留来源证据；历史覆盖不完整；不能发送或修改系统权限
模型或服务商失败保留真实错误，不算缺少输入
