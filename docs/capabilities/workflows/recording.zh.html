录制工作流

在任意一个或多个应用里做一遍任务，聊天 Agent 把录制变成 Workflow。

需要

条件说明
macOS 桌面 App浏览器或其他系统的 + 菜单没有这一项
Workflow Recording 应用默认开启。在应用页或用 openprogram programs disable workflow_recording 关闭后没有菜单项。应用
辅助功能、屏幕与系统录音系统设置 → 隐私与安全性。缺哪项时开始对话框会说明并打开对应面板。
解说（可选）Settings → Voice 选的语音引擎和麦克风。没有引擎时没有解说。

录制

  1. 输入框 + 菜单 → Record a workflow。
  2. 设置 Narrate with the microphone 和麦克风，点 Start recording。
  3. 所有窗口上方有一条栏：录制点、时长、步数、麦克风开关、Discard（垃圾桶）和红色 Stop。照常做任务。说出下次会变的东西（“日期总是上周一”）。
  4. Stop。窗口回来，录制在输入框里：“Recorded demonstration · 12 steps · 48.3 s · 9 images”。
  5. 可加一句，比如何时运行，然后发送。
情况结果
不从聊天开始新标签页的 Workflow Recording，或应用页的 Open。开始时打开新聊天，录制在其输入框等待。
发送后Agent 读取步骤和截图，询问决定输入的内容，写包，运行 openprogram programs check，总结步骤、输入和假设供你更正。卡片显示每步和截图。
十分钟自动停止，等同点击；提前 30 秒在栏上提醒
Discard停止并删除
从输入框移除仍在磁盘上

录制内容

录制不录制
点击，含应用、窗口和控件密码框的文字（步骤只说明输入了密码）
输入的文字；Return、Tab、Escape、快捷键；滚动；切换应用和窗口OpenProgram 内的操作、密码管理器、钥匙串访问、系统凭证弹窗
点击、Return 和切换窗口时的屏幕截图OpenProgram 自己的窗口
解说文字音频：声音丢弃

存于 ~/.openprogram/recordings/<id>/：session.json、events.jsonl（每步一行）、images/。发送时步骤列表和最多 12 张截图交给模型，和其他消息内容一样。随时可删文件夹，卡片会显示录制已不在。

作为上下文的录制

用途是 context 而不是 workflow 时，Agent 只把它作为这条消息的上下文，除非你要求否则不写 Workflow。开始对话框按 Workflow 录制；context 来自 POST /api/recordings，内容 {"purpose": "context"}。

提示

  • 一次录一个任务，从平时的起点开始。
  • 用一次典型运行的真实输入；Agent 把会变的值变成参数，不确定时询问。
  • 对话里信息够时不必录制：直接要 Workflow，缺口先从之前的对话和记忆补，再问你。
