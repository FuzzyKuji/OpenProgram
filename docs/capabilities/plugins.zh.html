插件

插件是一份清单，声明技能、斜杠命令、Agent、hook、MCP 服务器和模型服务商目录，格式沿用 Claude Code、Codex、OpenCode 或 Hermes。OpenProgram 自己挂载这些内容，不运行插件代码。要添加工具或自己的界面，用应用。

命令

命令效果
openprogram plugins list已安装的插件
openprogram plugins search <query>搜索已配置的市场
openprogram plugins install git <url> --ref v1.2克隆到 ~/.openprogram/plugins/
openprogram plugins install npm <package>装进它的 node_modules/
openprogram plugins install path /abs/path链接过去，改动在 reload 时生效
openprogram plugins update --all重装 npm 插件，或指定一个名字
openprogram plugins enable <name>、disable <name>开关
openprogram plugins reload <name>重读清单和文件
openprogram plugins uninstall <name>链接的插件只删链接
openprogram plugins inspect插件可包含什么、所有 hook 事件、什么被拒绝、每项的暴露级别；--json
信任存于 ~/.openprogram/plugin-trust.json
verified、community可以启用。本地 path 安装为 community。
untrusted未列出插件的默认值。不启用，因为 hook 和 MCP 服务器会运行命令。

Web UI 通过插件路由使用同一套管理 API。

内容

按此顺序查找清单：

  1. .claude-plugin/plugin.json（Claude Code）、.codex-plugin/plugin.json（Codex）或根目录 plugin.json
  2. pyproject.toml 的 [tool.openprogram.plugin]
  3. package.json 的 openprogram、opencode 或 hermes 字段
  4. plugin.yaml 或 plugin.yml（Hermes）

字段：name、version、description、trust、entrypoints、options、requires。贡献键也可放顶层，和 Claude Code 写法一致。requires 决定拓扑加载顺序，缺失时报 missing dependencies: ...。

键内容
skillsSKILL.md 技能目录
commands{name: {description, prompt}}，或带 front matter 的 .md 文件目录
agents{name, description, prompt, tools} 列表，或 .md Agent 目录。创建为 <plugin>-<name>；禁用时保留，因为删除 Agent 会删除它的会话。
hooks事件触发的 shell 命令，内联或 .json 路径
mcpServers内联 {name: {command, args, env} | {url}}，或 .mcp.json 路径。启用期间运行。
providers子目录各含一个 provider.json 的目录

所有内容通过 plugin:<name> 拥有的一个上下文挂载，disable 和 reload 全部移除。

Hook

OpenProgram 的形式（与 config.json 的 hooks 相同），然后是 Claude Code 的 hooks/hooks.json：

{"tool.before": [{"command": "${CLAUDE_PLUGIN_ROOT}/check.sh", "timeout": 30}]}
{"hooks": {"PreToolUse": [{"matcher": "bash|write", "hooks": [
  {"type": "command", "command": "${CLAUDE_PLUGIN_ROOT}/check.sh"}]}]}}
Claude CodeOpenProgram
PreToolUsetool.before
PostToolUsetool.after
UserPromptSubmitchat.before_send
Stopturn.stop
SessionStartsession.start
  • matcher 是对工具名的正则表达式。
  • ${CLAUDE_PLUGIN_ROOT} 替换为插件目录。命令在 worker 的工作目录运行，事件以 JSON 从 stdin 传入。
  • 门控事件（tool.before、turn.stop）退出码 2 表示拒绝，stderr 是原因；其他退出码放行。

拒绝的内容

install 拒绝声明代码的清单，并删除 git 克隆或 npm 包；手放进目录的会列出错误且永不加载。拒绝信息点名键，并让你添加 application.json 后运行 openprogram programs install <dir>。

  • python、module、setup、main、tools：Python 或 JavaScript 代码
  • client、web、sidebar：自己的界面
  • 写成 module:name 的 hooks：Python 处理函数映射
  • 带 __init__.py 的 Hermes plugin.yaml
  • pip 来源

写一个

house-style/
  .claude-plugin/plugin.json
  skills/review/SKILL.md
  commands/summarize.md
  hooks/hooks.json
{"name": "house-style", "version": "0.1.0", "skills": "./skills",
 "commands": "./commands", "hooks": "./hooks/hooks.json"}
openprogram plugins install path /abs/path/to/house-style   # 链接这个目录
openprogram plugins enable house-style
openprogram plugins reload house-style                      # 改完文件后

Agent 有 plugin 工具（需要审批；聊天渠道和计划模式下不提供）。guide 返回运行版本生成的编写指南；install 传目录绝对路径，一步完成链接、信任和启用；reload 应用修改。声明代码的插件被拒绝，信息与 CLI 相同。
