Open applications from the new tab page

An application is a Program with its own interface: standard HTML, CSS and JavaScript, optionally backed by Python operations. It appears beside Files, New chat, Browser and Terminal; clicking opens it in a tab, opening again selects the same instance, and closing the tab does not cancel its operations.

Where they appear

PlaceShows
Applications in the sidebarEvery application with icon, title, version, scope and description. Filters All, Built in, Installed. Row: Open if it has a window, enabled switch, ⋯ menu (Show in Abilities, Hide from new tab or Show in new tab, Update from source, Uninstall). Install… opens the install form.
Abilities → ProgramsPlain folder view, one folder per application directory, sorted by name (browser, calculator, auto_research), holding real subfolders and source files. Applications under Applications with installed programs that have no UI; built-in tools under Tools.
Selecting an application thereSame icon, title and description, directory name, kind, version; Open, Use in chat with a single Agent entry; enabled switch; Agent entries with descriptions; location, window and permissions. Call logic folded at the bottom. A tool lists parameters; a source file shows its call logic.
Details of these views
  • Uninstall asks first and keeps the application's data. Update from source shows the source directory and opens the install form filled in; review the source before submitting.
  • The install form requires explicit trust for Python backends and for files.project.write.
  • An application inside an installed package is that package's subfolder, such as auto_research/app. Its call logic is the union of the Agent entries it registers, such as web_use for browser.
  • An application the Agent cannot call says so in one line: a UI-only application only opens as a window; a package that only exports Python functions for other Programs is a Python library.
  • The new tab page refreshes its list when focused and every ten seconds.

Python backends run as trusted local code with your operating-system account. files.project.write lets it create and replace files in the bound project. A directory placed directly in ~/.openprogram/programs/ needs no install: the worker records it on its next scan, and one needing trust is listed as needs trust until installed with --trust.

  "title": "Notes",
  "description": "Keeps notes per project and summarises them on request.",
  "icon": "notebook-pen",
  "version": "1.0.0",
  "scope": "global",
  "dataSchema": 1,
  "ui": {"root": "ui", "entry": "index.html"},
  "capabilities": ["storage.app", "model.invoke"],
  "backend": {"kind": "python", "entry": "backend:operations"},
  "operations": {
    "summarize": {
      "agent": true,
      "input": {"type": "object"},
      "output": {"type": "string"}
    }
  }
}
FieldRule
application.jsonIn the package root
title, descriptionShown on the New tab page, Applications page and Abilities. Description: one plain sentence, one line, at most 300 characters. Without application.json a Program uses the first # Heading of its README.md and the first sentence below it, or its directory name.
iconGlyph on those pages and the tab. Any other name, or none: a generic tile coloured from the id.
ui.root, ui.entryRoot is relative to the package, entry to the root. Keep Python and private configuration outside ui.root.
backendExports a dictionary of callables taking (input, context) and returning JSON, sync or async
backend.dependenciesExact pins, such as ["package-name==1.2.3"]. One Python environment per set, created on first use; it also uses the installed host framework.
operationsInput and output are JSON Schema. Only agent: true is callable through the Program client.

CapabilityGrants the backend
storage.appcontext.load() and context.save(): the instance's saved state
model.invokeAn ambient Runtime for llm() and agent()
files.project.readcontext.read_file(relative_path) inside the bound project
files.project.writecontext.write_file(relative_path, content) inside the bound project; needs a Python backend and --trust

Capabilities restrict the host bridge, not the operating-system permissions of trusted Python. Backends are checked in a separate process before registration; listing applications does not import their code.

Sandbox
  • Web UI runs in a sandboxed iframe with an opaque origin. Its interface need not use OpenProgram components.
  • Bundle frontend dependencies locally and use relative asset URLs, including JavaScript module imports.
  • Blocked: remote scripts, direct owner API access, nested frames and form navigation.
  • A resource URL authorizes reads of only that application's UI directory at the digest it was opened with; it is not an owner credential.

Use an application as a resource

Enabled applications appear as application.<id> in resource(action="describe"), reflecting install, disable, update and uninstall without a restart. The Resources view and top tab open the same instance in the same sandboxed frame.

ActionBehaviour
openAccepts project_id for project scope. Associates the instance with the calling session. Returns the instance_id and digest to use; an older digest is rejected after an update.
observeInstance state and recent runs
actA declared Agent-visible operation and a stable request_key
status, cancel, answerNeed a run of that exact instance
saveUses the expected storage version when storage.app is declared
releaseRemoves the session association; keeps instance, data and running operations. Hiding its view also leaves operations running.
Agent entriesRule
Name<id>__<operation>, other characters than letters, digits, _ and - replaced by _: local_notes__summarize
InputThe operation input as input, plus project_id for project scope. Waits for the run and returns it. A run waiting on a question returns its id, for status, answer or cancel.
ExposureNeed approval, like resource. Deferred: the model sees names and loads a schema with tool_search. While the application is open for a conversation they are resident there.
agent: falseNo entry

Owner API for a window: POST /api/applications/{id}/open with session_id associates; POST /api/applications/{id}/close with instance_id and session_id releases.
