提醒

在任何对话里用平常的话说。回复写明确切的触发时间，例如“fires Fri 2026-10-23 17:00 CST (in 2.5 h)”。

你说到时间
通知“20 分钟后提醒我把面包拿出来。”收到消息
唤醒 Agent“明天 9 点看看 CI 过了没有，告诉我哪里失败了。”收到消息，然后在同一对话开始一轮

要“提醒”就是通知，要 Agent“做”事就是唤醒。在意的话说明要哪种。要重复已经做过的工作并保留你的修正，存成 routine。

时间

你说触发
“20 分钟后”从现在起 20 分钟
“17:00”下一个 17:00：今天还没到就是今天，否则明天
“12 月 1 日 10:00”那个日期和时间
“每个工作日 9:00”重复；Agent 写 cron 表达式，如 0 9 * * 1-5

除非你指定，否则用电脑本地时区。在时间到后一分钟内触发。Agent 用的是 remind 工具。

限制

  • 提醒运行在本机 worker 里。它没运行时，一次性提醒在重启后立即触发。用 openprogram worker install 保持运行。
  • 重复任务错过的时间在 12 小时内，worker 重启后补跑一次；更早的显示为一次错过的运行。那个时间之后才开启或改过的任务不会补跑。
  • 会话已归档，或上一次运行还没结束（worker 重启后也算）时，任务的 Agent 运行会跳过，Activity 里能看到。已归档会话里的唤醒提醒只发通知。
  • 已触发过的一次性任务改了时间，会在新时间再触发一次。
  • 专注模式和勿扰把系统通知留在通知中心。App 的 Notifications 设置也会关掉它自己的通知。
  • 只有所有者或替所有者工作的 Agent 能设置提醒，定时或后台轮次和聊天一样。
  • 定时运行的 Agent 或命令超过 2 小时会被停止，重启前的时间也算在内，并显示为一次失败的运行。

运行你自己的命令

每次触发是一个 reminder.fired 事件。config.json 的 hooks 条目通过标准输入收到 JSON；hooks 在 worker 启动时读取。

{"hooks": {"reminder.fired": [{"command": "python ~/bin/on_reminder.py", "timeout": 30}]}}
