Tune Memory

Settings → Memory. Changes save at once and apply on the next turn; only Enable Memory needs a restart. Config keys: memory.* in Configuration keys.

Background writing

SettingEffect
Writer modelWrites and organizes Memory. Automatic: the default Agent's model, or the last used model when it has none.
Automatic writingTurns finished conversation into Topic records
Write frequencyAbout 8K, 16K or 32K tokens gather before a write
Verify after writingAsks about one fact just recorded, looks it up in a copy of Memory, repairs Topics if not found. Off by default: at least three more model calls per write, three more per repair.

openprogram memory status reports these under verification: passed, repaired, unrepaired, errors and the latest.

Recall

SettingEffect
Recall methodAgent: adds nothing automatically, the model reads with its tools. Keyword: BM25. Semantic: embeddings. Hybrid: both, merged.
Hybrid weightingKeyword first 70/30, Balanced 50/50, Semantic first 30/70. Automatic leans on keywords when a message has a date, quoted phrase or name, otherwise balances. Hybrid only.
Favour well-matched TopicsRanks a Topic higher when several paragraphs match. On by default. Hybrid only.
Recall depthMost records added to a turn: 3, 5, 8 or 10
Embedding model for Semantic and Hybrid

They need the model plus sentence-transformers and PyTorch, which the App does not include. Install next to Embedding model downloads all of them: about 1 GB of packages and a 90 MB model. Packages go to ~/.openprogram/extras/embedding/, so an App update keeps them.

Project memory

SettingEffect
Project memoryA project conversation also reads ~/.openprogram/projects/<project>/memory. Recall, Memory tools and Core Memory cover both, project first. On by default.
Write to project memoryWrites a project's conversations there instead of your personal Memory. Needs Project memory. On by default.
  • Conversations outside a project read your personal Memory only: the home project's, at ~/.openprogram/projects/default/memory.
  • A project's Memory counts once something is written. Nothing goes into the project's own folder. History shows it under its Memory tab.
  • With both layers, Memory tools name the layer in paths: project:topics/api.md.
  • A turn is written to one layer, so switching writes never copies a conversation across. A chat moved to another project writes only later turns there; earlier records stay.
