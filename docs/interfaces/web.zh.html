发送、恢复和历史读取
情况行为
发送的消息立即显示，确认前为待定。随后出现占位（双环标记，减少动态时静止）；文本、thinking 和工具块按序流式显示。非默认 Agent 的回复带其名称。
断开时发送的消息进入队列。确认前连接断开时不自动重发。
刷新恢复活动执行及其控件，包括审批等待后。没有输出不代表结束；过时的 Worker 注册不会让执行保持活动。
历史读取失败显示重试并保留缓存消息。读取 15 秒过期；重试不重新提交；迟到的响应不会替换更新的响应。
快照过期Retry history 重读位置，Go to latest history 打开最新
重连后先加载所选对话；恢复用紧凑快照，一次一个。查看历史绝不恢复任务。
取消本地 shell 命令先停止进程组再报告。恢复的对话把助手记为已取消。等待页面锁的浏览器操作会重新检查取消；已发送的不撤销。
长对话先打开最近一小页。Activity 只在一次运行的行展开时读取它的事件。短暂刷新失败静默重试。

一次运行一行，带开始时间、时长和时间轴上的长条，每次 20 行（Show earlier）。原地展开后依次是提问、每一步的输入和结果、带错误的尝试、子 Agent 和回复。最新一次失败或仍在进行时自动展开。
运行的操作支持时有 Pause、Continue、Retry、Add instruction、Cancel；待答问题在列表末尾。Technical details：Step、Create branch、代码策略、ID、版本、检查点、原始事件。取到快照不代表 Agent 正在运行。
调用、长内容调用按其请求命名。长内容显示八行，Show all 展开。
进度来源##progress 45/100 samples、OSC 9;4、tqdm 和 pip 进度条、Epoch 3/10 这样的计数。否则显示已运行时间和最后一行。
输出按终端方式显示，有上限，并标明截断。Stop program 只针对该进程组。
等待后仍在运行的 bash变成程序。其监管进程跨 Worker 重启存活。分离到其他会话或框架外启动的进程不归入。
更新事件、打开面板和恢复时；没有刷新按钮。回退：快照 30 秒，程序 3 秒，打开的程序 1 秒。失败时保留最后数据并提示。只缺模型响应的已结束尝试显示为已结束。
常驻行在已检出分支的运行上方。展开后有 Wake now、目标、当前 Goal、频率、是否还在运行、上次和下次唤醒、花费、关于报告的要求。报告是运行列表里的行，带去向和 Don't report things like this。归档对话即停止；计划在 Agents → Always-on 设置。
Branch with new instructions从保存点：准备、检查、确认、发布。编辑会产生新草稿并使校验失效。敏感改动需独立批准。
Create branch独立的暂停子执行；Continue 启动
Retry在该点用原版本创建独立的暂停执行

预览

类型打开方式
Markdown类似 Obsidian 阅读视图：标题、属性表。相对图片和链接可用。原始 HTML 显示为文本。
Obsidian 语法标注 > [!note]，折叠 -，展开 +；==mark==；#tag；[[Note]]、[[Note#Heading]]、[[Note|label]]；![[image.png|300]]。同文件夹或写明的路径，无全局搜索和大纲。
HTML，在 App 中通过 file:// 在浏览器标签页打开网页；View page 和查看源文件切换。浏览器中或 Worker 在远程时：源文件。
PDF连续阅读，含缩略图、大纲、适配、搜索、下载。项目文件可加高亮和笔记，保存为标准注释。本地解码，最大 64 MiB。复制默认去掉版面换行。
情况行为
新回复在聊天旁打开第一个支持的输出；历史和后台回复不打开
File changed显示在可见的预览上。Refresh 失败时保留旧视图，并保留未保存的编辑。
同一文件的多个标签页共享编辑器和草稿；Show here 移动编辑器
完成的 Goal在回复下显示状态和时长

外观

设置作用
主题标准（默认）、代码雨，或彩色渐变（新标签页背后的靛蓝、紫和青色）。按浏览器保存。
代码雨空聊天在输入框后下雨；新消息从中解码；运行中的标签、加载图标和进度条显示为代码。历史、选择、复制和查找使用真实文字。减少动态时：静止一帧，无代码雨。
代码雨密度10–100%，默认 40%
标签拖动外观透明度 0–100%（20）、背景模糊 0–40px（16）、阴影强度 0–100%（25）。立即生效，按浏览器保存，只影响标签和分屏标题。恢复默认重置这些项。
