书签与历史

  • 书签栏显示 Bookmarks bar 的直接内容；放不下的进双箭头菜单。All bookmarks 打开管理器，含 Other 和 Mobile 书签。名称、顺序、内容不变。嵌套菜单逐层打开，在窗口内滚动。
  • 管理器有文件夹树、当前文件夹列表、搜索、图标和条目菜单。历史按本地日期分组。
  • 图标：已保存的图标，然后站点的 /favicon.ico，然后浏览器图标。不发 referrer，不用第三方服务。主页快捷方式显示 /favicon.ico 或站点首字母。
  • 主页快捷方式：Add，地址，可选名称。取消、关闭、Escape、点外部或再点 Add 都清除。
  • 历史和持久的 webtabs 分区在 Electron 的用户数据目录；聊天、项目、Program 和 Worker 配置在 ~/.openprogram/。清除浏览数据不影响后者。
图标缓存

解码后的图标在每个渲染进程的书签栏、菜单和标签页间共享。缓存有上限，失败来源五分钟后重试，复用来源三十分钟后刷新。重新打开书签菜单复用其文档。关闭窗口时释放；重启后可经浏览器缓存重新加载。

设计：内置浏览器、Web Use 与 Computer Use 边界

Agent 与 Browser 窗格

同一窗口里可见的内置 Browser 窗格，会在第一次模型响应前把该标签页的有界描述附到本轮：标题、来源、可见文本、ARIA 地标和浏览器控制工具。在左侧、右侧或画中画都可用，不需要系统焦点。

方面规则
定位操作绑定到发起的窗口和标签页。默认用 DOM、ARIA、文本和元素引用；只有视觉任务或结构定位失败时才用一张视口截图。没有 OCR、目标检测、迭代裁剪、组件或视觉记忆、流程回放。
你的操作点击、滚动、输入、导航或关闭都不暂停 Agent。Agent 也可操作 OpenProgram 自身界面。用输入框旁的任务控件暂停。
页面丢失Agent 重新获取或打开上次地址，并重读状态。点击和提交绝不重放。无法恢复的登录或内容会报告。
已选页面复用，不重新加载也不换页。每步操作后重新观察和验证。
安全上限停止任务，不重试已完成的操作；清理保留对话身份。

上传与验证
  • upload 配合新的文件输入 ref 和 path（最大 50 MiB）选择用户批准的文件。始终走普通权限关卡，文件读取限制仍适用。
  • 观察只暴露文件名，不暴露内容或路径。file_selected 只验证已选择；是否被接受要另设断言。不确定的上传不重复。
  • 验证用 assertion 和非空 value；text 用于输入或报告阻塞。
  • 同一观察上连续三次操作失败或断言不满足时，停止并给出原因。被拒绝时停止，不重复。报告阻塞绝不算完成。操作计数统计 Page 变更。

Shell 元数据与 resource 工具

在 macOS zsh 和兼容的 Bash 3.2 登录 shell 上，terminal_use(action="observe", ...) 和 resource(provider="terminal", action="observe", ...) 返回 shell_integration：

字段含义
statusstarting ready unavailable ended
mode reasonzsh-hooks 或 bash-debug；不可用的原因
event_sequence最新接受的 shell 报告序号
cwdvalue 中的目录及其序号；报告前为 null
cycle前台 id、phase（running finished unknown）、exit_code；第一条命令前为 null
  • start_cwd 是起始目录；顶层 exit_code 属于终端进程。周期的退出码只在前台完成后出现。command_complete 保持 null。
  • bash-preexec、自定义 DEBUG trap、提示命令、只读提示配置和不兼容的跟踪设置回退到 unavailable，不动你的钩子。缺失或 unavailable 表示未知；报告不授予权限，可能过时。
  • resource(action="describe") 返回 Provider 和 Schema。web 和 terminal 保留原生身份和检查；observe 返回 generation、binding、输入版本和输出游标。
  • Web release 结束控制并保留 Page；close 关闭观察到的标签页，报告 page_closed，未确认时报错。Terminal release 保留进程；close 请求终止。本地 Terminal 操作需要发起窗口中的活动执行，不能绕过沙箱。
  • 受信 Python：openprogram.host.resources.registry.register(...) 注册 ResourceProvider，每个操作有 JSON Schema 和适配器，由适配器负责授权和生命周期。重名被拒绝，参数先校验。openprogram.host.resources.session.resource_use(kind, title, target) 在受信运行时会话内报告使用，退出时释放。URL 身份去掉凭据、查询和片段。命令文本绝不解析成资源。已安装并启用的应用注册 application.<id>。

重启之后

内容恢复方式
运行中的对话在原处自动继续，用已记录的输入和结果。不增加消息；一条回复里带 Worker 已重启，已继续 步骤。
手动暂停、取消、完成的任务；已发送更新消息后被中断的任务；未回答的审批保持停止。第二种可从 Activity 继续。
未关闭的页面在后台恢复，同一保留标签页、会话和分支归属，上次确认的地址和标题，运行在新的活动页面上。站点存储保留；未保存的表单不保留。不开第二份；已关闭页面和隐藏的预览保持原状。
关闭标签页或 App 窗口Worker 任务继续运行
行状态含义
正在恢复网页…恢复中，留在原分组
网页恢复失败失败，或旧记录没有保留标签页描述
需要重新连接活动页面需要新连接
续跑规则
  • execution.auto_resume_window_seconds：-1 无限制（默认），0 关闭，正数为秒。截止时间会持久化，重启不延长，升级时保留；到期后任务暂停，可手动继续。
  • 任务在完成的 Provider 和工具边界保存检查点。续跑保留任务身份、权限和资源准入，需要兼容的运行时约定。恢复的是持久检查点，不是进程内存。已确认的工具结果复用；外部结果未知时需要对账。
  • 自更新续跑、约定变化后的重新规划和后续跟进使用同一设置，从更新最后的活动算起。运行中的更新不受其限制。
  • 对话里有所请求更新的结果，但没有更新历史、控件或恢复提示，打开对话也不启动更新轮询。
  • 恢复页面不启动 Agent；新任务照常观察并检查权限。
重启后的浏览器工具
  • 列出页面最多等 App 20 秒，然后报告 desktop_unavailable 并要求重试。窗口已不在时列出其他窗口的页面。
  • 之前的会话或页面 token 回到同一标签页并给出新观察。不重复操作，不重新打开已关闭的页面。
  • 未知标签页返回当前页面及新 token。
  • 操作后立即截图会先观察，不会因过期失败。

Programs

Abilities → Programs 有两个根。Tools：openprogram/programs/tools/，按类别。Applications：内置的来自 openprogram/programs/applications/，已安装的在 ~/.openprogram/programs/。每项展开为入口和源文件；详情显示是否禁用，你的包还显示加载失败或暂不可调用。放在其他应用目录里的目录应用单独列出并注明目录。打开时选中第一个应用，没有则第一个工具。

离开时保留目录树、选中项和调用图。可见时每五秒及重新聚焦时检查；未变文件复用分析。检查失败保留上次内容。

长对话
  • 历史先加载最新一页，滚动时获取附近消息，保持位置和流式输出。失败自动重试。较远的页离开内存。重新打开时若消息仍在所选分支上，恢复到可见消息。
  • 主对话和分屏窗格在有未加载的新消息时显示跳到最新。失败后可重试。滚动、点击或按键取消等待中的跳转或恢复。关闭窗格保存位置。重连不再等旧的重试延迟。
  • DAG 打开时才加载。Markdown 使用有界缓存。存储的历史和模型上下文不变。
