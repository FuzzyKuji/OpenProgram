Use the CLI

openprogram --print "Summarize what the python files in this directory do"

Prints one reply and exits, without the TUI. The conversation is saved and can be continued in the Web UI or TUI.

--print takes only its argument and does not read stdin. To include a file:

openprogram --print "Review this code: $(cat <file>)"

--json-schema PATH requires output matching a JSON Schema; - reads the schema from stdin.

Resume a session

openprogram sessions list
openprogram --resume <session-id> --print "Given last time's conclusion, what is the next step"

Without --print, --resume opens that session in the TUI.

Isolate an environment

openprogram --profile ci --print "..."

--profile <name> moves config, sessions and credentials to ~/.openprogram-<name>/. Environment variable: OPENPROGRAM_PROFILE.

Other scriptable commands

openprogram sessions list
openprogram providers list --json
openprogram providers discover --json
openprogram status
openprogram programs run <name> --arg key=value

Most subcommands support --json. openprogram -h and each subcommand's -h give the full list.
