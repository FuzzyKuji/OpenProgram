Voice input

ActionResult
Microphone button, bottom-left of the composerClick to start, click to stop
Hold ⌥Space (Alt+Space) while typingTalk; release to stop
EscDiscards the recording and the text it inserted

Each phrase is transcribed when you pause and inserted at the cursor. Nothing is sent. While recording, a strip before the send button shows a dot for quiet and a loudness bar for speech. After stopping, the button returns once the last phrase is done. The browser or App asks for microphone access the first time.
