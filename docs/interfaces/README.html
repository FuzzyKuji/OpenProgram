Interfaces

Desktop embeds the Web UI and adds native Browser and Terminal panes. With no worker running, Desktop or the TUI starts one.

Which one

InterfaceOpen withBest for

Isolated workspaces

--profile <name> or OPENPROGRAM_PROFILE moves state from ~/.openprogram/ to ~/.openprogram-<name>/: config, sessions, logs and credentials are separate, and each profile has its own worker.
