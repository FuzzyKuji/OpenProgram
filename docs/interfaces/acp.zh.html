编辑器（ACP）

openprogram acp 是 ACP（Agent Client Protocol）的 Agent 端。Zed 原生支持，无需扩展。由编辑器启动该命令；它在 stdin 和 stdout 上使用 JSON-RPC，编辑器断开时退出。

Zed

在 settings.json（cmd-shift-p → zed: open settings file）的 agent_servers 下加入这段，然后在 Agent Panel 的新建线程菜单选 OpenProgram。如果 Zed 的 PATH 里没有 openprogram，把 which openprogram 的结果写进 command。

{
  "agent_servers": {
    "OpenProgram": {
      "type": "custom",
      "command": "openprogram",
      "args": ["acp"],
      "env": {}
    }
  }
}
参数效果
--agent <id>用这个 agent 而不是 main 运行会话，有自己的系统提示和工具
--permission <mode>bypass（Bypass permissions，默认）、auto、ask、plan 或 acceptEdits：权限
"args": ["acp", "--agent", "coding", "--permission", "acceptEdits"]

支持什么

功能行为
流式输出逐 token；模型产生推理时作为单独的思考流
工具调用开始和结束时报告参数和结果；文件工具报告路径，Zed 可以跟随
编辑器上下文附加的选区或文件按路径写入提示，模型可继续读取
权限提示Allow、Always allow、Reject。Always allow 把该工具的持久规则写入项目设置，和 Web UI 一样。
取消停止线程会取消当前轮次并撤回未答的提示
恢复重新打开的线程从会话存储回放。会话是普通会话，在 Web 和 TUI 可见，可从任一处继续。

范围

  • 会话以本机所有者权限运行，这正是能弹出审批的前提。不要通过网络传输暴露这个命令。
  • session/new 传入的 MCP 服务器被忽略；OpenProgram 用自己的 MCP 配置。不支持音频提示。
  • 协议版本 1：编辑器发 initialize、session/new、session/load、session/prompt、session/cancel；返回 session/update、session/request_permission。
