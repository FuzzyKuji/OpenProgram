界面

桌面 App 内嵌 Web UI，并增加原生的浏览器和终端面板。没有 worker 时，桌面 App 或 TUI 会启动一个。

选哪个

界面打开方式适合
macOS 桌面/Applications/OpenProgram.app多面板聊天、Files、内置浏览器、终端、Agent 控制可见的内部网页
Web UIopenprogram web，然后 http://localhost:18100聊天、DAG 分支视图、函数/技能/MCP/记忆管理、设置
终端 TUIopenprogram tui；只输入 openprogram 会先问终端还是网页在终端聊天：斜杠命令、权限配置、可滚动历史
CLI 单次调用openprogram --print "..."脚本、被其他程序调用、快速提问

换个界面继续会话

从方式
终端到 Web在侧栏里，点击即可
Web 到终端TUI 里 /resume，或 openprogram --resume <session-id> --print "..."
单次调用也会保存，任何界面都能打开

启动交互式 TUI 时 --resume 暂时不会选中会话，用 /resume。

Worker

命令效果
openprogram status、stop、restart管理后台服务
openprogram worker install登录时启动

隔离的工作区

--profile <name> 或 OPENPROGRAM_PROFILE 把状态从 ~/.openprogram/ 移到 ~/.openprogram-<name>/：配置、会话、日志和凭证都分开，每个 profile 有自己的 worker。
