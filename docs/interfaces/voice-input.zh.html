语音输入

操作结果
输入框左下角的麦克风按钮点一下开始，再点一下停止
打字时按住 ⌥空格（Alt+空格）说话；松开即停止
Esc放弃录音并删除它插入的文字

每次停顿时，这一句被转写并插入到光标处。不会自动发送。录音时，发送按钮前的指示条在安静时显示一个点，说话时显示音量竖条。停止后，最后一句转写完成按钮才恢复。浏览器或 App 第一次使用时请求麦克风权限。

识别服务

所有选项都在 设置 → 语音，也可用 openprogram config set voice.engine local。

设置取值含义
服务 voice.engineauto openai groq local由谁转写
说话语言 voice.languageauto zh en ja ko fr de esauto 自动检测。zh 输出简体字。
模型 voice.model文本留空用该服务的默认模型。auto 时忽略。
服务默认模型需要音频
openaigpt-4o-mini-transcribe设置 → Provider 里的 OpenAI 密钥每句发送给 OpenAI
groqwhisper-large-v3-turbo设置 → Provider 里的 Groq 密钥每句发送给 Groq
locallarge-v3-turbo-q5_0，约 570 MB，首次使用时下载到状态目录brew install whisper-cpp（whisper.cpp）留在本机。Apple 芯片上每句一到两秒。

auto 的顺序：已下载模型的本地服务、OpenAI、Groq、需首次下载的本地服务。页面显示正在使用的服务和本机可用的服务。computer_use_agent 录下的声音也由同一服务转写。

限制

限制值
格式16 kHz 单声道，一次一句
单句连续 25 秒不停顿时在此切断
上传20 MB
没有可用服务点麦克风显示提示，指向设置 → 语音，不录音
