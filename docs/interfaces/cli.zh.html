使用 CLI

openprogram --print "总结这个目录下的 python 文件做了什么"

打印一条回复后退出，不进入 TUI。对话会保存，之后可在 Web UI 或 TUI 里继续。

该 profile 的 Worker运行位置具备
运行中（桌面 App、openprogram worker start、前台 openprogram web）该 Worker，在对应的 Web UI 会话里实时显示内置浏览器、频道桥接、会话设置
没有，或用了 --standalone（OPENPROGRAM_PRINT_IN_PROCESS=1）当前进程没有浏览器和频道
在 Worker 上结果
Agent 追问打印到 stderr，在终端作答。没有终端时不作答，轮次继续。
Ctrl-C 或 SIGTERM像 Web UI 的停止键一样在 Worker 上停止这一轮，最多等 30 秒让它结束（再来一个信号后等 2 秒）；退出码 130，SIGTERM 为 143。等待中 Worker 重启也不会丢掉这次停止：命令重新连接，在回来的 Worker 上停止这一轮。Worker 没有确认停止时，stderr 会说明这一轮可能仍在运行
在 Web UI 里停止stderr 打印 [cancelled]，退出码 130；已输出的部分回复留在会话里
Worker 报错打印到 stderr，退出码 1
Worker 重启（刷新、晋升）命令重新连接，跟随同一轮次直到结束
三分钟内没有 Worker 回来，或轮次已被中断命令会说明；Web UI 会话显示停在哪里

管道输入作为 <stdin> 块随提示一起发送；-p 是 --print 的简写，不给提示时提示本身从 stdin 读：

cat <file> | openprogram -p "审查这段代码"
echo "总结 README" | openprogram -p

--json-schema PATH 要求输出符合 JSON Schema；- 表示从 stdin 读 Schema。

恢复会话

openprogram sessions list
openprogram --resume <session-id> --print "基于上次的结论，下一步是什么"

不带 --print 时，--resume 在 TUI 里打开该会话。

隔离环境

openprogram --profile ci --print "..."

--profile <name> 把配置、会话和凭据换到 ~/.openprogram-<name>/。环境变量：OPENPROGRAM_PROFILE。

其他可脚本化的命令

openprogram sessions list
openprogram providers list --json
openprogram providers discover --json
openprogram status
openprogram programs run <name> --arg key=value

多数子命令支持 --json。完整列表见 openprogram -h 和各子命令的 -h。
