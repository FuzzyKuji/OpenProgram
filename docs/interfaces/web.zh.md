重启或刷新应用后，打开会话会显示最新消息。同一次运行中，离开不足一小时后返回会话，恢复阅读状态：之前在底部则继续跟随最新消息和延迟排版，之前上翻阅读历史则恢复阅读位置。离开满一小时后返回，或应用失去焦点满一小时后重新激活，则显示最新消息。正在阅读时不会因为计时而自动跳动，上翻操作会取消跟随。已加载的文件修改摘要在返回会话时直接显示，文件历史操作仍检查当前状态。

会话菜单中的 **Copy link（复制链接）** 复制所选会话的地址。桌面 App 使用系统剪贴板，浏览器使用剪贴板 API 并提供选择复制作为备用方式；复制成功后才显示成功提示。

选中聊天消息中的文字后点击**加入当前聊天**即可引用。引用追加到当前消息所属会话的草稿，不会自动发送；分屏中的两个会话分别使用自己的输入框。点击用户消息的**编辑消息**，可以修改文字和链接、移除原附件，以及选择、粘贴或拖入图片和文件，也支持 `@` 文件引用。**保存并重新发送**会创建新分支，原消息仍然保留。Cmd/Ctrl+Enter 保存，Escape 取消；保存失败时保留编辑内容和附件，可直接重试。

# 网页界面

网页小窗默认停靠在对话的右上角：会话视图里在视图按钮左边，图视图里在小地图下面；拖出来可以放到任何位置，拖回右上角附近会重新吸附停靠。网页小窗固定使用 1920 × 1080 CSS 像素的页面视口。调整小窗大小只改变显示比例，未使用的区域留白，网页布局和 Agent 操作坐标保持不变。打开为完整标签页后恢复正常窗口尺寸和原有页面缩放。 小窗隐藏页面最外层的滚动条轨道，仍可使用滚轮和键盘滚动；打开完整标签页后恢复原有滚动条。移动小窗位置不会重新设置网页缩放。

在会话的 ⋯ 菜单中选择 **自动命名（Auto rename）**，即可让你上一次使用的模型根据会话内容生成名称。**重命名（Rename）** 仍可手动输入名称。生成期间显示原名称；生成失败时保留原名称并显示提示。名称描述会话当前在做的事：取自当前分支，越新的轮次权重越大，开头的寒暄会被忽略。你手动输入的名称不会被后台自动命名覆盖；生成的名称不锁定，随着会话推进，后台命名可能把它改得更准确。以寒暄开场的会话会在第 2、3 次回复后再命名一次，之后在第 6、16、40 次回复后更新。聊天区域的会话菜单也提供同一入口。该操作不会发送聊天消息或调用工具。

每个标签独立保存后退和前进历史，默认入口页是该标签的初始页面。后退和前进通常恢复当前标签中的页面，切换标签不增加历史。非会话页面可以从不同入口页分别打开。后退后选择新目的地，只替换当前标签的前进记录。历史随标签保存；网页内部的 URL 导航由浏览器控件处理。

桌面 App 的网页悬浮预览显示同一个实时页面，可以直接点击、滚动和输入。拖动标题栏移动窗口，拖动边缘调整大小；按住鼠标期间，当前画面随窗口移动或缩放；松开后恢复页面实时显示和交互。点击打开页面将同一页面显示为完整标签，隐藏预览会将页面保留在 Resources 中。普通浏览器使用独立的 sandboxed iframe 嵌入页面，网站可能禁止嵌入，且它不共享桌面 Page 的状态；需要时使用打开页面。

**操作历史**在桌面 App 和浏览器中都通过当前页面的菜单显示。聚焦按钮后按 Enter 或空格打开；Escape 关闭菜单，并将焦点返回按钮。承载它的浮动 Agent 按钮在 Agent 操作结束后仍留在页面上，操作历史和显示操作照样可用；只有页面关闭时它才消失。

打开当前窗口已经显示的会话时，直接选中已有标签，从入口页或另一会话打开时也如此。目标尚未打开时，复用当前会话标签或入口页。后退和前进的目标会话若已打开，也会选中已有标签，并保留来源标签的历史。唯一性按会话 ID 判断，同名会话不会合并。重新加载旧的重复标签时，保留当前激活的一份；没有激活项则保留第一份，并保留它的历史和分组，移除其他重复标签。草稿输入和后台更新的标题在导航和重新加载后保留，已删除会话会从全部历史中移除。删除一个正在运行的会话会停止它的这一轮，关闭它待答的提问和审批，并丢弃排队的消息。

当前打开的会话正在运行时，在侧栏点击另一个会话会在当前标签旁边新开一个标签，运行中的会话保留原标签。任何时候中键点击会话都会在新标签中打开。删除会话会把它从所有标签的历史中移除：该标签之前显示过别的页面就回到那个页面，否则标签关闭，焦点移到右侧（或左侧）的标签，与关闭标签相同。删除最后一个标签里的会话后会留下一个新会话。**新会话（New chat）** 会复用已打开的空会话，但不会复用已经发出第一条消息的会话。

不在屏幕上的会话完成一轮后，侧栏圆点变蓝；这一轮失败时变红。打开该会话即清除；一轮结束时正显示在屏幕上的会话不会出现圆点。

会话和标签的快捷键（Windows 和 Linux 用 Ctrl 代替 Cmd）：

| 快捷键 | 作用 |
| --- | --- |
| Cmd+N | 新会话 |
| Cmd+T | 新标签 |
| Cmd+W | 关闭标签 |
| Cmd+Shift+] / Cmd+Shift+[ | 下一个 / 上一个标签 |
| Cmd+1 … Cmd+8 | 切换到对应位置的标签 |
| Cmd+9 | 切换到最后一个标签 |

桌面 App 中这些快捷键在任何位置都有效，包括网页内部。普通浏览器中，浏览器自身保留的快捷键仍由浏览器处理。

在 Files 或文件标签页中，后退和前进会依次返回当前项目中浏览过的文件夹与文件。返回 Files 时恢复文件夹展开状态和滚动位置；后退后打开新位置会替换原有前进记录。文件位置属于当前标签保存的页面历史，与文档版本 History 分开。目录列表快照失效时，重新读取已加载范围期间保留已有文件行。

Markdown 文件以渲染后的文档打开。`figures/a.png` 这类相对图片路径从文档所在文件夹加载；相对链接会在新标签中打开对应文件。文件里的原始 HTML 显示为文本，不会执行。`#installation` 这类链接只在当前文档内滚动；`guide.md#installation` 打开目标文件，并在内容加载后滚动。标题键使用小写可见文本，保留 Unicode 字母与数字，将空格替换为连字符，并为重复标题添加数字后缀。章节请求是临时状态，重开 App 后不会恢复；导航保留未保存文本。

文档按 Obsidian 阅读视图排版：文件名显示为标题，YAML frontmatter 显示为 **属性** 表，`tags` 这类列表值显示为圆角标签。Obsidian 语法同样会渲染：

- `> [!note] 标题` 提示块（callout），支持 note、tip、warning、danger 等标准类型。`> [!tip]-` 默认折叠，`> [!tip]+` 默认展开，点标题切换。
- `==文字==` 高亮和 `#标签`。
- `[[笔记]]`、`[[笔记#标题]]`、`[[笔记|显示文字]]` 链接到文档所在文件夹（或名字前写的文件夹）里的 `笔记.md`，在新标签中打开。
- `![[image.png]]` 从同一位置嵌入图片，`![[image.png|300]]` 设定宽度。嵌入其他笔记时显示为链接。

双链不会像 Obsidian 那样在整个文件夹树里查找同名文件，也没有大纲。

在桌面 App 中，HTML 文件以网页形式在浏览器标签页里打开：回复中的文件卡片把它打开在所属对话旁边，文件标签页里的 **网页预览** 打开已保存的文件。页面通过 `file://` 地址从磁盘加载，旁边的样式表、图片和脚本会像在 Chrome 中一样加载并运行。浏览器工具栏中的 **查看源文件** 回到文件，编辑和历史照常可用；文件标签页的第一个按钮显示为 **源代码**。在普通浏览器中，或 worker 运行在另一台机器上时，HTML 文件仍作为源文件显示。

PDF 文件支持连续阅读、页码跳转、缩略图、文档目录、适合宽度或页面的缩放、正文选字、搜索高亮和下载原文件。复制选中文字时默认清除排版换行，保留段落分隔和正常连字符；关闭该选项可保留原换行。项目中的文件支持高亮和文字批注，并通过文档保存与 History 写入标准 PDF 批注。附件与历史版本保持只读。PDF 解码器随程序本地安装，兼容 App 内置运行时；打开 PDF 不会将文件上传至外部查看器。预览文件大小上限为 64 MiB。

项目菜单还支持在系统文件管理器中显示文件夹、创建持久 Git worktree、归档该项目聊天，以及移除侧边栏项目入口。Worktree 从当前提交创建新分支，使用源 Git 仓库外的新绝对路径；未提交改动保留在原目录。创建过程中对话框会显示当前步骤（创建分支、检出文件——大仓库会显示百分比、打开项目）；检出文件时点 **停止**，会删掉做了一半的文件夹和它的分支。移除项目保留文件、聊天及项目归属，可在项目页面恢复或重新打开文件夹。默认主目录项目不可移除。已归档聊天可通过“已归档”筛选查看；隐藏项目的聊天仍保留在日期或平铺历史中。

项目目录或额外工作目录位于 Git 仓库中时，输入框里该目录的胶囊会多出一个 git 半边，显示分支，以及用绿红小块表示的未提交行数。这一行放不下时，名字先截短，再收起分支名，最后小块变成左绿右红的圆点。它的菜单可以在 Review 中打开这些修改、切换或新建分支，以及把目录换到另一个 worktree 或在仓库旁新建的 worktree。已开始会话的主目录是固定的，在那里选的 worktree 会作为额外工作目录加入。**创建 PR** 会推送分支并执行 `gh pr create --fill`，需要已登录的 GitHub CLI，且当前不在默认分支。有未提交修改时，**让 agent 提交并创建 PR** 会把一段指令填进输入框，但不发送。当前分支已有打开的 PR 时，菜单里是 **查看 PR**，下面显示它的 CI 检查中有几个未通过、几个运行中、几个已通过，每次打开菜单时用 `gh` 读取。有未通过的检查时，**让 agent 修复未通过的检查** 会把一段写明这些检查名的指令填进输入框，同样不发送。同一仓库里的多个目录只显示一个 git 半边。

右键项目或点击省略号，可以打开项目设置、新建聊天、置顶、编辑或移动到自定义分区。项目编辑窗口支持修改显示名称、文字图标或表情、说明和额外源文件夹。源文件夹用于尚未单独设置目录的会话；移除文件夹不会删除文件。主目录移动仍在项目设置中操作。分区菜单可重命名或移除分区；移除分区会保留其项目。

项目排序与聊天排序相互独立。在侧边栏筛选菜单中，可以将项目按最近活动、最早活动、名称或手动顺序排列。新消息会自动更新项目活动时间。点击项目的置顶按钮，可以让该项目保持在未置顶项目上方。聊天可按旧到新、新到旧排列，标题也支持 A–Z 和 Z–A。拖动项目会切换为手动排序。这些显示偏好保存在本地。

在侧边栏选择 **分组 → 项目** 后，可以拖动项目标题，将它移到另一项目的上方或下方；插入线显示目标位置。也可以聚焦项目标题后按 Alt+上方向键或 Alt+下方向键。顺序保存在当前设备，刷新后仍然保留。要把聊天移到另一个项目，把它那一行拖到那个项目上，或在聊天菜单里选 **移动到项目**。要一次处理多个聊天：⌘ 点击（Windows 和 Linux 上是 Ctrl 点击）把某个聊天加入或移出选择，Shift 点击选中从上一个选中的聊天到这里的一段；当前打开的聊天算作已选中。在选中的聊天上右键，可以把它们一起移到某个项目或分组，或一起归档。普通点击或按 Escape 取消选择。拖动时那一行跟着鼠标走；到了另一个项目上，整个项目（项目头连同它的聊天）被一个框框住，中间的行和项目头会让开，在聊天将要加入的位置空出一格（项目内的聊天仍按时间排序）。松在别处或按 Esc，一切滑回原位。

一个聊天的这一轮在你没看着它时结束，侧边栏里它会出现蓝点；这一轮失败则是红点。打开这个聊天会清除圆点，所有打开的窗口一起清除。

项目里的聊天按最后活跃时间排列，最新的在前。把聊天拖到项目里的另一个位置，或拖进项目时落在某个位置，它就占着那个位置：直到它自己有新活动为止，其他聊天的新活动仍会排到它前面。置顶的聊天留在所在项目的顶部。侧栏按活跃时间排序时才能这样摆放。聊天记录随之搬过去，之后的轮次在新项目的文件夹里工作、写新项目的记忆，这次移动会记在对话里；旧项目记忆里已有的内容留在原处。正在运行的聊天要等它结束才能移动。正在运行的会话只在当前选中行保留彩色扫光；其他正在运行、但未选中的会话只显示标题左侧的三个闪动点。等待你输入的会话显示黄色圆点，置顶会话也遵循这一规则。

工具审批行为及运行中切换请参见[工具权限模式](../capabilities/permissions.zh.md)。

### 文件操作

复制和剪切会记录来源项目，只能在来源项目内粘贴。切回来源项目后可继续粘贴。刷新文件列表会重新执行当前文件搜索。

删除文件或文件夹会将其移入 OpenProgram 的可恢复存储。运行 `openprogram trash list` 查找记录，再运行 `openprogram trash restore <entry_id>` 恢复。恢复操作不会覆盖已存在的路径。删除或重命名符号链接只操作链接本身，不操作它指向的目标。

文本文件存在未保存修改时，删除前会询问保存、导出或丢弃。导出会启动浏览器下载，并继续保留本地草稿，因为浏览器不会确认下载完成。恢复文件后重新打开，可恢复保留的草稿。

## 命令面板

在 App 任意位置按 **⌘K**（macOS）或 **Ctrl+K**（Windows、Linux）打开命令面板；再按一次或按 Escape 关闭。输入文字筛选，用 ↑ 和 ↓ 移动，按 Enter 执行选中项。

- **操作**：新建会话，或打开页面：智能体、技能、应用、项目、历史、记忆、定时任务和设置。
- **会话**：列出未归档的会话，最近活动的在前，右侧显示上次活动时间，运行中的显示**运行中**。选中后打开该会话；已经打开的会切到它所在的标签页。

会话按标题、最新消息预览和项目名匹配，与历史页搜索的字段相同；不搜索消息正文。面板最多列出 300 个会话，更早的请到历史页查找。终端获得焦点时，⌘K 仍是终端自己的快捷键。

## 聊天页（/chat、/s/&lt;session-id&gt;）

`/chat` 是聊天主界面；`/s/<session-id>` 是单个会话的直达链接，切换会话不重新加载页面，WebSocket 连接保持不断。

### 收起输入框上下的按钮行

在输入框里点文字以外的地方，比如文字上下的空白，或者麦克风、发送按钮旁边的空白，鼠标移到这些地方会变成手形。点一下，输入框会轻轻弹一下，上方的按钮行往下、下方的按钮行往上，缩到输入框后面，输入框本身位置不变。再点一次就展开。这个选择会在当前浏览器里记住。点文字本身只会放光标。函数表单不响应这种点击。

### 消息流式

消息写入连接后，文字立即显示在对话中，本次提交的输入框文字随即清空。服务端确认接收前，消息保留待确认状态；确认后更新同一条消息。随后显示回复占位，text、thinking、工具调用等块通过 WebSocket 按到达顺序增量渲染。多个 agent 写入同一会话时，非默认 agent 的每条回复上方标出产出它的 agent 名字。

### 回复中的卡片与排版视图

除了 Markdown、表格、代码和公式，回复里还可以出现小型排版视图：状态卡片、一排关键数字、清单，或用标签页对比几个方案。模型用 [A2UI](https://a2ui.org) v0.9 格式写在 `a2ui` 代码块里，聊天区按 App 主题绘制。Web 与桌面端会话会在系统提示中告诉模型这种格式；其他渠道（微信、Telegram、TUI）不会。

只绘制展示类组件：Card、Column、Row、List、Tabs、Text、Divider、Icon、Image（HTTPS 或内嵌 PNG/JPEG/GIF/WebP），以及作为只读清单项的 CheckBox。按钮、输入框和动作不会绘制，代码块里的代码或 HTML 都不会执行。代码块还在输出时显示占位卡片。不是合法 A2UI 的代码块按普通代码块显示；复制回复时复制的是原文。

`mermaid` 代码块会在同一张代码卡片里绘制成 [Mermaid](https://mermaid.js.org) 图表（流程图、时序图、类图、状态图、甘特图等 Mermaid 支持的类型），配色跟随 App 主题。卡片标题栏的 **源码** 显示原文，**图表** 切换回来；复制按钮始终复制原文。Mermaid 无法解析的代码块（包括还在输出中的）按普通代码块显示。图表以严格模式绘制，原文里的链接和脚本不会执行。图表库在会话首次出现图表时才加载。

### 运行期间发送消息

运行期间，发送时按的键决定消息去处。按**回车**是 steer：消息插入当前轮。按 **Cmd+回车**（Windows 和 Linux 上为 Ctrl+回车）是排队：排队消息按顺序保存，前一轮完成后再开始下一轮。拖动排队消息那一行可以调整顺序，也可以聚焦它的文字后按 Alt+↑ 或 Alt+↓；正在插入当前轮或正在编辑的消息位置不变。Steer 和排队消息的“插入当前轮”操作会立即结束正在生成的回复（文本、思考，或仍在写参数的工具调用），保留已生成的文本和思考，并在同一轮中根据补充指令继续。仍在写参数的工具调用会被丢弃，不会执行。已开始运行的工具和结构化输出在下一个安全点接收指令，已开始的工具不会被取消。补充指令不修改模型、工具或权限设置。在设置中关闭 **Steer interrupts the current response**（`execution.instant_steer`）后，补充指令会等当前回复结束再生效。停止是独立操作：运行期间，不管草稿里有没有内容，输入框的操作按钮都是停止按钮；在输入框里按 **Esc** 也会停止这一轮。草稿保留。运行期间或等待你答复请求时输入的斜杠命令按命令执行。`/compact` 和 `/rewind` 会改动会话历史，所以会提示等这一轮结束或先停止它；`/task`、`/merge` 和 `/skill` 排到下一轮。停止后，排队消息会等被停止的那一轮释放后再按顺序发出。因停止而取消的待补充消息保留为未发送草稿，明确重试或编辑后才发送，不自动启动下一轮。已生成的部分回复在停止和刷新后仍保留在会话记录中。

补充消息被接收后，显示在此前与此后的回复内容之间。查询发送结果时保持同一条等待提示，不反复切换发送状态。没有保存分界的旧历史记录将补充消息显示在所属回复前。

无法追加到当前轮时，消息保留在队列。如果无法确认投递结果，消息行继续显示，重试使用同一条命令以避免重复投递，不会自动作为新一轮再次发送。补充指令最多支持 4,096 个字符，更长的消息保留排队。排队的文字消息在重新加载页面、关闭窗口或重启 App 后仍然保留，直到发送：下一个打开的窗口接管这些消息，等会话空闲后按顺序发送。两个同时打开的窗口不会发送同一条消息。带附件的消息只保存在当前窗口内存中。待处理和发送结果未确认的文字 steer 命令以同样方式恢复，并使用原命令继续确认。因停止而保留的 steer 草稿也恢复为未发送草稿。版本重试始终绑定原执行；如果已经开始另一轮，补充消息保留为未发送状态，直到明确重试或编辑。带附件的消息同样可以插入当前轮：附件像普通发送一样保存到会话里，agent 按路径读取；模型支持图片时也会直接看到图片。4,096 字符的限制包含每个附件的名称行。排队消息集中显示在输入框上方的一张卡片里。标题显示排队条数和其中正在插入当前轮的条数，点击可折叠卡片。每条消息占一行并带标签：插入中为“插入当前轮”，等待中为“下一轮”，连接断开时为“等待连接”，失败后为“未发送”或“待确认”。“未发送”的消息不会挡住排在它后面的消息。悬停一行可看到时间和操作。点击正文展开完整消息和附件，再点击附件卡片即可预览。“全部清除”移除所有排队消息，正在编辑的和当前轮已经取走的除外。编辑排队消息时可以修改文字、添加文件和移除附件；保存保留原队列位置，取消保留原内容。编辑期间暂停该条消息发送。移除只撤回选中的排队消息。“插入当前轮”的消息要等当前轮的下一个安全点才会加入，工具正在运行时可能要等一会儿；在那之前仍然可以编辑或移除它，操作时会先把它从当前轮撤回：编辑后的消息回到队列，变成“下一轮”消息。当前轮取走消息之后就不能再改，它出现在对话里时离开队列。本地文档附件使用与项目文件相同的只读预览。

### 停止与重新连接

历史读取失败时会显示重试按钮，并保留已经显示的消息。连接恢复后重新读取可见会话。历史请求在 15 秒后超时；重试读取不会重新发送消息或重新运行函数。迟到的读取响应不能替换更新的请求，也不能清除实时进度。

如果历史快照与阅读位置都已失效，自动翻页会停止。“重试历史加载”不再使用失效游标，重新读取当前位置；“查看最新历史”则明确打开最新历史窗口。

重新连接后，先加载当前会话，再恢复保存的执行状态。后台恢复只读取简要的执行快照，一次处理一个请求，不会因为恢复已结束的执行而反复重载聊天内容。遗漏的实时更新通过当前执行状态补齐。查看历史不会恢复执行或重新运行任务。

点击输入框中的 **Cancel execution**，或在输入框里按 **Esc**，停止当前执行。连接断开时，发出的消息会进入队列（输入框会提示未连接），连接恢复后发送。刷新或重新打开会话时，会恢复正在执行的任务及其停止控制，包括审批等待后恢复的执行。没有新输出不代表执行已经结束；系统不会仅因一段时间没有输出就移除运行状态。已经结束的执行不会因为残留的线程注册继续显示为运行中。

回复生成期间，思考、已有正文和工具步骤会持续保存，刷新后可以恢复。回复失败时，已有过程与错误提示同时保留；手动停止也会保留已经收到的过程。

本地 shell 命令会先结束其进程组，再报告取消。恢复执行的会话会将原助手消息持久化为已取消，并将会话恢复为空闲，刷新后仍保持停止状态。

网页动作等待页面操作锁后，会在派发前再次检查取消状态。取消可以阻止待执行动作，不会撤销已经发送到浏览器的动作。

等待首段回复时，原有“思考中…”提示使用新版双环加载标识。执行摘要、函数步骤和回复正文不额外添加双环。颜色跟随主题，减少动态效果设置下显示静态图形。

### thinking 折叠

模型的思考过程渲染为可折叠块，默认收起，流式期间只显示最新一行，点击展开完整内容。

### 对话显示方式

对话右上角的 ⋯ 菜单可以选择显示多少 agent 的工作过程，和 Claude Code 一样：**普通** 把每轮的工具调用折成一行，**显示思考** 展开它们并展开思考步骤，**详细** 展开所有步骤。**设为默认显示方式** 把当前选择设为默认，也可以在 **设置 → 通用 → 对话显示方式** 里设。不管哪种方式，点折叠行都能单独展开或收起。选择按对话保存在这个浏览器里。

### 聊天宽度

**设置 → 通用 → 聊天宽度** 决定对话和输入框有多宽：**窄** 保持最宽 900px 的阅读列，**全宽** 铺满整个聊天区。选择保存在这个浏览器里。

### 专注模式

对话右上角视图切换按钮和 ⋯ 菜单之间的全屏按钮把整个窗口交给对话：左右侧栏、标签栏和分栏布局里的其他面板都让开，只留下消息和输入框。切到图视图时按钮仍在同一位置，在两种视图之间切换不会退出全屏。再点一次按钮或按 **Esc** 回到原来的布局。在桌面 App 里，专注模式期间侧栏和面板里的网页会隐藏。

### 函数调用时间线

每轮回复中的函数 / 工具调用渲染成一条可展开的执行时间线：每步一行，函数调用带参数、输出、错误和耗时，嵌套调用按上下文树递归展示，子 agent 也是时间线中的一步。点击某一步会在右侧栏打开执行详情面板。从 `/programs` 页 Run 对话框手动运行的函数也用同一套时间线渲染。回复完成后保留流式时间线；缺少有序内容块的旧记录也使用相同折叠组件，不再显示独立的工具调用表格。

### 任务清单

agent 用 `todo_create` 和 `todo_update` 工具规划工作时，计划会以任务清单的形式显示在修改它的那一轮回复下方。这一轮运行期间，清单保持展开并随 agent 推进实时更新：每项标为已完成、进行中或待办，进行中的那一项会转动。这一轮结束后，清单收起为一行，例如 **任务 5/5 · 已完成**、**任务 2/5 · 已停止**（你停止了这一轮）、**任务 2/5 · 出错**（这一轮因错误结束），这一轮结束时还有未做完的事项则只显示 **任务 2/5**；点击这一行可展开清单。之后某一轮再修改计划，会在自己的回复下方显示一份新的清单，之前的清单保持那一轮结束时的状态。agent 在之前的任务全部完成后再添加的任务会开始新计划，显示为单独的一份清单。清单属于它所在的那一轮：编辑消息或切换到回复的其他版本后，不再显示的那些轮次的清单也随之消失。子 agent 自己的计划显示在子 agent 的对话里，不显示在你的对话中。重新打开会话会看到同样的清单。

### 建议下一句

回复结束后，空的输入框里可以用灰字显示你可能要说的下一句，和 Codex 的 composer predictions 一样。按 Tab 把它放进输入框作为草稿，可以再改；不会替你发送。开始输入、开始新一轮或切换对话后建议消失。建议由你上次用的模型读最近几轮对话生成，所以每次回复多一次简短的模型调用。可以在 **设置 → 通用** 里关闭。

### 在对话中查找

在对话里按 **⌘F**（Windows 和 Linux 上为 **Ctrl+F**），聊天区右上角会打开查找栏。查找不区分大小写，覆盖当前分支上你的消息和 agent 回复的文字，包括尚未加载的历史；工具输出和 thinking 不在查找范围内。计数显示当前是第几个匹配、共几个。按 Enter 或 **⌘G** 跳到下一个，Shift+Enter 或 **⇧⌘G** 跳到上一个；需要时聊天会先加载那段历史，再滚动到匹配处，并高亮所有可见的匹配，当前匹配颜色更深。按 Escape 或关闭按钮关闭查找栏。查找从离你当前阅读位置最近的匹配开始。焦点在网页、终端或文件编辑器里时，⌘F 不会打开对话的查找栏；网页会打开它自己的查找栏。

### 消息导航与章节

会话里你发过两条及以上消息后，聊天区左缘会出现一列短横线刻度，你发的每条消息一条。正在阅读的那条消息的刻度更亮。指针移到这一列上，离得最近的刻度会变长，并弹出一张卡片，显示那条消息和回复的开头；点击刻度滚动到那条消息。

想以后再找到某一轮，在它的回复的操作栏里点 **钉为章节**。钉选属于这一轮，记在开启这一轮的那条你的消息上，所以重新加载后仍在，在包含这条消息的每个分支上也都在。被钉选的那一轮的刻度用主题的紫色绘制，比其他刻度更粗更长，其他刻度变淡时它仍是满紫色，位置和交互不变，其他每条消息仍有自己的刻度。这一轮被钉选时，这条回复的操作栏一直显示，不再只在悬停时出现，书签按钮填充为紫色；再点一次（**取消章节**）取消钉选。在一个窗口里钉选，打开着这个会话的其他窗口也会同时显示。

### 附件

可以粘贴截图、拖入文件，也可以通过输入框菜单选择文件。图片和文件按添加顺序紧凑排列，每项显示名称、格式和大小。点击附件查看预览或详情，点击 × 移除。

agent 发给你的文件显示在它的回复下方。图片直接显示，视频和音频直接在回复里播放，带各自的播放控件；文件名旁的箭头会在对话旁的标签页里打开文件。其他文件，以及回复里只是链接到的文件，显示为卡片，点击打开预览。图片或视频无法显示时，退回同样的卡片。

发送前要在图片上做标注，点开图片再点铅笔：可以用画笔、矩形、箭头或文字，有七种颜色，用按钮或 ⌘Z 撤销，点 **完成** 后标注过的副本替换原图。从浏览器标签页截的区域截图进入输入框后也能这样标注。

输入框会边输入边显示 Markdown 格式：粗体、斜体、删除线、`行内代码`、链接、标题、引用、列表和代码块直接显示为对应样式，标记符号只在光标靠近时才出现。发送的仍是原始 Markdown。粘贴超过 2,000 个字符时，输入框里插入一个 **Pasted · N lines** 标签，而不是整段文字；悬停可预览内容，按一次退格整块删除。输入完成的 `@路径` 引用同样显示为标签。模型收到的是完整的粘贴内容；发送后的消息里，粘贴部分折叠成同样的标签，点击即可展开。标签显示为 **lost** 表示粘贴内容已丢失，发送前请删除后重新粘贴。

`@file` 查询等待响应时，不带 Shift 的 Enter 和 Tab 保持编辑，不选择旧结果或发送。Escape 关闭当前查询，即使响应稍后返回也不会重新打开；修改 token 后可重新搜索。查询无结果或失败后，Enter 正常发送，Tab 移动焦点；查询期间 Shift+Enter 和输入法确认保持编辑行为。

`@path` 提及在会话的工作目录中搜索和解析：它的 worktree 或项目文件夹；没有项目的会话用默认项目的文件夹；新会话用为它选的项目。`@` 菜单在文件之前列出标题、地址、名称或 bundle id 包含所输入文字的已打开网页标签和正在运行的应用；查询里含 `/` 时只搜索文件。选中标签页会把 `@` 查询替换成它的标题和地址（链接形式），选中应用则替换成它的名称和 bundle id，这样 agent 操作的就是你指的那个页面或应用，不用去猜。agent 永远不会操作的应用（如「密码」）不会列出。

已发送消息里的访问令牌和私钥会被遮住：只显示开头几个字符，后面是圆点，点旁边的眼睛按钮可以显示或隐藏完整内容。识别范围是带固定前缀的令牌，例如 GitHub（`github_pat_`、`ghp_`）、OpenAI 和 Anthropic（`sk-`）、AWS（`AKIA`）、Slack、Stripe、Google、Hugging Face、npm 和 GitLab，以及 JWT 和 PEM 私钥块。这只改变显示，模型仍会收到完整消息；不想再共享的令牌请及时作废。

消息、会话或显示文本变化后，已经展开的密钥会重新隐藏。折叠粘贴内容的预览先遮蔽完整的已识别密钥，再缩短预览文本。复制和编辑操作仍使用原文。

图片直接提供给支持看图的模型，同时在聊天中保存原图副本。应用接受最多 32 MiB 的原图，发送版本过大时等比缩小到不超过 5 MiB。所选模型不支持看图时会明确报错，不会悄悄忽略图片。

桌面 App 中的文本、代码、数据、PDF 和 Office 文件引用原路径，由助手根据任务调用工具读取，不自动把文件正文加入提示词。拖入文件夹时只提供第一层目录，最多 200 项或 8 KiB，不扫描子文件夹。浏览器选入且没有原路径的文件由后端保存，再引用保存位置。

读取完成的草稿附件随所属聊天保留，刷新后可以恢复。发送后只在后端确认接收时清除本次提交的项目。读取失败或发送被拒绝时，文字和附件继续保留。如果连接在确认前断开，应用不会自动重新发送。

消息正在准备文件提及时，重复提交相同草稿不会发送两次。如果在准备期间修改草稿并再次提交，应用会明确提示更改后的草稿尚未发送，并保留文字和附件。请在准备完成后再次发送该草稿。其他会话可以独立发送。

### 无头或远程 Linux 上的项目目录

Project 文件夹和额外工作目录都指向运行 worker 的机器上的路径。通常
OpenProgram 会打开这台机器的原生文件夹选择器；如果 Linux 没有 X11 或
Wayland display（例如通过 SSH 使用服务器），Web UI 会改为显示服务器路径
输入框。填写 `/srv/projects/example` 这样的绝对路径后，worker 会先确认目录
存在再使用。原生选择器可用时，用户点取消仍然只是取消，不会误弹手工输入框。

### 会话分支与 DAG 视图

会话历史按 DAG 存储，不是扁平列表。一个会话同一时间只运行一轮；有轮次在运行时，它的 HEAD（聊天显示、下一条消息接着往下写的那个分支）不能移动：重新生成、保存并重新发送、checkout 分支和切换版本都会被拒绝，直到这一轮结束或被停止。

消息操作栏上，每条消息都有 **复制**；用户消息另有 **编辑消息** 和 **回退到这里**，助手回复另有 **重新生成** 和 **钉为章节**（见[消息导航与章节](#消息导航与章节)）。

在会话内 fork，所有版本都留在同一个会话里：

- 回复上的 **重新生成** 把它上面的那条用户轮作为原轮次的兄弟重新运行一遍。
- **编辑消息** 后点 **保存并重新发送**，用新文字 fork 这条用户消息并运行。
- 在图视角里双击用户轮，即 fork 并编辑它。

旧版本仍可访问：同一条消息的多个版本用 `< N/M >` 切换器切换，只移动显示位置，不删除历史。

会话右上角 ⋯ 菜单里的 **复制会话** 会新建一个独立会话，内容是到当前 HEAD 为止的历史，所在项目和环境、Agent、模型和运行设置都与原会话相同。有轮次在运行时，复制到它之前最后一个已完成的轮次。新会话像点击侧栏的一行那样打开（原会话正在运行时在旁边新开），之后两个会话各自独立运行。它的标题是原会话标题加上 "(copy)"，转录顶部有一条"复制自"横幅，点一下即可打开原会话。

浏览分支：

- 图视角（聊天右上角的切换按钮）把会话画成实时 DAG，画布可平移、缩放：每一轮一个节点，按分支着色，一轮里的工具调用折叠成一个计数。默认的浏览工具下，单击节点折叠 / 展开它的调用，双击用户轮即 fork 并编辑，双击其他节点即 checkout 到那里。右键节点打开完整卡片和操作。
- 画布左缘的工具条切换浏览（H）、选择（V）、套索（L）。选择工具下单击节点即选中，在空白处拖动即拉框；框和套索碰到即选，按住 Shift 追加选择。选择时按住空格可平移。按 Delete 删除所选节点：后面的内容接到前一个节点上，回复的工具调用一并删除。⌘Z 或左上角操作条的"撤销"可以恢复。根节点和压缩摘要不能删，有轮次在运行时也不能删。
- 在输入框里输入 `/branch <名称>` 给当前分支命名；只输入 `/branch` 则按内容自动命名。
- 会话有多个分支时，右栏的运行记录面板按分支分组显示其中的 Agent 和运行。

### 审阅改动

Review 面板列出某一轮、当前分支或工作目录改动过的文件，并显示每个文件的差异。每个改动块的标题上有 **撤销**，会把磁盘上文件里的这几行恢复成改动前的样子；文件其余部分和其他改动块保持不变。撤销只作用于对话项目文件夹里的文件，并会核对这些行是否仍和差异里一致：如果文件之后又被改过，就不会写入，差异会刷新。暂存区的改动、跨差异分页的改动块、位于文件末尾且文件末尾没有换行的改动块，以及整个新增或删除的文件，都不提供撤销；有一轮正在运行时也要等它结束再撤销。撤销是对文件的一次普通编辑，所以可以在文件的 History 里恢复之前的版本。

把指针悬停在某一行上，点评论按钮即可评论这一行。**加入消息** 会把文件名、行号、被引用的那行代码和你的评论追加到对话输入框末尾，但不会发送；你可以攒几条评论，和下一条消息一起发出。⌘Enter（Ctrl+Enter）加入评论，Escape 取消。

### 回滚

每条消息的操作菜单里有 "Rewind to here"：把会话真正回退到该消息处，被撤销的用户输入会预填回输入框，可修改后重发。输入框斜杠命令 `/rewind` 是同一功能。`/doctor` 运行健康检查，并把报告显示在会话里，不发给模型。

网页小窗铺满紧凑标题栏下方的区域，外轮廓采用 10px 圆角，不保留外框或左右、底部留白。拖动标题栏可移动小窗，拖动边缘或扩大的角部区域可调整大小。放好的小窗与对话区域较近一侧的距离保持不变，所以它靠在另一侧时，展开、收起或拖宽侧边栏都不会让它在屏幕上移动。只有鼠标悬停的角显示弧形提示；移动或缩放时，其他角仍不显示提示。

### 代码雨风格

设置 → General 里的“代码雨风格”让聊天变成黑客帝国风格。默认关闭，保存在当前浏览器。

- **空白对话**：新建的空白对话会在输入框背后播放代码雨：绿色的字母、数字、符号和片假名成列落下，铺满聊天区。“代码雨密度”调整同时落下的雨滴数量，范围 10% 到 100%（默认 40%），拖动时即时生效。
- **新消息**：对话有了消息之后，背景代码雨会淡出，之后只有新消息从雨中落下。雨流落在你发出的消息上，也落在流式回复的每一段新内容上：雨流经过的字先显示为代码，再解码成真实的字，并从绿色渐变为正文颜色。雨流从对话里已有文字的后面穿过。加载的历史消息或滚回视野的内容照常显示，选择、复制和查找始终作用于真实文本。
- **进行中**：所有还在运行的东西都显示为代码。“思考中…”状态、运行中的工具组标题（例如 *Searching the web…*）和运行中步骤的标题变成绿色等宽文字，先由乱码解码成字，之后不时闪回成代码；加载图标和运行中步骤的图标变成几列下落的字符；流式输出的子调用末尾是闪烁的方块光标；Activity 里运行中程序的进度条由绿色方块填充，输出显示为绿色终端。步骤完成后恢复平常的样子。

系统开启“减少动态效果”时，空白对话的代码雨只画一帧静止画面，新消息不播放雨的动画，进行中的文字保持静止。

### 标签拖动外观

设置 → General 的“标签拖动外观”同时控制标签栏内外的标签拖动外观，以及分屏标题的悬浮预览。透明度可调为 0–100%，背景模糊可调为 0–40px，阴影强度可调为 0–100%。修改即时生效，设置预览与实际拖动标签共用这些数值。默认透明度 20%、模糊 16px、阴影强度 25%。“恢复默认”只重置这三个选项，不改变主题或其他偏好。

偏好保存在本浏览器，并同步到同源窗口。重新加载或切换明暗主题后保留数值。透明度 0% 为不透明；模糊 0px 和阴影 0% 分别关闭对应效果。这些选项不改变普通按钮或 Resources 拖放目标的描边。

### 会话运行记录

“运行记录”合并原来的 Running 和 Debugger。只有当前标签、可见页面路径和聊天状态指向同一会话时，才显示该会话的记录；新标签页、尚未发送的草稿及非会话页面显示空提示，不残留上一个会话的数据。从 Abilities 打开 Program 会进入草稿标签，仅打开参数表单不会产生执行历史。面板先列出“Agents”和“程序和命令”，再列出会话自己在做的事：“常驻”“未完成事项”和“定时任务”。消息留在聊天里。每一行点进去都是一个页面，顶部的箭头写出要返回的页面。点分组标题可以把这一组收起，和侧栏一样；收起状态保存在这个浏览器里。除此之外不原地展开。

“Agents”只显示“主代理”，写出它正在运行什么（蓝色）、失败了（红色），否则只写最后一条消息的时间，后面跟模型启动的子代理个数，例如“10月15日 · 5 个子代理”。有事等你回答或授权时，图标右上角显示红色数字，和程序坞里 App 的角标一样；子代理本身在它的页面里，所以不管有多少个，列表都很短。会话有多个分支时（你分叉或编辑消息产生的），每个分支各占一行，形式相同：名称和颜色与流程图一致，当前检出的带“当前”，状态和子代理各算各的。子代理自己的对话不会被列成分支。不是当前分支时，分支页面里有“切换到这个分支”。“程序和命令”列出正在运行的命令、运行被中断时还没返回的命令（显示“已中断”）和所有后台程序：正在运行的排前面，然后是其余的。没有内容的列表不显示。只缺模型响应记录的已结束尝试显示为已结束。

主代理页面显示会话标题（一行）和状态、在等你回答或授权的事（每条写出是哪条消息）、“正在运行”、“最后一条消息”和“子代理”。所有子代理都列在这里，从新到旧，子代理启动的子代理挂在它下面。每一行写出它是否正在运行及在做什么，或最后的结果：已完成、失败、已取消或已中断。等你回答或授权的子代理只在原位出现一次，图标上带红色数字；已中断的只是历史记录，不需要你做什么。这个列表也包括没有启动成功的调用；这类调用的页面显示报错和任务，没有对话可以打开。“子代理”标题右边的按钮打开一个菜单，有两项设置。“显示”可选“全部”“等你处理”或“正在运行”；筛选后的树保留每个匹配项上面的子代理。“排列”可选“按结构”（树）或“按时间”：一个列表，最近的在前，每个子代理的状态后面写出是谁启动的。任一设置不是默认值时按钮保持高亮，两项设置都保存在浏览器里。列表每次显示 20 行，点“显示更早”继续加载。

子代理页面显示开始时间、用时、名称和状态。它在等的问题或授权排在最前面，显示问的内容和可选项；回答在聊天输入框上方的卡片里进行，“去聊天里回答”（审批为“去聊天里授权”）会滚到那张卡片。等待回答的子代理在列表里显示“等你回答”或“等你授权”。“打开它的对话”把聊天切到子代理的分支。“由谁启动”打开主代理或启动它的那个子代理，“来自”打开启动它的那条消息对应的运行，“任务”显示任务原文，“步骤”列出它启动的子代理（包括没有启动成功的）、未返回的调用和后台程序。从“来自”、主代理的“最后一条消息”或停在问题上的消息进入的运行页面使用同样的布局。“步骤”下面的“进展”是这次运行自己的记录：到目前为止的进展；执行支持时提供暂停、继续、单步和重试；“补充指令”和“创建分支”使用统一编辑弹窗；待回答的问题和审批；最后折叠在“技术详情”里的内部 ID、修订、检查点和原始事件。读取到快照并不代表 Agent 当前正在运行。

调用页面以这次调用要做的事为标题，显示类型、开始时间、状态、来自哪次运行，以及任务或命令。任务按正常文字显示，默认五行，点“展开全文”看全部；只有命令和输出使用等宽字体。程序以它做的事为标题（模型给命令写的描述；没有时用它运行的脚本或模块名），标题下用等宽字体显示命令。运行中，列表行显示从输出里读出的进度（例如“45 / 100 samples · 3.4/s”）和一条细进度条，右端写剩余时间；不知道总量时显示已运行多久和最后一行输出，进度条来回流动。进度来自 `##progress 45/100 samples` 行、OSC 9;4 终端进度序列、tqdm 和 pip 进度条，以及 `Epoch 3/10` 这类计数。程序页面最上面是进度（数量、百分比、进度条、已用时间、速度和剩余时间；结束后是用时、结束时间和退出码），然后是命令和按终端方式显示的输出：保留颜色，重绘的进度行只保留最后一帧，停在末尾时自动跟随新内容；最后是来自哪次运行、工作目录和运行环境。“停止程序”只控制该程序的受管进程组，包括普通后台子进程，不影响其他程序。输出有容量限制；发生截断时明确提示，程序记录仍然保留。Activity 根据执行和 Job 事件自动更新，打开面板、恢复连接或页面恢复可见时也会自动读取，没有手动刷新按钮。执行快照每 30 秒补充检查一次；托管程序尚无专用事件流，因此页面可见时每 3 秒检查程序状态，打开的程序页面每秒检查一次。首次读取失败显示加载错误，不声称已有旧记录。调用和程序在运行列表读取后才归位，不会先闪现为无归属。读取失败时保留上次记录、所选程序详情和输出，并提示状态可能过时。

会话的 Agent 设为[常驻](../capabilities/always-on-agents.zh.md)时显示“常驻”。这一行写出会话正在做什么，或目标状态和下次唤醒时间。它的页面显示常驻目标、当前目标、唤醒间隔、上次唤醒及结果、下次唤醒，以及每条报告和它发到了哪里。“立即唤醒”会马上唤醒一次。要停止唤醒就归档会话；计划本身在 Agents → 常驻 里设置。“未完成事项”列出 Agent 在这个会话里仍欠你的事（[未完成事项](../capabilities/agents.zh.md#未完成事项)）；每一项的页面显示备注、“标为完成”（或“重新打开”）和“删除”。“定时任务”列出在这个会话里设置的定时任务、[提醒](../capabilities/reminders.zh.md)和[事件触发](../capabilities/event-triggers.zh.md)，写出类型和运行时间。任务页面显示它的提示词、提醒内容或命令，以及它监视的命令；webhook 的页面还有地址和密钥，各带“复制”。“在定时任务中打开”会跳到定时任务页面，在那里暂停、修改或删除任务。这三个列表只在有内容时显示；Agent 改动它们时、打开面板时以及每 30 秒都会更新。

`bash` 命令到等待时间还没跑完时，会成为这里的程序，归属来自可信执行与会话上下文。独立监督进程在 worker 重启后继续保留输出和控制；普通 shell 后台子进程仍属该进程组。刻意脱离进程组的程序，或未通过框架进程管理启动的程序，不宣称已被监控。

从保存点创建 Agent 分支时，在“按新指令创建分支”输入指令，然后准备、检查、确认并发布修订。创建分支后选中独立的暂停子执行，点击继续后使用已发布指令。原执行的消息和保存点不变。修改未发布指令会生成新草稿版本，旧校验和审批失效。仅补充指令的修订保留程序与运行契约；修改程序、工具、模型或输出契约仍要求独立审批。

重试在保存点创建独立、暂停的 Agent 执行并保留原修订，点击继续后恢复。

## 管理项目文件

Files 顶部依次为路径行、操作行、按需展开的搜索行和列标题。列顺序为名称、大小、修改时间和类型。窄侧边栏显示名称和大小；视图宽到放得下四列时才显示修改时间和类型。纵向滚动时列标题保持可见。点击列标题排序，再次点击切换升降序；搜索结果保持相关度排序。点击路径分段可以在项目树中定位对应目录。操作行提供搜索、新建文件、新建文件夹、刷新、排序与显示、查看详细信息。每个目录可以按名称、修改时间、大小或类型排列，选择升降序、文件夹优先，以及是否显示隐藏项和 Git 忽略项。设置按项目保存在本地，侧边栏和中央 Files 共用。搜索仍按相关度排列。

工具栏和文件右键菜单均可打开详细信息，查看路径、文件字节数、时间和只读权限。没有缓存结果的可见文件夹通过有限队列统计大小。已结束的统计保存在本地 profile，重新打开 Files 或重启 App 后直接复用，包含有跳过条目的不完整结果。重新打开视图或详细信息不会重新扫描已有缓存。使用刷新或重新计算更新目录总大小；通过 Files 修改文件也会使共用统计失效。目录行显示完整统计或缓存估值，`≥` 表示部分结果；详情提供统计时间、跳过条目数以及继续、取消、重新计算。统计累计文件逻辑字节数，包含隐藏文件，跳过符号链接、受限目录和不可读条目。结果是在一段时间内取得的样本，不是原子快照或磁盘分配量，缓存可能过期。近期完整统计参与大小排序；计算完成后刷新可以重新排列，未知大小和部分统计排在同组末尾。

移动文件时，把它拖到文件夹上（拖到空白处则放到项目根目录）；悬停在未展开的文件夹上会自动展开。⌘ 点击（Windows 和 Linux 上为 Ctrl 点击）可以加入或移出选择，Shift 点击选择一段范围，多个文件可以一起移动、剪切、复制或删除。要把文件移到较远的位置，右键选择 **移动到…**（⇧⌘M，Windows 和 Linux 上为 Ctrl+Shift+M）：输入文件夹名，或像 `Desktop/pro` 这样的路径查看 Desktop 里的文件夹，按 Tab 进入高亮的文件夹；不输入时可以直接选项目根目录、最近移动到的文件夹或顶层文件夹。项目不太大时，只输入名称还会搜索整个项目。输入的路径还不存在时，**新建“…”并移到这里** 会一步建好文件夹并移入。每次移动都会显示带“撤销”的提示。服务端拒绝的移动（例如目标位置已有同名项）不会保留。在文件树上，⌘C、⌘X、⌘V（Windows 和 Linux 上为 Ctrl）复制、剪切并粘贴到选中的文件夹，⌘Backspace 或 Delete 确认后删除，F2 重命名。新建文件、新建文件夹和重命名都直接在文件树的那一行里输入名字：新建项出现在所在文件夹的最上方，按 Enter 或点到别处即确定，按 Escape（或名字留空）则取消。删除的内容移入可恢复存储。

从访达或文件资源管理器把文件或文件夹拖到文件树上，即可加入项目：内容放到指针下的文件夹，拖动时会有标签写明目标文件夹。已存在的同名文件不会被覆盖，并在提示中统计数量。单个文件最大 1 GiB。

回到窗口时，Files 会重新读取已展开的目录，在其他应用中做的改动无需点刷新即可看到。

路径使用较大字号，最右侧按钮复制完整绝对路径。刷新保留选中路径、展开目录和已加载分页范围。普通文件行显示可读大小（包括空文件）；长文件名在剩余空间内缩略，大小保持完整宽度，悬停大小可查看准确字节数。

侧边栏只显示有未归档对话的项目。空项目仍可在项目选择器和项目管理界面找到。

对话历史存放在 OpenProgram 状态目录中，按稳定的项目 ID 分组。登记项目时，会在 `<project>/.openprogram/project.json` 写入小型标识文件。移动文件夹（包括跨磁盘移动）时应保留这个隐藏目录。启动或访问项目时，OpenProgram 在已知项目的父目录内查找标识，最多检查三级目录、4,000 个条目，不扫描整个磁盘，也不依赖操作系统书签。

如果新位置不在查找范围内，重新打开一次新目录或其中任意子目录，即可关联原项目及对话。一起移动的项目会跟着恢复：一个项目在新位置被找到或定位后，原来与它相邻的其他缺失项目只要在对应位置找到各自的标识文件，就会一并重新关联。因此在被整体移动的项目目录里定位一个项目，其余项目也会修复。原目录仍可用时，打开副本会创建独立项目。发现多个副本时需要“定位文件夹”。把一个缺失的项目定位到已经属于另一个项目的目录时，如果缺失的项目没有对话，它会被移除，并改为选中那个项目。旧项目的身份无法核实，或文件夹的身份不再匹配时，提供“就是这个位置的文件夹”：一键确认记录路径上仍在的文件夹，无需打开选择器。项目菜单、项目管理页和 Files 显示相同的提示和操作；Files 在文件树位置显示。登记和定位时应允许写入标识文件；文件损坏或无法读取会明确报错，不会静默改变身份。

工作目录不可用时仍可阅读历史，该项目的新任务等到位置恢复有效后才会启动。另一个占用相同路径的目录不会继承原来的对话。原目录删除后仅剩一个副本时，按移动处理。

按下顶部标签只高亮，未拖动时松开才切换页面；拖动期间保留当前页面。拖出标签栏后松开可使用现有新窗口分离功能，拖出标签栏时，标签在页面上方跟随鼠标显示，原位置隐藏；拖回标签栏或结束拖动后恢复。要把已打开的网页加入会话，先保持该会话显示，再把网页标签拖到 **Resources** 入口或其展开内容区，松开即绑定原页面。顶部标签和原有关联保留，绑定失败不会改变页面。

长会话先加载一小页最近记录，向上滚动时继续读取历史。Activity 初始只读取运行列表，打开某次运行的“技术详情”后才读取执行事件和调试详情。短暂的状态刷新失败会自动重试；重试较久时显示普通状态提示，持续无法读取且没有已保存记录时才显示错误。

悬浮预览限制在所属会话窗格内，启动恢复布局和调整分屏尺寸后会重新定位，标题栏与缩放控件不会进入相邻原生网页区域。

多个会话同时分屏显示时，点击或聚焦某个会话，右侧 Files、Activity 和 Resources 会切换到该会话。项目请求和延迟返回的结果按会话区分，不依赖主路由是否已切换到该窗格。

拖动分屏顶部的三个点时，鼠标旁显示包含图标和标题的完整标签按钮；三个点本身不跟随移动。

### 输出文件预览

完成的回复会为本地文件链接和返回的附件显示“打开预览”卡片。当前会话的新回复会将第一个支持预览的输出文件显示在聊天旁边。重新打开历史记录或收到后台会话回复时不会自动打开文件。已有分屏布局和预览中的未保存编辑会保留；点击卡片可主动打开文件。会话项目内的文件使用项目编辑器，其他获准访问的附件以只读方式打开。

可见的预览会检查磁盘变化，在源文件被修改或重新生成后显示“文件已修改”。点击“刷新”加载最新内容。读取失败时保留之前的预览，未保存编辑也会保留，直到保存或主动放弃。已完成的 Goal 会在回复下方显示紧凑状态及实际记录的活动时长；点击状态可查看原始 Goal 详情。

同一项目文件的标签共享编辑器和草稿。关闭一个标签后，其他标签仍可使用。如果同一文件在两栏中同时可见，可点击“在此显示”将编辑器移到这一栏。

关闭已关联会话的网页标签，只隐藏显示入口；同一个页面及其导航状态继续保留在 **Resources**，包括手动打开后关联到会话的页面。通过“在标签中打开”可重新打开同一个页面；在 Resources 点击“关闭网页”才会真正关闭。没有关联任何会话的独立网页，关闭标签时仍会真正关闭。

回复失败时，已生成的正文和函数记录会保留，失败提示显示在该回复末尾。展开**错误详情**可查看原始报错；刷新对话后仍可查看提示和详情。

在输入框第一行按 ↑ 可查看历史消息；在最新历史消息上按 ↓ 会恢复尚未发送的草稿。编辑历史文本后开始新的历史查看周期；Ctrl/⌘/Alt/Shift 加方向键以及选中文本时保持正常编辑行为。

Markdown 文件预览把原始 HTML 显示为文本。文档链接支持本地文件、页内片段、HTTP(S) 和 mailto；协议相对链接使用 HTTPS。图片支持经权限检查的本地文件与 HTTP(S)，并保留 SVG 片段。data 图片地址、可执行或不支持的协议不会加载；本地 URL 的查询参数不改变文件权限。数学内容在排版前保持文本，行内与围栏代码中的数学分隔符保持字面形式。
