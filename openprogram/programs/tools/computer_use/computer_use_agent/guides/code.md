Code: for loops, conditions or data handling, send code instead of action: Python with top-level await, run in an isolated interpreter (no files, network or processes) whose variables persist for the rest of this turn (macOS only). Each target is an object whose methods are its actions with the same arguments: {examples}. A call returns {"text": …, "json_data": …}; print what you want to see (up to 256 KB). Name the target and, for an app, args.app (for the user's own browser, args.browser): code acts only on the app or browser its call names. One call may take 120 seconds (timeout, 60 by default) and 100 actions. A step that fails raises; the steps before it stay made, so read the state before repeating. Example:
computer_use_agent(target="app", args={"app": "Numbers"}, code="for value in ['3', '5', '8']:\n    await cu.app.type_text(app='Numbers', text=value + '\\n')")
